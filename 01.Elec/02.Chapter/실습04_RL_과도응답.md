# 실습 04: RL 과도응답/역기전력 (RL Transient)

[← 목차](../README.md)

## 1. 이론 (상세)

### 1.1 인덕터란

- 도선을 코일 모양으로 감은 부품. **전류의 변화를 막으려는 성질**(관성)을 가진다.
- 전류·전압 관계: `V = L × dI/dt`
  - 전류가 급변하면 큰 전압(역기전력)이 발생한다.
  - 전류가 일정(직류 정상상태)하면 전압이 0이 되어 **단락**처럼 동작한다.

### 1.2 저장 에너지

- `E = ½LI²` (전류가 흐르면 자기장 형태로 에너지 저장)
- 전류를 끊으려 해도 인덕터는 이 에너지를 방출하려 하므로 **스파이크 전압**이 생긴다.

### 1.3 RL 시정수

- `τ = L / R`
- 본 실습: `τ = 10mH / 100Ω = 0.1ms`
- 스위치를 켠 뒤 전류는 지수적으로 증가해 정상상태에 도달한다.

### 1.4 전류 상승 방정식

- `I(t) = I_final × (1 - e^(-t/τ))`, 단 `I_final = V/R`
- 본 실습: `I_final = 5V / 100Ω = 50mA`
- 1τ 후 63.2%, 5τ(0.5ms) 후 거의 정상상태.

### 1.5 역기전력 (Back-EMF) — 핵심 개념

- 스위치를 **끄는 순간** 전류가 순간 0이 되려 하면 `V = L·dI/dt`가 매우 커진다.
- 실제 회로에서는 큰 음(-)의 스파이크 전압이 발생한다.
- 이 스파이크는:
  - 접점/스위칭 소자(MOSFET 등)에 **과전압 스트레스**를 준다
  - **프리휠링 다이오드**(전류가 계속 흐를 경로)를 병렬로 달아 흡수해야 한다
  - 다음 장([실습 07](실습07_반파_정류.md), [실습 13](실습13_초퍼_모터_드라이버.md))에서 실제로 적용

### 1.6 응용

- **Buck/Boost 컨버터**: 인덕터로 에너지를 저장·방출하며 전압을 승/강압
- **모터 드라이버**: 전류의 리플을 줄여 부드러운 구동

1. 파일 열기 → **▶(Run)** 클릭
2. **L1 위**에 마우스를 올리고 클릭(전류계) → 전류가 `τ = L/R = 0.1ms`로 지수 증가 후 정상상태(50mA)에 도달

   (Vsw 노드 → GND 쪽) → 스위치 오프 시 큰 **스파이크(역기전력)** 확인
4. 스파이크의 극성·크기를 관찰하고, [실습 07](실습07_반파_정류.md)의 **프리휠링 다이오드** 필요성과 연결
