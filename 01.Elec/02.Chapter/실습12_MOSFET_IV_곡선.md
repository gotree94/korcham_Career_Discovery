# 실습 12: MOSFET I-V 특성 곡선 (출력 특성)

[← 목차](../README.md)

## 1. 이론 (상세)

### 1.1 출력 특성(I_D-V_DS) 곡선

- **V_GS를 파라미터로 고정**하고, V_DS를 0부터 올리며 I_D를 그린 곡선 묶음.
- 각 V_GS마다 I_D 곡선이 하나씩 → **패밀리 커브(family curves)**.
- 본 실습: `.dc Vds 0 10 0.1 Vgs 2 6 1` (V_GS = 2,3,4,5,6V)

### 1.2 두 구간

- **트라이오드(선형) 구간**: V_DS가 작을 때. 채널이 저항처럼 동작 → I_D가 V_DS에 비례 (기울기 존재)
- **포화(평탄) 구간**: V_DS가 일정 값 이상. I_D가 V_DS와 무관하게 **일정** (정전류원처럼 동작)
- 두 구간의 경계: `V_DS = V_GS - V_TH`

### 1.3 포화 영역 전류식 (근사)

```
I_D = k × (V_GS - V_TH)²
```

- **제곱 법칙**: V_GS가 커질수록 포화 전류가 제곱으로 커진다.
- V_GS = 2,3,4,5,6V에 따라 곡선 간격이 점점 벌어지는 것이 관찰된다.

### 1.4 실용적 의미

- **트라이오드 영역**: 가변 저항(아날로그 스위치, 전류 제한)
- **포화 영역**: 증폭기·정전류원
- 실제 스위치 사용 시에는 트라이오드(온)영역과 차단(오프)영역만 오간다.

## 2. 회로 구성

| 항목 | 내용 |
|---|---|
| 실습 파일 | `12_MOSFET_IV_curve.asc` |
| 회로 구성 | `Vds + Vgs(파라미터) - M1(IRF540N)` |
| 해석 종류 | `.dc` (DC 스윕, 중첩) — [해석 상세](../01.Analysis/03_dc_sweep.md) |
| 지시어 | `.dc Vds 0 10 0.1 Vgs 2 6 1` |

## 3. UI로 진행하기

1. 파일 열기 → **▶(Run)** 클릭 → x축이 Vds인 그래프가 열림
2. **M1의 Drain 핀** 클릭(전류계) → V_GS별 **I_D 곡선 묶음(패밀리 커브)** 표시
3. 각 곡선에서 **트라이오드(선형) 구간과 포화(평탄) 구간의 경계**를 확인
4. V_GS가 커질수록 포화 전류(I_D)가 커지는(제곱 법칙) 것 확인

## 4. 확인 사항

- V_GS 파라미터에 따른 I_D-V_DS 곡선 묶음
- 트라이오드↔포화 경계 (`V_DS = V_GS - V_TH` 근처에서 꺾임)
- V_GS 증가 시 포화 전류가 제곱으로 커지는지
