# 실습 08: 제너 다이오드 정전압 회로 (Zener Regulator)

[← 목차](../README.md)

## 1. 이론 (상세)

### 1.1 제너 다이오드란

- 역방향 **항복 전압(V_Z)**을 의도적으로 이용하는 다이오드.
- 일반 다이오드는 항복을 피하지만, 제너는 항복 영역에서 **전압을 일정하게 유지**한다.
- 역방향으로 V_Z 이상을 걸면 전류가 흘러도 **양단 전압이 V_Z에 고정**된다.

### 1.2 정전압(레귤레이션) 원리

- 직렬 저항 R1이 전류를 제한하고, 제너 D1이 출력 전압을 고정한다.
- 입력 전압 V1이 변해도:
  - 제너에 걸리는 전압은 항복전압으로 고정
  - 변동분은 **R1 양단 전압이 흡수**
- 결과적으로 **부하(Vout)에는 일정한 전압**이 공급된다.
- 본 실습: BZX55C5V6 → V_Z ≈ 5.6V

### 1.3 직렬 저항 R1의 역할

- R1은 두 가지 역할:
  1. 제너 전류를 제한해 과전류/소손 방지
  2. 입력 전압 변동(부하 전류 변동)을 흡수
- R1이 너무 작으면 제너에 과전류, 너무 크면 레귤레이션 불능.

### 1.4 특성 곡선

- Vout 곡선에서 **기울기가 바뀌는 지점**이 V_Z.
- V1 < V_Z: 출력이 V1을 따라감 (아직 항복 전)
- V1 ≥ V_Z: 출력이 V_Z에 고정
- 고정된 값은 V_Z 근처이며, 약간의 슬로프(내부 저항)가 존재한다.

### 1.5 응용

- **기준 전압(reference)**: ADC/비교기 입력의 기준
- **보호 회로**: 과전압이 걸리면 전류를 빼내 회로 보호
- 저전류용 정전압 (고전류는 레귤레이터 IC 사용)

## 2. 회로 구성

| 항목 | 내용 |
|---|---|
| 실습 파일 | `08_zener_regulator.asc` |
| 회로 구성 | `V1(12V) - R1(470) - Vout - D1(BZX55C5V6) - GND` |
| 해석 종류 | `.dc` (DC 스윕) — [해석 상세](../01.Analysis/03_dc_sweep.md) |
| 지시어 | `.dc V1 0 20 0.1` |

## 3. UI로 진행하기

1. 파일 열기 → **▶(Run)** 클릭 → x축이 V1인 그래프가 열림
2. **Vout 노드** 클릭 → 입력 전압(V1)이 제너 전압(5.6V)을 넘어서면 **출력이 5.6V에 고정**되는 것 확인
3. Vout 곡선의 기울기가 바뀌는 지점이 항복전압(V_Z)임을 확인
4. **(선택)** V1을 우클릭 → 12 → 20으로 바꿔도 Vout이 유지되는지 확인
   - ※ 모델이 없다는 오류가 나면 D1 **우클릭 → Pick New Zener**로 다른 제너 선택

## 4. 확인 사항

- 입력 변동에도 출력이 V_Z 근처에서 고정되는지
- R1 양단 전압이 변동분을 흡수하는 원리 이해
- 기준전압·보호회로 응용 이해
