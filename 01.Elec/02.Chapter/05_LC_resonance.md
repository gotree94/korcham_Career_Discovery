# 실습 05: LC 공진 (LC Resonance)

[← 목차](README.md)

## 1. 이론 (상세)

### 1.1 인덕터의 주파수 의존성

- 인덕터 임피던스: `Z_L = jωL`
- **주파수가 높을수록 임피던스가 커진다** (저주파는 쉽게 통과).
- 캐패시터(`Z_C = 1/jωC`)와 반대 성질 → 둘을 조합하면 공진이 생긴다.

### 1.2 직렬 LC 공진

- LC 직렬 회로의 총 임피던스: `Z = jωL + 1/(jωC)`
- 어떤 주파수에서 `jωL`과 `1/(jωC)`가 서로 상쇄되어 **임피던스가 최소(0)**가 된다.
- 이 주파수를 **공진 주파수**라 한다.

### 1.3 공진 주파수

```
f0 = 1 / (2π√(LC))
```

- 본 실습: `f0 = 1/(2π√(1m × 1u)) = 1/(2π√(1e-9)) ≈ 5.03kHz`
- 공진점에서 캐패시터/인덕터에 저장된 에너지가 매 주기 서로 주고받으며
  전압·전류가 최대치로 커진다.

### 1.4 공진 특성

- **직렬 공진**: 공진에서 임피던스 최소 → 전류 최대. 각 소자 양단 전압이 입력보다 클 수 있음.
- **병렬 공진**: 공진에서 임피던스 최대 → 전류 최소.
- 공진 폭(선택도)은 **Q값**으로 표현: Q가 높을수록 날카로운 공진(좁은 대역).

### 1.5 응용

- **주파수 선택**(튜닝): 라디오/통신의 동조 회로
- **필터 설계**: 특정 주파수 통과/차단
- **임피던스 정합**, 발진기 등

## 2. 회로 구성

## 3. UI로 진행하기

1. 파일 열기 → **▶(Run)** 클릭
2. **Vout 노드** 클릭 → 주파수 응답 표시
3. **공진 피크 확인**: 커서로 그래프의 최대점을 찾아
   `f0 ≈ 5.03kHz` 이론값과 비교
4. **(선택)** 파형 창 우클릭 → **Add Trace** → `V(vout)` 로도 표시 가능

## 4. 확인 사항

- 공진 피크 주파수 = f0 이론값(`1/2π√(LC)`)
- 공진점에서 임피던스가 최소가 되어 전압(전류)이 커지는지
- 공진점 전후로 저주파(L가 통과)/고주파(C가 통과) 특성이 바뀌는지
