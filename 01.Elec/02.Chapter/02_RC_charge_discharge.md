# 실습 02: RC 충방전 (RC Charge/Discharge)

[← 목차](README.md)

## 1. 이론 (상세)

### 1.1 캐패시터란

- 두 도체 사이에 절연체(유전체)를 둔 부품. 전하(에너지)를 저장하는 소자.
- 저장 전하: `Q = C × V` (C: 캐패시턴스[F], V: 양단 전압)

### 1.2 전류-전압 관계

- `I = C × dV/dt`
- **전압이 급변하면 전류가 크게 흐른다.** 반대로 전류가 흐르면 전압이 서서히 변한다.
- 직류(DC)는 전압이 변하지 않으므로 정상상태에서 캐패시터는 **개방**처럼 동작한다.

### 1.3 시정수 (Time Constant)

- `τ = R × C` (단위: 초)
- 저항을 통해 캐패시터가 충전될 때 전압 상승 속도를 결정한다.
- **63.2% 규칙**: 한 시정수(τ) 후 캐패시터 전압은 최종값의 **63.2%**에 도달.
  - 2τ → 86.5%, 3τ → 95.0%, 5τ → 99.3% (거의 충전 완료)

### 1.4 충전/방전 방정식

- 충전: `Vc(t) = V_final × (1 - e^(-t/RC))`
- 방전: `Vc(t) = V_initial × e^(-t/RC)`
- e ≈ 2.718 (자연상수). RC가 클수록(저항↑ 또는 캐패시터↑) 충방전이 느려진다.

### 1.5 응용

- **타이머**: RC 시정수로 지연 시간 설정 (예: 555 타이머)
- **디바운싱**: 스위치 접점의 떨림을 RC로 평탄화
- **디커플링/전원 안정화**: 전원 라인의 순간 전압 강하를 캐패시터가 보충
- **필터**: 커패시터와 저항 조합으로 주파수 특성 제어 (실습 03에서 계속)

## 2. 회로 구성

| 항목 | 내용 |
|---|---|
| 실습 파일 | `02_RC_charge_discharge.asc` |
| 회로 구성 | `PULSE(0 5 0 1n 1n 5m 10m) - R1(1k) - C1(1u) - GND` |
| 해석 종류 | `.tran` (시간 영역) — [해석 상세](../01.Analysis/01_transient.md) |
| 지시어 | `.tran 20m` |

## 3. UI로 진행하기

1. 파일 열기 → **▶(Run)** 클릭
2. **Vsw 노드**(전압원과 R1 사이)를 클릭 → 0V↔5V 펄스 확인
3. **C1 위**에 마우스를 올리고 클릭(전류계) → 충전 전류가 지수적으로 감소하는 것 확인
4. **C1 위 노드**(R1과 C1 사이 배선) 클릭 → 캐패시터 전압이 `τ = 1k×1u = 1ms`에 맞춰 63.2%(3.16V)까지 충전되는 것 확인
5. **실험**: `C1` 값을 **우클릭으로 0.1u → 10u로 변경 → ▶ 재실행** → 충전 속도 차이 비교

## 4. 직접 그려보기 (선택)

- `F2` → voltage, res, cap 배치 + `G` 접지 → `F3` 배선
- 전압원을 더블클릭해 `PULSE(0 5 0 1n 1n 5m 10m)` 입력 → `S` → `.tran 20m`

## 5. 확인 사항

- τ = R×C와 파형의 63.2% 지점 일치 (`5V × 0.632 = 3.16V`)
- C를 키우면 충전이 느려지는지 (τ = RC 증가)
