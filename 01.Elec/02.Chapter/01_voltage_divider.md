# 실습 01: 저항 전압 분배기 (Voltage Divider)

[← 목차](README.md)

## 1. 이론 (상세)

### 1.1 옴의 법칙

- 전압·전류·저항의 관계: `V = I × R`
- 저항에 전압이 걸리면 그 값에 반비례하여 전류가 흐른다.
- 예: 12V 전원에 1kΩ이 연결되면 `I = 12V / 1kΩ = 12mA`

### 1.2 전력

- 저항에서 열로 소모되는 전력: `P = I²R = V²/R = V×I`
- 저항에 붙은 **정격전력**을 넘기면 과열·소손되므로 값 선정 시 확인해야 한다.

### 1.3 직렬과 병렬 합성

- 직렬: `R_total = R1 + R2 + ...` (전류 동일, 전압 분배)
- 병렬: `1/R_total = 1/R1 + 1/R2 + ...` (전압 동일, 전류 분배)

### 1.4 전압 분배 법칙 (핵심)

- R1, R2가 직렬로 연결되고 V1이 걸릴 때 R2 양단 전압:

```
Vout = V1 × R2 / (R1 + R2)
```

- 본 실습: `Vout = 12 × 2000 / (1000 + 2000) = 8V`
- R2가 커질수록 Vout은 V1에 가까워진다 (R2=∞면 Vout=V1).
- R2가 작을수록 Vout은 0V에 가까워진다 (R2=0이면 단락).

### 1.5 로딩 효과 (Load Effect)

- 분배기의 출력에 다른 회로(부하)를 연결하면 부하 저항이 R2와 병렬로 붙어
  **분배비가 실제 계산과 달라진다.** 이를 로딩 효과라 한다.
- 정확한 전압을 유지하려면 부하 저항이 R2보다 훨씬 큰 것이 좋다.
- 디지털 입력 핀처럼 소비 전류가 거의 없는 부하는 로딩 효과가 작다.

### 1.6 풀업/풀다운 저항 응용

- 스위치가 연결되지 않았을 때 입력 핀 전압을 확정(HIGH/LOW)시켜 주는 저항.
- 풀업: 입력을 Vcc에 묶어 기본 HIGH / 풀다운: GND에 묶어 기본 LOW.

## 2. 회로 구성

| 항목 | 내용 |
|---|---|
| 실습 파일 | `01_voltage_divider.asc` |
| 회로 구성 | `V1(12V) - R1(1k) - Vout - R2(2k) - GND` |
| 해석 종류 | `.op` (DC 동작점) — [해석 상세](../01.Analysis/06_dc_operating_point.md) |
| 지시어 | `.op` |

## 3. UI로 진행하기

1. `01_voltage_divider.asc` **더블클릭** → 회로 창이 열림
2. 툴바 **▶(Run)** 클릭 → `.op` **동작점 창**이 열림
3. 동작점 창에서 노드 전압 확인 → **Vout = 12 × (2k/(1k+2k)) = 8V** 이론값과 비교
   (동작점 창 대신 회로 창에서 **Vout 노드 위에 마우스를 올리면 전압이 표시**됨)
4. **실험**: `R2`를 **우클릭 → Value를 1k/4.7k/10k로 변경 → ▶ 재실행** → 전압 변화를 표로 정리
   (R2=1k→6V, R2=4.7k→9.9V, R2=10k→10.9V 예상)
5. **(선택) 스윕**: R2의 Value를 `{R2}`로 바꾸고 `S` → `.step param R2 1k 10k 1k` 입력 → ▶ 실행

## 4. 직접 그려보기 (선택)

- `F2` → `voltage` 배치 / `F2` → `res` 2개 배치 / `G`로 GND / `F3`로 배선 / `S` → `.op`
- 소자 값을 더블클릭해 V1=12, R1=1k, R2=2k로 설정 → ▶ 실행

## 5. 확인 사항

- Vout이 이론식(`V1×R2/(R1+R2)`)과 일치하는지
- R2 변경 시 Vout 변화율이 기대와 같은지 (R2↑ → Vout↑)
