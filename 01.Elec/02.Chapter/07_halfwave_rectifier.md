# 실습 07: 반파 정류 회로 (Half-Wave Rectifier)

[← 목차](README.md)

## 1. 이론 (상세)

### 1.1 정류의 필요성

- 가정용/변압기 출력은 **교류(AC)**: 전압이 주기적으로 +/−로 변한다.
- 대부분의 전자회로는 일정한 **직류(DC)** 전원을 필요로 한다.
- 정류 회로는 AC를 DC로 바꾸는 과정의 첫 단계.

### 1.2 반파 정류 원리

- 다이오드는 한 방향으로만 전류를 흘린다.
- AC 입력의 **양(+) 반주기**: 다이오드 도통 → 출력에 전압 나타남
- AC 입력의 **음(-) 반주기**: 다이오드 차단 → 출력 0V
- 결과: 입력의 절반만 남은 **반파** 파형. (출력 평균 = 입력 최대값/π ≈ 0.318·Vp)

### 1.3 리플과 필터 캐패시터

- 반파 정류 출력은 0V와 피크 사이를 오가는 **맥동 DC**다.
- 캐패시터를 부하와 **병렬**로 달면:
  - 피크에서 캐패시터가 충전
  - 다이오드가 꺼진 구간(음의 반주기)에 캐패시터가 방전하며 전압을 유지
- 결과적으로 출력이 평탄해진다. 이를 **리플 감소**(평활화)라 한다.
- 리플이 작을수록(C 커질수록) 더 깨끗한 DC에 가깝다.

### 1.4 리플 전압 근사식

```
Vripple ≈ I_load / (f × C)
```

- 부하 전류가 크거나, 주파수 f가 작거나, C가 작을수록 리플이 커진다.
- 완벽한 DC로 만들려면 추가로 **전압 레귤레이터**(제너/레귤레이터 IC)가 필요하다.

### 1.5 한계

- 반파 정류는 입력의 절반을 버리므로 **효율이 낮다**.
- 실용적으로는 양 반주기를 모두 쓰는 **전파 정류**(브리지)를 주로 사용.

## 2. 회로 구성

| 항목 | 내용 |
|---|---|
| 실습 파일 | `07_halfwave_rectifier.asc` |
| 회로 구성 | `SINE(0 10 60) - D1(1N4007) - Vout - Rload(1k) - GND` |
| 해석 종류 | `.tran` (시간 영역) — [해석 상세](../01.Analysis/01_transient.md) |
| 지시어 | `.tran 50m` |

## 3. UI로 진행하기

1. 파일 열기 → **▶(Run)** 클릭
2. **Vout 노드** 클릭 → 음(-) 반주기가 제거된 **반파** 파형 확인
3. **D1 위** 클릭(전류계) → 다이오드가 도통/차단하는 구간 확인
4. **리플 필터 실험**: `F2` → `cap` 선택 → **Rload와 병렬로** 캐패시터(10u) 배치 → 우클릭으로 값 입력 → ▶ 재실행 → 출력이 평탄해지는(리플 감소) 것 확인

## 4. 확인 사항

- 반파 정류 파형 (양 반주기만 출력)
- 필터 캐패시터 추가 시 리플 감소(충전·방전 반복) 확인
- C값을 키우면 리플이 더 작아지는지
