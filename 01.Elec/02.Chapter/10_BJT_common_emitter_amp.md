# 실습 10: 공통 이미터 증폭기 (소신호 증폭)

[← 목차](README.md)

## 1. 이론 (상세)

### 1.1 증폭의 원리

- BJT는 작은 베이스 전류 변화(I_B)를 큰 컬렉터 전류 변화(I_C = β·I_B)로 키운다.
- 이 전류 변화를 저항(R_C)에서 전압 변화로 바꾸면 **전압 증폭**이 된다.

### 1.2 공통 이미터(CE) 구성

- 이미터가 공통(접지)이 되는 기본 증폭 구조.
- 입력: 베이스, 출력: 컬렉터
- **출력이 입력과 180° 반전**된다 (반전 증폭).

### 1.3 DC 바이어스와 Q-point

- 트랜지스터가 **활성영역**(V_CE가 공급전압 중간 부근)에 머물도록 DC 동작점(Q-point)을 잡는다.
- 전압분배 바이어스(R1/R2)로 베이스 전압을 고정한다.
- Q-point가 너무 위/아래로 치우치면 신호가 클 때 **클리핑**(포화/차단으로 출력 잘림)이 생긴다.

### 1.4 전압 이득 (대략식)

```
Av = -R_C / R_E
```

- `R_E`: 이미터 저항. 이득을 안정화(부궤환)한다.
- 본 실습: `Av ≈ -2.2k / 1k = -2.2` (CE 바이패스 캐패시터가 있으면 R_E가 신호에서 단락되어 이득이 더 커짐)
- 마이너스 부호 = 180° 반전.

### 1.5 CE 바이패스 캐패시터

- 이미터 저항과 병렬로 캐패시터를 달면 DC 바이어스는 유지하면서
  **교류(신호)에 대해서만 R_E를 단락**시켜 이득을 높인다.

### 1.6 클리핑

- 입력 진폭이 지나치게 크면 출력이 Vcc(포화) 또는 GND(차단) 쪽에 닿아 **평평하게 잘린다**.
- 증폭기의 동작 범위 = Q-point + 이득에 의해 결정된다.

## 2. 회로 구성

## 3. UI로 진행하기

1. 파일 열기 → **▶(Run)** 클릭 → 시간 영역 그래프가 열림
2. **Vin 노드**(입력, 1kHz 사인) 클릭 → 작은 입력 신호 확인
3. **Vout 노드** 클릭 → 입력보다 **크고 180° 뒤집힌**(반전) 증폭 파형 확인
   - 이득 `Av ≈ -RC/RE = -2.2k/1k = -2.2` (CE 바이패스가 있으면 이론상 더 큰 이득)
4. **(선택) Q-point 확인**: `S` → `.op` 지시어 추가 → ▶ 실행 → VCE가 공급전압 중간 부근(활성영역)인지 확인
5. **(선택) Bode**: `S` → `.ac dec 100 10 1Meg` 추가 → ▶ 실행 → Vout 클릭 → 이득-주파수 응답 확인
6. **(선택) 클리핑**: Vin 진폭을 크게(0.01→0.1) 바꾸면 출력이 찌그러지는(클리핑) 것 확인 → 바이어스 중요성

## 4. 확인 사항

- 증폭/반전 동작 (출력이 입력과 180° 차이)
- Q-point가 활성영역인지 (VCE ≈ Vcc/2 부근)
- 입력을 키울 때 클리핑 발생 조건
