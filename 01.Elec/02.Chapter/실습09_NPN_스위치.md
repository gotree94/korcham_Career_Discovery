# 실습 09: NPN 스위치 (LED 구동)

[← 목차](../README.md)

## 1. 이론 (상세)

### 1.1 BJT 구조

- 3단자 소자: **B**(ase, 베이스), **C**(ollector, 컬렉터), **E**(mitter, 이미터)
- NPN / PNP 두 가지 형태. 본 실습은 NPN.
- 소량의 베이스 전류로 **컬렉터 전류를 제어**하는 **전류 제어 소자**.

### 1.2 전류이득 β (hFE)

```
I_C = β × I_B
```

- β는 보통 100~300. 예: I_B=0.1mA → I_C 최대 10~30mA.
- 베이스-이미터 순방향 전압: `V_BE ≈ 0.7V`

### 1.3 동작 영역

| 영역 | 조건 | 동작 |
|---|---|---|
| 차단 (Cutoff) | V_BE < 0.6V | 전류 없음, 스위치 OFF |
| 활성 (Active) | V_BE≈0.7V, V_CE>V_CE(sat) | 증폭용 |
| 포화 (Saturation) | I_B 충분, V_CE≈0.2V | 스위치 ON |

### 1.4 스위치로 쓰는 법

- 베이스에 충분한 전류를 흘려 **포화영역**에 진입시킨다.
- 포화 시 `V_CE(sat) ≈ 0.2V` → 컬렉터와 이미터 사이가 거의 단락처럼 동작.
- I_B를 너무 작게 하면 활성영역에 머물러 전압강하가 커지고 전류도 제한된다.

### 1.5 베이스 저항 계산 (포화 조건)

```
R_B = (V_drive - V_BE) / I_B
I_B ≥ I_C / β
```

- 예: LED 전류 20mA, β=100이면 최소 I_B = 0.2mA
- 5V 구동이면 `R_B ≈ (5 - 0.7)/0.2mA ≈ 21kΩ` 이하로 선택 (본 실습은 1k로 충분한 포화)

## 2. 회로 구성

| 항목 | 내용 |
|---|---|
| 실습 파일 | `09_BJT_switch_LED.asc` |

## 3. UI로 진행하기

1. 파일 열기 → **▶(Run)** 클릭
2. **LED 위**에 마우스를 올리고 클릭(전류계) → V1이 5V일 때만 LED 전류가 흐르는 **스위칭** 확인
3. **Collector 노드** 클릭 → ON일 때 `V_CE ≈ 0.2V`(포화)인지 확인
4. **실험**: `RB` 값을 우클릭으로 1k → 10k, 100k로 키우며 ▶ 재실행 → 포화에서 벗어나
   (활성/차단) LED 전류가 작아지는 지점 = "포화에 필요한 최소 베이스 전류" 탐구

## 4. 확인 사항

- 스위치 동작(차단↔포화) — OFF 시 V_CE=Vcc(12V), ON 시 V_CE≈0.2V
- RB에 따른 포화 전류 변화 (RB↑ → I_B↓ → 포화 이탈)
