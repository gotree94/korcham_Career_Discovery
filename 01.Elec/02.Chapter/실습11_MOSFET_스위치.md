# 실습 11: MOSFET 스위치 (모터/LED 구동)

[← 목차](../README.md)

## 1. 이론 (상세)

### 1.1 MOSFET 구조

- 3단자 소자: **G**(ate, 게이트), **D**(rain, 드레인), **S**(ource, 소스)
- N-channel / P-channel 두 형태. 본 실습은 N-channel (IRF540N).
- **게이트 전압으로 드레인 전류를 제어**하는 **전압 제어 소자**.

### 1.2 전압 제어 특성

- 게이트는 산화막으로 절연되어 있어 **전류가 거의 흐르지 않는다** → 고입력 임피던스.
- BJT(전류 제어)와의 핵심 차이: 게이트 구동에 전류가 거의 필요 없다.
- 게이트-소스 전압 `V_GS`가 **문턱전압 V_TH** 이상이면 채널이 형성된다.

### 1.3 동작 영역

| 영역 | 조건 | 동작 |
|---|---|---|
| 차단 (Cutoff) | V_GS < V_TH | 전류 없음, 스위치 OFF |
| 트라이오드 (Triode/선형) | V_GS > V_TH, V_DS 작음 | 저항처럼 동작 |
| 포화 (Saturation) | V_GS > V_TH, V_DS 큼 | 정전류원처럼 동작 (증폭용) |

### 1.4 스위치로 쓰는 법

- 게이트에 V_TH보다 충분히 큰 전압을 걸면 채널이 완전히 열린다.
- 완전 도통 시 드레인-소스 사이는 매우 작은 저항 `R_DS(on)`만 남는다.
- IRF540N: R_DS(on) ≈ 0.077Ω → ON 시 Drain 전압이 0V 부근이 된다.
- BJT 대비 **전력 스위칭**(모터, 전원)에 유리 (대전류·저손실).

### 1.5 문턱 실험의 의미

- V_GS를 V_TH(IRF540N 기준 약 2~4V) 부근으로 낮추면:
  - 채널이 부분적으로만 열려 드레인 전류가 감소 (트라이오드/포화 전이)
  - 게이트 전압에 따라 부하 전류가 달라지는 것 확인

### 1.6 게이트 구동 저항

- 게이트 충전 전류(스위칭 순간)를 제한해 스위칭 손실·링잉을 조절하는 데 사용.

## 2. 회로 구성

| 항목 | 내용 |
|---|---|
| 실습 파일 | `11_MOSFET_switch.asc` |
| 회로 구성 | `Vgs(PULSE 0 10) - M1(IRF540N) - Vcc(12V)/Rload(100)` |
| 해석 종류 | `.tran` (시간 영역) — [해석 상세](../01.Analysis/01_transient.md) |
| 지시어 | `.tran 10m` |

## 3. UI로 진행하기

1. 파일 열기 → **▶(Run)** 클릭
2. **Rload 위** 클릭(전류계) → 게이트 10V일 때만 부하 전류가 흐르는 **스위칭** 확인
3. **Drain 노드** 클릭 → ON일 때 Drain 전압이 0V 부근(완전 도통)인지 확인
4. **(선택) 문턱 실험**: Vgs의 PULSE 최종값을 우클릭으로 10 → 3V, 4V로 낮춰 ▶ 재실행 →
   부하 전류가 조금만 흐르는(트라이오드/포화 전이) 현상 관찰

## 4. 확인 사항

- MOSFET 스위치 동작 (ON 시 Drain ≈ 0V, OFF 시 Drain = Vcc)
- V_TH 부근에서의 동작영역 전이 (게이트 전압과 부하 전류 관계)
