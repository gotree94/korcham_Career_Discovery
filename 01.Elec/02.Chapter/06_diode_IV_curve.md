# 실습 06: 다이오드 I-V 특성 곡선 (Diode I-V)

[← 목차](README.md)

## 1. 이론 (상세)

### 1.1 PN 접합과 정류 특성

- 다이오드는 P형 반도체와 N형 반도체를 접합한 2단자 소자.
- **순방향** (Anode(+) → Cathode(-)): 전류가 흐른다.
- **역방향** (Cathode(+) → Anode(-)): 전류가 차단된다.
- 즉, **전류를 한 방향으로만** 흘리는 정류 소자.

### 1.2 Shockley 다이오드 방정식

```
I = I_S × (e^(V/nV_T) - 1)
```

- `I_S`: 포화 전류 (극히 작음), `V_T ≈ 26mV` (실온), `n`: 이성 계수(보통 1~2)
- 순방향 전압이 일정 값에 도달하기 전에는 전류가 거의 흐르지 않고,
  넘어서면 **지수적으로 급증**한다.

### 1.3 순방향 전압강하 (V_F)

- 실리콘 다이오드: 약 **0.6~0.7V**
- 쇼트키 다이오드: 약 **0.2~0.4V** (빠른 스위칭, 낮은 전압손실)
- LED: 약 1.8~3.3V (색에 따라 다름)

### 1.4 I-V 곡선의 구간

- **차단 구간** (V < 0.6V): 전류 거의 0
- **도통 구간** (V > 0.6V): 전류 급증
- **역방향 구간** (V < 0): 미소 누설 전류만
- **항복 구간** (역방향으로 매우 큰 전압): 전류 급증 → 제너 다이오드는 이를 의도적으로 사용(실습 08)

### 1.5 소자 종류

| 종류 | 특성 | 용도 |
|---|---|---|
| 1N4148 | 소신호 고속 | 신호 정류/보호 |
| 1N4007 | 전력 정류(1A, 1000V) | 전원 정류 |
| 쇼트키 | 저전압강하 고속 | 스위칭 전원, 프리휠링 |
| 제너 | 역방향 항복 활용 | 정전압, 기준전압 |
| LED | 빛 방출 | 표시등 |

## 2. 회로 구성

| 항목 | 내용 |
|---|---|
| 실습 파일 | `06_diode_IV_curve.asc` |
| 회로 구성 | `V1 - D1(1N4148) - GND` |
| 해석 종류 | `.dc` (DC 스윕) — [해석 상세](../01.Analysis/03_dc_sweep.md) |
| 지시어 | `.dc V1 -1 1 0.01` |

## 3. UI로 진행하기

1. 파일 열기 → **▶(Run)** 클릭 → x축이 V1인 그래프가 열림
2. **D1 위**에 마우스를 올리고 클릭(전류계) → **I(D1) 곡선** 표시
3. 순방향 **약 0.6~0.7V**부터 전류가 지수적으로 급증하는 특성 확인
4. **(선택)** 역방향(-1V~0V)에서 전류가 거의 0인 차단 특성도 함께 확인
5. **(선택)** D1을 **우클릭 → Pick New Diode**로 1N4007(정류용)/쇼트키 등으로 바꿔 순방향 전압차이 비교

## 4. 확인 사항

- 순방향 기울기(지수 특성)와 차단 구간
- 소자별 순방향 전압 차이 (실리콘 0.6~0.7V vs 쇼트키 0.2~0.4V)
