# 실습 13: 초퍼 모터 드라이버 (VT6-mini 프로젝트 연계)

[← 목차](../README.md)

## 1. 이론 (상세)

### 1.1 PWM(펄스폭 변조) 제어

- 스위치를 빠르게 ON/OFF 하며 **ON 시간의 비율(듀티비)**로 평균 전압을 조절한다.

```
평균 출력 전압 = Vcc × 듀티비
듀티비 D = T_ON / T_period
```

- 예: 12V에서 듀티비 50% → 평균 6V (모터 속도 절반)
- 본 실습: `Vpwm(20kHz) - PULSE(0 10 0 1n 1n 25u 50u)` → 듀티비 50%(25u/50u)

### 1.2 왜 PWM인가

- 선형 전압조절은 스위칭 소자에서 열손실이 크지만,
- PWM은 소자를 포화(ON)/차단(OFF)만 하므로 **손실이 매우 작다** → 높은 효율.

### 1.3 모터를 인덕터로 보기

- 모터의 권선은 **인덕터**다 (전류의 급변을 막음).
- PWM 스위칭에도 모터 전류는 0으로 끊기지 않고 **리플**을 그리며 유지된다.
- 듀티비가 평균 전류(속도)를 결정한다.

### 1.4 프리휠링 다이오드 (핵심)

- 스위치(MOSFET)가 OFF 되는 순간 인덕터(모터)는 전류를 유지하려 하며 **큰 역기전력**을 만든다.
- 다이오드를 모터 양단에 역방향으로 병렬 연결하면:
  - OFF 동안 전류가 다이오드를 통해 계속 흐른다 (전류 경로 유지)
  - 역기전력 스파이크가 소자에 가는 것을 막는다
- 다이오드가 없으면 MOSFET이 과전압으로 손상될 수 있다 ([실습 04](실습04_RL_과도응답.md)와 연결)

### 1.5 리플과 PWM 주파수

- 리플 크기는 주파수·인덕턴스·듀티비에 따라 달라진다.
- 주파수를 높이면 리플이 작아지지만, 스위칭 손실이 늘어난다 → 트레이드오프.

### 1.6 종합

- 이 회로는 [인덕터(실습04)](실습04_RL_과도응답.md) + [다이오드(실습06~08)](실습06_다이오드_IV_곡선.md) + [MOSFET 스위치(실습11)](실습11_MOSFET_스위치.md)의 **종합 응용**이다.
- VT6-mini(모터 제어 보드)의 핵심 구동 원리와 동일.

## 3. UI로 진행하기

1. 파일 열기 → **▶(Run)** 클릭
2. **Lmotor 위** 클릭(전류계) → PWM 스위칭에도 **모터 전류가 끊기지 않고 리플**을 그리는 파형 확인
   (인덕터가 전류 급변을 막는 성질 + 프리휠링 다이오드가 전류 경로를 유지)
3. **Vbus/Drain 노드** 클릭 → MOSFET이 ON/OFF 되는 전압 파형 확인
4. **듀티비 실험**: `Vpwm`의 PULSE 값을 우클릭 → `PULSE(0 10 0 1n 1n 25u 50u)`에서
   ON 시간 `25u`를 **10u(20% 듀티) → 40u(80% 듀티)**로 바꾸며 ▶ 재실행 →
   **평균 모터 전류/전압이 듀티비에 비례**해 변하는지 확인 (PWM 제어 원리)
5. **(선택)** D1을 지워 본 뒤 ▶ 재실행 → OFF 순간 모터 전압 스파이크가 커지는 것 확인
   (프리휠링 다이오드의 필요성 실증)

## 4. 확인 사항

- 듀티비-평균전류/전압 관계 (D↑ → 평균↑ → 속도↑)
- 프리휠링 다이오드 유무에 따른 스파이크 전압 차이
- PWM 주파수·인덕턴스에 따른 리플 크기
