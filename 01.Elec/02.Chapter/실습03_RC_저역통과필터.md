# 실습 03: RC 저역통과필터 (Bode Plot)

[← 목차](../README.md)

## 1. 이론 (상세)

### 1.1 캐패시터의 주파수 의존성

- 캐패시터의 임피던스: `Z_C = 1/(jωC)` (ω = 2πf)
- **주파수가 높을수록 임피던스가 작아진다.** (고주파는 쉽게 통과)
- 낮은 주파수에서는 임피던스가 커서 신호가 거의 통과하지 못한다.

### 1.2 저역통과필터(LPF)의 원리

- RC 직렬 회로에서 출력을 캐패시터 양단에서 취하면:
  - **저주파**: 캐패시터 임피던스가 큼 → 출력 전압 거의 그대로
  - **고주파**: 캐패시터 임피던스가 작아짐 → 고주파가 GND로 빠져 출력 감소
- 결과적으로 **낮은 주파수만 통과**시키는 저역통과필터가 된다.

### 1.3 컷오프 주파수 (Cutoff Frequency)

```
fc = 1 / (2πRC)
```

- 이 주파수에서 출력이 입력의 **1/√2 (≈ 0.707)**배로 감소한다.
- 데시벨로는 **-3dB** 지점이다: `20·log10(0.707) ≈ -3.01 dB`
- 본 실습: `fc = 1/(2π×1k×1u) ≈ 159Hz`
- 컷오프 이후 주파수가 10배 오를 때마다 이득은 -20dB 감소(1차 필터, -20dB/decade).

### 1.4 Bode Plot 해석

- **x축**: 주파수 (로그 눈금)
- **y축**: 이득 크기(dB) 또는 위상(°)
- 용어: `dB = 20·log10(이득)` — 이득 1=0dB, 0.707≈-3dB, 0.1=-20dB
- 주파수 응답이 "어느 주파수까지 통과하고 어디서부터 막히는지"를 한눈에 보여준다.

### 1.5 응용

- 오디오 톤 컨트롤, 센서 신호의 노이즈 제거(고주파 잡음 차단)
- ADC 입력 앞단의 안티앨리어싱 필터

## 2. 회로 구성

| 항목 | 내용 |
|---|---|
| 실습 파일 | `03_RC_lowpass_filter.asc` |
| 회로 구성 | `AC 1 - R1(1k) - Vout - C1(1u) - GND` |
| 해석 종류 | `.ac` (주파수 영역) — [해석 상세](../01.Analysis/02_ac_analysis.md) |
| 지시어 | `.ac dec 100 1 1Meg` |

> 필수 조건: 입력 전압원에 `AC 1` (AC 진폭) 지정 — [해석 상세](../01.Analysis/02_ac_analysis.md)

## 3. UI로 진행하기

1. 파일 열기 → **▶(Run)** 클릭 → 주파수 축(로그) 그래프가 열림
2. **Vout 노드**(이름표)를 클릭 → 주파수 응답(Bode) 표시
3. **-3dB 지점 확인**: 파형 창에서 커서를 움직이거나 상태표시줄 좌표로
   `fc ≈ 159Hz` 부근에서 이득이 약 -3dB로 떨어지는지 확인
4. **(선택)** Vout 파형이 없으면 파형 창 우클릭 → **Add Trace** → `V(vout)` 추가

## 4. 확인 사항

- -3dB 주파수 = 이론 fc(`1/2πRC`)와 일치
- 저주파 통과·고주파 감쇠 확인 (고주파로 갈수록 이득이 -20dB/decade로 감소)
