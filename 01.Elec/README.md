## 0. LTspice 설치 (상세)

### 0.1 시스템 요구사항

| 항목 | 요구사항 |
|---|---|
| OS | Windows 10/11 (64비트) 권장. macOS 지원. Linux는 공식 미지원(Wine 가능) |
| 저장 공간 | 설치 파일 약 178MB + 설치 후 약 500MB |
| 메모리 | 4GB 이상 권장 (간단한 실습 회로는 2GB도 가능) |
| 인터넷 | 다운로드/모델 라이브러리 최초 업데이트 시 필요 |

### 0.2 다운로드

1. 브라우저로 **공식 사이트** 접속: https://www.analog.com/en/resources/design-tools-and-calculators/ltspice-simulator.html
2. 페이지의 **Download LTspice** 영역에서 본인 OS 선택:
   - Windows 10/11 64비트 → **Download for Windows 10/11 x64** → `LTspice64.msi` 다운로드
   - macOS → **Download for macOS**
   - 과거 버전(LTspice XVII)은 지원 종료. 특별한 이유가 없으면 최신 버전 사용
3. 파일 크기가 약 178MB이므로 다운로드 완료를 확인한 뒤 진행

> 참고: 검색엔진 광고/유사 사이트가 아닌 **반드시 analog.com** 에서만 다운로드할 것.
> LTspice는 공식적으로 무료이며, 설치 파일 자체는 인터넷 없이도 재배포 가능하다.

### 0.3 설치 (Windows 기준)

1. 다운로드한 `LTspice64.msi`를 **더블클릭**
2. Windows 보안 경고(UAC)가 뜨면 **[예]** 클릭
3. 설치 마법사 순서:
   - **Next** → 설치 유형 선택 (**Everyone** 권장) → Next
   - 설치 위치는 기본값 `C:\Program Files\ADI\LTspice` 유지 권장
   - **Install** → 완료 표시 → **Finish**
4. 설치 확인: **시작 메뉴 → "LTspice" 검색** → 실행
   (바탕화면에 `LTspice` 바로가기가 생성됨)

### 0.4 최초 실행 및 환경 확인

1. 첫 실행 시 **사용 약관 동의** 화면 → **[Accept]** 클릭
2. **Tools > Update Components** 실행 → 최신 모델 라이브러리 업데이트 (인터넷 필요, 최초 1회)
3. `.asc` 파일 연결 설정(한 번만):
   - `01_voltage_divider.asc` 우클릭 → **연결 프로그램 → LTspice** → **"항상 이 앱 사용"** 체크
4. 정상 동작 확인: 예제 파일을 더블클릭해 열리고, **▶(Run) 버튼**이 보이는지 확인

### 0.5 실습실(학원) 일괄 배포 팁

- `LTspice64.msi` 하나만 USB로 복사하면 **인터넷 없이 전 교실 설치** 가능
- 설치 후 최초 1회만 인터넷으로 `Update Components` 실행 (못 하면 대부분 모델이 내장되어 있어 실습 진행 가능)
- 학생별 계정이 다른 PC라면 설치 유형을 **Everyone**으로 선택

### 0.6 설치/실행 문제 해결

| 증상 | 해결 |
|---|---|
| `.asc` 더블클릭해도 안 열림 | 0.4의 연결 프로그램 설정, 또는 LTspice에서 **File > Open** |
| 파일을 저장/열 때 오류 | 한글·특수문자 **경로** 문제 → 영문 경로(예: `C:\LTspice_work`)로 복사 |
| "Unknown subcircuit" 모델 오류 | **Tools > Update Components** 실행 후 재시뮬레이션 |
| 실행 즉시 종료됨 | 보안 S/W 확인, 다른 버전(XVII 또는 최신) 설치 시도 |

## 1. LTspice 기본 사용법 (UI 중심)

### 1.1 회로 파일 열기

- 파일 탐색기에서 `.asc` **더블클릭** (연결 설정 후) 또는
- LTspice 메뉴 **File > Open** → 파일 선택

### 1.2 시뮬레이션 실행

- 툴바의 **▶(Run)** 버튼 클릭, 또는 메뉴 **Simulate > Run**
- 해석 종류에 따라 결과가 열린다:
  - `.op` → **동작점(Operating Point) 창** (노드 전압/소자 전류 표)
  - `.tran` → **시간 영역 그래프**
  - `.ac` → **주파수 영역 그래프(Bode)**
  - `.dc` → **스윕 변수 그래프(I-V 곡선)**
- 실행 중이면 ▶가 ▣(Stop)로 바뀜. 중단하려면 클릭

### 1.3 파형 보기 (프로브 커서)

시뮬레이션 실행 후 **회로 창**에서 마우스를 올리면 커서가 바뀌며, 클릭하면 파형이 그려진다.

| 마우스 동작 | 커서 | 표시 파형 |
|---|---|---|
| **배선(노드) 위**에 올리고 클릭 | 전압계(프로브) | 그 노드의 전압 |
| **2단자 소자 위**에 올리고 클릭 | 전류계(화살표) | 그 소자를 흐르는 전류 |
| **다단자 소자 핀 위**에 올리고 클릭 | 전류계 | 그 핀으로 흐르는 전류 |
| 노드에서 다른 노드로 **드래그** | 프로브 2개 | 두 노드 간 **전압차** |
| 소자 위 **Alt+클릭** | 온도계 | 순시 전력 |
| 소자 위 **Ctrl+클릭** | 온도계 | 평균 전력 |

- 한 파형만 크게 보고 싶으면 해당 노드를 **더블클릭** → 다른 파형 지우고 하나만 표시

### 1.4 파형 확대/측정

- **확대**: 파형 창에서 `Ctrl` + 마우스휠, 또는 `Ctrl` + 좌클릭 드래그
- **이동(팬)**: 마우스휠 / `Shift` + 휠
- **커서 측정**: 파형 창 툴바의 커서(∓) 버튼 또는 **Plot Settings > Cursor > 1st & 2nd** → 두 커서 사이 Δt/ΔV 읽기
- **좌표 읽기**: 파형 위에 마우스를 올리면 창 하단 상태표시줄에 값 표시
- **로그/선형 축**: 파형 창 우클릭 → 축 종류 변경 (`.ac`는 로그 축이 기본)

### 1.5 회로 직접 그리기 (단축키)

| 단축키 | 동작 | 단축키 | 동작 |
|---|---|---|---|
| `F2` | 부품 선택(Component) | `F5` | 삭제 |
| `F3` | 배선(Wire) | `F6` | 복사 |
| `F4` | 노드 이름(Net Label) | `F7` | 이동 |
| `G` | 접지(GND) | `F8` | 드래그 |
| `S` | SPICE 지시어(`.tran` 등) | `Ctrl+R` | **회전** |
| `T` | 텍스트/주석 | `Ctrl+E` | **좌우 미러** |
| `R` / `C` / `L` / `D` | 저항/캐패시터/인덕터/다이오드 배치 | `Esc` | 모드 종료 |
| `F9` / `Shift+F9` | 실행취소 / 재실행 | | |

> ⚠️ **주의**: 기존 안내의 "R=회전, Ctrl+R=미러"는 오타다. **R은 저항 배치**, **Ctrl+R이 회전**, **Ctrl+E가 미러**이다.

### 1.6 결과(파형/이미지) 저장

- 파형 창을 활성화한 상태에서 **File > Export image as...** → PNG 등으로 저장
- 데이터 저장: **File > Export data as text** → CSV로 내보내기
- 빠른 복사: 파형 창 `Ctrl+C` → 그림판/문서에 붙여넣기

## 2. 저항 (Resistor)

### 2.1 이론

- 옴의 법칙: `V = I × R`
- 전력: `P = I²R = V²/R`
- 직렬: `R_total = R1 + R2 + ...`
- 병렬: `1/R_total = 1/R1 + 1/R2 + ...`
- 실제 저항: 온도계수(TCR), 정격전력, 허용오차(1%, 5%) 존재

### 2.2 교육 포인트

- 전압 분배 회로(Voltage Divider)의 원리와 로딩 효과(load effect)
- 풀업/풀다운 저항의 역할 (디지털 회로 입력단)

### 2.3 LTspice 실습: 전압 분배기

**실습 파일**: `01_voltage_divider.asc` — `V1(12V) - R1(1k) - Vout - R2(2k) - GND`, `.op`

**UI로 진행하기**
1. `01_voltage_divider.asc` **더블클릭** → 회로 창이 열림
2. 툴바 **▶(Run)** 클릭 → `.op` **동작점 창**이 열림
3. 동작점 창에서 노드 전압 확인 → **Vout = 12 × (2k/(1k+2k)) = 8V** 이론값과 비교
   (동작점 창 대신 회로 창에서 **Vout 노드 위에 마우스를 올리면 전압이 표시**됨)
4. **실험**: `R2`를 **우클릭 → Value를 1k/4.7k/10k로 변경 → ▶ 재실행** → 전압 변화를 표로 정리
   (R2=1k→6V, R2=4.7k→9.9V, R2=10k→10.9V 예상)
5. **(선택) 스윕**: R2의 Value를 `{R2}`로 바꾸고 `S` → `.step param R2 1k 10k 1k` 입력 → ▶ 실행

**직접 그려보기 (선택)**
- `F2` → `voltage` 배치 / `F2` → `res` 2개 배치 / `G`로 GND / `F3`로 배선 / `S` → `.op`
- 소자 값을 더블클릭해 V1=12, R1=1k, R2=2k로 설정 → ▶ 실행

**확인 사항**: Vout이 이론식과 일치하는지 / R2 변경 시 Vout 변화율이 기대와 같은지

## 3. 캐패시터 (Capacitor)

### 3.1 이론

- 전하 저장: `Q = C × V`
- 전류-전압 관계: `I = C × dV/dt` (전압이 급변하면 전류가 크게 흐름)
- 직렬: `1/C_total = 1/C1 + 1/C2`
- 병렬: `C_total = C1 + C2`
- RC 시정수: `τ = R × C` (63.2% 충전/36.8% 방전 도달 시간)
- 임피던스(주파수영역): `Z_C = 1/(jωC)` → 고주파일수록 임피던스 감소 (커플링/디커플링 활용)

### 3.2 교육 포인트

- 충방전 특성이 타이머, 디바운싱, 전원 디커플링에 활용되는 원리
- RC 저역통과필터(LPF)의 컷오프 주파수: `f_c = 1/(2πRC)`

### 3.3 LTspice 실습: RC 충방전

**실습 파일**: `02_RC_charge_discharge.asc` — `PULSE(0 5 0 1n 1n 5m 10m) - R1(1k) - C1(1u) - GND`, `.tran 20m`

**UI로 진행하기**
1. 파일 열기 → **▶(Run)** 클릭
2. **Vsw 노드**(전압원과 R1 사이)를 클릭 → 0V↔5V 펄스 확인
3. **C1 위**에 마우스를 올리고 클릭(전류계) → 충전 전류가 지수적으로 감소하는 것 확인
4. **C1 위 노드**(R1과 C1 사이 배선) 클릭 → 캐패시터 전압이 `τ = 1k×1u = 1ms`에 맞춰 63.2%(3.16V)까지 충전되는 것 확인
5. **실험**: `C1` 값을 **우클릭으로 0.1u → 10u로 변경 → ▶ 재실행** → 충전 속도 차이 비교

**직접 그려보기 (선택)**
- `F2` → voltage, res, cap 배치 + `G` 접지 → `F3` 배선
- 전압원을 더블클릭해 `PULSE(0 5 0 1n 1n 5m 10m)` 입력 → `S` → `.tran 20m`

**확인 사항**: τ=R·C와 파형의 63.2% 지점 일치 / C를 키우면 충전이 느려지는지

### 3.4 LTspice 실습: RC 저역통과필터 (Bode Plot)

**실습 파일**: `03_RC_lowpass_filter.asc` — `AC 1 - R1(1k) - Vout - C1(1u) - GND`, `.ac dec 100 1 1Meg`

**UI로 진행하기**
1. 파일 열기 → **▶(Run)** 클릭 → 주파수 축(로그) 그래프가 열림
2. **Vout 노드**(이름표)를 클릭 → 주파수 응답(Bode) 표시
3. **-3dB 지점 확인**: 파형 창에서 커서를 움직이거나 상태표시줄 좌표로
   `f_c = 1/(2π×1k×1u) ≈ 159Hz` 부근에서 이득이 약 -3dB로 떨어지는지 확인
4. **(선택)** Vout 파형이 없으면 파형 창 우클릭 → **Add Trace** → `V(vout)` 추가

**확인 사항**: -3dB 주파수 = 이론 f_c와 일치 / 저주파 통과·고주파 감쇠 확인

## 4. 인덕터 (Inductor)

### 4.1 이론

- 전압-전류 관계: `V = L × dI/dt` (전류가 급변하면 큰 역기전력 발생)
- 저장 에너지: `E = ½LI²`
- 직렬: `L_total = L1 + L2`
- 병렬: `1/L_total = 1/L1 + 1/L2`
- 임피던스: `Z_L = jωL` → 고주파일수록 임피던스 증가 (캐패시터와 반대)
- 시정수(RL 회로): `τ = L/R`

### 4.2 교육 포인트

- 인덕터는 전류의 급격한 변화를 막으려는 성질 → 스위칭 레귤레이터(Buck/Boost)의 핵심
- 캐패시터와 반대 주파수 특성 → LC 공진회로, 필터 설계에 활용

### 4.3 LTspice 실습: RL 과도응답

**실습 파일**: `04_RL_transient.asc` — `PULSE(0 5 ...) - R1(100) - Vsw - L1(10m) - GND`, `.tran 5m`

**UI로 진행하기**
1. 파일 열기 → **▶(Run)** 클릭
2. **L1 위**에 마우스를 올리고 클릭(전류계) → 전류가 `τ = L/R = 0.1ms`로 지수 증가 후 정상상태(5V/100Ω=50mA)에 도달
3. **역기전력 관찰(핵심)**: 펄스가 꺼지는 순간의 전압을 보기 위해 **L1 양끝을 드래그**
   (Vsw 노드 → GND 쪽) → 스위치 오프 시 큰 **스파이크(역기전력)** 확인
4. 스파이크의 극성·크기를 관찰하고, 다음 장(다이오드)의 **프리휠링 다이오드** 필요성과 연결

**확인 사항**: τ = L/R 일치 / 스위치 오프 순간 역기전력 스파이크 발생 확인

### 4.4 LTspice 실습: LC 공진

**실습 파일**: `05_LC_resonance.asc` — `AC 1 - L1(1m) - Vout - C1(1u) - GND`, `.ac dec 100 100 100k`

**UI로 진행하기**
1. 파일 열기 → **▶(Run)** 클릭
2. **Vout 노드** 클릭 → 주파수 응답 표시
3. **공진 피크 확인**: 커서로 그래프의 최대점을 찾아
   `f_0 = 1/(2π√(L1·C1)) = 1/(2π√(1m·1u)) ≈ 5.03kHz` 이론값과 비교
4. **(선택)** 파형 창 우클릭 → **Add Trace** → `V(vout)` 로도 표시 가능

**확인 사항**: 공진 피크 주파수 = f_0 이론값 / 공진점에서 임피던스가 최소가 되어 전압이 커지는지

## 5. 다이오드 (Diode)

### 5.1 이론

- PN 접합의 정류 특성: 순방향 전도, 역방향 차단
- Shockley 다이오드 방정식: `I = I_S (e^(V/nV_T) - 1)`
- 실리콘 다이오드 순방향 전압강하 약 0.6~0.7V, 쇼트키 다이오드는 약 0.2~0.4V
- 종류: 정류 다이오드, 제너 다이오드(정전압), LED, 쇼트키 다이오드
- 제너 다이오드: 역방향 항복전압(V_Z)에서 전압을 고정 → 기준전압/보호회로에 사용

### 5.2 교육 포인트

- 반파/전파 정류 회로의 원리
- 인덕터 실습에서 발생한 역기전력을 다이오드로 흡수하는 프리휠링 다이오드 회로

### 5.3 LTspice 실습: 다이오드 I-V 특성 곡선

**실습 파일**: `06_diode_IV_curve.asc` — `V1 - D1(1N4148) - GND`, `.dc V1 -1 1 0.01`

**UI로 진행하기**
1. 파일 열기 → **▶(Run)** 클릭 → x축이 V1인 그래프가 열림
2. **D1 위**에 마우스를 올리고 클릭(전류계) → **I(D1) 곡선** 표시
3. 순방향 **약 0.6~0.7V**부터 전류가 지수적으로 급증하는 특성 확인
4. **(선택)** 역방향(-1V~0V)에서 전류가 거의 0인 차단 특성도 함께 확인
5. **(선택)** D1을 **우클릭 → Pick New Diode**로 1N4007(정류용)/쇼트키 등으로 바꿔 순방향 전압차이 비교

**확인 사항**: 순방향 기울기(지수 특성)와 항복/차단 구간 / 소자별 순방향 전압 차이

### 5.4 LTspice 실습: 반파 정류 회로

**실습 파일**: `07_halfwave_rectifier.asc` — `SINE(0 10 60) - D1(1N4007) - Vout - Rload(1k) - GND`, `.tran 50m`

**UI로 진행하기**
1. 파일 열기 → **▶(Run)** 클릭
2. **Vout 노드** 클릭 → 음(-) 반주기가 제거된 **반파** 파형 확인
3. **D1 위** 클릭(전류계) → 다이오드가 도통/차단하는 구간 확인
4. **리플 필터 실험**: `F2` → `cap` 선택 → **Rload와 병렬로** 캐패시터(10u) 배치 → 우클릭으로 값 입력 → ▶ 재실행 → 출력이 평탄해지는(리플 감소) 것 확인

**확인 사항**: 반파 정류 파형 / 필터 캐패시터 추가 시 리플 감소(충전·방전 반복) 확인

### 5.5 LTspice 실습: 제너 다이오드 정전압 회로

**실습 파일**: `08_zener_regulator.asc` — `V1(12V) - R1(470) - Vout - D1(BZX55C5V6) - GND`, `.dc V1 0 20 0.1`

**UI로 진행하기**
1. 파일 열기 → **▶(Run)** 클릭 → x축이 V1인 그래프가 열림
2. **Vout 노드** 클릭 → 입력 전압(V1)이 제너 전압(5.6V)을 넘어서면 **출력이 5.6V에 고정**되는 것 확인
3. Vout 곡선의 기울기가 바뀌는 지점이 항복전압(V_Z)임을 확인
4. **(선택)** V1을 우클릭 → 12 → 20으로 바꿔도 Vout이 유지되는지 확인
   - ※ 모델이 없다는 오류가 나면 D1 **우클릭 → Pick New Zener**로 다른 제너 선택

**확인 사항**: 입력 변동에도 출력이 V_Z 근처에서 고정 / 기준전압·보호회로 응용 이해

## 6. BJT (Bipolar Junction Transistor)

### 6.1 이론

- 3단자 소자: Base, Collector, Emitter / NPN, PNP 두 형태
- 전류 제어 소자: `I_C = β × I_B` (β는 전류이득, hFE)
- 동작 영역: 차단(Cutoff), 활성(Active, 증폭용), 포화(Saturation, 스위치용)
- 활성영역 조건: `V_BE ≈ 0.7V`, `V_CE > V_CE(sat)`
- 스위치로 사용 시: 베이스 전류를 충분히 흘려 포화영역 진입 → `V_CE(sat) ≈ 0.2V`

### 6.2 교육 포인트

- 증폭기(공통 이미터) vs 스위치 동작의 차이
- 부하선(Load Line) 개념과 동작점(Q-point) 설정

### 6.3 LTspice 실습: NPN 스위치 회로 (LED 구동)

**실습 파일**: `09_BJT_switch_LED.asc` — `V1(PULSE 0 5) - RB(1k) - Base, Vcc(12V) - LED - Collector, 2N2222`, `.tran 10m`

**UI로 진행하기**
1. 파일 열기 → **▶(Run)** 클릭
2. **LED 위**에 마우스를 올리고 클릭(전류계) → V1이 5V일 때만 LED 전류가 흐르는 **스위칭** 확인
3. **Collector 노드** 클릭 → ON일 때 `V_CE ≈ 0.2V`(포화)인지 확인
4. **실험**: `RB` 값을 우클릭으로 1k → 10k, 100k로 키우며 ▶ 재실행 → 포화에서 벗어나
   (활성/차단) LED 전류가 작아지는 지점 = "포화에 필요한 최소 베이스 전류" 탐구

**확인 사항**: 스위치 동작(차단↔포화) / RB에 따른 포화 전류 변화

### 6.4 LTspice 실습: 공통 이미터 증폭기 (소신호 증폭)

**실습 파일**: `10_BJT_common_emitter_amp.asc` — `Vcc(12V) + 전압분배 바이어스 + CE 바이패스 + 2N2222`, `.tran 5m`

**UI로 진행하기**
1. 파일 열기 → **▶(Run)** 클릭 → 시간 영역 그래프가 열림
2. **Vin 노드**(입력, 1kHz 사인) 클릭 → 작은 입력 신호 확인
3. **Vout 노드** 클릭 → 입력보다 **크고 180° 뒤집힌**(반전) 증폭 파형 확인
   - 이득 `Av ≈ -RC/RE = -2.2k/1k = -2.2` (CE 바이패스가 있으면 이론상 더 큰 이득)
4. **(선택) Q-point 확인**: `S` → `.op` 지시어 추가 → ▶ 실행 → VCE가 공급전압 중간 부근(활성영역)인지 확인
5. **(선택) Bode**: `S` → `.ac dec 100 10 1Meg` 추가 → ▶ 실행 → Vout 클릭 → 이득-주파수 응답 확인
6. **(선택) 클리핑**: Vin 진폭을 크게(0.01→0.1) 바꾸면 출력이 찌그러지는(클리핑) 것 확인 → 바이어스 중요성

**확인 사항**: 증폭/반전 동작, Q-point가 활성영역인지, 클리핑 발생 조건

## 7. FET (전계효과 트랜지스터, MOSFET 중심)

### 7.1 이론

- 3단자: Gate, Drain, Source (N-channel, P-channel)
- 전압 제어 소자: 게이트-소스 전압(V_GS)으로 드레인 전류 제어, 게이트로 전류가 거의 흐르지 않음(고입력 임피던스)
- 동작 영역: 차단(V_GS < V_TH), 트라이오드(선형, 저항처럼 동작), 포화(정전류원처럼 동작)
- 문턱전압(V_TH) 이상에서 채널 형성
- 포화영역 전류식: `I_D = k(V_GS - V_TH)²` (근사식)
- BJT와 비교: FET은 전압제어, BJT는 전류제어 / FET은 게이트 누설전류가 매우 작아 고임피던스 회로에 유리

### 7.2 교육 포인트

- 전력 MOSFET의 스위칭 응용 (모터 드라이버, DC-DC 컨버터)
- 게이트 구동 저항과 스위칭 손실의 관계

### 7.3 LTspice 실습: MOSFET 스위치 (모터/LED 구동)

**실습 파일**: `11_MOSFET_switch.asc` — `Vgs(PULSE 0 10) - M1(IRF540N) - Vcc(12V)/Rload(100)`, `.tran 10m`

**UI로 진행하기**
1. 파일 열기 → **▶(Run)** 클릭
2. **Rload 위** 클릭(전류계) → 게이트 10V일 때만 부하 전류가 흐르는 **스위칭** 확인
3. **Drain 노드** 클릭 → ON일 때 Drain 전압이 0V 부근(완전 도통)인지 확인
4. **(선택) 문턱 실험**: Vgs의 PULSE 최종값을 우클릭으로 10 → 3V, 4V로 낮춰 ▶ 재실행 →
   부하 전류가 조금만 흐르는(트라이오드/포화 전이) 현상 관찰

**확인 사항**: MOSFET 스위치 동작 / V_TH 부근에서의 동작영역 전이

### 7.4 LTspice 실습: MOSFET I-V 특성 곡선 (출력 특성)

**실습 파일**: `12_MOSFET_IV_curve.asc` — `Vds + Vgs(파라미터) - M1(IRF540N)`, `.dc Vds 0 10 0.1 Vgs 2 6 1`

**UI로 진행하기**
1. 파일 열기 → **▶(Run)** 클릭 → x축이 Vds인 그래프가 열림
2. **M1의 Drain 핀** 클릭(전류계) → V_GS별 **I_D 곡선 묶음(패밀리 커브)** 표시
3. 각 곡선에서 **트라이오드(선형) 구간과 포화(평탄) 구간의 경계**를 확인
4. V_GS가 커질수록 포화 전류(I_D)가 커지는(제곱 법칙) 것 확인

**확인 사항**: V_GS 파라미터에 따른 I_D-V_DS 곡선 묶음 / 트라이오드↔포화 경계

### 7.5 LTspice 실습: 초퍼 구동회로 (VT6-mini 프로젝트 연계)

**실습 파일**: `13_chopper_motor_driver.asc` — `Vpwm(20kHz) - M1(IRF540N) - 모터(R2+L5m) - 프리휠링 D1(MBR1045)`, `.tran 5m`

**UI로 진행하기**
1. 파일 열기 → **▶(Run)** 클릭
2. **Lmotor 위** 클릭(전류계) → PWM 스위칭에도 **모터 전류가 끊기지 않고 리플**을 그리는 파형 확인
   (인덕터가 전류 급변을 막는 성질 + 프리휠링 다이오드가 전류 경로를 유지)
3. **Vbus/Drain 노드** 클릭 → MOSFET이 ON/OFF 되는 전압 파형 확인
4. **듀티비 실험**: `Vpwm`의 PULSE 값을 우클릭 → `PULSE(0 10 0 1n 1n 25u 50u)`에서
   ON 시간 `25u`를 **10u(20% 듀티) → 40u(80% 듀티)**로 바꾸며 ▶ 재실행 →
   **평균 모터 전류/전압이 듀티비에 비례**해 변하는지 확인 (PWM 제어 원리)
5. **(선택)** D1을 지워 본 뒤 ▶ 재실행 → OFF 순간 모터 전압 스파이크가 커지는 것 확인
   (프리휠링 다이오드의 필요성 실증)

**확인 사항**: 인덕터(3장)+다이오드(4장)+MOSFET(6장)의 종합 / 듀티비-평균전류 관계

## 8. LTspice 공통 사용법 요약

### 8.1 시뮬레이션 지시어

| 지시어 | 용도 | 예시 |
|---|---|---|
| `.tran` | 시간영역 과도해석 | `.tran 10m` |
| `.ac` | 주파수영역 해석 (Bode Plot) | `.ac dec 100 1 1Meg` |
| `.dc` | DC 스윕 (I-V 곡선) | `.dc V1 0 10 0.1` |
| `.op` | 동작점(bias point) 계산 | `.op` |
| `.step param` | 파라미터 반복 스윕 | `.step param R 1k 10k 1k` |
| `.model` | 소자 모델 파라미터 정의 | 다이오드/트랜지스터 커스텀 모델 |

### 8.2 UI 조작 요약

| 동작 | 방법 |
|---|---|
| 실행 | 툴바 **▶(Run)** 또는 Simulate > Run |
| 전압 파형 | 배선(노드) 위에 마우스 → 클릭 |
| 전류 파형 | 소자/핀 위에 마우스(전류계 커서) → 클릭 |
| 두 노드 전압차 | 한 노드 → 다른 노드로 드래그 |
| 소자 교체/값 변경 | 소자 **우클릭** → Pick New ... / Value 수정 |
| 값 스윕 | Value를 `{X}`로 바꾸고 `.step param X ...` 추가 |
| 확대/이동 | Ctrl+휠, Ctrl+좌클릭 드래그 |
| 커서 측정 | 파형 창 툴바 커서 버튼 또는 Plot Settings > Cursor |
| 이미지/데이터 저장 | 파형 창 활성화 → File > Export image / data |

**팁**: 각 소자 위에서 **우클릭 → "Pick New ~"** 메뉴로 실제 상용 부품(1N4148, 2N2222, IRF540N 등) SPICE 모델을 바로 불러와 실습에 사용 가능.

수동소자(R→C→L) → 이론적 주파수 특성 비교(RC/RL/LC) → 비선형 소자(다이오드) → 능동소자(BJT→FET) → 종합(초퍼 회로)로 이어지는 흐름이 바닥부터 위로 쌓이는 구조라 초심자에게 자연스럽습니다.

> **실습 운영 팁**: 모든 예제는 "파일을 더블클릭 → ▶(Run) → 마우스로 파형 찍기"만으로 1~2분 안에
> 동작을 보여줄 수 있다. 이론 설명 전에 **먼저 시뮬레이션으로 결과를 보여주고**,
> "왜 이렇게 되는가"를 이론으로 돌아와 설명하면 흥미 유지에 효과적이다.
