## 1. 개요

Jetson Xavier NX에서 AI 프로그램을 실행하기 전에, **PC에서 Python 개발 환경**을 먼저 익히는 것이 좋다.

- Jetson 보드에서도 동일하게 Python → 가상 환경 → Jupyter Notebook 패턴을 사용한다.
- PC에서 먼저 익숙해지면, 이후 Jetson에서 발생하는 문제도 훨씬 쉽게 해결할 수 있다.

```text
PC (Windows)
    │
    ├─ Anaconda 설치 (Python + 패키지 관리)
    ├─ conda 가상 환경 생성
    ├─ Jupyter Notebook 실행
    ├─ 코드 실습 (Python, NumPy, Pandas, Matplotlib)
    │
    ▼
Jetson Xavier NX에서 같은 패턴으로 확장
    │
    ├─ Miniconda / Jupyter
    ├─ TensorRT, CUDA, PyTorch 등 설치
    └─ AI 추론 실습
```

> 본 문서의 **핵심 목표**: Anaconda 설치 → 가상 환경 → Jupyter Notebook 실행 → 기본 코드 실행을
> 순서대로 직접 해보는 것.

## 2. Anaconda란 무엇인가?

**Anaconda**는 데이터 과학 / 머신러닝용 **Python 배포판**이다.

| 구성 요소 | 역할 |
|---|---|
| **Python** | 프로그램 실행 언어 (기본 포함) |
| **conda** | 패키지 및 가상 환경 관리 도구 |
| **Anaconda Navigator** | 그래픽(GUI)으로 환경과 앱을 관리하는 화면 |
| **Anaconda Prompt** | conda 명령을 사용하는 명령 프롬프트 |
| **Jupyter Notebook** | 브라우저에서 코드를 실행하는 노트북 환경 |
| **주요 패키지** | NumPy, Pandas, Matplotlib, SciPy 등 수백 개를 미리 포함 |

### 2.1 왜 가상 환경이 필요한가?

프로젝트마다 필요한 패키지 버전이 다르다. 가상 환경을 만들면 **프로젝트별로 독립된
패키지 묶음**을 유지할 수 있다.

```text
PC
 ├─ base 환경   : Anaconda 기본 (일반 목적)
 ├─ jetson_env  : Jetson 실습용 (TensorRT 관련 예제 등)
 └─ web_env     : 웹 프로젝트용
```

패키지를 섞지 않고 분리하므로 **버전 충돌로 인한 오류를 줄일 수 있다.**

## 3. Anaconda 설치 준비

### 3.1 권장 사양

## 4. Anaconda 설치 (Windows)

### 4.1 설치 실행

1. 다운로드한 `Anaconda3-...-Windows-x86_64.exe` 파일을 더블클릭한다.
2. "Next"를 눌러 진행한다.

> 첫 화면에서 "License Agreement"가 나오면 "I Agree"를 선택한다.

### 4.2 설치 유형 선택

"Install for:" 부분에서 **"Just Me (recommended)"** 를 선택한다.

### 4.3 설치 폴더

기본값 그대로 사용한다.

```text
C:\Users\사용자이름\anaconda3
```

> 한글이나 공백이 없는 경로를 권장한다. (한글 경로는 일부 패키지에서 문제가 생길 수 있다.)

### 4.4 PATH 옵션 (중요)

마지막 단계에서 두 가지 체크박스가 나온다.

| 옵션 | 권장 | 설명 |
|---|---|---|
| Add Anaconda3 to my PATH environment variable | 체크 안 함 | 다른 Python과 충돌할 수 있음 |
| Register Anaconda3 as my default Python 3.XX | 체크 권장 | 시스템 기본 Python으로 등록 |

> 초보자는 **두 번째 옵션만 체크**하고 Install을 누른다. PATH 설정은 Anaconda Prompt를
> 사용하면 굳이 하지 않아도 된다.

### 4.5 설치 완료

설치가 끝나면 "Finish"를 누른다. 이제 시작 메뉴에 아래 프로그램들이 생성된다.

```text
Anaconda Navigator
Anaconda Prompt
Jupyter Notebook
Spyder
```

## 6. 가상 환경 만들기

Anaconda Prompt에서 다음 명령으로 환경을 만든다.

### 6.1 환경 생성

```text
conda create -n jetson_env python=3.11
```

| 옵션 | 의미 |
|---|---|
| `create` | 환경 생성 |
| `-n jetson_env` | 환경 이름을 `jetson_env`로 지정 |
| `python=3.11` | Python 3.11 버전으로 설치 |

진행 여부를 물어보면 `y`를 입력하고 Enter를 누른다.

### 6.2 환경 목록 확인

```text
conda env list
```

출력 예:

```text
# conda environments:
#
base                  *  C:\Users\사용자이름\anaconda3
jetson_env               C:\Users\사용자이름\anaconda3\envs\jetson_env
```

`*` 표시가 현재 활성화된 환경을 나타낸다.

### 6.3 환경 활성화

```text
conda activate jetson_env
```

프롬프트가 `(base)`에서 `(jetson_env)`로 바뀌면 성공이다.

```text
(jetson_env) C:\Users\사용자이름>
```

### 6.4 환경 비활성화 / 삭제 (참고)

```text
conda deactivate                      # 환경 비활성화
conda env remove -n jetson_env        # 환경 삭제
```

### 6.5 핵심 conda 명령 요약표

| 목적 | 명령 |
|---|---|
| 환경 생성 | `conda create -n 환경이름 python=3.11` |
| 환경 목록 | `conda env list` |
| 환경 활성화 | `conda activate 환경이름` |
| 환경 비활성화 | `conda deactivate` |
| 환경 삭제 | `conda env remove -n 환경이름` |
| 패키지 설치 | `conda install 패키지명` |
| 패키지 목록 | `conda list` |
| 패키지 검색 | `conda search 패키지명` |

## 8. Jupyter Notebook 기본 사용법

### 8.1 노트북 구성 요소

Jupyter Notebook은 **셀(Cell)** 단위로 코드를 실행한다.

| 요소 | 설명 |
|---|---|
| 셀 (Cell) | 코드 또는 설명이 들어가는 하나의 블록 |
| 코드 셀 | Python 코드 실행 |
| Markdown 셀 | 설명/제목/그림 등을 표시 (실행 안 함) |
| 커널 (Kernel) | 코드를 실제로 실행하는 Python 프로세스 |

### 8.2 주요 단축키

| 단축키 | 동작 |
|---|---|
| `Shift + Enter` | 현재 셀 실행 후 다음 셀로 이동 |
| `Ctrl + Enter` | 현재 셀만 실행 |
| `Alt + Enter` | 실행 후 새 셀 삽입 |
| `A` | 위에 새 셀 삽입 |
| `B` | 아래에 새 셀 삽입 |
| `M` | 현재 셀을 Markdown 셀로 변경 |
| `Y` | 현재 셀을 Code 셀로 변경 |
| `DD` | 셀 삭제 |
| `Esc` | 명령 모드로 전환 (단축키 입력 가능) |
| `Enter` | 편집 모드로 전환 |
| `Ctrl + S` | 저장 |

> 단축키는 `Esc` 후 사용해야 동작한다. 예: `Esc` → `M` → `Shift+Enter` 하면
> Markdown 셀이 적용된 결과를 볼 수 있다.

### 8.3 셀 실행 순서 개념

셀은 **위에서 아래로 순서대로** 실행하는 것을 원칙으로 한다.

```text
셀 1 : import numpy as np          ← 먼저 실행
셀 2 : a = 10                      ← 다음 실행
셀 3 : a * 2                       ← 마지막 실행 → 출력 20
```

순서가 뒤바뀌면 오류가 날 수 있으므로 처음에는 반드시 순서대로 실행한다.

### 10.3 Matplotlib 그래프

```python
import numpy as np
import matplotlib.pyplot as plt

x = np.linspace(0, 2 * np.pi, 100)
y = np.sin(x)

plt.figure(figsize=(8, 4))
plt.plot(x, y, label="sin(x)", color="blue")
plt.plot(x, np.cos(x), label="cos(x)", color="red", linestyle="--")
plt.xlabel("x")
plt.ylabel("y")
plt.title("sin and cos")
plt.legend()
plt.grid(True)
```

```text

```

### 10.4 여러 그래프 그리기

```python
import numpy as np
import matplotlib.pyplot as plt

x = np.linspace(-5, 5, 100)

plt.figure(figsize=(10, 6))

plt.subplot(2, 2, 1)
plt.plot(x, x ** 2)
plt.title("y = x^2")

plt.subplot(2, 2, 2)
plt.plot(x, np.exp(-(x ** 2)))
plt.title("y = exp(-x^2)")

plt.subplot(2, 2, 3)
plt.plot(x, np.abs(x))
plt.title("y = |x|")

plt.subplot(2, 2, 4)
plt.plot(x, 1 / (1 + np.exp(-x)))
plt.title("sigmoid")

plt.tight_layout()
plt.show()
```

## 11. 실습 3: 표 형태 데이터 다루기 (Pandas)

```python
print("배터리 평균:", df["배터리"].mean())
```

```text
예: practice_basic.ipynb
```

### 12.2 불러오기

- Jupyter 홈 화면(`http://localhost:8888/tree`)에서 파일을 클릭하면 다시 열린다.

### 12.3 다른 형식으로 내보내기

- **File → Download as → HTML / PDF / Python (.py)** 선택

```text
.ipynb   : 노트북 파일 (다시 열어 실행 가능)
.html    : 브라우저로 보는 결과물 (실행 불가)
.py      : 순수 Python 코드 (수정 후 실행 가능)
```

## 14. 문제 해결

### 14.1 `conda` 명령이 없다고 나올 때

- Anaconda Prompt를 사용했는지 확인한다. (일반 cmd가 아닌 **Anaconda Prompt**)
- 시작 메뉴에서 "Anaconda Prompt"를 검색해 실행한다.

### 14.2 `jupyter` 명령을 찾지 못할 때

```text
'jupyter'은(는) 내부 또는 외부 명령, 실행할 수 있는 프로그램, 또는 배치 파일이 아닙니다.
```

- `jetson_env` 환경이 활성화되어 있는지 확인한다.

```text
conda activate jetson_env
conda install jupyter notebook
jupyter notebook
```

### 14.3 브라우저가 열리지 않을 때

```text
conda activate jetson_env
jupyter notebook
```

출력된 `http://localhost:8888/tree` 주소를 브라우저에 직접 입력한다.

### 14.4 브라우저에서 코드가 실행되지 않을 때

- 커널(Kernel)이 꺼져 있을 수 있다. 상단 **Kernel → Restart & Run All** 실행
- `[*]` 표시가 오래 유지되면 코드가 실행 중이므로 잠시 기다린다.

### 14.5 한글 그래프 폰트가 깨질 때

```python
import matplotlib.pyplot as plt
plt.rcParams["font.family"] = "Malgun Gothic"
plt.rcParams["axes.unicode_minus"] = False
```

### 14.6 포트가 이미 사용 중일 때

```text
conda activate jetson_env
jupyter notebook --port=8889
```
