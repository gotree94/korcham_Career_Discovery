# Anaconda + Jupyter Notebook 실습 (PC 환경)

> **한 줄 요약:** Anaconda 설치 → conda 가상 환경 → Jupyter Notebook → Python 코드 실행.
> 이 4단계를 PC에서 먼저 연습한 뒤, Jetson Xavier NX로 확장한다.

---

```text
┌─────────────────────────────────────────────────────┐

│                                                     │
│  Anaconda                                           │
│    ├─ conda (패키지/환경 관리)                       │
│    ├─ Python 3.11                                   │
│    ├─ 가상 환경 jetson_env                           │
│    │     ├─ numpy, pandas, matplotlib              │
```

## Part 1: Anaconda 설치

### 1.1 다운로드

https://www.anaconda.com/download → **Windows → 64-Bit Graphical Installer**

파일명 예: `Anaconda3-2024.XX-Windows-x86_64.exe`

### 1.2 설치 실행

| 단계 | 선택 |
|---|---|
| License | **I Agree** |
| Install for | **Just Me (recommended)** |
| Destination | 기본값 사용 (한글/공백 없는 경로) |
| Options 1: Add to PATH | **체크 해제** (다른 Python과 충돌 방지) |
| Options 2: Register as default Python | **체크** |

설치 완료 → **Finish**

### 1.3 설치 확인

시작 메뉴에서 **Anaconda Prompt** 실행 → `(base)` 프롬프트 확인:

```text
(base) C:\Users\사용자이름>conda --version
conda 24.x.x

(base) C:\Users\사용자이름>python --version
Python 3.11.x
```

> 💡 일반 `cmd`가 아닌 **Anaconda Prompt**를 사용해야 `conda` 명령이 동작한다.

## Part 2: 작업 공간 만들기

### 2.1 작업 폴더 생성

바탕화면이나 문서 폴더 안에 전용 폴더를 만든다.

```text
C:\Users\사용자이름\jupyter_workspace
```

### 2.2 가상 환경 (conda env)

**왜 필요한가?** 프로젝트마다 필요한 패키지 버전이 다르다. 환경을 분리하면 버전 충돌을 막을 수 있다.

```text
(base)  ─── Anaconda 기본 (건드리지 않음)
jetson_env  ─── 실습 전용 (새로 만듦)
```

#### 환경 생성

```text
conda create -n jetson_env python=3.11
```

`Proceed ([y]/n)?` → `y` 입력

#### 환경 활성화 / 비활성화

```text
conda activate jetson_env      # 켜기 → 프롬프트가 (jetson_env)로 변함
conda deactivate               # 끄기 → 다시 (base)로
```

#### 패키지 설치

`jetson_env`가 활성화된 상태에서:

```text
conda install numpy matplotlib pandas jupyter
```

#### 핵심 명령 정리

| 동작 | 명령 |
|---|---|
| 환경 생성 | `conda create -n 이름 python=3.11` |
| 활성화 | `conda activate 이름` |
| 비활성화 | `conda deactivate` |
| 환경 목록 | `conda env list` |
| 환경 삭제 | `conda env remove -n 이름` |
| 패키지 설치 | `conda install 패키지명` |
| 패키지 목록 | `conda list` |

## Part 3: Jupyter Notebook 실행

### 3.1 실행

```text
cd C:\Users\사용자이름\jupyter_workspace
conda activate jetson_env
jupyter notebook
```

→ 기본 브라우저가 자동으로 열리며 `http://localhost:8888/tree` 접속

### 3.2 새 노트북 만들기

1. 우측 **New → Python 3**
2. 첫 셀에 입력 → `Shift + Enter`로 실행

### 3.3 인터페이스 구조

```text
┌──────────────────────────────────────────┐
│  Menu Bar: File  Edit  View  Kernel      │
├──────────────────────────────────────────┤
│  Toolbar: 💾  ➕  ✂️  ⬆️  ⬇️  ▶️  ⏹️     │
├──────────────────────────────────────────┤
│  ┌────────────────────────────────────┐  │
│  │  In [1]: print("Hello")           │  │  ← Code 셀
│  │  Out[1]: Hello                     │  │
│  └────────────────────────────────────┘  │
│  ┌────────────────────────────────────┐  │
│  │  # 제목                            │  │  ← Markdown 셀
│  │  설명 텍스트                        │  │

└──────────────────────────────────────────┘
```

### 3.4 단축키 (자주 쓰는 것만)

| 모드 | 키 | 동작 |
|---|---|---|
| 공통 | `Shift + Enter` | 셀 실행 + 다음 셀로 |
| 공통 | `Ctrl + Enter` | 셀 실행만 |
| 명령 모드 (`Esc`) | `A` | 위에 셀 삽입 |
| 명령 모드 | `B` | 아래에 셀 삽입 |
| 명령 모드 | `M` | Markdown 셀로 변경 |
| 명령 모드 | `Y` | Code 셀로 변경 |
| 명령 모드 | `DD` | 셀 삭제 |
| 편집 모드 (`Enter`) | `Ctrl + S` | 저장 |

> 명령 모드 / 편집 모드 전환: `Esc` ↔ `Enter`

## Part 4: 실습 — 코드 직접 실행

### 4.1 기초: print, 변수, 연산

```python
print("Hello, Jupyter!")

a, b = 7, 3
print(f"+ {a+b}, - {a-b}, * {a*b}, / {a/b:.2f}")
print(f"// {a//b}, % {a%b}, ** {a**b}")

scores = [90, 85, 78, 92, 88]
print(f"평균: {sum(scores)/len(scores):.1f}")
```

```text
Hello, Jupyter!
+ 10, - 4, * 21, / 2.33
// 2, % 1, ** 343
평균: 86.6
```

### 4.2 NumPy: 배열과 행렬

```python
import numpy as np

arr = np.arange(1, 6)
print(arr)
print(f"평균 {np.mean(arr)}, 합 {np.sum(arr)}, 최대 {np.max(arr)}")

m = np.arange(1, 10).reshape(3, 3)
print(m)
print(f"전치:\n{m.T}")
print(f"행렬곰:\n{m @ m.T}")
```

```text
[1 2 3 4 5]
평균 3.0, 합 15, 최대 5
[[1 2 3]
 [4 5 6]
 [7 8 9]]
```

### 4.3 Matplotlib: 그래프

```python
import numpy as np
import matplotlib.pyplot as plt

plt.rcParams["font.family"] = "Malgun Gothic"   # 한글 폰트
plt.rcParams["axes.unicode_minus"] = False

x = np.linspace(0, 2*np.pi, 100)

plt.figure(figsize=(8, 4))
plt.plot(x, np.sin(x), label="sin(x)")
plt.plot(x, np.cos(x), "--", label="cos(x)")
plt.xlabel("x"); plt.ylabel("y")
plt.title("sin & cos"); plt.legend(); plt.grid(True)
plt.show()
```

```text
→ 셀 아래에 그래프가 바로 표시됨
```

#### subplot (한 화면에 여러 그래프)

```python
x = np.linspace(-5, 5, 100)

fig, ax = plt.subplots(2, 2, figsize=(8, 6))
ax[0,0].plot(x, x**2);        ax[0,0].set_title("x²")
ax[0,1].plot(x, np.exp(-x**2)); ax[0,1].set_title("gaussian")
ax[1,0].plot(x, np.abs(x));   ax[1,0].set_title("|x|")
ax[1,1].plot(x, 1/(1+np.exp(-x))); ax[1,1].set_title("sigmoid")
plt.tight_layout(); plt.show()
```

### 4.4 Pandas: 표 데이터

```python
import pandas as pd

df = pd.DataFrame({
    "로봇": ["A", "B", "C"],
    "속도": [120, 85, 150],
    "배터리": [87, 65, 92],
})

df["등급"] = df["속도"].apply(lambda v: "High" if v >= 120 else "Low")
print(df)
print(f"\n평균 배터리: {df['배터리'].mean():.1f}")
```

```text
  로봇   속도  배터리    등급
0  A   120    87  High
1  B    85    65   Low
2  C   150    92  High

평균 배터리: 81.3
```

## Part 6: Jetson Xavier NX로 확장

PC에서 익힌 패턴은 Jetson에서도 동일하다.

```text
PC                                Jetson Xavier NX
──────────────────────────────    ──────────────────────────────
Anaconda 설치                     Miniconda / apt로 Jupyter 설치
conda create -n jetson_env        동일
conda install numpy ...          + cuda, torch, tensorrt
jupyter notebook                  jupyter notebook --ip=0.0.0.0
브라우저: localhost:8888          PC 브라우저 → http://Jetson_IP:8888
```

### Jetson에서 원격 Jupyter 실습 (미리보기)

```bash
# Jetson에서
jupyter notebook --ip=0.0.0.0 --port=8888 --no-browser

# PC 브라우저에서
# http://192.168.0.37:8888  (Jetson IP로 접속)
```

> 자세한 Jetson 원격 실습은 다음 과정에서 다룬다. 여기서는 **"PC에서 익힌 패턴이
> 그대로 쓰인다"**는 점만 기억하면 된다.

## 문제 해결 (FAQ)

| 증상 | 해결 |
|---|---|
| `'conda'은(는) 내부 또는 외부 명령…` | **Anaconda Prompt**를 열어라 (일반 cmd 아님) |
| `'jupyter'은(는) 내부 또는 외부 명령…` | `conda activate jetson_env` → `conda install jupyter` |
| 브라우저가 안 열림 | 출력된 `http://localhost:8888/tree` 주소를 브라우저에 직접 입력 |
| 코드가 안 실행되고 `[*]` 표시 | 실행 중 → 기다림. 또는 `Kernel → Restart & Run All` |
| 한글 그래프 깨짐 | `plt.rcParams["font.family"] = "Malgun Gothic"` 추가 |
| 포트 충돌 | `jupyter notebook --port=8889` |
