## Part 11: 클래스

### 11.1 정의 · 인스턴스

```python
class Robot:
    def __init__(self, name, speed=100):
        self.name = name
        self.speed = speed
        self.battery = 100

    def move(self):
        print(f"{self.name} 이동 중 (속도 {self.speed})")

    def charge(self):
        self.battery = 100
        print(f"{self.name} 충전 완료")

r1 = Robot("로봇A", 120)
r1.move()   # 로봇A 이동 중 (속도 120)
```

### 11.2 상속

```python
class FlyingRobot(Robot):
    def __init__(self, name, speed=100):
        super().__init__(name, speed)
        self.altitude = 0

    def fly(self):
        self.altitude = 50
        print(f"{self.name} 비행 고도 {self.altitude}m")

drone = FlyingRobot("드론X", 200)
drone.move()  # 부모 메서드
drone.fly()   # 자식 메서드
```

### 11.3 실습: 계좌

```python
class Account:
    def __init__(self, owner, balance=0):
        self.owner = owner
        self.balance = balance

    def deposit(self, amount):
        self.balance += amount
        print(f"{amount}원 입금 → 잔액: {self.balance}")

    def withdraw(self, amount):
        if self.balance >= amount:
            self.balance -= amount
            print(f"{amount}원 출금 → 잔액: {self.balance}")
        else:
            print("잔액 부족")

acc = Account("홍길동", 10000)
acc.deposit(5000)     # 15000
acc.withdraw(3000)    # 12000
acc.withdraw(20000)   # 잔액 부족
```

## Part 13: 종합 실습

### 13.1 로봇 관리 시스템

```python
class RobotManager:
    def __init__(self):
        self.robots = []

    def add(self, name, speed, battery):
        self.robots.append({"name": name, "speed": speed, "battery": battery})

    def show_all(self):
        for r in self.robots:
            print(f"  {r['name']:8s} 속도:{r['speed']:4d}  배터리:{r['battery']:3d}%")

    def fastest(self):
        return max(self.robots, key=lambda r: r["speed"])

    def low_battery(self, threshold=30):
        return [r for r in self.robots if r["battery"] < threshold]


mgr = RobotManager()
mgr.add("Alpha", 120, 87)
mgr.add("Beta",  85,  25)
mgr.add("Gamma", 150, 92)
mgr.add("Delta", 95,  18)

print("=== 전체 로봇 ===")
mgr.show_all()
print(f"\n=== 최고 속도: {mgr.fastest()['name']} ===")
print("\n=== 배터리 부족 ===")
for r in mgr.low_battery():
    print(f"  {r['name']}: {r['battery']}%")
```

```text
=== 전체 로봇 ===
  Alpha     속도: 120  배터리: 87%
  Beta      속도:  85  배터리: 25%
  Gamma     속도: 150  배터리: 92%
  Delta     속도:  95  배터리: 18%

=== 최고 속도: Gamma ===

=== 배터리 부족 ===
  Beta: 25%
  Delta: 18%
```

### 13.2 숫자 맞추기 게임

target = random.randint(1, 100)

## 오류 해결 (FAQ)

| 오류 | 원인 | 해결 |
|---|---|---|
| `NameError` | 변수 미선언 | 변수 먼저 정의 |
| `SyntaxError` | 문법 오류 | 괄호, 콜론, 따옴표 확인 |
| `IndentationError` | 들여쓰기 | 4칸 공백 일관되게 |
| `TypeError` | 자료형 불일치 | `str()` 또는 f-string |
| `IndexError` | 범위 초과 | `len()`으로 확인 |
| `KeyError` | 딕셔너리 키 없음 | `key in dict`로 확인 |
| `ZeroDivisionError` | 0으로 나눔 | 분모 0 체크 |
| `ModuleNotFoundError` | 모듈 미설치 | `conda install 모듈명` |
| `[*]` 실행 안 됨 | 커널 멈춤 | `Kernel → Restart` |
