# 07. 종합 프로젝트

## 프로젝트 개요

지금까지 배운 내용을 통합하여 **AI 객체 인식 + 자율 주행 로봇** 데모를 완성합니다.

- Jetson Xavier NX: 카메라 + 객체 인식 + 제어 명령 생성
- 로봇 본체: 터틀봇 / 옴니휠 로봇
- ROS 2: 노드 간 통신
- 호스트 PC: 모니터링 및 원격 제어

---

## 팀 역할 분담

| 역할 | 업무 | 관련 장 |
| ---- | ---- | ------- |
| Vision | 카메라 캡처, 객체 인식 | 04, 05 |
| AI | TensorRT 모델 최적화 | 05 |
| Control | ROS 2 주행 제어 노드 | 06 |
| Integration | 시스템 통합, 발표 | 07 |

---

## 개발 단계

### 1단계. 기능 정의
- 인식할 객체 (예: 사람, 컵, 장애물)
- 로봇 동작 규칙 (예: 인식 → 추적/회피)

### 2단계. 개별 개발
- 인식 노드: 영상 → 객체 좌표/라벨 발행
- 제어 노드: 객체 정보 → `/cmd_vel` 변환

### 3단계. 통합
- 노드 간 토픽 연결 (`rqt_graph`로 검증)
- 실내 환경 테스트

### 4단계. 발표
- 데모 시연 + 성능 측정 + 트러블슈팅 정리

---

## 예시 노드 구성

```text
[카메라] → [객체인식 노드] → /detections → [제어 노드] → /cmd_vel → [로봇]
                                    ↘            ↗
                              /image (시각화)  호스트 PC 모니터링
```
