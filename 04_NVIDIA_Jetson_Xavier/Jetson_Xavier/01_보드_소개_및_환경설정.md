## 1. Jetson Xavier NX 하드웨어 소개

> ※ 여기에 보드 사양, 핀맵, I/O 구성에 대한 교습 내용을 작성합니다.

| 항목 | 내용 |
| ---- | ---- |
| GPU | Volta (384 CUDA cores) |
| CPU | 6-core Carmel ARMv8.2 |
| 메모리 | 8GB LPDDR4x |
| 저장장치 | microSD / NVMe |
| I/O | GPIO, I2C, UART, SPI, USB 3.1, CSI |

### 보드 핀맵 (40-Pin Header)

- 전원: 3.3V / 5V / GND
- 통신: I2C, UART, SPI
- GPIO 핀 번호와 사용 시 주의사항

---

## 2. JetPack 설치

### SDK Manager 사용법

1. NVIDIA SDK Manager 실행
2. Jetson Xavier NX 선택 → JetPack 버전 선택
3. 호스트에 CUDA/TensorRT 설치
4. microSD/디바이스에 OS 플래싱

> ※ 설치 순서 및 화면 단계별 캡처 자료를 첨부하세요.

### 부팅 확인

```bash
$ nvcc --version        # CUDA 버전 확인
$ jetson_release        # 보드 정보 확인
$ cat /etc/nv_tegra_release
```

---

## 3. SSH 원격 접속

```bash
$ sudo apt update && sudo apt install openssh-server
$ ip addr show         # Jetson IP 주소 확인
$ ssh ubuntu@<Jetson_IP>
```

> ※ VirtualBox 호스트 Ubuntu와의 네트워크 설정(브리지/같은 서브넷) 안내
