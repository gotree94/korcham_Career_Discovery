## 1. 개요

NVIDIA Jetson Xavier NX에서 **시리얼 콘솔(Serial Terminal)만 사용**해 Ubuntu의 Wi-Fi를 설정하는 방법을 정리한다.

일반적으로 **NetworkManager의 `nmcli` 명령**을 이용하면 GUI 없이도 Wi-Fi 검색, 연결, IP 확인 및 자동 연결 설정을 모두 할 수 있다.

```text
Jetson Xavier NX
      │
      │ Serial Console
      ▼
Ubuntu Terminal
      │
      ├─ 1. Wi-Fi 장치 확인
      ├─ 2. Wi-Fi 활성화
      ├─ 3. 주변 AP 검색
      ├─ 4. AP 연결
      ├─ 5. IP 주소 확인
      └─ 6. 인터넷 연결 확인
```

---

## 2. Wi-Fi 장치 인식 확인

### 2.1 NetworkManager 장치 목록 확인

```bash
nmcli device status
```

예:

```text
DEVICE    TYPE      STATE         CONNECTION
wlan0     wifi      disconnected  --
eth0      ethernet  disconnected  --
lo        loopback  unmanaged      --
```

`wlan0     wifi` 항목이 보이면 Wi-Fi 인터페이스가 인식된 것이다.

> `wlan0`은 Jetson에서 사용하는 Wi-Fi 인터페이스의 대표적인 이름이며, Wi-Fi 모듈이나 Linux 환경에 따라 이름이 다를 수 있다.

### 2.2 무선 인터페이스 직접 확인

```bash
iw dev
```

예:

```text
phy#0
    Interface wlan0
        ifindex 3
        wdev 0x1
        addr xx:xx:xx:xx:xx:xx
        type managed
```

`Interface wlan0`이 확인되면 Linux에서 Wi-Fi 인터페이스가 정상적으로 인식된 것이다.

---

## 3. Wi-Fi 활성화 확인

```bash
nmcli radio wifi
```

정상적으로 활성화되어 있으면:

```text
enabled
```

`disabled`로 나오면 Wi-Fi를 켠다.

```bash
sudo nmcli radio wifi on
```

그 후 다시 `nmcli radio wifi`로 확인한다.

---

## 4. 주변 Wi-Fi 검색

```bash
nmcli device wifi list
```

또는:

```bash
nmcli dev wifi
```

예:

```text
IN-USE  SSID        MODE   CHAN  RATE        SIGNAL
        MyHomeWiFi  Infra  36    540 Mbit/s  80
        OfficeWiFi  Infra  11    270 Mbit/s  65
        Guest       Infra  1     130 Mbit/s  45
```

여기서 연결하려는 **SSID**를 확인한다. (예: `MyHomeWiFi`)

---

## 5. Wi-Fi 연결

SSID와 비밀번호를 이용하여 연결한다.

```bash
sudo nmcli device wifi connect "MyHomeWiFi" password "12345678"
```

정상적으로 연결되면 다음과 비슷한 메시지가 출력된다.

```text
Device 'wlan0' successfully activated with 'xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx'.
```

여기서 `wlan0`이 실제 Wi-Fi 인터페이스이다.

## 6. 연결 상태 · IP · 인터넷 확인

연결 성공 메시지가 나왔다고 끝내지 말고 아래 ①~⑤를 순서대로 확인한다.

### ① 연결 상태

```bash
nmcli device status
```

정상적인 경우:

```text
DEVICE    TYPE      STATE      CONNECTION
wlan0     wifi      connected  MyHomeWiFi
eth0      ethernet  unavailable --
```

핵심은 `wlan0     wifi      connected`가 나타나는 것이다.

### ② IP 주소

```bash
ip addr show wlan0
```

예:

```text
3: wlan0:
    inet 192.168.0.25/24
```

이 경우 Jetson의 Wi-Fi IP 주소는 `192.168.0.25`이다.

더 간단하게 확인하려면:

```bash
hostname -I
```

```text
192.168.0.25
```

### ③ Gateway / DNS 정보

```bash
nmcli device show wlan0
```

여기서 다음 항목을 확인할 수 있다.

```text
IP4.ADDRESS
IP4.GATEWAY
IP4.DNS
GENERAL.CONNECTION
```

### ④ 인터넷 연결 (IP 통신)

```bash
ping -c 4 8.8.8.8
```

정상적인 경우:

```text
64 bytes from 8.8.8.8: icmp_seq=1 ttl=...
64 bytes from 8.8.8.8: icmp_seq=2 ttl=...
```

### ⑤ DNS 확인

```bash
ping -c 4 google.com
```

이 명령까지 정상 응답하면 다음 체인이 모두 정상이라는 뜻이다.

```text
Wi-Fi 연결
   ↓
DHCP
   ↓
IP 주소
   ↓
Gateway
   ↓
DNS
   ↓
Internet
```

## 7. 저장된 연결과 자동 연결 설정

### 7.1 현재 저장된 연결 확인

```bash
nmcli connection show
```

예:

```text
NAME          UUID                                  TYPE      DEVICE
MyHomeWiFi    xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx  wifi      wlan0
```

특정 연결의 상세 정보를 확인하려면:

```bash
nmcli connection show "MyHomeWiFi"
```

### 7.2 재부팅 후 자동 연결 설정

NetworkManager로 만든 Wi-Fi 연결은 연결 정보가 저장된다. 자동 연결 여부를 확인한다.

```bash
nmcli connection show "MyHomeWiFi" | grep autoconnect
```

정상적으로 설정되어 있다면:

```text
connection.autoconnect: yes
```

만약 `no`라면 다음과 같이 설정한다.

```bash
sudo nmcli connection modify "MyHomeWiFi" connection.autoconnect yes
```

이제 Jetson을 재부팅해도 해당 Wi-Fi에 자동으로 연결된다.

## 8. 핵심 `nmcli` 명령 요약표

시리얼 콘솔 + SSH 기반 임베디드 장비로 운용한다면 다음 명령들을 기억해 두면 편리하다.

| 목적 | 명령 |
|---|---|
| 네트워크 장치 확인 | `nmcli device status` |
| Wi-Fi 상태 확인 | `nmcli radio wifi` |
| Wi-Fi 켜기 | `sudo nmcli radio wifi on` |
| 주변 AP 검색 | `nmcli device wifi list` |
| Wi-Fi 연결 | `sudo nmcli device wifi connect "SSID" password "PASSWORD"` |
| 연결 정보 확인 | `nmcli connection show` |
| Wi-Fi 장치 정보 | `nmcli device show wlan0` |
| IP 주소 확인 | `ip addr show wlan0` |
| 간단한 IP 확인 | `hostname -I` |
| 인터넷 테스트 | `ping -c 4 8.8.8.8` |
| DNS 테스트 | `ping -c 4 google.com` |
| Wi-Fi 연결 해제 | `sudo nmcli device disconnect wlan0` |
| Wi-Fi 재연결 | `sudo nmcli device connect wlan0` |

## 9. 실전 예시 (실제 터미널 로그)

### 9.1 현재 네트워크 장치 확인

```text
bready@bready-desktop:~$ nmcli device status
DEVICE   TYPE      STATE                                  CONNECTION
l4tbr0   bridge    connected                              l4tbr0
docker0  bridge    connected                              docker0
wlan0    wifi      connecting (getting IP configuration)  007
eth0     ethernet  unavailable                            --
dummy0   dummy     unmanaged                              --
rndis0   ethernet  unmanaged                              --
usb0     ethernet  unmanaged                              --
lo       loopback  unmanaged                              --
bready@bready-desktop:~$
```

**분석**

```text
wlan0    wifi    connecting (getting IP configuration)    room407
```

| 항목 | 의미 |
|---|---|
| `wlan0` | Wi-Fi 인터페이스 |
| `wifi` | 무선 장치 |
| `007` | 현재 선택된 SSID |
| `connecting (getting IP configuration)` | AP에는 연결했지만 아직 IP 설정을 받는 중 |

> `getting IP configuration` 상태가 **장시간 지속**된다면 DHCP 또는 네트워크 설정을 확인할 필요가 있다.

### 9.2 주변 Wi-Fi 검색

```text
bready@bready-desktop:~$ nmcli device wifi list
IN-USE  SSID     MODE   CHAN  RATE       SIGNAL  BARS  SECURITY
        010  Infra  1     44 Mbit/s  70      ▂▄▆_  WPA2
        iptime   Infra  9     44 Mbit/s  70      ▂▄▆_  --
        007  Infra  4     44 Mbit/s  50      ▂▄__  WPA2
        006  Infra  6     44 Mbit/s  23      ▂___  WPA2
bready@bready-desktop:~$
```

| SSID | 채널 | 신호 | 보안 |
|---|---:|---:|---|
| 010 | 1 | 70 | WPA2 |
| iptime | 9 | 70 | 없음 |
| 007 | 4 | 50 | WPA2 |
| 006 | 6 | 23 | WPA2 |

여기서는 `010`의 신호가 `70`으로 비교적 강하게 검색되고 있다.

### 9.3 Wi-Fi 연결

```text
bready@bready-desktop:~$ sudo nmcli device wifi connect "010" password "11111111"
[sudo] password for bready:
Device 'wlan0' successfully activated with 'aa949f7e-8888-4444-8888-17c5cfc0e261'.
bready@bready-desktop:~$
```

핵심 명령:

```bash
sudo nmcli device wifi connect "010" password "01234567"
```

`Device 'wlan0' successfully activated with '...'` 메시지가 출력되면 **`wlan0`이 `010` AP에 성공적으로 연결된 것**이다.

## 10. 문제 해결: Wi-Fi가 검색되지 않을 때

다음 순서로 하드웨어와 드라이버를 확인한다.

### 10.1 NetworkManager 동작 확인

```bash
which nmcli
```

```bash
systemctl status NetworkManager
```

정상적인 경우:

```text
Active: active (running)
```

### 10.2 무선 인터페이스 확인

```bash
iw dev
```

### 10.3 PCI 방식 Wi-Fi 장치 확인

내장/PCIe 방식의 Wi-Fi 장치를 사용하는 경우:

```bash
lspci
```

### 10.4 USB Wi-Fi 장치 확인

USB Wi-Fi 동글을 사용하는 경우:

```bash
lsusb
```

## 11. 최종 확인 체크리스트

Wi-Fi 연결을 문제없이 구성하려면 다음 계층이 모두 정상이어야 한다.

```text
┌──────────────────────────────┐
│       Wi-Fi Access Point     │
│        (공유기 / AP)          │
└──────────────┬───────────────┘
               │
             Wi-Fi
               │
┌──────────────▼───────────────┐
│      Jetson Xavier NX        │
│                              │
│  Wi-Fi Module                │
│       ↓                      │
│  Linux Driver                │
│       ↓                      │
│  wlan0                       │
│       ↓                      │
│  NetworkManager              │
│       ↓                      │
│  nmcli                       │
│       ↓                      │
│  DHCP                        │
│       ↓                      │
│  IP / Gateway / DNS          │
└──────────────────────────────┘
```

문제가 발생했을 때는 **어느 계층에서 문제가 발생했는지**부터 확인하면 된다.

## 12. SSH 원격 접속으로 이어가기

Wi-Fi가 정상적으로 연결되고 Jetson에 IP가 할당되면 시리얼 케이블을 제거하고 다른 PC에서 SSH로 접속할 수 있다.

예를 들어 Jetson의 IP가 `192.168.0.37`이라면:

```bash
ssh 사용자이름@192.168.0.37
```

이 과정을 도식화하면:

```text
처음 설정
    │
    ▼
USB/UART Serial Console
    │
    ▼
Wi-Fi 설정
    │
    ▼
wlan0
    │
    ▼
IP 주소 획득
    │
    ▼
SSH
    │
    ▼
원격 개발 / ROS2 / Docker / AI 실행
```

> **주의:** 실제 Wi-Fi 비밀번호를 문서에 저장하거나 공유할 때는 보안에 유의한다. 위 예시는 교육용으로 제공된 값이다.

## 부록 B. 최소 명령만으로 연결하기

처음 설정 상황이라면 다음 명령만 순서대로 실행해도 된다.

```bash
nmcli device status
```

```bash
nmcli device wifi list
```

```bash
sudo nmcli device wifi connect "WiFi이름" password "WiFi비밀번호"
```

```bash
nmcli device status
```

```bash
hostname -I
```

```bash
ping -c 4 8.8.8.8
```

최종적으로 다음 체인이 모두 정상이면 Wi-Fi 설정이 완료된 것이다.

```text
wlan0
  ↓
connected
  ↓
IP 주소 획득
  ↓
Gateway 연결
  ↓
DNS 정상
  ↓
Internet 정상
```
