# 1-1. LED 점멸 제어

옴니휠 로봇 교육 과정의 첫 번째 실습으로, **I2C PWM 제어 칩(PCA9685)**과 연결된 **LED 8개**를 순차적으로 ON/OFF 시키는 방법을 배운다. 본 실습을 통해 Jetson Xavier NX에서 I2C 통신을 초기화하고, PWM 신호의 duty_cycle 개념을 이해하게 된다.

## 1. 학습 목표

- Jetson Xavier NX에서 I2C 통신 버스(busio, board)를 초기화하는 방법을 이해한다.
- PCA9685 PWM 드라이버 칩의 역할과 채널 개념을 이해한다.
- `duty_cycle` 값을 이용해 LED를 ON/OFF 제어하는 방법을 익힌다.
- PWM 주파수(frequency)가 LED 제어에 미치는 영향을 이해한다.
- for 문과 time.sleep()을 이용해 LED를 순차적으로 점멸시키는 코드를 작성한다.

## 2. 준비 사항

### 2.1 필요 하드웨어

- NVIDIA Jetson Xavier NX (JetPack 4.x, Ubuntu 18.04)
- 옴니휠 로봇 본체에 내장된 PCA9685 보드와 LED 8개(채널 0~7)
- I2C 통신 연결(SCL, SDA)

### 2.2 필요 라이브러리 (설치 명령 포함)

```bash
sudo pip3 install adafruit-circuitpython-busio adafruit-circuitpython-pca9685
```

- `busio`, `board`: CircuitPython의 I2C 통신 버스 모듈 (Adafruit Blinka에서 제공)
- `adafruit_pca9685`: PCA9685 PWM 드라이버 제어용 라이브러리
- `time`: 시간 지연을 위한 표준 라이브러리 (별도 설치 불필요)

### 2.3 사전 설정

- I2C 활성화 및 장치 접근 권한 확인:
  ```bash
  sudo chmod 666 /sys/bus/i2c/devices/i2c-0/bus_clk_rate
  i2cdetect -y -r 1
  ```
- `i2cdetect` 결과에서 PCA9685 주소 **0x40**이 검출되는지 확인한다.
- 노트북 파일이 위치한 `01. Device` 폴더가 Jupyter 작업 디렉터리인지 확인한다. (namespace package이므로 `__init__.py`는 필요 없지만, `libraries` import가 필요한 노트북에서는 작업 디렉터리가 반드시 `01. Device`여야 한다.)

## 3. 실행 방법 (셀 실행 순서 안내)

1. **[셀 1] 모듈 추가 (I2C)**: `busio`, `board` 모듈을 import 한다.
2. **[셀 2] 모듈 추가 (PWM)**: `adafruit_pca9685` 모듈을 import 한다.
3. **[셀 3] 모듈 추가 (time)**: `time` 모듈을 import 한다.
4. **[셀 4] 클래스 객체 생성**: `i2c` 객체를 생성한다.
5. **[셀 5] PCA9685 객체 생성**: `pca9685` 객체를 생성하고 주파수를 60Hz로 설정한다.
6. **[셀 6] LED 순차 ON**: 채널 0~7 LED를 0.5초 간격으로 켠다.
7. **[셀 7] LED 순차 OFF**: 채널 7~0 LED를 0.5초 간격으로 끈다.
8. **[셀 8] (빈 셀)**: 반복 실습을 위해 위 셀들을 다시 실행할 수 있다.

> 주의: 실행 순서는 반드시 위 순서대로 수행해야 한다. 셀을 임의로 건너뛰면 `pca9685` 객체가 생성되지 않아 NameError가 발생한다.

## 4. 코드 해설 (원본 코드를 단계별로 블록 인용하고, 각 줄/함수의 역할을 상세 설명)

### 4.1 모듈 추가 (셀 1~3)

```python
# I2C 통신을 위한 통신 버스 모듈 추가
import busio
import board
```

- `import busio`: I2C/UART/SPI 등 하드웨어 통신 버스를 추상화하는 CircuitPython 모듈. I2C 클래스를 제공한다.
- `import board`: Jetson 보드의 핀(SDA, SCL 등)을 Python 이름으로 매핑해주는 모듈. `board.SCL`, `board.SDA`로 실제 I2C 핀을 참조할 수 있다.

```python
# I2C PWM 제어 칩 전용 모듈 추가
import adafruit_pca9685
```

- `import adafruit_pca9685`: PCA9685 16채널 PWM 드라이버를 제어하는 라이브러리. 내부적으로 서보/모터/LED 제어에 널리 쓰인다.

```python
# 시간 지연을 위한 time 모듈 추가
import time
```

- `import time`: `time.sleep()`으로 실행을 잠시 멈추는 표준 라이브러리.

### 4.2 클래스 객체 생성 (셀 4~5)

```python
# I2C 통신을 이용하기 위해 busio의 I2C 클래스 객체 생성
i2c = busio.I2C(board.SCL, board.SDA)
```

- `busio.I2C(SCL, SDA)`: Jetson의 I2C 핀(SCL=클럭, SDA=데이터)을 이용해 I2C 통신 객체를 생성한다. 이후 모든 I2C 장치가 이 객체를 공유한다.
- 생성 시 기본 통신 속도는 100kHz이며, 첫 접근 시 자동으로 스캔/초기화된다.

```python
# PCA9685 칩을 제어하기 위해 클래스 객체 생성
pca9685 = adafruit_pca9685.PCA9685(i2c)

# PWM 주파수 주기(Hz) 설정
pca9685.frequency = 60
```

- `adafruit_pca9685.PCA9685(i2c)`: 위에서 만든 `i2c` 버스를 사용해 주소 0x40의 PCA9685 칩을 제어하는 객체를 생성한다.
- `pca9685.frequency = 60`: PWM 주파수를 60Hz로 설정한다. 60Hz이므로 1주기가 약 16.7ms가 되고, LED 점멸에 적합한 주파수다.

### 4.3 동작 제어 (셀 6~7)

```python
# 0~7까지 LED 8개를 순서대로 ON
for index in range(0, 8):
    pca9685.channels[index].duty_cycle = 4095
    time.sleep(0.5)
```

- `range(0, 8)`: 0, 1, ..., 7을 생성. 채널 0~7까지 총 8개 LED를 차례로 선택한다.
- `pca9685.channels[index]`: PCA9685의 index번째 PWM 채널 객체. 채널 0~7에 LED가 연결되어 있다.
- `duty_cycle = 4095`: duty cycle을 최댓값 4095(0x0FFF, 12비트)로 설정하면 채널이 100% ON 상태가 되어 LED가 켜진다.
- `time.sleep(0.5)`: 0.5초 대기하여 LED가 켜진 상태를 유지한다. 그 결과 LED가 왼쪽부터 오른쪽으로 하나씩 켜지는 효과가 나타난다.

```python
# 7~0까지 LED 8개를 순서대로 OFF
for index in range(8, -1, -1):
    pca9685.channels[index].duty_cycle = 0
    time.sleep(0.5)
```

- `range(8, -1, -1)`: 8, 7, ..., 0을 생성. 채널 8~0을 역순으로 선택한다. (원본 코드 그대로이며, 8번 채널은 LED가 없어 무시되지만 코드 동작에는 문제가 없다.)
- `duty_cycle = 0`: duty cycle을 0으로 설정하면 채널이 완전히 OFF 상태가 되어 LED가 꺼진다.
- `time.sleep(0.5)`: 0.5초 대기. LED가 오른쪽에서 왼쪽으로 하나씩 꺼지는 효과가 나타난다.

## 6. 주의사항 및 트러블슈팅

- **NameError: name 'pca9685' is not defined**: 셀 4~5를 실행하지 않고 셀 6을 실행하면 발생. 반드시 순서대로 실행한다.
- **I2C 장치를 찾지 못하는 경우**: `i2cdetect -y -r 1`로 PCA9685 주소 0x40이 보이는지 확인하고, 배선과 I2C 권한(`sudo chmod 666 ...`)을 점검한다.
- **셀 실행 순서 오류**: Jupyter는 커널 상태를 유지하므로, 커널을 재시작(Restart Kernel)하면 모든 객체가 사라지므로 처음부터 다시 실행해야 한다.
- **LED가 켜지지 않는 경우**: 해당 채널 번호와 duty_cycle 값을 다시 확인한다. duty_cycle 4095가 최대, 0이 OFF이다.
- **무한 반복 없음**: 이 노트북에는 while True 루프가 없으므로 정상적으로 셀이 종료된다.
