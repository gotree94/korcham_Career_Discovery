# 7. 적외선 온도 센서 모니터링

옴니휠 로봇 교육 과정에서 **I2C로 연결된 적외선 온도 센서(MLX90614)**를 이용해 주변 온도(ambient)와 물체의 온도(object)를 측정한다. MLX90614는 물체에서 방출되는 적외선을 감지하여 비접촉으로 온도를 측정하는 센서이다.

## 1. 학습 목표

- MLX90614 적외선 온도 센서의 비접촉 측정 원리를 이해한다.
- `ambient_temperature`(주변 온도)와 `object_temperature`(물체 온도)의 차이를 이해한다.
- I2C 센서 객체를 생성하고 온도 값을 읽는 방법을 익힌다.
- 무한루프 기반 실시간 모니터링 패턴을 학습한다.

## 2. 준비 사항

### 2.1 필요 하드웨어

- NVIDIA Jetson Xavier NX (JetPack 4.x, Ubuntu 18.04)
- MLX90614 적외선 온도 센서(주소 0x5A)
- I2C 통신 연결(SCL, SDA)

### 2.2 필요 라이브러리 (설치 명령 포함)

```bash
sudo pip3 install adafruit-circuitpython-busio adafruit-circuitpython-mlx90614
```

- `busio`, `board`: I2C 통신 버스 모듈
- `adafruit_mlx90614`: MLX90614 적외선 온도 센서 드라이버 라이브러리
- `time`: 시간 지연 표준 라이브러리

### 2.3 사전 설정

- I2C 활성화 및 권한 확인. `i2cdetect -y -r 1`에서 주소 **0x5A** 검출 확인.
- `01. Device` 폴더가 작업 디렉터리인지 확인한다.

## 3. 실행 방법 (셀 실행 순서 안내)

1. **[셀 1~3] 모듈 추가**: `busio`, `board`, `adafruit_mlx90614`, `time`을 import 한다.
2. **[셀 4] i2c 객체 생성**: 100kHz I2C 버스 생성.
3. **[셀 5] 센서 객체 생성**: `adafruit_mlx90614.MLX90614(i2c)`.
4. **[셀 6] 센서 값 모니터링**: 무한루프로 주변/물체 온도를 1초 간격으로 출력.
5. 실습 종료 후 커널 중지(Interrupt Kernel).

## 4. 코드 해설 (원본 코드를 단계별로 블록 인용하고, 각 줄/함수의 역할을 상세 설명)

### 4.1 모듈 추가 (셀 1~3)

```python
# I2C 통신을 위한 통신 버스 모듈 추가
import busio
import board
```

- I2C 버스 초기화 모듈.

```python
# I2C 적외선 온도 센서 전용 모듈 추가
import adafruit_mlx90614
```

- MLX90614 드라이버를 import 한다. 이 센서는 물체의 적외선 복사량을 읽어 온도로 환산하므로 접촉 없이 온도를 잴 수 있다.

```python
# 시간 지연을 위한 time 모듈 추가
import time
```

- `time.sleep()`을 위한 표준 모듈.

### 4.2 클래스 객체 생성 (셀 4~5)

```python
# I2C 통신을 이용하기 위해 busio의 I2C 클래스 객체 생성
i2c = busio.I2C(board.SCL, board.SDA, frequency = 100000)
```

- 100kHz의 I2C 버스 객체 생성.

```python
# 적외선 온도 센서를 사용하기 위해 객체 생성
mlx = adafruit_mlx90614.MLX90614(i2c)
```

- 주소 0x5A의 MLX90614 센서 객체를 생성한다. 생성 후 `mlx.ambient_temperature`와 `mlx.object_temperature` 속성을 사용할 수 있다.

### 4.3 센서 값 모니터링 (셀 6)

```python
while True:
    temp_amb = mlx.ambient_temperature
    temp_obj = mlx.object_temperature

    print("Ambent Temp: %.2f" %temp_amb)
    print("Object Temp: %.2f" %temp_obj)
    time.sleep(1)
```

- `while True:`: 실시간 측정 무한루프.
- `temp_amb = mlx.ambient_temperature`: 센서 주변 환경(센서 자체 주변) 온도를 섭씨(℃)로 읽는다.
- `temp_obj = mlx.object_temperature`: 센서가 바라보는 물체 표면의 온도를 섭씨(℃)로 읽는다.
- `print("Ambent Temp: %.2f" %temp_amb)`: 주변 온도를 소수점 2자리로 출력한다. (원본 코드의 "Ambent"는 "Ambient"의 오타로, 실행에는 문제가 없다)
- `print("Object Temp: %.2f" %temp_obj)`: 물체 온도를 소수점 2자리로 출력한다.
- `time.sleep(1)`: 1초 간격으로 측정한다.

## 5. 실행 결과 예시

```
Ambent Temp: 25.30
Object Temp: 25.40
(센서를 손바닥에 가까이 대면)
Ambent Temp: 25.50
Object Temp: 33.20
```

- 주변 온도는 크게 변하지 않지만, 물체 온도는 손(체온) 등 측정 대상에 따라 변화한다.

## 6. 주의사항 및 트러블슈팅

- **무한루프 중지**: 셀 6은 끝나지 않는다. **Kernel → Interrupt**로 중지한다.
- **센서 인식 실패**: `i2cdetect -y -r 1`에서 0x5A가 보이지 않으면 배선(SCL/SDA, 전원 3.3V/5V)을 확인한다.
- **물체 온도가 항상 주변 온도와 같음**: 측정 거리가 너무 먼 경우 물체의 적외선을 제대로 읽지 못한다. 측정 대상과 5~10cm 정도 가까이 맞춘다.
- **온도가 비현실적으로 높음/낮음**: 센서 앞에 열원(전등, 손 등)이 있거나, 측정 대상의 복사 특성(반사율)에 따라 차이가 날 수 있다.
- **접촉 오염**: 센서 앞 렌즈에 먼지나 기름이 묻으면 오차가 커진다. 부드러운 천으로 닦는다.
- **원본 오타**: "Ambent"는 "Ambient"의 오타지만 코드는 정상 동작한다. 오타를 고치려면 `print("Ambient Temp: %.2f" %temp_amb)`로 수정하면 된다.
