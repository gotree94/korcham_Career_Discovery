# 5. Flame 센서 모니터링

옴니휠 로봇 교육 과정에서 **I2C ADC/DAC 칩(PCF8591)**의 A2 핀에 연결된 Flame(화염) 센서로 불꽃 감지 여부를 측정한다. PCF8591로 읽은 아날로그 전압이 특정 임계값(1.6V) **미만**일 때 화염이 감지된 것으로 판정한다.

## 1. 학습 목표

- Flame 센서의 동작 원리(적외선 불꽃 파장을 전압 변화로 변환)를 이해한다.
- ADC 원시값을 전압값으로 변환하는 공식을 복습한다.
- 4번 실습(PIR)과 반대로 임계값 **미만**으로 감지 판정하는 논리를 이해한다.
- 센서별 임계값의 차이(민감도 조정)를 이해한다.

## 2. 준비 사항

### 2.1 필요 하드웨어

- NVIDIA Jetson Xavier NX (JetPack 4.x, Ubuntu 18.04)
- PCF8591 ADC/DAC 칩(주소 0x48)과 Flame 센서(2번 채널 A2에 연결)
- I2C 통신 연결(SCL, SDA)

### 2.2 필요 라이브러리 (설치 명령 포함)

```bash
sudo pip3 install adafruit-circuitpython-busio adafruit-circuitpython-pcf8591
```

- `busio`, `board`: I2C 통신 버스 모듈
- `adafruit_pcf8591`: PCF8591 ADC 드라이버. `pcf8591` 모듈과 `AnalogIn` 클래스 제공
- `time`: 시간 지연 표준 라이브러리

### 2.3 사전 설정

- I2C 활성화 및 권한 확인. `i2cdetect -y -r 1`에서 주소 **0x48** 검출 확인.
- `01. Device` 폴더가 작업 디렉터리인지 확인한다.

## 3. 실행 방법 (셀 실행 순서 안내)

1. **[셀 1~3] 모듈 추가**: `busio`, `board`, `adafruit_pcf8591.pcf8591`, `AnalogIn`, `time`을 import 한다.
2. **[셀 4] i2c 객체 생성**: 100kHz I2C 버스 생성.
3. **[셀 5] PCF8591 객체 생성**: `PCF.PCF8591(i2c)`.
4. **[셀 6] A2 핀 객체 생성**: `AnalogIn(pcf, PCF.A2)`.
5. **[셀 7] 센서 값 모니터링**: 전압이 1.6V 미만이면 "Flame 센서 감지됨" 출력.
6. 실습 종료 후 커널 중지(Interrupt Kernel).

## 4. 코드 해설 (원본 코드를 단계별로 블록 인용하고, 각 줄/함수의 역할을 상세 설명)

### 4.1 모듈 추가 (셀 1~3)

```python
# I2C 통신을 위한 통신 버스 모듈 추가
import busio
import board
```

- I2C 버스 초기화 모듈.

```python
# I2C AD/DA Converter 칩 전용 모듈의 내용 중 pcf8591클래스와 AnalogIn 클래스를 추가
import adafruit_pcf8591.pcf8591 as PCF
from adafruit_pcf8591.analog_in import AnalogIn
```

- `PCF`(PCF8591 클래스 + A0~A3 채널 상수)와 `AnalogIn`(아날로그 입력 클래스)을 import 한다.

```python
# 시간 지연을 위한 time 모듈 추가
import time
```

- `time.sleep()`을 위한 표준 모듈.

### 4.2 클래스 객체 생성 (셀 4~6)

```python
# I2C 통신을 이용하기 위해 busio의 I2C 클래스 객체 생성
i2c = busio.I2C(board.SCL, board.SDA, frequency = 100000)
```

- 100kHz의 I2C 버스 객체 생성.

```python
# PCF8591 칩을 제어하기 위해 클래스 객체 생성
pcf = PCF.PCF8591(i2c)
```

- 주소 0x48의 PCF8591 객체 생성.

```python
# PCF8591 칩의 2번 핀과 Flame 센서가 연결되어 있으므로 2번핀 객체 생성
pcf_in_2 = AnalogIn(pcf, PCF.A2)
```

- `AnalogIn(pcf, PCF.A2)`: PCF8591의 **A2 채널**에 연결된 Flame 센서 입력 객체를 생성한다. `pcf_in_2.value`로 0~65535 원시값을 읽는다.

### 4.3 센서 값 모니터링 (셀 7)

```python
while True:
    raw_value = pcf_in_2.value

    scaled_value = (raw_value / 65535) * pcf_in_2.reference_voltage
    
    if(scaled_value < 1.6):
        print("Flame 센서 감지됨")

    time.sleep(0.3)
```

- `while True:`: 실시간 감지 무한루프.
- `raw_value = pcf_in_2.value`: A2 채널의 ADC 원시값(0~65535)을 읽는다.
- `scaled_value = (raw_value / 65535) * pcf_in_2.reference_voltage`: 원시값을 실제 전압(V)으로 환산한다.
- `if(scaled_value < 1.6):`: **1.6V 미만**이면 화염이 감지된 것으로 판단한다. Flame 센서는 화염에 가까워질수록 출력 전압이 낮아지는 특성이 있어 임계값 미만 비교를 사용한다. (PIR의 1.6V 초과 판정과 반대)
- `print("Flame 센서 감지됨")`: 감지 시 출력.
- `time.sleep(0.3)`: 0.3초 대기 후 재측정.

## 5. 실행 결과 예시

```
(라이터/성냥불을 센서에 가까이 가져가면)
Flame 센서 감지됨
Flame 센서 감지됨
(불꽃을 치우면)
(출력 없음)
```

- 화염(적외선)이 센서에 닿으면 `Flame 센서 감지됨`이 출력된다.

## 6. 주의사항 및 트러블슈팅

- **무한루프 중지**: 셀 7은 끝나지 않는다. **Kernel → Interrupt**로 중지한다.
- **안전 주의**: 화염 실험은 반드시 불꽃을 조절 가능한 상태(라이터, 성냥 등)에서 짧게 수행하고, 로봇 주변에 가연물이 없도록 한다.
- **감지 판정 반대**: PIR(4번)은 `> 1.6`이지만 Flame은 `< 1.6`이다. 센서 특성이 다르므로 조건을 혼동하지 않도록 주의한다.
- **항상 감지됨**: 주변에 적외선 열원(햇빛, 난방기 등)이 있으면 오감지할 수 있다. 주변 환경을 점검한다.
- **값이 항상 0**: A2 핀 연결 및 `PCF.A2` 상수 확인.
- **멀티채널 혼동**: PIR은 A1, Flame은 A2에 연결되어 있다. 객체를 잘못 만들면 다른 센서를 읽는다.
