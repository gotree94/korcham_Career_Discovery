# 14. Encoder 모니터링

옴니휠 로봇 교육 과정에서 **직렬 통신**으로 Arduino의 **3개 바퀴 엔코더(오도미터)** 값을 요청·수신해 X, Y, Z 위치값을 모니터링한다. 시작 시 엔코더 초기화(리셋) 패킷(0xC2)을 보낸 뒤, 각 바퀴(MID 0x80/0x81/0x82)별로 값을 차례로 요청하는 방식이다.

## 1. 학습 목표

- 엔코더의 역할(바퀴 회전량 측정)과 오도미터(위치 추정) 개념을 이해한다.
- 엔코더 초기화 CMD(0xC2)와 오도미터 요청 CMD(0xA0)/응답 CMD(0xB0)를 이해한다.
- MID별로 요청-응답을 반복하는 멀티 센서 폴링 패턴을 익힌다.
- X/Y/Z(3바퀴) 좌표값의 의미와 갱신을 해석한다.

### 4.2 프로토콜 정의 (셀 2)

```python
Arduino_ID = 0x20
REQUEST_ODOMETER = 0xA0
ANSWER_ODOMETER = 0xB0
ENCODER_CLEAR = 0xC2

MID_ENCODER_WHEEL_1 = 0x80
MID_ENCODER_WHEEL_2 = 0x81
MID_ENCODER_WHEEL_3 = 0x82

MID_list=[MID_ENCODER_WHEEL_1,
          MID_ENCODER_WHEEL_2,     
          MID_ENCODER_WHEEL_3]
```

- `Arduino_ID = 0x20`: Arduino 고유 ID.
- `REQUEST_ODOMETER = 0xA0`: 오도미터(엔코더 위치) 값 요청 CMD.
- `ANSWER_ODOMETER = 0xB0`: 오도미터 값 응답 CMD.
- `ENCODER_CLEAR = 0xC2`: 엔코더 카운트를 **0으로 초기화**하는 제어 CMD.
- `MID_ENCODER_WHEEL_1/2/3 = 0x80/0x81/0x82`: 바퀴 1(→X), 바퀴 2(→Y), 바퀴 3(→Z 회전) 엔코더의 MID.
- `MID_list`: 세 바퀴 MID를 담은 리스트. 폴링 반복문에서 차례로 사용된다.

### 4.6 송신 함수 (셀 9)

```python
def Packet_send(_id, _cmd, _mid, _data = None):
    # 전역변수 사용
    global send_flag

    # 전송 완료 플래그 확인 
    if(send_flag==False):

        # 초기화
        send_packet.clearPacket()

        # ID 설정
        send_packet.setID(_id)

        # CMD 설정
        send_packet.setCMD(_cmd)

        # Payload 초기화
        send_packet.clearPayload()

        # MID, data 설정
        send_packet.addPayload(_mid, _data)

        # 패킷 LRC 계산
        send_packet.calcLRC_Lower()

        # 패킷을 리스트로 변환
        send_list=send_packet.packetToList()

        # 아두이노 에 패킷 리스트 전송
        Serial_Arduino.write(send_list)
        
        # 전송 완료 플래그 설정
        send_flag=True  
```

- 12/13번 실습과 동일한 요청-응답 동기화 송신 함수.
- `send_flag`가 False일 때만 전송하고 전송 후 True로 바꾼다.

### 4.7 수신 함수 (셀 10)

```python
def Packet_receive(ser):
    # 전역변수 사용
    global send_flag
    
    # 전송 완료 플래그 확인
    if(send_flag==True):
        
        # 수신받은 데이터가 없을때까지
        while ser.inWaiting() > 0:
            
            # 1바이트씩 데이터를 받음
            Arduino_Data = ser.read(1)
            
            # 데이터를 받은 경우
            if(len(Arduino_Data)>0):
                
                # 수신 패킷 리스트에 수신 데이터 저장
                recv_list.append(ord(Arduino_Data))
                
                # 패킷 종료 데이터를 받은 경우
                if(ord(Arduino_Data)==0x03):
                    
                    # 수신 받은 데이터 파싱
                    if(recv_packet.parsingList(recv_list)):
                        
                        # 파싱한 데이터를 파싱완료 리스트에 저장
                        recv_parsing_packet.append(recv_packet)
                        
                        # 패킷 리스트 초기화
                        recv_list.clear()
                        
                        # 전송 완료 플래그 해제
                        send_flag=False
                        
                        # 반복문 탈출
                        break
```

- ETX(0x03) 수신 시 `parsingList()`로 파싱하고, 성공하면 패킷을 큐에 넣고 `send_flag=False`로 돌린다.

### 4.8 수신 리스트 초기화 함수 (셀 11)

```python
def Received_packet():
    # 파싱 완료 리스트의 첫번째 패킷을 result 변수에 저장함
    result=recv_parsing_packet[0]
    
    # 저장 완료한 파싱 완료 리스트 삭제 
    del recv_parsing_packet[0]
    
    # result 변수값 반환
    return result
```

- 파싱 완료 큐의 첫 패킷을 꺼내 반환.

### 4.9 센서 데이터 저장 함수 (셀 12)

```python
# 인자값으로 Received_packet() 함수에서 반환된 값을 넣어줌
def Encoder_Data(packet):
    # 전역변수를 사용 설정
    global MID_list
    global data_wheel_1_encoder_count
    global data_wheel_2_encoder_count
    global data_wheel_3_encoder_count

    # 패킷에서 ID 추출
    packet_id=packet.getID()
    
    # 패킷에서 CMD 추출
    packet_cmd=packet.getCMD()
    
    # 추출한 ID 가 Arduino_ID 와 맞는지 확인
    if(packet_id==Arduino_ID):

        #추출한 CMD가 응답 CMD가 맞는지 확인
        if(packet_cmd==ANSWER_ODOMETER):

            # 패킷에서 Payload 값을 추출함
            for payload in packet.getPayload():

                # 추출한 MID가 Encoder 센서가 맞는지 확인
                if(payload.getID()==MID_list[0]):
                    
                    # Payload 에서 읽어온 데이터를 저장 
                    data_wheel_1_encoder_count = int(float(payload.getData()))

                elif(payload.getID()==MID_list[1]):
                    # Payload 에서 읽어온 데이터를 저장 
                    data_wheel_2_encoder_count = int(float(payload.getData()))
                    
                elif(payload.getID()==MID_list[2]):
                    # Payload 에서 읽어온 데이터를 저장 
                    data_wheel_3_encoder_count = int(float(payload.getData()))
```

- `Encoder_Data(packet)`: 수신 패킷에서 바퀴별 엔코더 카운트를 추출·저장하는 함수.
- ID가 Arduino_ID, CMD가 오도미터 응답(0xB0)일 때만 진행한다.
- `for payload in packet.getPayload()`: Payload 순회.
- `if(payload.getID()==MID_list[0])`: MID가 바퀴 1(0x80)이면...
- `data_wheel_1_encoder_count = int(float(payload.getData()))`: 해당 바퀴의 카운트를 정수로 변환해 저장한다.
- `elif(payload.getID()==MID_list[1])`: 바퀴 2(0x81) → `data_wheel_2_encoder_count`.
- `elif(payload.getID()==MID_list[2])`: 바퀴 3(0x82) → `data_wheel_3_encoder_count`.
- 각 바퀴의 카운트는 앞으로 굴리면 증가, 뒤로 굴리면 감소한다.

### 4.10 센서 값 모니터링 (셀 13)

```python
#Encoder 센서 초기화 패킷 송신
Packet_send(Arduino_ID, ENCODER_CLEAR, MID_ENCODER_WHEEL_1)

#전송 완료 플래그  해제
send_flag=False

while(True):
    # MID_list리스트에서 하나씩 mid를 가져옴
    for mid in MID_list:
        
        #데이터 요청 패킷 송신
        Packet_send(Arduino_ID, REQUEST_ODOMETER, mid)
        
        #일정 시간 대기
        time.sleep(0.1)
        
        # 응답 데이터 패킷 수신
        Packet_receive(Serial_Arduino)
        
        # 응답받은 데이터가 있을경우
        if(len(recv_parsing_packet)>0):

                # 파싱완료 리스트에서 첫번째 패킷을 가져옴
                p=Received_packet()

                # 수신한 패킷을 파싱하고 Encoder 센서 측정 값을 저장
                Encoder_Data(p)
            
    # 데이터 출력
    print("X : "+str(data_wheel_1_encoder_count)+" Y: "+str(data_wheel_2_encoder_count)+" Z : "+str(data_wheel_3_encoder_count))
                 
    # 일정시간 대기
    time.sleep(0.5)
```

- `Packet_send(Arduino_ID, ENCODER_CLEAR, MID_ENCODER_WHEEL_1)`: **시작 시 엔코더를 0으로 초기화**하는 제어 패킷(CMD 0xC2)을 전송한다.
- `send_flag=False`: 초기화 패킷은 응답을 받는 구조가 아니므로, 다음 요청을 위해 플래그를 수동으로 해제한다.
- `while(True):`: 실시간 폴링 루프.
- `for mid in MID_list:`: 바퀴 MID(0x80, 0x81, 0x82)를 하나씩 순회한다.
- `Packet_send(Arduino_ID, REQUEST_ODOMETER, mid)`: 현재 바퀴의 오도미터 값 요청.
- `time.sleep(0.1)`: 0.1초 대기. Arduino가 응답을 준비할 시간을 준다.
- `Packet_receive(Serial_Arduino)`: 응답 수신·파싱.
- `if(len(recv_parsing_packet)>0):`: 파싱 완료 패킷이 있으면 `Received_packet()`으로 꺼내 `Encoder_Data(p)`로 저장한다. 3바퀴를 차례로 폴링하며 각 카운트를 갱신한다.
- `print("X : "+str(data_wheel_1_encoder_count)+" Y: "+str(data_wheel_2_encoder_count)+" Z : "+str(data_wheel_3_encoder_count))`: 세 바퀴의 위치값(X, Y, Z)을 출력한다.
- `time.sleep(0.5)`: 0.5초 후 다시 3바퀴를 순회한다.

## 6. 주의사항 및 트러블슈팅

- **무한루프 중지**: 셀 13은 끝나지 않는다. **Kernel → Interrupt**로 중지한다.
- **포트 권한 오류**: `sudo chmod 777 /dev/ttyACM0` 실행 필요.
- **모듈 import 실패**: 작업 디렉터리가 `01. Device`인지 확인.
- **값이 계속 0**: 로봇이 정지 상태이거나, 바퀴를 직접 회전시켜 확인한다. 엔코더 초기화(0xC2)가 전송됐는지 확인한다.
- **요청 순서와 응답 순서**: 각 MID 요청 직후 0.1초 대기 후 수신하므로, 응답이 늦어지면 값 갱신이 느려진다.
- **send_flag 수동 해제**: 초기화 패킷은 응답이 없어 `send_flag`가 자동으로 풀리지 않는다. `send_flag=False` 문장을 빠뜨리면 이후 요청이 모두 멈춘다.
- **함수 정의 셀 먼저 실행**: 셀 9~12를 먼저 실행해야 한다.
