# 4. PIR 센서 모니터링

옴니휠 로봇 교육 과정에서 **I2C ADC/DAC 칩(PCF8591)**의 A1 핀에 연결된 PIR(인체 감지) 센서로 인체의 움직임을 감지한다. PCF8591의 아날로그 입력을 읽어 전압값으로 변환하고, 임계값과 비교하여 감지 여부를 판정한다.

## 1. 학습 목표

- PCF8591 ADC 칩의 아날로그 입력 채널(A0~A3) 개념을 이해한다.
- `AnalogIn` 객체를 이용해 아날로그 값을 읽고, 전압(`scaled_value`)으로 변환하는 수식을 이해한다.
- 임계 전압(1.6V)과 비교하여 PIR 센서의 감지 여부를 판정하는 방법을 익힌다.
- 무한루프 기반 실시간 모니터링 패턴을 학습한다.

## 2. 준비 사항

### 2.1 필요 하드웨어

- NVIDIA Jetson Xavier NX (JetPack 4.x, Ubuntu 18.04)
- PCF8591 ADC/DAC 칩(주소 0x48)과 PIR 센서(1번 채널 A1에 연결)
- I2C 통신 연결(SCL, SDA)

### 2.2 필요 라이브러리 (설치 명령 포함)

```bash
sudo pip3 install adafruit-circuitpython-busio adafruit-circuitpython-pcf8591
```

- `busio`, `board`: I2C 통신 버스 모듈
- `adafruit_pcf8591`: PCF8591 ADC/DAC 칩 드라이버 라이브러리. `pcf8591` 모듈과 `analog_in.AnalogIn` 클래스를 제공한다.
- `time`: 시간 지연 표준 라이브러리

### 2.3 사전 설정

- I2C 활성화 및 권한 확인. `i2cdetect -y -r 1`에서 PCF8591 주소 **0x48**이 검출되는지 확인한다.
- `01. Device` 폴더가 작업 디렉터리인지 확인한다.

## 3. 실행 방법 (셀 실행 순서 안내)

1. **[셀 1~3] 모듈 추가**: `busio`, `board`, `adafruit_pcf8591.pcf8591`, `AnalogIn`, `time`을 import 한다.
2. **[셀 4] i2c 객체 생성**: `busio.I2C`를 100kHz로 생성한다.
3. **[셀 5] PCF8591 객체 생성**: `PCF.PCF8591(i2c)` 객체를 생성한다.
4. **[셀 6] A1 핀 객체 생성**: `AnalogIn(pcf, PCF.A1)`로 PIR 센서 입력 객체를 만든다.
5. **[셀 7] 센서 값 모니터링**: 무한루프로 전압을 읽고 1.6V 이상이면 "PIR 센서 감지됨"을 출력한다.
6. 실습 종료 후 커널을 중지(Interrupt Kernel)한다.

## 4. 코드 해설 (원본 코드를 단계별로 블록 인용하고, 각 줄/함수의 역할을 상세 설명)

### 4.1 모듈 추가 (셀 1~3)

```python
# I2C 통신을 위한 통신 버스 모듈 추가
import busio
import board
```

- I2C 버스 초기화 모듈.

```python
# I2C AD/DA Converter 칩 전용 모듈의 내용 중 pcf8591클래스와 AnalogIn 클래스를 추가
import adafruit_pcf8591.pcf8591 as PCF
from adafruit_pcf8591.analog_in import AnalogIn
```

- `import adafruit_pcf8591.pcf8591 as PCF`: PCF8591 클래스와 채널 상수(A0~A3)를 `PCF`라는 이름으로 import 한다.
- `from adafruit_pcf8591.analog_in import AnalogIn`: 아날로그 입력을 읽는 `AnalogIn` 클래스를 import 한다. 이 클래스는 내부적으로 I2C를 통해 ADC 변환값과 기준 전압을 제공한다.

```python
# 시간 지연을 위한 time 모듈 추가
import time
```

- `time.sleep()`을 위한 표준 모듈.

### 4.2 클래스 객체 생성 (셀 4~6)

```python
# I2C 통신을 이용하기 위해 busio의 I2C 클래스 객체 생성
i2c = busio.I2C(board.SCL, board.SDA, frequency = 100000)
```

- `busio.I2C(SCL, SDA, frequency=100000)`: I2C 버스를 **100kHz**(표준 모드)로 생성한다. PCF8591과 같은 아날로그 칩은 기본 속도가 안정적이다.

```python
# PCF8591 칩을 제어하기 위해 클래스 객체 생성
pcf = PCF.PCF8591(i2c)
```

- 주소 0x48의 PCF8591 객체를 생성한다. 4개의 아날로그 입력(A0~A3)과 1개의 아날로그 출력(DAC)을 제공한다.

```python
# PCF8591 칩의 1번 핀과 PIR 센서가 연결되어 있으므로 1번핀 객체 생성
pcf_in_1 = AnalogIn(pcf, PCF.A1)
```

- `AnalogIn(pcf, PCF.A1)`: PCF8591의 **A1 채널**에 연결된 아날로그 입력 객체를 생성한다. PIR 센서의 출력 전압을 이 핀에서 읽는다.
- `pcf_in_1.value`로 0~65535 사이의 16비트 ADC 원시값을, `pcf_in_1.reference_voltage`로 기준 전압(일반적으로 3.3V 또는 5V)을 얻을 수 있다.

### 4.3 센서 값 모니터링 (셀 7)

```python
while True:
    raw_value = pcf_in_1.value
    
    scaled_value = (raw_value / 65535) * pcf_in_1.reference_voltage
    
    if(scaled_value > 1.6):
        print("PIR 센서 감지됨")
        
    time.sleep(0.3)
```

- `while True:`: 실시간 감지를 위한 무한루프.
- `raw_value = pcf_in_1.value`: ADC가 변환한 원시값(0~65535)을 읽는다.
- `scaled_value = (raw_value / 65535) * pcf_in_1.reference_voltage`: 원시값을 실제 전압(볼트)으로 변환한다. `raw_value/65535`로 0~1 사이의 비율로 바꾼 뒤 기준 전압을 곱한다.
- `if(scaled_value > 1.6):`: 변환된 전압이 **1.6V 초과**이면 PIR 센서가 인체를 감지한 것으로 판단한다.
- `print("PIR 센서 감지됨")`: 감지 시 콘솔에 출력한다.
- `time.sleep(0.3)`: 0.3초 대기 후 다시 측정한다.

## 5. 실행 결과 예시

```
(센서 앞을 지나가면)
PIR 센서 감지됨
PIR 센서 감지됨
(아무것도 없으면)
(출력 없음)
```

- 사람이 지나가거나 움직일 때 `PIR 센서 감지됨`이 0.3초 간격으로 출력된다.

## 6. 주의사항 및 트러블슈팅

- **무한루프 중지**: 셀 7은 끝나지 않는다. **Kernel → Interrupt**로 중지한다.
- **항상 감지됨/미감지**: `scaled_value` 값이 임계값(1.6V)과 비교하는 조건을 확인한다. PIR 센서의 전압이 낮게(예: 3.3V 기준) 나오면 임계값을 조정해볼 수 있다.
- **값이 항상 0**: A1 핀에 PIR 센서가 연결되었는지, `PCF.A1` 상수가 맞는지 확인한다. PCF8591은 멀티플렉서 방식이라 읽기 전에 채널 설정이 필요하지만 `AnalogIn`이 이를 자동 처리한다.
- **raw_value 범위**: `value`는 16비트(0~65535) 정수다. 이 값이 안정적으로 변하는지 먼저 출력해보면 디버깅에 도움이 된다.
- **I2C 스캔**: `i2cdetect -y -r 1`에서 0x48이 보이지 않으면 배선 또는 보드 전원을 점검한다.
