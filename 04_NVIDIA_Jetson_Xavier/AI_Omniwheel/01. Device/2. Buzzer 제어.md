# 2. Buzzer 제어

옴니휠 로봇 교육 과정에서 **I2C PWM 제어 칩(PCA9685)의 채널 15에 연결된 부저(Buzzer)**를 제어해 음계를 출력한다. PWM 주파수를 음계의 주파수에 맞추면 부저가 해당 음을 내는 원리를 이해하고, 간단한 멜로디(도~도)를 연주해본다.

## 1. 학습 목표

- 부저가 특정 음(주파수)을 내는 원리를 이해한다.
- PCA9685의 `frequency`를 변경하면 부저의 음높이가 바뀌는 것을 이해한다.
- duty_cycle을 절반(50%)으로 설정하면 소리가 나고, 0으로 설정하면 소리가 멈추는 것을 이해한다.
- 주파수 배열을 이용해 멜로디를 연주하는 코드를 작성한다.

## 2. 준비 사항

### 2.1 필요 하드웨어

- NVIDIA Jetson Xavier NX (JetPack 4.x, Ubuntu 18.04)
- PCA9685 보드와 **채널 15에 연결된 부저**
- I2C 통신 연결(SCL, SDA)

### 2.2 필요 라이브러리 (설치 명령 포함)

```bash
sudo pip3 install adafruit-circuitpython-busio adafruit-circuitpython-pca9685
```

- `busio`, `board`: I2C 통신 버스 모듈
- `adafruit_pca9685`: PCA9685 PWM 드라이버 라이브러리
- `time`: 시간 지연 표준 라이브러리

### 2.3 사전 설정

- I2C 활성화 및 권한 확인 (`i2cdetect -y -r 1`에서 0x40 검출 확인).
- `01. Device` 폴더가 작업 디렉터리인지 확인한다.

## 3. 실행 방법 (셀 실행 순서 안내)

1. **[셀 1~3] 모듈 추가**: `busio`, `board`, `adafruit_pca9685`, `time`을 import 한다.
2. **[셀 4] 객체 생성 + 초기화**: `i2c`, `pca9685` 객체를 생성하고 채널 15의 duty_cycle을 0으로 초기화한다.
3. **[셀 5] 멜로디 주파수 배열 정의**: `melody` 리스트에 8개 음계 주파수를 저장한다.
4. **[셀 6] 동작 제어**: `melody`의 주파수를 차례로 부저에 적용하여 멜로디를 연주한다.

## 4. 코드 해설 (원본 코드를 단계별로 블록 인용하고, 각 줄/함수의 역할을 상세 설명)

### 4.1 모듈 추가 (셀 1~3)

```python
# I2C 통신을 위한 통신 버스 모듈 추가
import busio
import board
```

- I2C 통신 버스 초기화에 필요한 모듈. `busio.I2C`와 `board.SCL`, `board.SDA`를 제공한다.

```python
# I2C PWM 제어 칩 전용 모듈 추가
import adafruit_pca9685
```

- PCA9685 칩 제어 라이브러리.

```python
# 시간 지연을 위한 time 모듈 추가
import time
```

- `time.sleep()`을 위한 표준 모듈.

### 4.2 클래스 객체 생성 및 초기화 (셀 4)

```python
# I2C 통신을 이용하기 위해 busio의 I2C 클래스 객체 생성
i2c = busio.I2C(board.SCL, board.SDA)
```

- SCL/SDA 핀으로 I2C 버스 객체를 생성한다.

```python
# PCA9685 칩을 제어하기 위해 클래스 객체 생성
pca9685 = adafruit_pca9685.PCA9685(i2c)

# Duty Cycle 값 초기화
pca9685.channels[15].duty_cycle = 0
```

- 주소 0x40의 PCA9685 객체를 생성한다.
- `pca9685.channels[15].duty_cycle = 0`: 부저가 연결된 채널 15의 duty를 0으로 설정하여 초기에는 부저가 울리지 않게 한다.

### 4.3 멜로디 주파수의 인덱스 선언 (셀 5)

```python
#          도   레   미   파   솔   라   시   도
melody = [130, 146, 164, 175, 196, 220, 247, 262]
```

- `melody` 리스트에 8개 음계의 주파수(Hz)를 저장한다. 각각 저음 도(C3, 130Hz), 레(D3, 146Hz), 미(E3, 164Hz), 파(F3, 175Hz), 솔(G3, 196Hz), 라(A3, 220Hz), 시(B3, 247Hz), 높은 도(C4, 262Hz)이다.
- 주파수가 높을수록 음이 높아진다.

### 4.4 동작 제어 (셀 6)

```python
# melody의 음을 차례대로 출력한다.
for freq in melody:
    pca9685.frequency = freq
    
    pca9685.channels[15].duty_cycle = int(4096/2)
    time.sleep(0.9)
    
    pca9685.channels[15].duty_cycle = 0
    time.sleep(0.1)
```

- `for freq in melody`: melody 배열의 주파수 값을 하나씩 `freq`에 담아 반복한다.
- `pca9685.frequency = freq`: PWM 주파수를 현재 음계 주파수로 변경한다. 이 주파수가 부저의 진동수와 맞아야 해당 음이 난다.
- `pca9685.channels[15].duty_cycle = int(4096/2)`: 4096/2 = 2048, 즉 duty를 50%로 설정한다. PWM이 교대로 ON/OFF되어 부저가 진동하며 소리가 난다. (ON/OFF 비율이 50:50일 때 가장 큰 음량이 나온다)
- `time.sleep(0.9)`: 0.9초 동안 해당 음을 유지해 소리를 낸다.
- `pca9685.channels[15].duty_cycle = 0`: duty를 0으로 설정해 부저를 끈다.
- `time.sleep(0.1)`: 0.1초 동안 무음 상태로 유지하여 각 음 사이에 짧은 휴지(쉼표)를 둔다.
- 결과적으로 "도 레 미 파 솔 라 시 도"가 0.9초씩 연주된다.

## 6. 주의사항 및 트러블슈팅

- **소리가 나지 않는 경우**: `pca9685.channels[15].duty_cycle = int(4096/2)`가 실행되었는지 확인한다. duty가 0이면 소리가 나지 않는다.
- **음이 깨지거나 안 들리는 경우**: `pca9685.frequency`가 해당 음의 주파수로 정확히 설정됐는지 확인하고, 부저의 전원/배선 연결 상태를 점검한다.
- **셀 순서 오류**: `pca9685` 객체를 생성하기 전에 셀 6을 실행하면 NameError가 발생한다.
- **50% duty의 의미**: `int(4096/2)` = 2048. 4096은 PCA9685의 12비트 최대 카운트로, 절반이면 50% 듀티가 되어 소리가 가장 선명하다.
- **마지막에 부저가 계속 울리는 경우**: 커널을 재시작하거나, 별도 셀에서 `pca9685.channels[15].duty_cycle = 0`을 실행해 정지한다.
