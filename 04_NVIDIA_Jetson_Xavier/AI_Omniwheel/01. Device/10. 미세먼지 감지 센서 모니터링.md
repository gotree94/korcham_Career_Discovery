# 10. 미세먼지 감지 센서 모니터링

옴니휠 로봇 교육 과정에서 **PCF8591의 A0 핀(아날로그 입력)**과 **Jetson GPIO `SPI3_CS1_N` 핀(센서 내부 LED 제어)**을 함께 사용하여 미세먼지 감지 센서의 값을 측정한다. 적외선 LED를 켠 뒤 산란되는 빛의 세기로 미세먼지 농도에 비례하는 전압을 읽는 방식이다.

## 1. 학습 목표

- 미세먼지 감지 센서의 동작 원리(적외선 산란 방식)를 이해한다.
- GPIO 출력으로 센서 내부 LED를 켜고 끄는 타이밍을 제어하는 방법을 익힌다.
- PCF8591 A0 채널의 아날로그 값을 읽어 전압으로 변환하는 방법을 복습한다.
- `GPIO.setmode()`가 `GPIO.setup()`보다 먼저 실행되어야 하는 이유를 이해한다.

## 2. 준비 사항

### 2.1 필요 하드웨어

- NVIDIA Jetson Xavier NX (JetPack 4.x, Ubuntu 18.04)
- 미세먼지 감지 센서 (PCF8591 A0 핀 + GPIO `SPI3_CS1_N` 핀 연결)
- PCF8591 ADC/DAC 칩(주소 0x48)
- I2C 통신(SCL, SDA) 및 GPIO 배선

### 2.2 필요 라이브러리 (설치 명령 포함)

```bash
sudo pip3 install adafruit-circuitpython-busio adafruit-circuitpython-pcf8591 Jetson.GPIO
```

- `busio`, `board`: I2C 통신 버스 모듈
- `adafruit_pcf8591`: PCF8591 ADC 드라이버. `pcf8591` 모듈과 `AnalogIn` 클래스 제공
- `Jetson.GPIO`: GPIO 핀 제어 라이브러리
- `time`: 시간 지연 표준 라이브러리

### 2.3 사전 설정

- I2C 활성화 및 권한 확인. `i2cdetect -y -r 1`에서 주소 **0x48** 검출 확인.
- GPIO 접근 권한 및 udev 룰 설정 확인. (3번 실습의 사전 설정 참고)
- `01. Device` 폴더가 작업 디렉터리인지 확인한다.

## 3. 실행 방법 (셀 실행 순서 안내)

1. **[셀 1~4] 모듈 추가**: `busio`, `board`, `adafruit_pcf8591.pcf8591`, `AnalogIn`, `Jetson.GPIO`, `time`을 import 한다.
2. **[셀 5] GPIO 핀 설정**: `Light` 핀(`SPI3_CS1_N`)을 출력 모드로 설정하고 HIGH로 초기화한다.
   - ⚠ 원본 노트북에는 `GPIO.setmode(GPIO.TEGRA_SOC)` 문장이 없다. **`GPIO.setup()` 호출 전에 `GPIO.setmode(GPIO.TEGRA_SOC)`를 반드시 실행해야 한다.** 원본 그대로 실행하면 핀 모드 미지정으로 오류가 날 수 있다.
3. **[셀 6] i2c 객체 생성**: 100kHz I2C 버스 생성.
4. **[셀 7] PCF8591 객체 생성**: `PCF.PCF8591(i2c)`.
5. **[셀 8] A0 핀 객체 생성**: `AnalogIn(pcf, PCF.A0)`.
6. **[셀 9] 센서 값 모니터링**: 무한루프로 LED 점등→측정→소등→출력 사이클을 반복.
7. 실습 종료 후 커널 중지(Interrupt Kernel).

## 4. 코드 해설 (원본 코드를 단계별로 블록 인용하고, 각 줄/함수의 역할을 상세 설명)

### 4.1 모듈 추가 (셀 1~4)

```python
# I2C 통신을 위한 통신 버스 모듈 추가
import busio
import board
```

- I2C 버스 초기화 모듈.

```python
# I2C AD/DA Converter 칩 전용 모듈의 내용 중 pcf8591클래스와 AnalogIn 클래스를 추가
import adafruit_pcf8591.pcf8591 as PCF
from adafruit_pcf8591.analog_in import AnalogIn
```

- PCF8591 클래스/채널 상수와 `AnalogIn` 아날로그 입력 클래스를 import 한다.

```python
# GPIO핀 사용을 위한 Jetson GPIO 모듈 추가
import Jetson.GPIO as GPIO
```

- 센서 내부 적외선 LED를 제어하기 위한 GPIO 라이브러리를 import 한다. (3번 실습과 동일)

```python
# 시간 지연을 위한 time 모듈 추가
import time
```

- `time.sleep()`을 위한 표준 모듈.

### 4.2 핀 설정 (셀 5)

```python
# 센서 LED가 연결된 핀 정의
Light = 'SPI3_CS1_N'

# 센서 LED가 연결된 핀 출력 설정 및 초기화
GPIO.setup(Light, GPIO.OUT)
GPIO.output(Light, GPIO.HIGH)
```

- `Light = 'SPI3_CS1_N'`: 미세먼지 센서의 적외선 LED 제어용 GPIO 핀을 Tegra 이름으로 정의한다.
- `GPIO.setup(Light, GPIO.OUT)`: 해당 핀을 출력 모드로 설정한다.
- `GPIO.output(Light, GPIO.HIGH)`: LED를 꺼둔 상태(HIGH)로 초기화한다. 이 센서는 **LOW일 때 LED가 켜지는** active-low 방식이다.
- ⚠ **원본 코드에는 `GPIO.setmode(GPIO.TEGRA_SOC)`가 없다.** GPIO를 사용하기 전에 모드를 설정하지 않으면 오류가 발생하므로, 위 셀 이전에 `GPIO.setmode(GPIO.TEGRA_SOC)`를 실행해야 한다. (예: `GPIO.setwarnings(False)` 줄 근처에 추가)

### 4.3 클래스 객체 생성 (셀 6~8)

```python
# I2C 통신을 이용하기 위해 busio의 I2C 클래스 객체 생성
i2c = busio.I2C(board.SCL, board.SDA, frequency = 100000)
```

- 100kHz의 I2C 버스 객체 생성.

```python
# PCF8591 칩을 제어하기 위해 클래스 객체 생성
pcf = PCF.PCF8591(i2c)
```

- 주소 0x48의 PCF8591 객체 생성.

```python
# PCF8591 칩의 0번 핀과 미세먼지 센서가 연결되어 있으므로 0번핀 객체 생성
pcf_in_0 = AnalogIn(pcf, PCF.A0)
```

- `AnalogIn(pcf, PCF.A0)`: PCF8591의 **A0 채널**에 연결된 미세먼지 센서의 아날로그 입력 객체를 생성한다. 센서가 산란된 적외선의 세기를 전압으로 출력하면 이 핀에서 읽는다.

### 4.4 센서 값 모니터링 (셀 9)

```python
while True:
    GPIO.output(Light, GPIO.LOW)

    time.sleep(0.00028)
    raw_value = pcf_in_0.value
    scaled_value = (raw_value / 65535) * pcf_in_0.reference_voltage

    time.sleep(0.00004)
    GPIO.output(Light, GPIO.HIGH)

    time.sleep(0.00968)
    print("미세먼지량 : %.2f"%scaled_value)
```

- `while True:`: 실시간 측정 무한루프.
- `GPIO.output(Light, GPIO.LOW)`: GPIO를 LOW로 바꿔 센서 내부 적외선 LED를 켠다.
- `time.sleep(0.00028)`: 0.28ms 대기. LED가 켜진 뒤 적외선 산란 신호가 안정화되도록 잠시 기다린다.
- `raw_value = pcf_in_0.value`: A0 채널의 ADC 원시값(0~65535)을 읽는다. 미세먼지가 많을수록 산란광이 강해져 전압이 높아진다.
- `scaled_value = (raw_value / 65535) * pcf_in_0.reference_voltage`: 원시값을 실제 전압(V)으로 환산한다. 이 값이 곧 미세먼지량 지표이다.
- `time.sleep(0.00004)`: 0.04ms 대기 후 LED를 끄기 직전까지 측정 상태를 유지한다.
- `GPIO.output(Light, GPIO.HIGH)`: GPIO를 HIGH로 바꿔 적외선 LED를 끈다.
- `time.sleep(0.00968)`: 9.68ms 대기. LED를 끈 뒤 다음 측정 사이클 전에 센서가 리셋될 시간을 준다. (약 10ms 주기의 펄스 구동)
- `print("미세먼지량 : %.2f"%scaled_value)`: 측정된 전압값을 소수점 2자리로 출력한다.

## 6. 주의사항 및 트러블슈팅

- **무한루프 중지**: 셀 9는 끝나지 않는다. **Kernel → Interrupt**로 중지한다.
- **setmode 누락(중요)**: 원본 셀에는 `GPIO.setmode()`가 없다. `GPIO.setup()` 전에 `GPIO.setmode(GPIO.TEGRA_SOC)`를 실행하지 않으면 "Please set pin numbering mode" 오류가 발생한다. 커널을 재시작한 경우에도 setmode는 초기화되므로 다시 실행해야 한다.
- **`time.sleep`은 부동소수점 대기**: 0.00028초(0.28ms) 같은 짧은 대기가 GPIO 타이밍과 센서 펄스 특성을 맞추기 위해 사용된다. 값을 임의로 크게 바꾸면 측정이 부정확해질 수 있다.
- **값이 항상 낮음**: LED가 켜지는지(`GPIO.output(Light, GPIO.LOW)` 후 전압 상승 확인), A0 채널 연결이 맞는지 확인한다.
- **값이 항상 높음/포화**: 센서 렌즈가 오염되었거나, GPIO 상태가 HIGH로 고정되어 LED가 항상 켜져 있을 수 있다.
- **GPIO 권한 오류**: udev 룰이 설정되지 않으면 PermissionError가 발생한다. 3번 실습의 사전 설정을 참고한다.
