# 1-2. LED 밝기 제어

옴니휠 로봇 교육 과정의 두 번째 실습으로, **I2C PWM 제어 칩(PCA9685)**과 연결된 **LED 8개의 밝기를 점점 밝아지게/어두워지게** 제어한다. 1-1 실습에서 ON/OFF만 제어했다면, 이번 실습에서는 duty_cycle 값을 연속적으로 변화시켜 **PWM의 아날로그적 특성**을 이해한다.

## 1. 학습 목표

- PWM의 **duty cycle(듀티 사이클)** 개념을 이해하고, 이것이 LED 밝기를 결정하는 원리를 안다.
- `duty_cycle` 값을 0→4095로, 4095→0으로 변화시키며 밝기 변화를 관찰한다.
- 중첩 for 문을 사용해 여러 채널을 동시에 제어하는 방법을 익힌다.
- 아날로그 출력이 없는 디지털 장치에서 PWM으로 밝기를 흉내내는 방법을 이해한다.

## 2. 준비 사항

### 2.1 필요 하드웨어

- NVIDIA Jetson Xavier NX (JetPack 4.x, Ubuntu 18.04)
- PCA9685 보드와 LED 8개(채널 0~7)
- I2C 통신 연결(SCL, SDA)

### 2.2 필요 라이브러리 (설치 명령 포함)

```bash
sudo pip3 install adafruit-circuitpython-busio adafruit-circuitpython-pca9685
```

### 2.3 사전 설정

- I2C 활성화 및 권한 확인 (`i2cdetect -y -r 1`에서 0x40 검출 확인).
- `01. Device` 폴더가 작업 디렉터리인지 확인한다.

## 3. 실행 방법 (셀 실행 순서 안내)

1. **[셀 1~3] 모듈 추가**: `busio`, `board`, `adafruit_pca9685`, `time`을 import 한다.
2. **[셀 4~5] 클래스 객체 생성**: `i2c`와 `pca9685` 객체를 생성하고 주파수를 60Hz로 설정한다.
3. **[셀 6] 밝아지기**: 8개 LED의 밝기를 duty 0→4095까지 서서히 밝아지게 한다.
4. **[셀 7] 어두워지기**: 8개 LED의 밝기를 duty 4095→0까지 서서히 어두워지게 한다.
5. **[셀 8] (빈 셀)**: 필요 시 반복 실행한다.

- `time.sleep()`을 위한 표준 모듈.

```python
# I2C 통신을 이용하기 위해 busio의 I2C 클래스 객체 생성
```

### 4.2 동작 제어 (셀 6~7)

```python
# 8개의 LED 밝기를 점점 밝아지게 함
for duty in range(0, 4096):
    for index in range(0, 8):
        pca9685.channels[index].duty_cycle = duty
    time.sleep(0.0005)
```

- `for duty in range(0, 4096)`: duty 값이 0, 1, 2, ..., 4095까지 총 4096단계로 증가한다. 이 값이 곧 밝기 단계이다.
- `for index in range(0, 8)`: 채널 0~7, 즉 LED 8개를 순회한다.
- `pca9685.channels[index].duty_cycle = duty`: 8개 LED 모두에 현재 duty 값을 동시에 적용한다. duty가 클수록 LED가 밝게 켜진다. 즉 4096단계에 걸쳐 LED가 점점 밝아진다.
- `time.sleep(0.0005)`: 각 단계마다 0.5ms 대기하여 사람 눈에 밝기가 부드럽게 변하는 것처럼 보이게 한다. 대기 시간이 너무 짧으면 밝기 변화가 한 번에 완료되어 보인다.

```python
# 8개의 LED 밝기를 점점 어두워지게 함
for duty in range(4095, -1, -1):
    for index in range(0, 8):
        pca9685.channels[index].duty_cycle = duty
    time.sleep(0.0005)
```

- `range(4095, -1, -1)`: duty가 4095, 4094, ..., 0으로 감소한다. 즉 밝기가 최대에서 최소로 내려간다.
- 내부 for 문과 `time.sleep(0.0005)`는 위와 동일하며, 결과적으로 LED가 점점 어두워진다.
- 전체적으로 0→4095 증가(밝아짐)와 4095→0 감소(어두워짐)를 합쳐 LED 밝기가 서서히 올라갔다 내려가는 페이드 인/아웃 효과가 나타난다.

## 6. 주의사항 및 트러블슈팅

- **밝기 변화가 너무 빠르게 보이는 경우**: `time.sleep(0.0005)` 값을 더 크게(예: 0.005) 늘리면 변화가 천천히 보인다.
- **한쪽만 켜지는 경우**: 내부 for 문이 채널 0~7 전부에 duty를 적용하는지 확인한다. index 범위를 바꾸면 특정 채널만 제어된다.
- **duty 최대값**: PCA9685는 12비트 해상도이므로 duty_cycle의 유효 범위는 0~4095이다. 4096 이상의 값을 넣으면 의도와 다른 동작을 할 수 있다.
- **1-1과 달리 멀티턴 루프가 길다**: 셀 6~7은 각각 4096회 반복되므로 실행이 끝날 때까지 몇 초 걸린다. 중간에 멈추려면 커널 중지(Interrupt Kernel)를 사용한다.
- **커널 재시작 후에는 셀 1~5를 다시 실행**해야 한다.
