# 12. PSD 센서 모니터링

옴니휠 로봇 교육 과정에서 **직렬 통신(USB-UART)**으로 연결된 Arduino(마스터 보드)에 PSD(거리 측정) 센서 값 요청 패킷을 보내고, 응답 패킷을 수신하여 3개의 PSD 거리값(앞/옆/뒤)을 모니터링한다. 12~15번 실습부터는 옴니휠 통신 프로토콜(`libraries.Omniwheel_Protocol`)을 사용한다.

## 1. 학습 목표

- 옴니휠 통신 프로토콜의 패킷 구조(STX/ID/Length/CMD/Payload/LRC/ETX)를 이해한다.
- `Omniwheel_Protocol.Packet` 클래스의 송신(`setID`, `setCMD`, `addPayload`, `calcLRC_Lower`, `packetToList`) 및 수신(`parsingList`) 메서드를 이해한다.
- pyserial을 이용해 `/dev/ttyACM0`(115200 baud)로 통신하는 방법을 익힌다.
- CMD 체계(0xA1 요청/0xB1 응답)와 MID 체계(0x81 = PSD)를 이해한다.
- 수신된 ASCII 문자열을 3자리씩 분할해 거리값 배열로 변환하는 방법을 익힌다.

### 4.5 송신 함수 (셀 9)

```python
def Packet_send(_id, _cmd, _mid, _data = None):
    # 전역변수 사용
    global send_flag
    
    # 전송 완료 플래그 확인 
    if(send_flag==False):
        
        # 초기화
        send_packet.clearPacket()
        
        # ID 설정
        send_packet.setID(_id)
        
        # CMD 설정
        send_packet.setCMD(_cmd)
        
        # Payload 초기화
        send_packet.clearPayload()
        
        # MID, data 설정
        send_packet.addPayload(_mid, _data)
        
        # 패킷 LRC 계산
        send_packet.calcLRC_Lower()
        
        # 패킷을 리스트로 변환
        send_list=send_packet.packetToList()
        
        # Arduino 에 패킷 리스트 전송
        Serial_Arduino.write(send_list)
        
        # 전송 완료 플래그 설정
        send_flag=True
```

- `def Packet_send(_id, _cmd, _mid, _data = None)`: 패킷 송신 함수. ID, CMD, MID(및 선택 데이터)를 인자로 받는다.
- `global send_flag`: 함수 안에서 전역 플래그를 변경하기 위해 선언.
- `if(send_flag==False)`: 이전 요청의 응답을 아직 안 받았으면(send_flag=True) 새 패킷을 보내지 않는다. **요청-응답 일대일 동기화**를 위한 장치다.
- `send_packet.clearPacket()`: 패킷 내부를 초기화한다.
- `send_packet.setID(_id)`: 패킷의 ID 필드를 Arduino_ID로 설정.
- `send_packet.setCMD(_cmd)`: CMD 필드를 설정.
- `send_packet.clearPayload()`: Payload 리스트를 비우고 Length를 CMD(1)만큼 초기화.
- `send_packet.addPayload(_mid, _data)`: Payload에 MID와 데이터를 추가한다. 데이터가 None이면 MID만 포함된다. (이 실습은 센서 요청이므로 데이터 없음)
- `send_packet.calcLRC_Lower()`: CMD+Payload의 합에 대한 보수를 계산하여 2자리 대문자 LRC 검사 코드를 생성한다.
- `send_list=send_packet.packetToList()`: 완성된 패킷을 바이트 리스트로 변환한다. 결과는 `[STX, ID, Length 10자리×2, CMD, Payload, LRC 2자리, ETX]` 형태다.
- `Serial_Arduino.write(send_list)`: 변환된 패킷을 시리얼로 전송한다.
- `send_flag=True`: 응답 대기 상태로 플래그를 변경한다.

### 4.6 수신 함수 (셀 10)

```python
def Packet_receive(ser):
    # 전역변수 사용
    global send_flag
    
    # 전송 완료 플래그 확인
    if(send_flag==True):
        
        # 수신받은 데이터가 없을때까지
        while ser.inWaiting() > 0:
            
            # 1바이트씩 데이터를 받음
            Arduino_Data = ser.read(1)
            
            # 데이터를 받은 경우
            if(len(Arduino_Data)>0):
                
                # 수신 패킷 리스트에 수신 데이터 저장
                recv_list.append(ord(Arduino_Data))
                
                # 패킷 종료 데이터를 받은 경우
                if(ord(Arduino_Data)==0x03):
                    
                    # 수신 받은 데이터 파싱
                    if(recv_packet.parsingList(recv_list)):
                        
                        # 파싱한 데이터를 파싱완료 리스트에 저장
                        recv_parsing_packet.append(recv_packet)
                        
                        # 패킷 리스트 초기화
                        recv_list.clear()
                        
                        # 전송 완료 플래그 해제
                        send_flag=False
                        
                        # 반복문 탈출
                        break
```

- `def Packet_receive(ser)`: 수신 함수. 포트 객체를 인자로 받는다.
- `if(send_flag==True)`: 요청을 보낸 상태(send_flag=True)일 때만 수신을 시도한다.
- `while ser.inWaiting() > 0`: 수신 버퍼에 데이터가 남아 있는 동안 반복한다.
- `Arduino_Data = ser.read(1)`: 1바이트씩 읽는다.
- `if(len(Arduino_Data)>0)`: 실제 데이터가 들어왔는지 확인.
- `recv_list.append(ord(Arduino_Data))`: 바이트를 정수값으로 변환해 `recv_list`에 추가한다. (ord는 bytes의 정수 값을 돌려준다)
- `if(ord(Arduino_Data)==0x03)`: **ETX**(0x03)를 받으면 한 패킷이 끝났음을 의미한다.
- `if(recv_packet.parsingList(recv_list))`: 지금까지 모은 바이트 리스트를 `parsingList()`로 파싱한다. STX(0x02) 시작/ETX 종료 검사, ID/CMD 추출, Payload 분할, LRC 검증을 수행하고 참/거짓을 반환한다.
- `recv_parsing_packet.append(recv_packet)`: 파싱 성공한 패킷 객체를 완료 리스트에 저장한다.
- `recv_list.clear()`: 다음 패킷 수신을 위해 원시 리스트를 비운다.
- `send_flag=False`: 응답을 받았으므로 다음 요청을 보낼 수 있게 플래그를 해제한다.
- `break`: 패킷이 끝났으므로 while을 빠져나온다.

### 4.7 수신 리스트 초기화 함수 (셀 11)

```python
def Received_packet():
    # 파싱 완료 리스트의 첫번째 패킷을 result 변수에 저장함
    result=recv_parsing_packet[0]
    
    # 저장 완료한 파싱 완료 리스트 삭제 
    del recv_parsing_packet[0]
    
    # result 변수값 반환
    return result
```

- `Received_packet()`: 파싱 완료 리스트의 **첫 번째 패킷을 꺼내 반환**하는 함수. 반환한 뒤 해당 항목을 삭제하므로 리스트가 큐(Queue)처럼 동작한다.

### 4.8 센서 데이터 저장 함수 (셀 12)

```python
# 인자값으로 Received_packet() 함수에서 반환된 값을 넣어줌
def PSD_Data(packet):
    
    #전역함수 사용
    global data_PSD_Sensor
    
    # 패킷에서 ID 추출
    packet_id=packet.getID()
    
    # 패킷에서 CMD 추출
    packet_cmd=packet.getCMD()
    
    # 추출한 ID 가 Arduino_ID 와 맞는지 확인
    if(packet_id==Arduino_ID):
        
        #추출한 CMD가 응답 CMD가 맞는지 확인
        if(packet_cmd==ANSWER_PSD_SENSOR):
            
            # 패킷에서 Payload 값을 추출함
            for payload in packet.getPayload():
                
                # 추출한 MID가 PSD 센서가 맞는지 확인
                if(payload.getID()==MID_PSD_SENSOR):
                    
                    # Payload 에서 읽어온 데이터를 버퍼에 저장 
                    buf=str(payload.getData())
                    
                    # 버퍼에 있는 데이터 값(PSD 센서 거리 값) 을 확인할수 있게 배열로 나누어 저장 
                    data_PSD_Sensor = [int(float(buf[:3])), int(float(buf[3:6])), int(float(buf[6:]))]
```

- `def PSD_Data(packet)`: 수신 패킷에서 PSD 거리값을 추출·저장하는 함수.
- `global data_PSD_Sensor`: 전역 변수 사용 선언.
- `packet_id=packet.getID()`: 수신 패킷의 ID를 추출.
- `packet_cmd=packet.getCMD()`: 수신 패킷의 CMD를 추출.
- `if(packet_id==Arduino_ID)`: 보낸 상대가 Arduino인지 확인.
- `if(packet_cmd==ANSWER_PSD_SENSOR)`: CMD가 PSD **응답**(0xB1)인지 확인.
- `for payload in packet.getPayload()`: 패킷 안의 Payload 객체를 순회한다.
- `if(payload.getID()==MID_PSD_SENSOR)`: Payload의 MID가 PSD(0x81)인지 확인.
- `buf=str(payload.getData())`: Payload에 들어 있는 데이터(거리값이 이어붙은 ASCII 문자열)를 문자열로 변환한다.
- `data_PSD_Sensor = [int(float(buf[:3])), int(float(buf[3:6])), int(float(buf[6:]))]`: 문자열을 **3자리씩 분할**해 각각 정수로 변환한 뒤 배열에 저장한다. 앞쪽 3자리=앞 거리, 중간 3자리=옆 거리, 뒤 3자리=뒤 거리. (`buf[:3]`, `buf[3:6]`, `buf[6:]` 슬라이싱)

### 4.9 센서 값 모니터링 (셀 13)

```python
while(True):
    # 데이터 요청 패킷 송신
    Packet_send(Arduino_ID, REQUEST_PSD_SENSOR, MID_PSD_SENSOR)
    
    # 응답 데이터 패킷 수신
    Packet_receive(Serial_Arduino)
    
    # 응답받은 데이터가 있을경우
    if(len(recv_parsing_packet) > 0):
        
        # 파싱완료 리스트에서 첫번째 패킷을 가져옴
        p=Received_packet()
        
        # 수신한 패킷을 파싱하고 PSD 센서 거리값을 저장
        PSD_Data(p)
        
        # 데이터 출력
        print("PSD : "+str(data_PSD_Sensor))
        
    # 일정시간 대기
    time.sleep(0.5)
```

- `while(True):`: 실시간 모니터링 무한루프.
- `Packet_send(Arduino_ID, REQUEST_PSD_SENSOR, MID_PSD_SENSOR)`: PSD 센서 값 요청 패킷을 전송한다. (send_flag가 False일 때만)
- `Packet_receive(Serial_Arduino)`: 응답 패킷을 수신·파싱한다.
- `if(len(recv_parsing_packet) > 0)`: 정상 파싱된 패킷이 있으면 처리한다.
- `p=Received_packet()`: 파싱 완료된 첫 패킷을 꺼낸다.
- `PSD_Data(p)`: PSD 거리값을 `data_PSD_Sensor` 배열에 저장한다.
- `print("PSD : "+str(data_PSD_Sensor))`: [앞, 옆, 뒤] 거리 배열을 출력한다.
- `time.sleep(0.5)`: 0.5초 후 다음 요청을 보낸다.

## 6. 주의사항 및 트러블슈팅

- **무한루프 중지**: 셀 13은 끝나지 않는다. **Kernel → Interrupt**로 중지한다.
- **"connect complete"가 안 뜨는 경우**: `/dev/ttyACM0` 존재 여부, USB 연결 상태를 확인한다. 포트가 다르면 `ls /dev/ttyACM*`로 확인한다.
- **PermissionError**: `sudo chmod 777 /dev/ttyACM0` 실행이 필요하다.
- **모듈 import 실패**: 작업 디렉터리가 `01. Device`가 아니면 `libraries` import가 실패한다.
- **값이 갱신되지 않음**: `send_flag`가 True로 고정되면 요청이 중단된다. `Packet_receive`가 ETX(0x03)를 받지 못하면 send_flag가 해제되지 않는다. 시리얼 연결과 펌웨어를 점검한다.
- **ValueError**: `buf`가 9자리보다 짧거나 숫자가 아니면 변환 오류가 난다. 수신 패킷의 데이터 형식을 확인한다.
- **반드시 함수 정의 셀(9~12)을 먼저 실행**해야 모니터링 셀에서 함수를 호출할 수 있다.
