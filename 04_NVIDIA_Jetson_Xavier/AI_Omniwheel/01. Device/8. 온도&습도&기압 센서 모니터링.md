# 8. 온도/습도/기압 센서 모니터링

옴니휠 로봇 교육 과정에서 **I2C로 연결된 온도/습도/기압 센서(BME280)**를 이용해 온도(℃), 습도(%), 기압(hPa)을 동시에 측정한다. BME280 하나로 세 가지 환경 데이터를 얻을 수 있는 통합 환경 센서이다.

## 1. 학습 목표

- BME280 센서의 온도/습도/기압 측정 원리를 이해한다.
- `adafruit_bme280` 라이브러리를 사용해 3가지 값을 읽는 방법을 익힌다.
- I2C 주소 0x76을 객체 생성 시 명시적으로 지정하는 방법을 이해한다.
- 무한루프 기반 실시간 모니터링 패턴을 학습한다.

## 2. 준비 사항

### 2.1 필요 하드웨어

- NVIDIA Jetson Xavier NX (JetPack 4.x, Ubuntu 18.04)
- BME280 온도/습도/기압 센서(주소 0x76)
- I2C 통신 연결(SCL, SDA)

### 2.2 필요 라이브러리 (설치 명령 포함)

```bash
sudo pip3 install adafruit-circuitpython-busio adafruit-circuitpython-bme280
```

- `busio`, `board`: I2C 통신 버스 모듈
- `adafruit_bme280`: BME280 센서 드라이버 라이브러리. `basic` 서브모듈에서 `Adafruit_BME280_I2C` 클래스를 제공한다.
- `time`: 시간 지연 표준 라이브러리

### 2.3 사전 설정

- I2C 활성화 및 권한 확인. `i2cdetect -y -r 1`에서 주소 **0x76** 검출 확인.
- `01. Device` 폴더가 작업 디렉터리인지 확인한다.

## 3. 실행 방법 (셀 실행 순서 안내)

1. **[셀 1~3] 모듈 추가**: `busio`, `board`, `adafruit_bme280.basic`, `time`을 import 한다.
2. **[셀 4] i2c 객체 생성**: 100kHz I2C 버스 생성.
3. **[셀 5] 센서 객체 생성**: `Adafruit_BME280_I2C(i2c, 0x76)`.
4. **[셀 6] 센서 값 모니터링**: 무한루프로 온도/습도/기압을 1초 간격으로 출력.
5. 실습 종료 후 커널 중지(Interrupt Kernel).

## 4. 코드 해설 (원본 코드를 단계별로 블록 인용하고, 각 줄/함수의 역할을 상세 설명)

### 4.1 모듈 추가 (셀 1~3)

```python
# I2C 통신을 위한 통신 버스 모듈 추가
import busio
import board
```

- I2C 버스 초기화 모듈.

```python
# I2C 온도/습도/기압 감지 센서 전용 모듈 추가
from adafruit_bme280 import basic as adafruit_bme280
```

- `from adafruit_bme280 import basic as adafruit_bme280`: BME280 드라이버 패키지 중 `basic` 모듈을 `adafruit_bme280`이라는 이름으로 import 한다. `basic` 모듈에는 I2C/SPI 인터페이스용 클래스인 `Adafruit_BME280_I2C`가 정의되어 있다.
- BME280은 온도·습도·기압을 동시에 측정할 수 있는 환경 센서로, I2C 주소가 0x76(또는 0x77)이다.

```python
# 시간 지연을 위한 time 모듈 추가
import time
```

- `time.sleep()`을 위한 표준 모듈.

### 4.2 클래스 객체 생성 (셀 4~5)

```python
# I2C 통신을 이용하기 위해 busio의 I2C 클래스 객체 생성
i2c = busio.I2C(board.SCL, board.SDA, frequency = 100000)
```

- 100kHz의 I2C 버스 객체 생성.

```python
# 온도/습도/기압 센서를 사용하기 위해 객체 생성(address - 0x76)
bme280 = adafruit_bme280.Adafruit_BME280_I2C(i2c, 0x76)
```

- `Adafruit_BME280_I2C(i2c, 0x76)`: I2C 버스와 주소 0x76을 명시하여 BME280 센서 객체를 생성한다. 이 과정에서는 BME280이 0x76 주소에 연결되어 있으므로 반드시 두 번째 인자로 주소를 지정해야 한다.
- 생성 후 `bme280.temperature`, `bme280.humidity`, `bme280.pressure` 속성으로 측정값을 얻는다.

### 4.3 센서 값 모니터링 (셀 6)

```python
while True:
    temp = bme280.temperature
    humi = bme280.humidity
    press = bme280.pressure

    print("\nTemperature: %0.1f C" %temp)
    print("Humidity: %0.1f %%" %humi)
    print("Pressure: %0.1f hPa" %press)

    time.sleep(1)
```

- `while True:`: 실시간 측정 무한루프.
- `temp = bme280.temperature`: 온도를 섭씨(℃)로 읽는다.
- `humi = bme280.humidity`: 상대습도를 %(퍼센트)로 읽는다.
- `press = bme280.pressure`: 기압을 hPa(헥토파스칼)로 읽는다.
- `print("\nTemperature: %0.1f C" %temp)`: 온도를 소수점 1자리로 출력한다. `\n`으로 줄을 띄워 읽기 쉽게 한다.
- `print("Humidity: %0.1f %%" %humi)`: 습도를 출력한다. 서식 문자열에서 `%%`는 `%` 문자 하나를 출력하기 위한 이스케이프이다.
- `print("Pressure: %0.1f hPa" %press)`: 기압을 출력한다.
- `time.sleep(1)`: 1초 간격으로 측정한다.

## 5. 실행 결과 예시

```
Temperature: 25.4 C
Humidity: 45.2 %
Pressure: 1013.5 hPa

Temperature: 25.4 C
Humidity: 45.3 %
Pressure: 1013.5 hPa
```

- 1초 간격으로 온도/습도/기압이 새 줄에 출력된다. 습도에 숨을 불면 수치가 올라간다.

## 6. 주의사항 및 트러블슈팅

- **무한루프 중지**: 셀 6은 끝나지 않는다. **Kernel → Interrupt**로 중지한다.
- **센서 인식 실패**: `i2cdetect -y -r 1`에서 0x76이 보이지 않으면 배선과 주소 점퍼(SDO 핀)를 확인한다. SDO가 HIGH면 0x77, LOW면 0x76이다.
- **주소 불일치**: 객체 생성 시 주소 인자를 빠뜨리면 기본값(0x77)으로 생성되어 통신이 실패할 수 있다. 이 과정은 0x76이므로 반드시 `(i2c, 0x76)`처럼 명시한다.
- **습도가 비정상**: 센서가 공기 흐름이 없는 밀폐 상태라면 값이 천천히 변한다. 센서 주변을 막지 않는다.
- **출력 포맷**: `%0.1f`는 소수점 1자리, `%%`는 % 문자 출력. 포맷을 잘못 쓰면 TypeError가 날 수 있다.
