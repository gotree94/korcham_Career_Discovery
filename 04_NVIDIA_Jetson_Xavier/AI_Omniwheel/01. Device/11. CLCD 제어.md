# 11. CLCD 제어

옴니휠 로봇 교육 과정에서 **I2C로 연결된 CLCD(Character LCD, 2줄×16문자)**에 문자열을 출력한다. PCF8574(I2C 주소 0x27) 기반 백라이트가 포함된 LCD로, 이 과정의 `libraries.I2C_Charactor_Liquid_Crystal_Display`에서 제공하는 `LCD` 클래스를 사용한다.

## 1. 학습 목표

- CLCD의 구조(2줄×16문자, I2C PCF8574 어댑터)를 이해한다.
- `LCD` 클래스의 `backlight()`, `setCursor()`, `display_string()`, `clear()` 메서드를 이해한다.
- 백라이트 ON/OFF와 커서 위치 지정, 문자열 출력, 화면 초기화를 수행한다.
- 이 과정의 `libraries` 패키지를 import 하는 방법과 작업 디렉터리의 중요성을 이해한다.

## 2. 준비 사항

### 2.1 필요 하드웨어

- NVIDIA Jetson Xavier NX (JetPack 4.x, Ubuntu 18.04)
- I2C CLCD(PCF8574 어댑터, 주소 0x27) 2줄×16문자
- I2C 통신 연결(SCL, SDA)

### 2.2 필요 라이브러리 (설치 명령 포함)

```bash
sudo pip3 install adafruit-circuitpython-busio
```

- `busio`, `board`: I2C 통신 버스 모듈
- `libraries.I2C_Charactor_Liquid_Crystal_Display`: 이 과정에 포함된 LCD 제어 라이브러리. `libraries` 폴더가 있는 `01. Device` 디렉터리에서 실행해야 import된다. (이 라이브러리는 내부적으로 `LiquidCrystal_I2C` 모듈과 busio/board를 사용한다)
- `time`: 시간 지연 표준 라이브러리

### 2.3 사전 설정

- I2C 활성화 및 권한 확인. `i2cdetect -y -r 1`에서 주소 **0x27** 검출 확인.
- **작업 디렉터리 확인(중요)**: `libraries` 패키지는 namespace package이므로 `__init__.py`가 필요 없지만, 반드시 `libraries` 폴더가 있는 **`01. Device` 폴더를 Jupyter 작업 디렉터리로** 설정해야 import된다.

## 4. 코드 해설 (원본 코드를 단계별로 블록 인용하고, 각 줄/함수의 역할을 상세 설명)

### 4.1 모듈 추가 (셀 1~3)

```python
# I2C 통신을 위한 통신 버스 모듈 추가
import busio

```

- I2C 버스 초기화 모듈.

```python
# I2C CLCD 제어 모듈 추가
import libraries.I2C_Charactor_Liquid_Crystal_Display as i2c_lcd
```

- `import libraries.I2C_Charactor_Liquid_Crystal_Display as i2c_lcd`: 이 과정의 `libraries` 폴더에 들어 있는 LCD 제어 라이브러리를 `i2c_lcd`라는 이름으로 import 한다.
- 이 라이브러리의 `LCD` 클래스는 내부적으로 PCF8574(0x27)를 통해 HD44780 호환 LCD를 제어하며, `backlight`, `setCursor`, `display_string`, `clear` 메서드를 제공한다.
- ⚠ **반드시 `01. Device` 폴더가 작업 디렉터리여야** `libraries` 패키지가 import된다. 다른 폴더에서 실행하면 ModuleNotFoundError가 발생한다.

```python
# 시간 지연을 위한 time 모듈 추가
import time
```

- `time.sleep()`을 위한 표준 모듈.

### 4.2 클래스 객체 생성 (셀 4~5)

```python
# I2C 통신을 이용하기 위해 busio의 I2C 클래스 객체 생성
i2c = busio.I2C(board.SCL, board.SDA)
```

- SCL/SDA 핀으로 I2C 버스 객체를 생성한다.

```python
# LCD를 제어하기 위해 클래스 객체 생성
lcd = i2c_lcd.LCD(i2c)
```

- `i2c_lcd.LCD(i2c)`: 주소 0x27의 LCD 객체를 생성한다. 생성자에서 LCD 초기화 시퀀스(4비트 모드, 2라인, 디스플레이 ON, 커서 위치 등)를 자동으로 수행한다.

### 4.3 동작 제어 (셀 6~8)

```python
# CLCD의 Backlight 1초 간격으로 3회 ON/OFF
for i in range(0, 3):
    lcd.backlight(0)
    time.sleep(1)
    
    lcd.backlight(1)
    time.sleep(1)
```

- `for i in range(0, 3)`: 3회 반복.
- `lcd.backlight(0)`: 백라이트를 끈다. (state 1 = ON, 0 = OFF)
- `time.sleep(1)`: 1초 대기.
- `lcd.backlight(1)`: 백라이트를 켠다.
- `time.sleep(1)`: 1초 대기. 결과적으로 백라이트가 1초 간격으로 3회 점멸한다.

```python
# CLCD에 문자열 출력
lcd.setCursor(0, 0)
lcd.display_string("Hello World!")

lcd.setCursor(1, 0)
lcd.display_string("Omniwheel")
```

- `lcd.setCursor(0, 0)`: 커서를 **0행(line 0), 0열(pos 0)**으로 이동한다. line이 0이면 첫 번째 줄, 1이면 두 번째 줄을 의미한다.
- `lcd.display_string("Hello World!")`: 현재 커서 위치부터 문자열을 한 글자씩 출력한다. 첫 줄에 "Hello World!"가 표시된다.
- `lcd.setCursor(1, 0)`: 커서를 **1행(두 번째 줄), 0열**로 이동한다.
- `lcd.display_string("Omniwheel")`: 두 번째 줄에 "Omniwheel"을 출력한다.

```python
# LCD 화면 초기화
lcd.clear()
```

- `lcd.clear()`: LCD 화면의 모든 문자를 지우고 커서를 홈(0행 0열)으로 되돌린다.

## 6. 주의사항 및 트러블슈팅

- **ModuleNotFoundError: No module named 'libraries'**: 작업 디렉터리가 `01. Device`가 아니어서 발생. Jupyter 메뉴에서 작업 디렉터리를 `01. Device`로 바꾸거나, 노트북을 `01. Device` 폴더에서 실행한다.
- **LCD에 이상한 문자/정사각형만 표시**: 초기화가 제대로 안 된 것. 커널을 재시작하고 셀을 다시 실행하거나, LCD의 콘트라스트(가변 저항)를 조절한다.
- **아무것도 안 보임**: `i2cdetect -y -r 1`에서 0x27 확인, 백라이트 상태 확인. LCD 전원(5V) 연결을 점검한다.
- **주소 차이**: 일부 PCF8574A 기반 LCD는 주소가 0x3F다. 라이브러리 상단의 `ADDRESS` 값을 확인한다. (이 과정 기본은 0x27)
- **display_string의 최대 길이**: 2줄×16문자 LCD이므로 한 줄에 16자를 초과하면 다음 줄로 넘어간다. 초과분은 잘리거나 화면 밖으로 나간다.
- **setCursor 순서**: `setCursor(line, pos)`에서 line이 먼저, pos가 두 번째 인자임에 유의한다.
