# 통합예제 (초음파 거리 기반 주행 + 부저 + LCD 표시)

1~15번 실습에서 배운 내용을 하나로 결합한 통합 예제다. **초음파 센서(직렬통신)**로 가장 가까운 장애물 거리를 측정하고, 20cm 미만이면 **부저(PCA9685 채널 15)**를 울리면서 모터를 정지하고, 20cm 이상이면 **Y축 속도 -300으로 전진**한다. 측정 거리는 **CLCD(2줄 LCD)**에 실시간으로 표시된다.

## 1. 학습 목표

- 초음파 거리 측정, 모터 제어, 부저 제어, LCD 출력을 하나의 통합 시스템으로 결합한다.
- 초음파 6개 값에서 **최소값(최근접 거리)**을 계산하는 로직을 익힌다.
- 위험 판정 임계값(20cm)과 상태에 따른 분기(정지/주행/경고음)를 이해한다.
- 무한루프 기반 센서-액추에이터 통합 제어와 안전 정지 절차를 학습한다.

## 2. 준비 사항

### 2.1 필요 하드웨어

- NVIDIA Jetson Xavier NX (JetPack 4.x, Ubuntu 18.04)
- Arduino 보드(USB `/dev/ttyACM0`) + 초음파 센서 6개 + 옴니휠 모터 3개
- PCA9685(0x40) + 부저(채널 15)
- I2C CLCD(0x27)

### 2.2 필요 라이브러리 (설치 명령 포함)

```bash
sudo pip3 install pyserial adafruit-circuitpython-busio adafruit-circuitpython-pca9685
```

- `serial`(pyserial), `libraries.Omniwheel_Protocol`, `libraries.I2C_Charactor_Liquid_Crystal_Display`, `busio`, `board`, `adafruit_pca9685`, `time`

### 2.3 사전 설정

- **작업 디렉터리**: `01. Device` 폴더에서 실행해야 `libraries`가 import된다.

### 4.6 송신/수신 함수 정의 (셀 19~22)

```python
def Packet_send(_id, _cmd, _mid, _data = None):
    # 전역변수 사용
    global send_flag
    
    # 전송 완료 플래그 확인 
    if(send_flag==False):
        
        # 초기화
        send_packet.clearPacket()
        
        # ID 설정
        send_packet.setID(_id)
        
        # CMD 설정
        send_packet.setCMD(_cmd)
        
        # Payload 초기화
        send_packet.clearPayload()
        
        # MID, data 설정
        send_packet.addPayload(_mid, _data)
        
        # 패킷 LRC 계산
        send_packet.calcLRC_Lower()
        
        # 패킷을 리스트로 변환
        send_list=send_packet.packetToList()
        
        # Arduino 에 패킷 리스트 전송
        Serial_Arduino.write(send_list)
        
        # 전송 완료 플래그 설정
        send_flag=True
```

- `Packet_send()`: **초음파 값 요청용** 송신 함수. send_flag가 False일 때만 전송하고 True로 바꾼다. (12~14번 실습과 동일한 요청 방식)

```python
def Control_send(_id, _cmd, _mid, _data):
    # 패킷을 초기화 합니다.
    send_packet.clearPacket()

    # ID 설정 합니다.
    send_packet.setID(_id)

    # CMD 설정 합니다.
    send_packet.setCMD(_cmd)

    # Payload 초기화 합니다.
    send_packet.clearPayload()

    # MID, data 설정 합니다.
    send_packet.addPayload(_mid, _data)

    # 패킷 LRC 계산합니다.
    send_packet.calcLRC_Lower()

    # 패킷을 리스트로 변환합니다.
    send_list=send_packet.packetToList()
    
    # Arduino 에 패킷 리스트를 전송합니다.
    Serial_Arduino.write(send_list)
```

- `Control_send()`: **모터 제어용** 송신 함수. send_flag 없이 바로 전송한다. (15번 실습과 동일한 Control 방식)

```python
def Packet_receive(ser):
    # 전역변수 사용
    global send_flag
    
    # 전송 완료 플래그 확인
    if(send_flag==True):
        
        # 수신받은 데이터가 없을때까지
        while ser.inWaiting() > 0:
            
            # 1바이트씩 데이터를 받음
            Arduino_Data = ser.read(1)
            
            # 데이터를 받은 경우
            if(len(Arduino_Data)>0):
                
                # 수신 패킷 리스트에 수신 데이터 저장
                recv_list.append(ord(Arduino_Data))
                
                # 패킷 종료 데이터를 받은 경우
                if(ord(Arduino_Data)==0x03):
                    
                    # 수신 받은 데이터 파싱
                    if(recv_packet.parsingList(recv_list)):
                        
                        # 파싱한 데이터를 파싱완료 리스트에 저장
                        recv_parsing_packet.append(recv_packet)
                        
                        # 패킷 리스트 초기화
                        recv_list.clear()
                        
                        # 전송 완료 플래그 해제
                        send_flag=False
                        
                        # 반복문 탈출
                        break
```

- `Packet_receive(ser)`: ETX(0x03) 수신 시 `parsingList()`로 파싱하고 성공하면 큐에 저장 후 `send_flag=False`.

```python
def Received_packet():
    # 파싱 완료 리스트의 첫번째 패킷을 result 변수에 저장함
    result=recv_parsing_packet[0]
    
    # 저장 완료한 파싱 완료 리스트 삭제 
    del recv_parsing_packet[0]
    
    # result 변수값 반환
    return result
```

- 파싱 완료 큐의 첫 패킷을 꺼내 반환.

### 4.7 초음파 데이터 저장 함수 (셀 23)

```python
# 인자값으로 Received_packet() 함수에서 반환된 값을 넣어줌
def Ultrasonic_Data(packet):
    
    #전역 변수 사용
    global data_Ultrasonic_Sensors
    
    # 패킷에서 ID 추출
    packet_id=packet.getID()
    
    # 패킷에서 CMD 추출
    packet_cmd=packet.getCMD()
    
    # 추출한 ID 가 Arduino_ID 와 맞는지 확인
    if(packet_id==Arduino_ID):
        
        #추출한 CMD가 응답 CMD가 맞는지 확인
        if(packet_cmd==ANSWER_Ultra_Sonic_SENSOR):
            
            # 패킷에서 Payload 값을 추출함
            for payload in packet.getPayload():
                
                # 추출한 MID가 초음파 센서가 맞는지 확인
                if(payload.getID()==MID_Ultra_Sonic_SENSOR):
                    
                    # Payload 에서 읽어온 데이터를 버퍼에 저장 
                    buf=str(payload.getData())
                    
                    # 버퍼에 있는 데이터 값(초음파 센서 거리 값) 을 확인할수 있게 배열로 나누어 저장 
                    data_Ultrasonic_Sensors = [int(float(buf[:3])), 
                                               int(float(buf[3:6])),
                                               int(float(buf[6:9])), 
                                               int(float(buf[9:12])),
                                               int(float(buf[12:15])), 
                                               int(float(buf[15:]))]
```

- `Ultrasonic_Data(packet)`: 응답 패킷(0xB1, MID 0x80)의 18자리 거리 문자열을 3자리씩 6개로 분할해 `data_Ultrasonic_Sensors` 배열에 저장한다. (13번 실습과 동일)

```python
    time.sleep(0.5)
```

- `pca9685.frequency = melody[4]`: 부저의 주파수를 미리 **솔(196Hz)**로 설정해둔다. (경고음이 울릴 때 이 주파수로 울린다)
- `lower_dist = 9999`: 가장 가까운 거리를 저장할 변수. 매우 큰 값으로 초기화해 첫 비교에서 반드시 갱신되게 한다.
- `while(True):`: 통합 제어 무한루프.
- `Packet_send(Arduino_ID, REQUEST_Ultra_Sonic_SENSOR, MID_Ultra_Sonic_SENSOR)`: 초음파 값 요청.
- `Packet_receive(Serial_Arduino)`: 응답 수신·파싱.
- `if(len(recv_parsing_packet) > 0):`: 파싱 완료 패킷이 있으면 처리.
  - `lower_dist = 9999`: 매 사이클마다 최소값을 다시 찾도록 리셋한다.
  - `p=Received_packet()`: 첫 패킷을 꺼낸다.
  - `Ultrasonic_Data(p)`: 6개 거리값을 배열에 저장.
  - `print("Ultra_Sonic : "+ str(data_Ultrasonic_Sensors))`: 거리 배열을 출력한다.
  - `for d in data_Ultrasonic_Sensors: if(lower_dist > d): lower_dist = d`: 6개 거리값 중 **최소값(가장 가까운 장애물)**을 찾아 `lower_dist`에 저장한다.
- `if(lower_dist < 20):` **최근접 거리가 20cm 미만(위험)이면**:
  - `pca9685.channels[15].duty_cycle = int(4096/2)`: 부저를 50% duty로 울려 경고음을 낸다.
  - `for mid in MID_list: Control_send(Arduino_ID, CONTROL_DRIVE, mid, 0)`: 3개 축 모두에 0을 전송해 **모터를 정지**한다.
- `else:` **20cm 이상(안전)이면**:
  - `Control_send(Arduino_ID, CONTROL_DRIVE, MID_list[1], -300)`: **Y축(0x81)에 -300**을 전송해 로봇을 전진시킨다. (주석 처리된 for 문은 원본 그대로 유지되며, 실제로는 Y축만 제어한다)
  - `pca9685.channels[15].duty_cycle = 0`: 부저를 끈다.
- `display_lcd(str(lower_dist))`: LCD 2행에 현재 최근접 거리를 표시한다. (1행은 " Ultrasonic Low " 고정)
- `time.sleep(0.5)`: 0.5초 후 반복.

### 4.9 제어 정지 (셀 25)

```python
Control_send(Arduino_ID, CONTROL_DRIVE, MID_list[0], 0)
Control_send(Arduino_ID, CONTROL_DRIVE, MID_list[1], 0)
Control_send(Arduino_ID, CONTROL_DRIVE, MID_list[2], 0)
```

- X(0x80), Y(0x81), Z(0x82) 각각에 **0**을 전송해 모든 모터를 정지시킨다.
- **실습 종료 시 반드시 실행**해야 로봇이 계속 움직이지 않는다.

## 6. 주의사항 및 트러블슈팅

- **무한루프와 안전(중요)**: 셀 24는 끝나지 않는다. 로봇이 스스로 주행하므로 실행 직후 주변 안전을 확보하고, 관찰 후 **셀 25로 정지**하거나 Interrupt Kernel로 중지한다.
- **모터가 계속 움직임**: 셀 25(전부 0)를 실행해 정지한다. 커널만 종료하면 Arduino에 마지막 제어값이 남을 수 있다.
- **포트 권한**: `sudo chmod 777 /dev/ttyACM0` 필요.
- **모듈 import 실패**: 작업 디렉터리가 `01. Device`인지 확인.
- **LCD에 거리가 안 뜸**: LCD 0x27 주소와 콘트라스트를 확인하고, `display_lcd` 함수 정의 셀을 실행했는지 확인한다.
- **부저가 계속 울림**: `lower_dist`가 계속 20 미만인 상태. 장애물을 치우거나 수신이 실패해 `lower_dist`가 이전 작은 값에 머문 경우다. 수신 실패 시 `lower_dist`가 초기화되지 않는 점에 유의한다.
- **초음파 값이 갱신 안 됨**: send_flag 고착 여부, 시리얼 연결을 점검한다.
- **두 송신 함수 구분**: `Packet_send`(요청, send_flag 사용)와 `Control_send`(제어, send_flag 없음)의 용도를 혼동하지 않도록 주의한다.
