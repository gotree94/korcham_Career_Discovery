# 9. CO2 센서 모니터링

옴니휠 로봇 교육 과정에서 **I2C로 연결된 CO2 센서(CCS811)**를 이용해 이산화탄소(CO2) 가스량과 총휘발성유기화합물(TVOC)을 측정한다. CCS811은 공기 질을 평가하는 데 쓰이는 전기화학식 공기질 센서이다.

## 1. 학습 목표

- CCS811 센서의 CO2(eCO2)와 TVOC 측정 원리를 이해한다.
- `adafruit_ccs811` 라이브러리를 사용해 eCO2/TVOC 값을 읽는 방법을 익힌다.
- I2C 주소 0x5B를 객체 생성 시 명시적으로 지정하는 방법을 이해한다.
- 무한루프 기반 실시간 모니터링 패턴을 학습한다.

## 2. 준비 사항

### 2.1 필요 하드웨어

- NVIDIA Jetson Xavier NX (JetPack 4.x, Ubuntu 18.04)
- CCS811 CO2 센서(주소 0x5B)
- I2C 통신 연결(SCL, SDA)

### 2.2 필요 라이브러리 (설치 명령 포함)

```bash
sudo pip3 install adafruit-circuitpython-busio adafruit-circuitpython-ccs811
```

- `busio`, `board`: I2C 통신 버스 모듈
- `adafruit_ccs811`: CCS811 공기질 센서 드라이버 라이브러리
- `time`: 시간 지연 표준 라이브러리

### 2.3 사전 설정

- I2C 활성화 및 권한 확인. `i2cdetect -y -r 1`에서 주소 **0x5B** 검출 확인.
- `01. Device` 폴더가 작업 디렉터리인지 확인한다.

## 3. 실행 방법 (셀 실행 순서 안내)

1. **[셀 1~3] 모듈 추가**: `busio`, `board`, `adafruit_ccs811`, `time`을 import 한다.
2. **[셀 4] i2c 객체 생성**: 100kHz I2C 버스 생성.
3. **[셀 5] 센서 객체 생성**: `adafruit_ccs811.CCS811(i2c, 0x5b)`.
4. **[셀 6] 센서 값 모니터링**: 무한루프로 eCO2/TVOC를 1초 간격으로 출력.
5. 실습 종료 후 커널 중지(Interrupt Kernel).

> 참고: 원본 셀 2의 주석에는 "조도 감지 센서"라고 적혀 있지만 실제로는 CO2 센서(CCS811)를 import하는 코드이다. 코드 동작에는 영향이 없으며, 설명상의 오타이다.

## 4. 코드 해설 (원본 코드를 단계별로 블록 인용하고, 각 줄/함수의 역할을 상세 설명)

### 4.1 모듈 추가 (셀 1~3)

```python
# I2C 통신을 위한 통신 버스 모듈 추가
import busio
import board
```

- I2C 버스 초기화 모듈.

```python
# I2C 조도 감지 센서 전용 모듈 추가
import adafruit_ccs811
```

- `import adafruit_ccs811`: CCS811 센서 드라이버를 import 한다. 주석은 "조도 감지 센서"로 적혀 있으나 실제 import 대상은 CCS811 CO2 센서다. (원본 주석 오타. 실행에는 영향 없음)
- CCS811은 환경 센서로, 탄소 산화물 농도를 측정해 등가 CO2(eCO2) 농도와 TVOC(총휘발성유기화합물) 농도를 PPM 단위로 계산한다.

```python
# 시간 지연을 위한 time 모듈 추가
import time
```

- `time.sleep()`을 위한 표준 모듈.

### 4.2 클래스 객체 생성 (셀 4~5)

```python
# I2C 통신을 이용하기 위해 busio의 I2C 클래스 객체 생성
i2c = busio.I2C(board.SCL, board.SDA, frequency = 100000)
```

- 100kHz의 I2C 버스 객체 생성.

```python
# CO2 센서를 사용하기 위해 객체 생성(address - 0x5b)
ccs811 = adafruit_ccs811.CCS811(i2c, 0x5b)
```

- `CCS811(i2c, 0x5b)`: I2C 버스와 주소 0x5B를 명시하여 CCS811 센서 객체를 생성한다. 이 과정의 CCS811은 0x5B 주소에 연결되어 있으므로 주소 인자를 반드시 지정한다.
- 생성 후 `ccs811.eco2`와 `ccs811.tvoc` 속성으로 측정값을 얻는다.

### 4.3 센서 값 모니터링 (셀 6)

```python
while True:
    eco2 = ccs811.eco2
    tvoc = ccs811.tvoc

    print("CO2: %1.0f PPM" %eco2)
    print("TVOC: %1.0f PPM" %tvoc)

    time.sleep(1)
```

- `while True:`: 실시간 측정 무한루프.
- `eco2 = ccs811.eco2`: 등가 이산화탄소 농도를 PPM(parts per million)으로 읽는다. 대략 400~1000 PPM이 실내에서 일반적인 수준이다.
- `tvoc = ccs811.tvoc`: 총휘발성유기화합물 농도를 PPM으로 읽는다. TVOC는 페인트, 세제 등에서 발생하는 유기 가스의 총량을 나타낸다.
- `print("CO2: %1.0f PPM" %eco2)`: eCO2 값을 소수점 없이 정수 단위로 출력한다.
- `print("TVOC: %1.0f PPM" %tvoc)`: TVOC 값을 출력한다.
- `time.sleep(1)`: 1초 간격으로 측정한다.

## 5. 실행 결과 예시

```
CO2: 412 PPM
TVOC: 0 PPM
(입김을 센서에 계속 불면)
CO2: 1080 PPM
TVOC: 16 PPM
```

- 환기가 잘 된 실내에서는 CO2가 400~600 PPM, TVOC가 0 근처로 나온다. 입김을 불면 CO2가 상승한다.

## 6. 주의사항 및 트러블슈팅

- **무한루프 중지**: 셀 6은 끝나지 않는다. **Kernel → Interrupt**로 중지한다.
- **센서 인식 실패**: `i2cdetect -y -r 1`에서 0x5B가 보이지 않으면 배선과 전원(3.3V)을 확인한다.
- **초기 측정 전 워밍업**: CCS811은 전원을 켠 뒤 초기 가열(수 분)이 필요하다. 처음 값은 부정확할 수 있으므로 잠시 후 관찰한다.
- **값이 0으로만 출력**: 센서가 안정화되기 전이거나 오류 상태일 수 있다. 잠시 대기한 후 다시 확인한다.
- **주소 불일치**: CCS811은 기본 주소가 0x5B(WAKE 핀 설정에 따라 0x5A일 수도 있다)다. 이 과정은 0x5B를 사용하므로 `(i2c, 0x5b)`로 명시한다.
- **CO2 값 급상승**: 센서 앞에서 입김을 불거나 주변에 화기(알코올 램프 등)가 있으면 값이 급증한다. 환기와 측정 위치를 고려한다.
