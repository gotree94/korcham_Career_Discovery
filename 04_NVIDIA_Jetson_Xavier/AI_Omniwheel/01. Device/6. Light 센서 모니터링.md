# 6. Light 센서 모니터링

옴니휠 로봇 교육 과정에서 **I2C로 연결된 조도 센서(BH1750)**를 이용해 주변 빛의 세기(lux)를 측정한다. 조도 센서는 디지털 I2C 인터페이스를 가지므로 ADC 변환 없이 곧바로 lux 값을 읽을 수 있다.

## 1. 학습 목표

- BH1750 조도 센서의 특징(디지털 I2C, lux 단위)을 이해한다.
- `adafruit_bh1750` 라이브러리를 이용해 lux 값을 읽는 방법을 익힌다.
- 조명 상태 변화에 따른 lux 값 변화를 관찰하고 해석한다.
- 무한루프 기반 실시간 센서 모니터링 패턴을 학습한다.

## 2. 준비 사항

### 2.1 필요 하드웨어

- NVIDIA Jetson Xavier NX (JetPack 4.x, Ubuntu 18.04)
- BH1750 조도 센서(주소 0x23)
- I2C 통신 연결(SCL, SDA)

### 2.2 필요 라이브러리 (설치 명령 포함)

```bash
sudo pip3 install adafruit-circuitpython-busio adafruit-circuitpython-bh1750
```

- `busio`, `board`: I2C 통신 버스 모듈
- `adafruit_bh1750`: BH1750 조도 센서 드라이버 라이브러리
- `time`: 시간 지연 표준 라이브러리

### 2.3 사전 설정

- I2C 활성화 및 권한 확인. `i2cdetect -y -r 1`에서 주소 **0x23** 검출 확인.
- `01. Device` 폴더가 작업 디렉터리인지 확인한다.

## 3. 실행 방법 (셀 실행 순서 안내)

1. **[셀 1~3] 모듈 추가**: `busio`, `board`, `adafruit_bh1750`, `time`을 import 한다.
2. **[셀 4] i2c 객체 생성**: 100kHz I2C 버스 생성.
3. **[셀 5] 센서 객체 생성**: `adafruit_bh1750.BH1750(i2c)` 객체 생성.
4. **[셀 6] 센서 값 모니터링**: 무한루프로 lux 값을 1초 간격으로 출력.
5. 실습 종료 후 커널 중지(Interrupt Kernel).

## 4. 코드 해설 (원본 코드를 단계별로 블록 인용하고, 각 줄/함수의 역할을 상세 설명)

### 4.1 모듈 추가 (셀 1~3)

```python
# I2C 통신을 위한 통신 버스 모듈 추가
import busio
import board
```

- I2C 버스 초기화 모듈.

```python
# I2C 조도 센서 전용 모듈 추가
import adafruit_bh1750
```

- BH1750 조도 센서 드라이버를 import 한다. BH1750은 주변 밝기를 lux(룩스) 단위로 반환하는 디지털 조도 센서이다.

```python
# 시간 지연을 위한 time 모듈 추가
import time
```

- `time.sleep()`을 위한 표준 모듈.

### 4.2 클래스 객체 생성 (셀 4~5)

```python
# I2C 통신을 이용하기 위해 busio의 I2C 클래스 객체 생성
i2c = busio.I2C(board.SCL, board.SDA, frequency = 100000)
```

- 100kHz의 I2C 버스 객체 생성.

```python
# Light 센서를 사용하기 위해 객체 생성
light_sensor = adafruit_bh1750.BH1750(i2c)
```

- `adafruit_bh1750.BH1750(i2c)`: 주소 0x23의 BH1750 센서 객체를 생성한다. 생성 시 기본 측정 모드(연속 측정, 1lx 해상도)로 초기화된다.

### 4.3 센서 값 모니터링 (셀 6)

```python
while True:
    val = light_sensor.lux
    
    print("조도 감지 센서 : %.2f Lux"%val)
    time.sleep(1)
```

- `while True:`: 실시간 측정 무한루프.
- `val = light_sensor.lux`: 현재 조도값(lux)을 읽는다. I2C를 통해 센서 레지스터 값을 읽어 내부적으로 lux로 환산한 값이다.
- `print("조도 감지 센서 : %.2f Lux"%val)`: 조도값을 소수점 2자리까지 출력한다. `%.2f`는 부동소수점 서식, `%val`은 val을 대입한다.
- `time.sleep(1)`: 1초 간격으로 측정한다.

## 5. 실행 결과 예시

```
조도 감지 센서 : 123.45 Lux
조도 감지 센서 : 120.11 Lux
(센서를 가리면)
조도 감지 센서 : 8.32 Lux
조도 감지 센서 : 5.10 Lux
(손을 치우면)
조도 감지 센서 : 128.90 Lux
```

- 실내 밝기에 따라 수십~수백 lux가 출력되고, 센서를 가리면 lux가 급격히 낮아진다.

## 6. 주의사항 및 트러블슈팅

- **무한루프 중지**: 셀 6은 끝나지 않는다. **Kernel → Interrupt**로 중지한다.
- **센서 인식 실패**: `i2cdetect -y -r 1`에서 0x23이 보이지 않으면 배선과 주소 점퍼(0x23/0x5C 선택)를 확인한다.
- **lux 값이 너무 낮음**: 센서 보호 필름을 제거하고, 측정 방향이 광원을 향하도록 배치한다.
- **불규칙한 값**: 빠른 측정이 반복되면 값이 들쭉날쭉할 수 있다. `time.sleep(1)` 간격을 유지한다.
- **기본 주소 확인**: BH1750은 ADDR 핀에 따라 0x23 또는 0x5C 주소를 갖는다. 이 실습에서는 0x23을 사용한다.
