# 3. 모션 감지 센서 모니터링

옴니휠 로봇 교육 과정에서 **Jetson GPIO**에 연결된 모션 감지 센서(PIR형 모션 센서)로 전방의 물체 이동을 감지한다. GPIO 핀의 디지털 입력값을 읽어 물체가 움직이는지 여부를 판별하는 방법을 배운다.

## 1. 학습 목표

- Jetson.GPIO 라이브러리를 이용해 GPIO 핀을 입력 모드로 설정하는 방법을 이해한다.
- GPIO 핀 넘버링 모드(TEGRA_SOC)의 개념을 이해한다.
- 센서의 디지털 출력값(0/1)을 읽고 상태를 판단하는 방법을 익힌다.
- 무한루프(while True)를 사용해 실시간으로 센서를 모니터링하는 패턴을 학습한다.

## 2. 준비 사항

### 2.1 필요 하드웨어

- NVIDIA Jetson Xavier NX (JetPack 4.x, Ubuntu 18.04)
- 모션 감지 센서 1개 (Jetson GPIO 핀 `SPI3_CS0_N`에 연결)
- GPIO 배선(센서 VCC/GND/OUT)

### 2.2 필요 라이브러리 (설치 명령 포함)

```bash
sudo pip3 install Jetson.GPIO
```

- `Jetson.GPIO`: Jetson 보드의 GPIO를 제어하는 공식 라이브러리. Raspberry Pi의 RPi.GPIO와 API가 유사하다.
- `time`: 시간 지연 표준 라이브러리

### 2.3 사전 설정

- GPIO 접근 권한 및 사용자 그룹 설정이 되어 있어야 한다. (기본 설정이 되어 있지 않으면 아래 실행)
  ```bash
  sudo groupadd -f -r gpio
  sudo usermod -a -G gpio $USER
  # /opt/nvidia/jetson-gpio/etc/99-gpio.rules 를 /etc/udev/rules.d/ 로 복사
  sudo cp /opt/nvidia/jetson-gpio/etc/99-gpio.rules /etc/udev/rules.d/
  sudo udevadm control --reload-rules
  # 재부팅 후 Jupyter를 실행
  ```
- 센서가 로봇 전방을 향하도록 설치하고, 배선을 점검한다.

## 3. 실행 방법 (셀 실행 순서 안내)

1. **[셀 1] 모듈 추가 (GPIO)**: `Jetson.GPIO`를 import 하고 경고를 끈다.
2. **[셀 2] 모듈 추가 (time)**: `time` 모듈을 import 한다.
3. **[셀 3] 핀 설정**: GPIO 모드를 TEGRA_SOC로 설정하고, `SPI3_CS0_N` 핀을 입력 모드로 설정한다.
4. **[셀 4] 센서 값 모니터링**: 무한루프로 센서 값을 읽어 모션 감지 여부를 출력한다.
5. 실습을 마치면 커널을 중지(Interrupt Kernel)한다.

> 주의: 셀 4는 `while True` 무한루프이므로 끝나지 않는다. 관찰 후 반드시 **Interrupt Kernel**로 중지해야 한다.

## 4. 코드 해설 (원본 코드를 단계별로 블록 인용하고, 각 줄/함수의 역할을 상세 설명)

### 4.1 모듈 추가 (셀 1~2)

```python
# GPIO핀 사용을 위한 Jetson GPIO 모듈 추가
import Jetson.GPIO as GPIO
GPIO.setwarnings(False)
```

- `import Jetson.GPIO as GPIO`: Jetson GPIO 라이브러리를 `GPIO`라는 이름으로 import 한다.
- `GPIO.setwarnings(False)`: 사용 중인 핀을 다시 설정할 때 발생하는 경고 메시지를 끈다. (초보자가 실습 중 경고로 혼란을 겪지 않도록)

```python
# 시간 지연을 위한 time 모듈 추가
import time
```

- `time.sleep()`을 위한 표준 모듈.

### 4.2 핀 설정 (셀 3)

```python
# GPIO 모드 설정
GPIO.setmode(GPIO.TEGRA_SOC)
```

- `GPIO.setmode(GPIO.TEGRA_SOC)`: 핀 번호를 Tegra SOC 이름(예: `SPI3_CS0_N`)으로 참조하도록 모드를 설정한다. Jetson 보드의 핀맵에서 Tegra 이름을 그대로 사용할 수 있다.
- 다른 선택지로 `GPIO.BOARD`(물리 핀 번호)와 `GPIO.BCM`(Broadcom 번호)가 있으나, 이 과정에서는 TEGRA_SOC 모드를 사용한다.

```python
# 센서가 연결된 핀 정의
Motion = 'SPI3_CS0_N'
```

- `Motion` 변수에 모션 센서가 연결된 핀의 Tegra 이름을 문자열로 저장한다.

```python
# 센서가 연결된 핀 입력 설정
GPIO.setup(Motion, GPIO.IN)
```

- `GPIO.setup(핀, GPIO.IN)`: 해당 핀을 입력 모드로 설정한다. 이후 `GPIO.input()`으로 센서의 디지털 값을 읽을 수 있다.

### 4.3 센서 값 모니터링 (셀 4)

```python
while True:
    value = GPIO.input(Motion)
    
    # 모션 감지가 된 경우
    if(value == 0):
        print("모션 감지")

    time.sleep(0.3)
```

- `while True:`: 무한루프. 센서를 계속 읽어 실시간 감지를 수행한다.
- `value = GPIO.input(Motion)`: `Motion` 핀의 디지털 값을 읽는다. 이 센서는 출력이 LOW(0)일 때 감지 상태를 나타낸다. (감지 안 되면 1)
- `if(value == 0):`: 감지 값이 0이면(물체 움직임 감지 시) 아래 문장을 실행한다.
- `print("모션 감지")`: 물체 이동이 감지될 때 콘솔에 "모션 감지"를 출력한다.
- `time.sleep(0.3)`: 0.3초 대기 후 다시 반복. 너무 빠른 반복으로 인한 과부하를 방지하고, 감지 상태를 일정 시간 유지한다.
- 원본 코드의 동작 특성상, 감지가 지속되는 동안 0.3초 간격으로 "모션 감지"가 연속 출력된다.

## 5. 실행 결과 예시

```

(가만히 있으면)

```

- 물체가 움직이는 동안 0.3초 간격으로 `모션 감지`가 출력된다.

## 6. 주의사항 및 트러블슈팅

- **무한루프 중지**: 셀 4는 끝나지 않으므로, 관찰 후 메뉴에서 **Kernel → Interrupt**를 실행하거나 도구 모음의 정지 버튼(■)을 눌러 중지한다. 그대로 두면 커널이 계속 점유된다.
- **PermissionError**: GPIO 접근 권한이 없으면 에러가 발생한다. "2.3 사전 설정"의 udev 룰 적용 후 재부팅하거나, 터미널에서 Jupyter를 `sudo`로 실행한다.
- **핀 이름 오류**: `SPI3_CS0_N` 문자열이 정확한지 확인한다. 오타가 있으면 `GPIO.setup`에서 RuntimeError가 발생한다.
- **항상 0이 출력되는 경우**: 배선(GND 공유)을 확인하고, 핀 모드가 입력(`GPIO.IN`)으로 설정됐는지 확인한다.
- **setmode 미설정**: `GPIO.setup` 전에 반드시 `GPIO.setmode()`가 실행되어야 한다. 커널 재시작 후에는 setmode가 초기화되므로 다시 실행한다.
