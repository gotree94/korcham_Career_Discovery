# 15. 모터 제어

옴니휠 로봇 교육 과정에서 **직렬 통신**을 통해 Arduino로 모터 제어 패킷(CMD 0xC0)을 전송하여 옴니휠의 **X 선속도/Y 선속도/Z 각속도**를 제어한다. 값 범위는 -600~600이며, 이 실습에서는 `[600, 0, -600, 0]` 시퀀스를 반복하며 모터가 회전하는 것을 확인한다.

## 1. 학습 목표

- 옴니휠 로봇의 3축 제어 개념(X 선속도, Y 선속도, Z 각속도)을 이해한다.
- 모터 제어 CMD(0xC0)와 MID(0x80/0x81/0x82) 매핑을 이해한다.
- 제어 방식(Control) 송신은 응답 대기가 없으므로 `send_flag` 없이 `Packet_send`를 바로 사용함을 이해한다.
- 모터 값을 보내고 정지(0)를 보내는 안전 절차를 익힌다.

## 2. 준비 사항

### 2.1 필요 하드웨어

- NVIDIA Jetson Xavier NX (JetPack 4.x, Ubuntu 18.04)
- 옴니휠 로봇 제어용 Arduino 보드(USB 연결, `/dev/ttyACM0`)
- 옴니휠 모터 드라이버 및 모터 3개

### 2.2 필요 라이브러리 (설치 명령 포함)

```bash
sudo pip3 install pyserial
```

- `serial`(pyserial): 직렬 통신 라이브러리
- `libraries.Omniwheel_Protocol`: 옴니휠 패킷 프로토콜 라이브러리
- `time`: 시간 지연 표준 라이브러리

### 2.3 사전 설정

- **작업 디렉터리**: `01. Device` 폴더에서 실행해야 `libraries`가 import된다.
- **직렬 포트 권한**:
  ```bash

  ```
- ⚠ **안전**: 로봇이 움직일 수 있으므로 바닥이 넓은 공간에서 실습하고, 주변에 사람/물건이 없도록 한다. 실습 직후 반드시 정지 셀을 실행한다.

## 4. 코드 해설 (원본 코드를 단계별로 블록 인용하고, 각 줄/함수의 역할을 상세 설명)

### 4.1 모듈 추가 (셀 1)

```python
import libraries.Omniwheel_Protocol as Omniwheel_Protocol
import serial
import time
```

- 통신 프로토콜, pyserial, time을 import 한다.

### 4.2 프로토콜 정의 (셀 2)

```python
Arduino_ID = 0x20
CONTROL_DRIVE = 0xC0

MID_CONTROL_X_LINEAR_VELOCITY = 0x80
MID_CONTROL_Y_LINEAR_VELOCITY = 0x81
MID_CONTROL_W_ANGULAR_VELOCITY = 0x82

MID_list=[MID_CONTROL_X_LINEAR_VELOCITY,
          MID_CONTROL_Y_LINEAR_VELOCITY,
          MID_CONTROL_W_ANGULAR_VELOCITY
        ]
```

- `Arduino_ID = 0x20`: Arduino 고유 ID.
- `CONTROL_DRIVE = 0xC0`: **모터 제어** 명령 코드. (참고: 0xA0=오도미터 요청, 0xA1=센서 요청, 0xB0/0xB1=응답, 0xC2=엔코더 초기화)
- `MID_CONTROL_X_LINEAR_VELOCITY = 0x80`: X축 선속도 제어 MID.
- `MID_CONTROL_Y_LINEAR_VELOCITY = 0x81`: Y축 선속도 제어 MID.
- `MID_CONTROL_W_ANGULAR_VELOCITY = 0x82`: Z축 각속도(회전) 제어 MID.
- `MID_list`: 3개 축의 MID를 담은 리스트. 제어 반복문에서 사용된다.

### 4.3 변수 리스트 정의 (셀 3)

```python
# -600 ~ 600
Moter_Control= [ 600,
                 0,
                 -600,
                 0
                ] 
```

- `Moter_Control = [600, 0, -600, 0]`: 모터에 보낼 제어값 시퀀스. (원본의 "Moter"는 "Motor"의 오타지만 실행에는 문제가 없다)
- 값의 유효 범위는 **-600~600**이다. 양수는 한 방향, 음수는 반대 방향 회전을 의미한다. 순서는 [600(전진), 0(정지), -600(후진), 0(정지)]로, 전진했다 정지했다 후진하는 동작을 반복하기 위한 배열이다.
- 참고: 이 실습에서는 제어값 하나를 X/Y/Z에 모두 적용하는데, 각 축의 응답 특성에 따라 로봇이 특정 방향으로 움직이거나 회전한다.

### 4.4 송신 객체 생성 및 초기화 (셀 4~5)

```python
send_packet = Omniwheel_Protocol.Packet()
```

- 송신용 `Packet` 객체 생성.

```python
send_packet.clearPacket()
```

- 패킷 초기화.

### 4.5 통신 포트 초기화 (셀 6)

```python
Serial_Arduino = serial.Serial(port ="/dev/ttyACM0" ,baudrate = 115200, timeout=.1)
time.sleep(1)
print("connect complete")
```

- Arduino와 115200 baud, 타임아웃 0.1초로 연결 후 "connect complete" 출력.

### 4.6 송신 함수 (셀 7)

```python
def Packet_send(_id, _cmd, _mid, _data):
    # 패킷을 초기화 합니다.
    send_packet.clearPacket()

    # ID 설정 합니다.
    send_packet.setID(_id)

    # CMD 설정 합니다.
    send_packet.setCMD(_cmd)

    # Payload 초기화 합니다.
    send_packet.clearPayload()

    # MID, data 설정 합니다.
    send_packet.addPayload(_mid, _data)

    # 패킷 LRC 계산합니다.
    send_packet.calcLRC_Lower()

    # 패킷을 리스트로 변환합니다.
    send_list=send_packet.packetToList()
    
    # Arduino 에 패킷 리스트를 전송합니다.
    Serial_Arduino.write(send_list)
```

- `def Packet_send(_id, _cmd, _mid, _data)`: 제어 패킷 송신 함수.
- **12~14번 실습과 달리 `send_flag`가 없다.** 모터 제어(0xC0)는 **Control 방식**이라 Arduino가 응답을 보내지 않으므로, 요청-응답 동기화가 필요 없다. 따라서 바로 전송한다.
- `send_packet.clearPacket()` → `setID(_id)` → `setCMD(_cmd)` → `clearPayload()` → `addPayload(_mid, _data)` 순서로 패킷을 구성한다.
- `_data`에 실제 제어값(예: 600)이 들어가므로, 이 실습에서는 `addPayload`에 데이터가 반드시 필요하다. (기본값 None이 없다)
- `calcLRC_Lower()`: CMD+Payload 합의 보수를 이용해 2자리 LRC를 계산한다.
- `packetToList()`: `[STX, ID, Length, CMD, MID+데이터, LRC, ETX]` 바이트 리스트로 변환.
- `Serial_Arduino.write(send_list)`: 시리얼로 전송한다.

### 4.7 동작 제어 (셀 8)

```python
while(True):
    # Moter_Control 리스트에 담겨있는 모터 제어값을 하나씩 가져옵니다.
    for data in Moter_Control:

        # MID_list 에 담겨있는 모터 MID 를 하나씩 가져옵니다.
        for mid in MID_list:

            # 모터 제어값을 아두이노에 전송합니다.
            Packet_send(Arduino_ID, CONTROL_DRIVE, mid, data)

        # 1초간 대기합니다.
        time.sleep(1.0)
```

- `while(True):`: **무한루프**. 모터가 계속 움직이므로 반드시 정지 셀을 별도로 실행해야 한다.
- `for data in Moter_Control:`: 제어값 시퀀스 [600, 0, -600, 0]을 하나씩 가져온다.
- `for mid in MID_list:`: 각 제어값에 대해 X(0x80), Y(0x81), Z(0x82) 순서로 3개 MID를 순회한다.
- `Packet_send(Arduino_ID, CONTROL_DRIVE, mid, data)`: 현재 MID에 제어값 data를 담아 모터 제어 패킷을 전송한다. (3개 축에 동일한 값 전송)
- `time.sleep(1.0)`: 1초 동안 현재 제어값을 유지한다. 따라서 [600→1초, 0→1초, -600→1초, 0→1초]가 반복된다.

### 4.8 제어 정지 (셀 9)

```python
# MID_list 에 담겨있는 모터 MID 를 하나씩 가져옵니다.
for mid in MID_list:

    # 모터 제어값을 아두이노에 전송합니다.
    Packet_send(Arduino_ID, CONTROL_DRIVE, mid, 0)
```

- `for mid in MID_list:`: X/Y/Z 3개 축을 순회하며...
- `Packet_send(Arduino_ID, CONTROL_DRIVE, mid, 0)`: 각 축에 제어값 **0**을 전송하여 모든 모터를 정지시킨다.
- **실습 종료 시 반드시 이 셀을 실행**해야 로봇이 계속 움직이지 않는다.

## 6. 주의사항 및 트러블슈팅

- **무한루프와 안전(중요)**: 셀 8은 끝나지 않는다. 실행 직후 로봇이 움직이므로, 관찰 후 반드시 **셀 9(정지)를 실행**하거나 **Kernel → Interrupt**로 중지한다. 로봇을 바닥에서 들어올려 바퀴만 회전시키는 방법도 안전하다.
- **포트 권한 오류**: `sudo chmod 777 /dev/ttyACM0` 실행 필요.
- **모듈 import 실패**: 작업 디렉터리가 `01. Device`인지 확인.
- **모터가 안 움직임**: 제어값 범위(-600~600)를 확인하고, Arduino 펌웨어와 모터 드라이버 전원을 점검한다.
- **한쪽 모터만 움직임**: MID 매핑(0x80/0x81/0x82)과 배선을 확인한다.
- **응답 대기 없음**: 이 노트북의 `Packet_send`는 Control 방식이라 `send_flag`가 없다. 12~14번 노트북의 요청용 함수와 혼동하지 않도록 주의한다.
- **정지 필수**: 커널을 종료해도 Arduino에는 마지막 제어값이 유지될 수 있으므로, 셀 9로 반드시 0을 보낸다.
