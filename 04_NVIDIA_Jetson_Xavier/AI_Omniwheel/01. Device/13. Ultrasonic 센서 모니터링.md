# 13. Ultrasonic 센서 모니터링

옴니휠 로봇 교육 과정에서 **직렬 통신(USB-UART)**으로 연결된 Arduino에 초음파 센서 값 요청 패킷을 보내고, 응답 패킷에서 **6개의 초음파 거리값**을 추출해 모니터링한다. 12번 실습(PSD)과 동일한 패킷 프로토콜 구조를 사용하며, MID만 0x80(초음파)로 다르다.

## 1. 학습 목표

- 초음파 센서의 측정 원리(음파 왕복 시간)를 이해한다.
- 12번 실습의 패킷 프로토콜을 복습하고, 센서별 MID 차이를 이해한다.
- 수신 문자열을 3자리씩 6개로 분할하는 슬라이싱 패턴을 익힌다.
- 6개 초음파의 방향별(전방, 측면 등) 거리 분포를 해석한다.

## 2. 준비 사항

### 2.1 필요 하드웨어

- 옴니휠 로봇 제어용 Arduino 보드(USB 연결, `/dev/ttyACM0`)
- 초음파 센서 6개(로봇 주위에 배치) - Arduino에 연결됨

### 2.2 필요 라이브러리 (설치 명령 포함)


### 2.3 사전 설정

## 4. 코드 해설 (원본 코드를 단계별로 블록 인용하고, 각 줄/함수의 역할을 상세 설명)

> 12번(PSD)과 중복되는 송수신 골격(셀 1, 4~11)은 동일하므로, 중복 설명은 줄이고 차이점을 중심으로 서술한다.

### 4.1 모듈 추가 (셀 1)

```python
import libraries.Omniwheel_Protocol as Omniwheel_Protocol
import serial
import time
```

- 통신 프로토콜 라이브러리, pyserial, time 표준 모듈을 import 한다.

### 4.2 프로토콜 정의 (셀 2)

```python
Arduino_ID = 0x20
REQUEST_Ultra_Sonic_SENSOR = 0xA1
ANSWER_Ultra_Sonic_SENSOR = 0xB1
MID_Ultra_Sonic_SENSOR =0x80
```

- `Arduino_ID = 0x20`: Arduino 고유 ID.
- `REQUEST_Ultra_Sonic_SENSOR = 0xA1`: 초음파 센서 값 요청 CMD.
- `ANSWER_Ultra_Sonic_SENSOR = 0xB1`: 초음파 센서 응답 CMD.
- `MID_Ultra_Sonic_SENSOR = 0x80`: 초음파 센서 데이터의 MID. (참고: 0x80=초음파/엔코더1번/X속도, 0x81=엔코더2번/Y속도/PSD, 0x82=엔코더3번/Z각속도)

### 4.3 변수 초기화 및 객체 생성 (셀 3~7)

```python
data_Ultrasonic_Sensors = 0
```

- 초음파 측정값(6개 거리 배열)을 저장할 전역 변수. 초기값 0.

```python
send_packet = Omniwheel_Protocol.Packet()
recv_packet = Omniwheel_Protocol.Packet()
```

- 송신/수신용 `Packet` 객체 생성. `Packet`은 STX(0x02)+ID+Length+CMD+Payload+LRC+ETX(0x03) 구조를 관리한다.

```python
recv_packet.clearPacket()
send_packet.clearPacket()
```

- 패킷 상태 초기화.

```python
recv_list = []
recv_parsing_packet = []
```

- 원시 수신 바이트 임시 리스트(`recv_list`)와 파싱 완료 패킷 큐(`recv_parsing_packet`).

```python
send_flag=False
```

- 송수신 동기화 플래그. (False=요청 가능, True=응답 대기)

### 4.4 통신 포트 초기화 (셀 8)

```python
Serial_Arduino = serial.Serial(port ="/dev/ttyACM0" ,baudrate = 115200, timeout=.1)
time.sleep(1)
print("connect complete")
```

- Arduino와 115200 baud, 타임아웃 0.1초로 직렬 포트를 연다.
- `time.sleep(1)`: 포트 안정화 대기 후 "connect complete" 출력.

### 4.5 송신 함수 (셀 9)

```python
def Packet_send(_id, _cmd, _mid, _data = None):
    # 전역변수 사용
    global send_flag
    
    # 전송 완료 플래그 확인 
    if(send_flag==False):
        
        # 초기화
        send_packet.clearPacket()
        
        # ID 설정
        send_packet.setID(_id)
        
        # CMD 설정
        send_packet.setCMD(_cmd)
        
        # Payload 초기화
        send_packet.clearPayload()
        
        # MID, data 설정
        send_packet.addPayload(_mid, _data)
        
        # 패킷 LRC 계산
        send_packet.calcLRC_Lower()
        
        # 패킷을 리스트로 변환
        send_list=send_packet.packetToList()
        
        # Arduino 에 패킷 리스트 전송
        Serial_Arduino.write(send_list)
        
        # 전송 완료 플래그 설정
        send_flag=True
```

- `Packet_send()`: 요청 패킷 송신 함수. 12번 실습과 동일하다.
- `send_flag`가 False일 때만 전송하고, 전송 직후 True로 바꿔 다음 요청을 막는다.
- `addPayload(_mid, _data)`에 데이터가 없으므로(MID만) 값 요청 패킷이 된다.

### 4.6 수신 함수 (셀 10)

```python
def Packet_receive(ser):
    # 전역변수 사용
    global send_flag
    
    # 전송 완료 플래그 확인
    if(send_flag==True):
        
        # 수신받은 데이터가 없을때까지
        while ser.inWaiting() > 0:
            
            # 1바이트씩 데이터를 받음
            Arduino_Data = ser.read(1)
            
            # 데이터를 받은 경우
            if(len(Arduino_Data)>0):
                
                # 수신 패킷 리스트에 수신 데이터 저장
                recv_list.append(ord(Arduino_Data))
                
                # 패킷 종료 데이터를 받은 경우
                if(ord(Arduino_Data)==0x03):
                    
                    # 수신 받은 데이터 파싱
                    if(recv_packet.parsingList(recv_list)):
                        
                        # 파싱한 데이터를 파싱완료 리스트에 저장
                        recv_parsing_packet.append(recv_packet)
                        
                        # 패킷 리스트 초기화
                        recv_list.clear()
                        
                        # 전송 완료 플래그 해제
                        send_flag=False
                        
                        # 반복문 탈출
                        break
```

- `Packet_receive(ser)`: 응답 수신 함수. send_flag가 True일 때만 읽는다.
- 1바이트씩 읽어 `ord()`로 정수화해 `recv_list`에 쌓고, **ETX(0x03)**를 만나면 `parsingList()`로 파싱한다.
- 파싱 성공 시 패킷을 완료 큐에 넣고, `send_flag=False`로 되돌려 다음 요청을 허용한다.

### 4.7 수신 리스트 초기화 함수 (셀 11)

```python
def Received_packet():
    # 파싱 완료 리스트의 첫번째 패킷을 result 변수에 저장함
    result=recv_parsing_packet[0]
    
    # 저장 완료한 파싱 완료 리스트 삭제 
    del recv_parsing_packet[0]
    
    # result 변수값 반환
    return result
```

- 파싱 완료 큐의 첫 패킷을 꺼내 반환하고 큐에서 제거한다.

### 4.8 센서 데이터 저장 함수 (셀 12)

```python
# 인자값으로 Received_packet() 함수에서 반환된 값을 넣어줌
def Ultrasonic_Data(packet):
    
    #전역 변수 사용
    global data_Ultrasonic_Sensors
    
    # 패킷에서 ID 추출
    packet_id=packet.getID()
    
    # 패킷에서 CMD 추출
    packet_cmd=packet.getCMD()
    
    # 추출한 ID 가 Arduino_ID 와 맞는지 확인
    if(packet_id==Arduino_ID):
        
        #추출한 CMD가 응답 CMD가 맞는지 확인
        if(packet_cmd==ANSWER_Ultra_Sonic_SENSOR):
            
            # 패킷에서 Payload 값을 추출함
            for payload in packet.getPayload():
                
                # 추출한 MID가 초음파 센서가 맞는지 확인
                if(payload.getID()==MID_Ultra_Sonic_SENSOR):
                    
                    # Payload 에서 읽어온 데이터를 버퍼에 저장 
                    buf=str(payload.getData())
                    
                    # 버퍼에 있는 데이터 값(초음파 센서 거리 값) 을 확인할수 있게 배열로 나누어 저장 
                    data_Ultrasonic_Sensors = [int(float(buf[:3])), 
                                               int(float(buf[3:6])),
                                               int(float(buf[6:9])), 
                                               int(float(buf[9:12])),
                                               int(float(buf[12:15])), 
                                               int(float(buf[15:]))]
```

- `Ultrasonic_Data(packet)`: 수신 패킷에서 초음파 거리값을 추출·저장하는 함수.
- ID가 Arduino_ID, CMD가 초음파 응답(0xB1)일 때만 진행한다.
- `for payload in packet.getPayload()`: 패킷의 Payload를 순회한다.
- `if(payload.getID()==MID_Ultra_Sonic_SENSOR)`: MID가 초음파(0x80)인지 확인.
- `buf=str(payload.getData())`: 6개 거리값이 3자리씩 이어붙어 온 문자열(총 18자리)을 얻는다.
- `data_Ultrasonic_Sensors = [int(float(buf[:3])), ..., int(float(buf[15:]))]`: 문자열을 **3자리씩 6개로 분할**해 각각 정수로 변환해 배열에 저장한다. (인덱스 0~5가 각각 6개 초음파의 거리값)

### 4.9 센서 값 모니터링 (셀 13)

```python
while(True):
    # 데이터 요청 패킷 송신
    Packet_send(Arduino_ID, REQUEST_Ultra_Sonic_SENSOR, MID_Ultra_Sonic_SENSOR)
    
    # 응답 데이터 패킷 수신
    Packet_receive(Serial_Arduino)
    
    # 응답받은 데이터가 있을경우
    if(len(recv_parsing_packet) > 0):
        # 파싱완료 리스트에서 첫번째 패킷을 가져옴
        p=Received_packet()
        
        # 수신한 패킷을 파싱하고 초음파 센서 거리값을 저장함
        Ultrasonic_Data(p)
        
        # 데이터 출력
        print("Ultra_Sonic : "+ str(data_Ultrasonic_Sensors))
        
    # 일정시간 대기
    time.sleep(0.5)
```

- `Packet_send(Arduino_ID, REQUEST_Ultra_Sonic_SENSOR, MID_Ultra_Sonic_SENSOR)`: 초음파 값 요청 전송.
- `Packet_receive(Serial_Arduino)`: 응답 수신·파싱.
- `if(len(recv_parsing_packet) > 0)`: 파싱 완료 패킷이 있으면 처리.
- `p=Received_packet()`: 첫 패킷을 꺼낸다.
- `Ultrasonic_Data(p)`: 6개 거리값을 배열에 저장.
- `print("Ultra_Sonic : "+ str(data_Ultrasonic_Sensors))`: 거리 배열 출력.
- `time.sleep(0.5)`: 0.5초 후 반복.

## 6. 주의사항 및 트러블슈팅

- **무한루프 중지**: 셀 13은 끝나지 않는다. **Kernel → Interrupt**로 중지한다.
- **포트 권한 오류**: `sudo chmod 777 /dev/ttyACM0` 실행 필요.
- **모듈 import 실패**: 작업 디렉터리가 `01. Device`인지 확인.
- **값이 0 또는 이상한 숫자**: 초음파가 측정 실패(측정 범위 초과/부족)하면 이상값이 나올 수 있다. 센서 각도와 반사 대상(음파 반사율)을 점검한다.
- **send_flag 고착**: ETX(0x03)를 받지 못하면 플래그가 풀리지 않아 요청이 멈춘다. 시리얼 연결을 점검한다.
- **분할 길이 오류**: `buf`가 18자리가 아니면 `int(float(...))` 변환 시 오류가 날 수 있다. 패킷 데이터 형식을 확인한다.
- **함수 정의 셀 먼저 실행**: 셀 9~12를 반드시 실행한 후 셀 13을 실행한다.
