# 12. PSD 센서 (Arduino 직렬통신으로 바닥면 PSD 측정)

## 1. 학습 목표
- Jetson과 Arduino 간 **직렬통신(UART, /dev/ttyUSB0)** 으로 센서 데이터를 주고받는 방법을 익힌다.
- `Omniwheel_Protocol.Packet` 클래스의 패킷 구성(STX/ID/CMD/MID/LRC)과 송수신 루틴을 이해한다.
- 요청 명령(0xA1 = 바닥 센서 요청)과 응답 명령(0xB1)의 흐름을 이해한다.
- 6자리 문자열 데이터를 3자리씩 나눠 파싱하는 방법을 배운다.
- **정의되지 않은 변수명 사용과 들여쓰기 구조 오류**를 찾아 고치는 능력을 기른다.

## 2. 준비 사항
### 2.1 필요 하드웨어
- NVIDIA Jetson Xavier NX 보드 (JetPack 4.x)
- Arduino 보드(옴니휠 로봇 하단 제어기) + 직렬(USB) 연결 케이블
- 바닥면(바닥 감지용) PSD 센서 (Arduino 아날로그 입력에 연결)

### 2.2 필요 라이브러리 (설치 명령 포함)
```bash
sudo pip3 install pyserial
```
- `Omniwheel_Protocol`은 외부 패키지가 아니라 프로젝트 내 모듈이다.
  - 이 아카이브에서 `Omniwheel_Protocol.py`는 `01. Device\libraries\` 아래에 있다.
  - **IoT2022 폴더에서 `import Omniwheel_Protocol`이 동작하려면** 해당 파일을 IoT2022 폴더로 복사하거나, `01. Device\libraries` 폴더가 현재 경로에 포함되어야 한다.

### 2.3 사전 설정
- Arduino를 USB로 Jetson에 연결하고 포트를 확인: `ls /dev/ttyUSB0`
- **포트 권한 부여** (필수):
  ```bash
  sudo chmod 777 /dev/ttyUSB0
  ```
  - 01. Device 버전은 `/dev/ttyACM0`, 115200을 사용하지만 **이 IoT2022 버전은 `/dev/ttyUSB0`, 9600** 이다. 반드시 이 값을 사용한다.
- 프로토콜 상수: Arduino_ID=0x20, 요청 CMD 0xA1(바닥 센서), 응답 CMD 0xB1, MID 0x81(바닥 PSD).

## 3. 실행 방법 (셀 실행 순서 안내)
1. `Omniwheel_Protocol`, `serial`, `time` import
2. 상수 정의 (Arduino_ID, REQUEST_BOTTOM_SENSOR, ANSWER_BOTTOM_SENSOR, MID_BOTTOM_PSD_SENSOR)
3. 시리얼 포트 `/dev/ttyUSB0` 9600으로 열기, 1초 대기 후 "connect complete" 확인
4. 패킷 송신(`Packet_send`), 수신(`Packet_receive`), 수신 파싱(`PSD_Data`) 함수 정의
5. 메인 루프에서 요청→수신→출력 반복

**중요**: 원본 코드에는 아래 5번의 오류(변수명 미정의 + 들여쓰기)가 있어 그대로 실행하면 동작하지 않는다. 반드시 수정 코드를 사용한다.

## 4. 코드 해설 (원본 코드 그대로)
```python
import Omniwheel_Protocol
import serial
import time

Arduino_ID = 0x20
REQUEST_BOTTOM_SENSOR = 0xA1
ANSWER_BOTTOM_SENSOR = 0xB1
MID_BOTTOM_PSD_SENSOR =0x81

data_PSD_Sensor = 0

send_packet = Omniwheel_Protocol.Packet()
recv_packet = Omniwheel_Protocol.Packet()
recv_packet.clearPacket()
send_packet.clearPacket()

recv_list = []
recv_parsing_packet = []

send_flag=False

Serial_Arduino = serial.Serial(port ="/dev/ttyUSB0", baudrate = 9600, timeout=.1)
time.sleep(1)
print("connect complete")

def Packet_send(_id, _cmd, _mid, _data = None):
    global send_flag

    if(send_flag==False):
        send_packet.clearPacket()
    send_packet.setID(_id)
    send_packet.setCMD(_cmd)
    send_packet.clearPayload()
    send_packet.addPayload(_mid, _data)
    send_packet.calcLRC_Lower()
    
    send_list=send_packet.packetToList()
    Serial_Arduino.write(send_list)
    send_flag=True
    
def Packet_receive(ser):
    global send_flag    
    if(send_flag==True):
        while ser.inWaiting() > 0:
            Arduino_Data = ser.read(1)
            if(len(Arduino_Data)>0):
                recv_list.append(ord(Arduino_Data))
                if(ord(Arduino_Data)==0x03):
                    if(recv_packet.parsingList(recv_list)):
                        recv_parsing_packet.append(recv_packet)
                        recv_list.clear()
                        send_flag=False
                        break
def Received_packet():
    result=recv_parsing_packet[0]
    del recv_parsing_packet[0]
    return result
def PSD_Data(packet):
    global data_PSD_Sensor
    packet_id=packet.getID()
    packet_cmd=packet.getCMD()
    if(packet_id==Arduino_ID):
        if(packet_cmd==ANSWER_PSD_SENSOR):
            for payload in packet.getPayload():
                if(payload.getID()==MID_PSD_SENSOR):
                    buf=str(payload.getData())
                    data_PSD_Sensor = [int(float(buf[:3])), int(float(buf[3:6])), int(float(buf[6:]))]
                    while(True):
                        Packet_send(Arduino_ID, REQUEST_PSD_SENSOR, MID_PSD_SENSOR)
                        Packet_receive(Serial_Arduino)
                        if(len(recv_parsing_packet) > 0):
                            p=Received_packet()
                            PSD_Data(p)
                            print("PSD : "+str(data_PSD_Sensor))
                            time.sleep(0.5)
```

**줄 단위 해설**
- `import Omniwheel_Protocol`: 프로젝트의 직렬 패킷 프로토콜 모듈. `Packet` 클래스를 제공한다.
- `import serial / time`: pyserial 시리얼 통신 모듈과 지연 모듈.
- `Arduino_ID = 0x20`: 통신 대상 Arduino의 ID.
- `REQUEST_BOTTOM_SENSOR = 0xA1`: 바닥 센서 데이터 요청 명령.
- `ANSWER_BOTTOM_SENSOR = 0xB1`: Arduino가 보내는 응답 명령.
- `MID_BOTTOM_PSD_SENSOR = 0x81`: 바닥 PSD 센서 데이터의 MID(메시지 ID).
- `data_PSD_Sensor = 0`: 측정값 저장용 전역 변수 초기화.
- `send_packet / recv_packet = Omniwheel_Protocol.Packet()`: 송수신용 패킷 객체 2개 생성 후 `clearPacket()`으로 버퍼 초기화.
- `recv_list = []`: 수신 바이트 임시 저장 리스트. / `recv_parsing_packet = []`: 파싱 완료된 패킷 객체 리스트.
- `send_flag = False`: 송수신 상태 플래그. 요청 후 응답을 받기 전까지 중복 요청을 막는다.
- `Serial_Arduino = serial.Serial(port="/dev/ttyUSB0", baudrate=9600, timeout=.1)`: **포트 /dev/ttyUSB0, 9600bps, 0.1초 타임아웃**으로 시리얼 열기. 이후 `time.sleep(1)` 안정화 대기 후 `print("connect complete")`로 연결 확인.
- `def Packet_send(_id, _cmd, _mid, _data=None):`: 패킷을 만들어 보내는 함수.
  - `setID(_id)` / `setCMD(_cmd)`: 패킷의 ID와 명령 코드(CMD) 필드 설정.
  - `clearPayload()` / `addPayload(_mid, _data)`: 페이로드를 비운 뒤 MID와 데이터로 추가.
  - `calcLRC_Lower()`: LRC(오류 검증 체크섬) 계산. / `packetToList()`: 패킷을 바이트 리스트로 변환.
  - `Serial_Arduino.write(send_list)`: 시리얼로 전송.
- `def Packet_receive(ser):`: 응답 바이트를 읽어 패킷으로 파싱.
  - `ser.inWaiting() > 0`: 수신 버퍼에 데이터가 있는 동안 `ser.read(1)`로 1바이트씩 읽고 `ord()`로 정수화.
  - `ord(Arduino_Data)==0x03`: **0x03(ETX, 패킷 끝)이면** `recv_packet.parsingList(recv_list)`로 패킷 파싱. 성공하면 `recv_parsing_packet`에 저장.
  - `send_flag=False`: 응답을 받았으므로 다음 요청을 허용.
- `def Received_packet():`: 큐의 맨 앞 패킷을 꺼내 반환.
- `def PSD_Data(packet):`: 응답 패킷에서 PSD 데이터를 추출하는 함수.
  - `packet.getID() == Arduino_ID`: 우리 보드로 온 패킷인지 확인. / `packet_cmd == ANSWER_PSD_SENSOR`: 응답 명령 확인. **(원본은 `ANSWER_PSD_SENSOR` 미정의)**
  - `packet.getPayload()` 순회 중 `payload.getID() == MID_PSD_SENSOR`인 페이로드 선택. **(원본은 `MID_PSD_SENSOR` 미정의)**
  - `buf=str(payload.getData())`: 데이터를 문자열로 변환.
  - `[int(float(buf[:3])), int(float(buf[3:6])), int(float(buf[6:]))]`: **6자리 값을 3자리씩 2개 센서값으로 분할**. 예: "050080" → [50, 80].
  - **문제**: 원본은 `while(True)` 루프가 이 함수 안에 중첩되어 있고, 함수 밖(모듈 레벨)에서 호출되는 곳이 없다. 따라서 프로그램이 아무것도 실행하지 않는다.

## 5. 원본 코드의 오타/수정 안내
원본에는 **2가지 치명적 문제**가 있다.

**문제 1: 정의되지 않은 변수명 사용**
- 정의된 상수는 `REQUEST_BOTTOM_SENSOR`, `ANSWER_BOTTOM_SENSOR`, `MID_BOTTOM_PSD_SENSOR`다.
- 그런데 `PSD_Data()` 내부에서 `ANSWER_PSD_SENSOR`, `MID_PSD_SENSOR`, `REQUEST_PSD_SENSOR`를 사용 → `NameError` 발생.
- 수정: 정의된 이름으로 통일.

**문제 2: 메인 루프의 위치 오류 (들여쓰기)**
- `while(True):` 루프가 `PSD_Data()` 함수의 if문 안쪽에 중첩되어 있고, `PSD_Data()`를 최초로 호출하는 코드가 없다.
- → 루프가 시작되지 않아 동작하지 않는다.
- 수정: `while(True)` 루프를 함수 밖(모듈 레벨)으로 옮기고, 최초 1회 요청 후 응답을 받을 때마다 재요청하는 구조로 바꾼다.

**수정 코드 (전체)**:

- 0.5초 간격으로 바닥 PSD 센서 2개의 값이 [전, 후] 형태로 출력된다.
- 센서를 손으로 가리면 값이 변화하는 것을 볼 수 있다.

## 7. 주의사항 및 트러블슈팅
- **반드시 수정 코드 사용**: 변수명(`ANSWER_PSD_SENSOR` 등)과 루프 위치를 고치지 않으면 동작하지 않는다.
- **포트와 baudrate**: 이 IoT2022 버전은 `/dev/ttyUSB0`, **9600**. 01. Device 버전(`/dev/ttyACM0`, 115200)을 그대로 쓰면 안 된다.
- **포트 권한**: `sudo chmod 777 /dev/ttyUSB0`을 실행하지 않으면 `PermissionError`가 발생한다.
- **Omniwheel_Protocol.py 위치**: IoT2022 폴더에 없으면 `ModuleNotFoundError`. `01. Device\libraries\Omniwheel_Protocol.py`를 IoT2022 폴더로 복사한다.
- **`send_flag` 의미**: 응답이 오기 전까지 다음 요청을 보내지 않도록 하는 역할. 응답이 안 오면 `send_flag=True`에 머물러 요청이 막힌다. 시리얼 연결/전원을 확인한다.
- **Arduino 프로그램**: Arduino 쪽에 바닥 PSD 센서 응답(0xB1)을 보내는 스케치가 로드되어 있어야 한다.

## 8. 실습 과제
1. 바닥 PSD 값이 100 이상이면 "장애물 감지"를 출력하도록 분기하라.
2. 측정 주기(`time.sleep`)를 0.1초/1초로 바꿔 응답 속도 차이를 비교하라.
3. 두 PSD 값의 평균을 계산해 출력하라.
4. `Packet_send`의 `_data` 파라미터에 임의 데이터를 넣어 Arduino로 요청을 보내고 동작을 확인하라.
5. 30초간 PSD 값을 저장하고 최대/최소를 출력하는 코드를 작성하라.
