# 4. Motion (Jetson.GPIO를 이용한 모션 센서 감지)

## 1. 학습 목표
- Jetson.Xavier NX의 GPIO 핀을 제어하는 `Jetson.GPIO` 라이브러리 사용법을 익힌다.
- GPIO 핀을 입력으로 설정하고(`GPIO.setup`) 디지털 값을 읽는 방법을 배운다.
- 모션(움직임) 센서가 LOW 신호를 출력하면 "모션 감지"를 표시하는 로직을 구현한다.
- 무한 루프(`while True`)와 폴링(polling) 방식의 센서 감지를 이해한다.

### 1.1 배경 지식: Jetson.GPIO와 디지털 입력
- Jetson.GPIO는 NVIDIA Jetson 시리즈 전용 GPIO 라이브러리로, Raspberry Pi의 RPi.GPIO와 문법이 매우 유사하다.
- 핀 지정 방식에는 `GPIO.BOARD`(물리 핀 번호), `GPIO.TEGRA_SOC`(테그라 SOC 핀 이름) 등이 있다. 이 실습은 `'UART2_RTS'`처럼 **핀 이름 문자열**을 사용하므로 `GPIO.TEGRA_SOC` 모드와 어울린다.
- `GPIO.setup(pin, GPIO.IN)`은 핀을 입력으로 설정하는 예약 명령이다. **이 코드에는 `setmode`가 누락되어 있어 일부 버전에서 예외가 발생**하므로 5번의 수정을 적용한다.
- 이 모션 센서는 감지 시 **LOW(0)** 를 출력한다. 따라서 `if(value == 0)` 판정을 사용한다.
- `time.sleep(0.3)`을 넣지 않으면 CPU가 버스를 계속 폴링해 부하가 커진다.

## 2. 준비 사항
### 2.1 필요 하드웨어
- NVIDIA Jetson Xavier NX 보드 (JetPack 4.x)
- 디지털 출력 모션 센서 1개
- 센서 신호선을 Jetson GPIO 핀 **'UART2_RTS'** 에 연결

### 2.2 필요 라이브러리 (설치 명령 포함)
```bash
sudo pip3 install Jetson.GPIO
```
- Jetson.GPIO는 NVIDIA Jetson 전용 GPIO 라이브러리이다. (Raspberry Pi의 RPi.GPIO와 API가 유사하다.)

### 2.3 사전 설정
- Jetson 보드의 GPIO 핀 레이아웃을 확인하고 'UART2_RTS' 핀 위치를 파악한다.
- 모션 센서의 VCC/GND/OUT 핀을 올바르게 연결한다. (센서 사양에 따라 3.3V 또는 5V)
- GPIO 접근 권한이 필요할 수 있다: `sudo chmod 777 /sys/class/gpio/export` (또는 사용자를 gpio 그룹에 추가)
- 핀 번호 표시 확인: `sudo python3 -c "import Jetson.GPIO as GPIO; print(GPIO.getmode())"`

### 2.4 센서 핀 레이아웃 (일반적인 연결)
| 센서 핀 | Jetson 연결 | 설명 |
| --- | --- | --- |
| VCC | 3.3V (또는 5V) | 전원 |
| GND | GND | 접지 |
| OUT | 'UART2_RTS' | 디지털 출력 신호 |

## 3. 실행 방법 (셀 실행 순서 안내)
1. `Jetson.GPIO`와 `time` 모듈 import
2. 감지할 핀 이름('UART2_RTS')을 변수에 저장
3. 해당 핀을 입력 모드로 설정
4. `while True` 루프에서 핀 값을 읽어 0이면 "모션 감지" 출력 후 0.3초 대기

셀 실행 후 센서 앞에서 움직임이 감지되면 "모션 감지"가 반복 출력된다. 중지하려면 Jupyter 정지 버튼을 누른다.

**단계별 예상 확인 포인트**
- 셀 실행 직후 오류 없이 루프가 시작되면 정상이다. (5번의 setmode 수정이 적용되었는지 확인)
- 센서 앞에서 손을 흔들면 "모션 감지"가 출력된다.
- 움직임이 없을 때는 아무것도 출력되지 않아야 한다.
- 항상 출력되거나 전혀 출력되지 않으면 7번의 트러블슈팅을 참고한다.

**중단 방법**: 이 실습은 무한 루프이므로 반드시 정지(■) 버튼으로 중지한다.

## 4. 코드 해설 (원본 코드 그대로)
```python
import Jetson.GPIO  as GPIO
import time
Motion = 'UART2_RTS'
GPIO.setup(Motion, GPIO.IN)
while True:
    value = GPIO.input(Motion)
    if(value == 0):
        print("모션 감지")
        time.sleep(0.3)
```

**줄 단위 해설**
- `import Jetson.GPIO as GPIO`: Jetson 전용 GPIO 라이브러리를 `GPIO` 별칭으로 import.
- `import time`: 대기 시간 제어용.
- `Motion = 'UART2_RTS'`: 모션 센서가 연결된 GPIO 핀 이름을 문자열로 지정. Jetson.GPIO는 핀 번호 대신 보드의 핀 이름(테그라 명칭)을 사용할 수 있다.
- `GPIO.setup(Motion, GPIO.IN)`: 해당 핀을 **입력 모드**로 설정해 디지털 값을 읽을 준비를 한다.
- `while True:`: 무한 반복 시작(폴링).
- `value = GPIO.input(Motion)`: 핀에서 디지털 값(0 또는 1)을 읽는다.
- `if(value == 0):`: 값이 0(LOW)일 때 조건 성립. 이 모션 센서는 움직임 감지 시 LOW 신호를 출력한다.
- `print("모션 감지")`: 감지 메시지 출력.
- `time.sleep(0.3)`: 0.3초 대기. 반복 출력 속도를 조절하고 GPIO 읽기 부하를 줄인다.

**동작 요약**: 0.3초마다 핀을 폴링하다가 LOW(0) 신호가 읽히면 "모션 감지"를 출력한다.

**동작 흐름 정리**
| 단계 | 동작 | 상세 |
| --- | --- | --- |
| 1 | 핀 설정 | 'UART2_RTS' 핀을 입력 모드로 설정 |
| 2 | 폴링 | `GPIO.input()`으로 디지털 값을 읽음 |
| 3 | 판정 | 값이 0(LOW)이면 감지 메시지 출력 |
| 4 | 대기 | 0.3초 대기 후 반복 |

- 센서가 감지 상태(LOW)를 계속 유지하면 메시지가 0.3초 간격으로 반복 출력된다.
- 감지 신호가 순간(펄스)만 발생하는 센서라면 메시지가 1회만 출력될 수 있다.

## 5. 원본 코드의 오타/수정 안내
이 노트북에는 **치명적 오류는 없지만 `GPIO.setmode()`가 누락**되어 있다.

- **문제**: Jetson.GPIO는 `GPIO.setmode(GPIO.TEGRA_SOC)`(또는 `GPIO.BOARD`) 호출 없이 `GPIO.setup()`을 사용하면 일부 버전에서 `ValueError: Please set pin numbering mode using GPIO.setmode()` 예외가 발생한다.
- **수정 전 (원본)**:
```python
Motion = 'UART2_RTS'
GPIO.setup(Motion, GPIO.IN)
```
- **수정 후 (권장)**:
```python
GPIO.setmode(GPIO.TEGRA_SOC)   # 또는 GPIO.BOARD
Motion = 'UART2_RTS'
GPIO.setup(Motion, GPIO.IN)
```
- 핀 이름('UART2_RTS')을 문자열로 사용한다면 `GPIO.TEGRA_SOC` 모드가 알맞다.
- 정리(cleanup)를 원하면 루프 종료 후 `GPIO.cleanup()`을 호출한다.

**학습 포인트 요약**
- `Jetson.GPIO`는 RPi.GPIO와 유사하지만 Jetson 전용이며, 핀 지정 방식에 따라 `setmode`가 필요하다.
- 디지털 입력은 `GPIO.setup(pin, GPIO.IN)` → `GPIO.input(pin)` 순서로 읽는다.
- 이 모션 센서는 **감지 시 LOW(0)** 를 출력하므로 `if(value == 0)`으로 판정한다.
- `time.sleep`을 넣어 폴링 주기를 조절하면 반응 속도와 CPU 부하를 조절할 수 있다.
- 무한 루프는 Jupyter 정지(■) 버튼으로만 종료된다는 점을 반드시 기억한다.

## 6. 실행 결과 예시
- 센서에 움직임이 없을 때: 화면에 아무것도 출력되지 않는다.
- 움직임이 감지될 때:
  ```
  모션 감지
  모션 감지
  ```
- 센서의 감지 범위 안에서 손을 흔들면 메시지가 반복 출력된다.
- 센서의 감지 후 복귀 지연(잠금 시간)이 있으면 메시지가 끊겨 나올 수 있다. 이는 센서 특성이며 코드 문제가 아니다.

## 7. 주의사항 및 트러블슈팅
- **setmode 누락**: 위 5번의 수정을 반드시 적용한 뒤 실행한다.
- **핀 번호/이름**: 핀 이름이 정확해야 한다. `jetson-gpio`의 핀 레이아웃 문서에서 'UART2_RTS' 위치를 확인한다.
- **권한 오류**: `Permission denied`가 나면 `sudo`로 Jupyter를 실행하거나 gpio 그룹 권한을 부여한다: `sudo usermod -aG gpio $USER`.
- **센서 로직 반전**: 이 센서는 감지 시 LOW(0)이다. HIGH(1)일 때 감지하는 센서면 `if(value == 1)`로 바꾼다.
- **노이즈**: 모터 등 주변 장치가 켜져 있으면 신호가 불안정할 수 있다. 풀업/풀다운 저항이 있는 센서인지 확인한다.
- **항상 "모션 감지" 출력**: 핀이 제대로 연결되지 않았거나 플로팅(부유) 상태면 값이 불안정하다. GND에 쇼트되는지 확인한다.
- **전혀 감지 안 됨**: 센서 OUT이 다른 핀에 연결되어 있는지, VCC 전원이 제대로 인가되는지, 핀 이름이 올바른지 확인한다.
- **GPIO 경고 메시지**: Jetson.GPIO가 `Channel already in use` 경고를 내면 이전 셀에서 cleanup이 안 됐을 수 있다. 커널 재부팅 또는 `GPIO.cleanup()` 실행 후 다시 시도한다.
- **다른 실습과 GPIO 공유**: 'UART2_RTS'가 다른 기능(UART 통신)과 공유되는 핀일 수 있다. 사용 중인 핀 표를 확인한다.
- **재실행 시 초기화**: Jupyter 커널을 재시작하면 GPIO 설정이 초기화된다. 재실행 전 셀을 위에서부터 순서대로 다시 실행한다.

## 8. 실습 과제
1. 감지 시 "모션 감지" 대신 감지 횟수를 카운트해 출력하라.
   - 힌트: `count = 0`을 두고 감지 시 `count += 1` 후 `print("감지 횟수:", count)`.
2. LOW 신호가 아닌 HIGH 신호로 감지하도록 센서에 맞게 로직을 수정하라.
   - 힌트: `if(value == 1):`로 바꾸고 실제 센서 출력을 먼저 출력해 확인한다.
3. 0.3초 대기 시간을 0.1초 / 1초로 바꿔 반응 속도를 비교하라.
   - 힌트: 대기가 짧을수록 반응이 빠르지만 CPU 부하가 커진다.
4. 모션 감지가 3회 누적되면 "경고!" 메시지를 출력하는 코드를 작성하라.
   - 힌트: 감지 횟수가 3이 되면 "경고!" 출력 후 횟수를 0으로 리셋한다.
5. `try/finally` 구조를 사용해 루프 종료 시 `GPIO.cleanup()`이 호출되도록 만들어 보라.
   - 힌트: `try:` 안에 while 루프를 두고 `finally:`에 `GPIO.cleanup()`을 넣으면 셀이 중단되어도 정리된다.
6. 모션 감지와 함께 부저(3.busio 방식)를 1초간 울리는 코드를 작성하라.
   - 힌트: 감지 시 PCA9685 채널 15를 50% 듀티로 1초 구동 후 끈다.
7. 감지 횟수를 리스트에 저장하고 10회 모으면 평균 감지 간격을 출력하라.
   - 힌트: `times = []`에 `time.time()`을 기록하고 `times[i+1]-times[i]`로 간격을 구한다.
