# 14. 엔코더/오도미터 (PSD.ipynb 파일명, 실제로는 바퀴 엔코더·오도미터 측정)

## 1. 학습 목표
- 파일명은 12.PSD와 같지만 **실제 내용은 옴니휠 로봇의 3개 바퀴 엔코더(오도미터) 측정**이다.
- 직렬통신으로 **오도미터 요청(0xA0)** 과 **엔코더 초기화(0xC2)** 명령을 보내는 방법을 익힌다.
- 응답 명령 0xB0에서 MID 0x80(X/엔코더1), 0x81(Y/엔코더2), 0x82(Z/엔코더3) 값을 분리하는 로직을 이해한다.
- **print 문의 문자열 연결 오류**(따옴표가 잘못 배치된 `str()` 호출)를 찾아 고치는 능력을 기른다.

## 2. 준비 사항
### 2.1 필요 하드웨어
- NVIDIA Jetson Xavier NX 보드 (JetPack 4.x)
- Arduino 보드 + USB 케이블
- 옴니휠 로봇의 3개 휠 엔코더(각각 MID 0x80/0x81/0x82)

### 2.2 필요 라이브러리 (설치 명령 포함)
```bash
sudo pip3 install pyserial
```
- `Omniwheel_Protocol.py`: `01. Device\libraries\` 아래에 있다. IoT2022 폴더로 복사하거나 해당 폴더가 현재 경로에 있어야 한다.

### 2.3 사전 설정
- 포트 확인: `ls /dev/ttyUSB0`
- **포트 권한 부여**: `sudo chmod 777 /dev/ttyUSB0`
- 이 IoT2022 버전은 **`/dev/ttyUSB0`, 9600** 사용. (01. Device 버전은 `/dev/ttyACM0`, 115200)
- 프로토콜: Arduino_ID=0x20, REQUEST_ODOMETER=0xA0, ANSWER_ODOMETER=0xB0, ENCODER_CLEAR=0xC2.

## 3. 실행 방법 (셀 실행 순서 안내)
1. 모듈 import 및 상수 정의 (MID_list에 3개 엔코더 MID 저장)
2. 시리얼 열기(/dev/ttyUSB0, 9600), "connect complete" 확인
3. 송신/수신/파싱 함수 정의
4. 엔코더 카운트를 0으로 초기화(`ENCODER_CLEAR`) 후
5. `while(True)`에서 3개 엔코더를 순회하며 요청→수신→출력

**중요**: 원본 print 문에 문자열 연결 오류가 있어 표시가 깨진다. 5번의 수정 코드를 사용한다.

## 4. 코드 해설 (원본 코드 그대로)
```python
import Omniwheel_Protocol
import serial
import time

Arduino_ID = 0x20
REQUEST_ODOMETER = 0xA0
ANSWER_ODOMETER = 0xB0
ENCODER_CLEAR = 0xC2
MID_ENCODER_WHEEL_1 = 0x80
MID_ENCODER_WHEEL_2 = 0x81
MID_ENCODER_WHEEL_3 = 0x82
MID_list = [MID_ENCODER_WHEEL_1,
            MID_ENCODER_WHEEL_2,
            MID_ENCODER_WHEEL_3]
data_wheel_1_encoder_count = 0
data_wheel_2_encoder_count = 0
data_wheel_3_encoder_count = 0
send_packet = Omniwheel_Protocol.Packet()
recv_packet = Omniwheel_Protocol.Packet()
recv_packet.clearPacket()
send_packet.clearPacket()
recv_list = []
recv_parsing_packet = []
send_flag = False
Serial_Arduino = serial.Serial(port="/dev/ttyUSB0", baudrate=9600, timeout=.1)
time.sleep(1)
print("connect complete")

def Packet_send(_id, _cmd, _mid, _data=None):
    global send_flag
    if(send_flag == False):
        send_packet.clearPacket()
        send_packet.setID(_id)
        send_packet.setCMD(_cmd)
        send_packet.clearPayload()
        send_packet.addPayload(_mid, _data)
        send_packet.calcLRC_Lower()
        send_list = send_packet.packetToList()
        Serial_Arduino.write(send_list)
        send_flag = True
def Packet_receive(ser):
    global send_flag
    if(send_flag == True):
        while ser.inWaiting() > 0:
            Arduino_Data = ser.read(1)
            if(len(Arduino_Data) > 0):
                recv_list.append(ord(Arduino_Data))
                if(ord(Arduino_Data) == 0x03):
                    if(recv_packet.parsingList(recv_list)):
                        recv_parsing_packet.append(recv_packet)
                        recv_list.clear()
                        send_flag = False
                        break

def Received_packet():
    result = recv_parsing_packet[0]
    del recv_parsing_packet[0]
    return result


def Encoder_Data(packet):
    global MID_list
    global data_wheel_1_encoder_count
    global data_wheel_2_encoder_count
    global data_wheel_3_encoder_count

    packet_id = packet.getID()
    packet_cmd = packet.getCMD()

    if(packet_id == Arduino_ID):
        if(packet_cmd == ANSWER_ODOMETER):
            for payload in packet.getPayload():
                if(payload.getID() == MID_list[0]):
                    data_wheel_1_encoder_count = int(float(payload.getData()))
                elif(payload.getID() == MID_list[1]):
                    data_wheel_2_encoder_count = int(float(payload.getData()))
                elif(payload.getID() == MID_list[2]):
                    data_wheel_3_encoder_count = int(float(payload.getData()))

Packet_send(Arduino_ID, ENCODER_CLEAR, None)
send_flag = False
while(True):
    for mid in MID_list:
        Packet_send(Arduino_ID, REQUEST_ODOMETER, mid)
        time.sleep(0.1)
        Packet_receive(Serial_Arduino)
        if(len(recv_parsing_packet) > 0):
            p = Received_packet()
            Encoder_Data(p)
        print("X:"
            "+str(data_wheel_1_encoder_count)+"
            "+str(data_wheel_2_encoder_count)"+" Z: "+str(data_wheel_3_encoder_count))
        time.sleep(0.5)
```

**줄 단위 해설**
- `import Omniwheel_Protocol / serial / time`: 프로토콜, 시리얼, 지연 모듈.
- `Arduino_ID = 0x20`: Arduino ID.
- `REQUEST_ODOMETER = 0xA0`: 오도미터(엔코더 카운트) 요청 명령.
- `ANSWER_ODOMETER = 0xB0`: 오도미터 응답 명령.
- `ENCODER_CLEAR = 0xC2`: 엔코더 카운트를 0으로 초기화하는 명령.
- `MID_ENCODER_WHEEL_1/2/3 = 0x80/0x81/0x82`: 3개 휠 엔코더의 MID. (X, Y, Z 축에 대응)
- `MID_list = [0x80, 0x81, 0x82]`: 순회용 MID 리스트.
- `data_wheel_1/2/3_encoder_count = 0`: 각 휠의 엔코더 카운트 저장 변수.
- `send_packet / recv_packet = Omniwheel_Protocol.Packet()` 후 `clearPacket()`: 송수신 패킷 객체 및 초기화.
- `recv_list = []`, `recv_parsing_packet = []`, `send_flag = False`: 수신 버퍼, 파싱 큐, 송수신 플래그.
- `Serial_Arduino = serial.Serial(port="/dev/ttyUSB0", baudrate=9600, timeout=.1)`: 시리얼 열기 후 `time.sleep(1)` 대기, `print("connect complete")`로 연결 확인.
- `def Packet_send(...)`: 요청 패킷 송신. (이 실습은 `send_flag`가 False일 때만 패킷을 만들고 보내는 구조)
- `def Packet_receive(ser):`: ETX(0x03)까지 수신해 패킷으로 파싱하고 `recv_parsing_packet`에 저장. / `def Received_packet():`: 큐에서 패킷을 꺼내 반환.
- `def Encoder_Data(packet):`: 오도미터 응답에서 MID별 엔코더 카운트를 분리.
  - `packet_cmd == ANSWER_ODOMETER`: 0xB0 응답 확인.
  - `payload.getID() == MID_list[0/1/2]`: 0x80/0x81/0x82에 따라 각각 1번/2번/3번 휠 카운트를 갱신. `int(float(payload.getData()))`로 문자열 숫자를 정수 변환.
- `Packet_send(Arduino_ID, ENCODER_CLEAR, None)`: 시작 전 엔코더를 0으로 초기화. 그 후 `send_flag = False`로 플래그 리셋.
- `while(True):` 메인 루프: `for mid in MID_list:`로 3개 MID를 순회하며 `Packet_send`로 오도미터 요청 → `time.sleep(0.1)` 응답 대기 → `Packet_receive` 수신 → 패킷이 있으면 `Encoder_Data`로 값 갱신.
  - `print("X:" ... )`: 현재 값을 출력. **이 print 문이 오류 위치** (아래 5번 참고).
  - `time.sleep(0.5)`: 루프 주기.

## 5. 원본 코드의 오타/수정 안내
원본의 print 문에 **문자열 연결 오류**가 있다.

**문제: print 문의 따옴표 배치 오류**
- 수정 전:
  ```python
  print("X:"
      "+str(data_wheel_1_encoder_count)+"
      "+str(data_wheel_2_encoder_count)"+" Z: "+str(data_wheel_3_encoder_count))
  ```
- 이 코드에서 `"+str(data_wheel_1_encoder_count)+"`와 `"+str(data_wheel_2_encoder_count)"` 부분은 **문자열 안에 있는 글자**로 취급된다. 즉 `+str(...)+`가 문자 그대로 출력된다. 의도는 `"X:" + str(data_wheel_1_encoder_count) + " Y: " + str(data_wheel_2_encoder_count) + " Z: " + str(...)`이다.
- 원본대로 실행하면 `X:+str(...)+`+str(...)`같은 깨진 문자열이 출력된다.

**수정 후**:
```python
print("X:" + str(data_wheel_1_encoder_count) + " Y: " + str(data_wheel_2_encoder_count) + " Z: " + str(data_wheel_3_encoder_count))
```
(원본에 Y 라벨이 빠져 있어 의도상 "Y" 라벨을 추가했다. 단순히 `str()` 호출만 살리고 싶으면 `" X:" + str(...) + " " + str(...) + " Z: " + str(...)` 형태로 고치면 된다.)

## 6. 실행 결과 예시
```
connect complete
X:0 Y:0 Z:0
X:12 Y:-3 Z:0
X:25 Y:-7 Z:1
```
- X/Y/Z(각각 1/2/3번 휠 엔코더) 카운트가 출력된다.
- 휠을 손으로 돌리면 해당 축의 카운트가 증가/감소한다.
- 부호는 회전 방향을 의미한다.

## 7. 주의사항 및 트러블슈팅
- **print 문 수정 필수**: 따옴표 배치를 고치지 않으면 깨진 문자열이 출력된다.
- **파일명 혼동**: 14.PSD.ipynb 파일명이지만 내용은 엔코더/오도미터다. 12.PSD(바닥 PSD)와 혼동하지 않는다.
- **포트와 baudrate**: 이 IoT2022 버전은 `/dev/ttyUSB0`, **9600**. 01. Device 버전(ACM0, 115200)을 쓰면 안 된다.
- **포트 권한**: `sudo chmod 777 /dev/ttyUSB0` 실행.
- **Omniwheel_Protocol.py**: IoT2022 폴더에 없으면 `ModuleNotFoundError`. `01. Device\libraries`에서 복사.
- **초기화 확인**: 시작 시 `ENCODER_CLEAR(0xC2)`로 카운트가 0이 되어야 한다. 계속 증가한다면 초기화가 안 된 것이므로 Arduino 스케치를 확인한다.

## 8. 실습 과제
1. X 엔코더 카운트만 100회 모아 평균 증가율을 계산하라.
2. Z축 카운트가 50 이상이면 "회전 감지"를 출력하도록 분기하라.
3. `ENCODER_CLEAR`를 루프 안에서 주기적으로 호출해 리셋 동작을 확인하라.
4. 카운트 변화량(델타)을 계산해 속도에 해당하는 값을 출력하라.
5. 세 축의 카운트 절대값 합이 1000이 되면 "이동 완료"를 출력하는 코드를 작성하라.
