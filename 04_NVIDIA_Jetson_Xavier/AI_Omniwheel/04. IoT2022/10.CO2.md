# 10. CO2 센서 (CCS811 이산화탄소/TVOC 측정)

## 1. 학습 목표
- CCS811 대기질 센서(I2C)를 사용해 이산화탄소(eco2)와 TVOC를 측정하는 방법을 익힌다.
- `adafruit_ccs811` 라이브러리의 `eco2`, `tvoc` 속성 사용법을 이해한다.
- 공기 질 지표(CO2, TVOC)의 의미와 실내 환경 모니터링 활용을 이해한다.

### 1.1 배경 지식: CO2와 TVOC
- **CO2(이산화탄소)**: 호흡에 의해 실내 농도가 상승한다. 일반적으로 **1000ppm 이상이면 환기가 필요**한 것으로 알려져 있다. (외기 CO2 ≈ 400ppm)
- **TVOC(총휘발성유기화합물)**: 페인트, 세제, 가구 등에서 방출되는 휘발성 유기물질의 총량. 원단위는 ppb이다.
- CCS811은 내부에 온습도 보정이 필요한 금속산화물(MOX) 방식 센서로, 첫 측정값이 안정되기까지 **워밍업 시간**이 필요하다.
- `eco2`는 "이산화탄소 등가 농도"로, 정확한 CO2가 아니라 환경 오염 종합 지표의 일종이다.
- 이 센서도 I2C 디지털 센서이므로 ADC 환산이 필요 없다.

## 2. 준비 사항
### 2.1 필요 하드웨어
- NVIDIA Jetson Xavier NX 보드 (JetPack 4.x)
- CCS811 대기질 센서 모듈 (I2C 주소 0x5B)

### 2.2 필요 라이브러리 (설치 명령 포함)
```bash
sudo pip3 install adafruit-circuitpython-ccs811
```

### 2.3 사전 설정
- CCS811의 SCL/SDA를 Jetson의 **SCL_1 / SDA_1** 핀에 연결한다.
- `sudo i2cdetect -y -r 1`로 0x5B 주소 확인.
- WAKE 핀이 있는 모듈이면 GND로 내려 활성 상태를 유지한다.

### 2.4 배선 요약
| CCS811 핀 | Jetson 연결 | 비고 |
| --- | --- | --- |
| VCC | 3.3V | 전원 |
| GND | GND | 접지 |
| SCL | SCL_1 | I2C 클록 |
| SDA | SDA_1 | I2C 데이터 |
| WAKE | GND | LOW 유지 시 활성 |

## 3. 실행 방법 (셀 실행 순서 안내)
1. 모듈 import
2. I2C(100kHz) 및 CCS811 객체 생성 (주소 0x5B 명시)
3. `while True`에서 eco2/tvoc를 읽어 출력하고 1초 대기

**주의**: CCS811은 첫 측정값이 신뢰할 수 없고 안정화(워밍업) 시간이 필요하다.

**단계별 예상 확인 포인트**
- 셀 실행 직후 CO2/TVOC가 매초 출력된다.
- 초기 값은 400ppm 부근 고정값 또는 부정확한 값일 수 있다. (워밍업 필요)
- 몇 분 뒤 숨을 센서 근처에서 내쉬면 CO2가 서서히 상승한다.
- 창문을 열어 환기하면 값이 다시 내려가는 것을 관찰한다.

**중단 방법**: 무한 루프이므로 정지(■) 버튼으로 중지한다.

## 4. 코드 해설 (원본 코드 그대로)
```python
import time
import busio
import board
import adafruit_ccs811
i2c = busio.I2C(board.SCL_1, board.SDA_1, frequency = 100000)
ccs811 = adafruit_ccs811.CCS811(i2c, 0x5b)
while True:
    eco2 = ccs811.eco2
    tvoc = ccs811.tvoc
    print("CO2: %1.0f PPM" %eco2)
    print("TVOC: %1.0f PPM" %tvoc)
    time.sleep(1)
```

**줄 단위 해설**
- `import time`: 지연 시간 모듈.
- `import busio / board`: I2C 버스 및 핀 정의 모듈.
- `import adafruit_ccs811`: CCS811 드라이버 모듈.
- `i2c = busio.I2C(board.SCL_1, board.SDA_1, frequency = 100000)`: SCL_1/SDA_1로 I2C 버스를 100kHz로 초기화.
- `ccs811 = adafruit_ccs811.CCS811(i2c, 0x5b)`: I2C 주소 **0x5B**를 명시해 CCS811 객체 생성. (드라이버가 센서 보정을 로드하고 시작)
- `while True:`: 무한 측정 루프.
- `eco2 = ccs811.eco2`: 이산화탄소 등가 농도(CO2 eq)를 ppm 단위로 읽는다.
- `tvoc = ccs811.tvoc`: 총 휘발성 유기화합물(TVOC)을 ppb 단위로 읽는다.
- `print("CO2: %1.0f PPM" %eco2)`: CO2 농도를 소수점 없는 정수 형태로 출력. `%1.0f`는 폭 최소 1 + 소수점 0자리로 `%.0f`와 동일하다.
- `print("TVOC: %1.0f PPM" %tvoc)`: TVOC 농도 출력.
- `time.sleep(1)`: 1초 대기 후 재측정.

**동작 요약**: 매초 CO2(ppm)와 TVOC(ppb) 농도를 출력한다. 실내에서 숨을 내쉬면 CO2 농도가 서서히 상승하는 것을 관찰할 수 있다.

**실내 CO2 기준 (참고)**
| 농도 | 상태 |
| --- | --- |
| ~400 ppm | 외기 수준 (쾌적) |
| 400~1000 ppm | 일반 실내 (무난) |
| 1000 ppm 이상 | 환기 권고 |
| 2000 ppm 이상 | 졸림·두통 유발 가능 |

- 원본은 TVOC를 "PPM"으로 표기하지만 단위 표기는 데이터시트 기준으로 PPB가 정확하다.

## 5. 원본 코드의 오타/수정 안내
이 노트북의 코드는 **오타 없이 정상 동작**한다.

참고 사항(필수 아님):
- `%1.0f`를 `%.0f` 또는 `%d`로 바꿔도 동일한 표시 결과를 얻는다.
- CCS811의 TVOC 단위는 데이터시트 기준 ppb이지만, 원본 출력은 "PPM"으로 표기한다. 표기를 맞추려면 `print("TVOC: %1.0f PPB" %tvoc)`로 수정하면 된다.

**학습 포인트 요약**
- `eco2`, `tvoc` 속성을 읽는 것만으로 대기질 지표를 얻을 수 있다는 것이 핵심이다.
- MOX 방식 센서는 **워밍업·베이스라인 안정화 시간**이 필요하므로 첫 값에 현혹되지 않는다.
- CO2 1000ppm 기준으로 환기 필요 여부를 판정하는 응용이 가능하다.
- 7~10번 실습까지 모두 "디지털 I2C 센서 = 전압 환산 없이 속성 읽기" 패턴이라는 공통점을 확인한다.

## 6. 실행 결과 예시
- 실내 환기가 잘 된 상태:
  ```
  CO2: 412 PPM
  TVOC: 5 PPM
  ```
- 사람이 여러 명 있는 밀폐된 공간에서 잠시 후:
  ```
  CO2: 1200 PPM
  TVOC: 180 PPM
  ```
- CO2 1000ppm 이상은 환기가 필요하다고 알려진 기준이다.
- TVOC 값은 CO2와 함께 변하는 경향이 있다. 페인트 냄새가 나는 공간에서는 TVOC만 크게 상승할 수 있다.
- 숨을 센서에 직접 불면 CO2가 순간적으로 높게 나타난다. (호기 CO2 농도 ≈ 40000ppm)

## 7. 주의사항 및 트러블슈팅
- **워밍업**: 전원 투입 직후 첫 값은 400ppm 등 고정값이거나 부정확하다. 수 분간 두고 관찰한다.
- **baseline 설정**: 신뢰할 수 있는 값은 일정 시간(수십 분) 구동 후 얻어진다.
- **I2C 주소**: 기본 0x5B. WAKE 핀이 제대로 연결되지 않으면 읽기가 실패할 수 있다.
- **NTC/보정**: 일부 모듈은 정확한 보정을 위해 주변 온도가 필요하다.
- **I2C 버스**: `board.SCL_1/SDA_1` 사용. 오류 시 01. Device 버전과 구분.
- **데이터시트 기준**: 값이 0으로만 출력되면 센서 에러 상태를 의미할 수 있으니 배선과 전압을 확인한다.
- **반응 지연**: MOX 센서는 가스 농도 변화에 수십 초~수 분 단위의 응답 지연이 있다. 즉시 반응하지 않아도 정상이다.
- **에러 값 출력**: 라이브러리가 에러 상태를 나타내는 특수값(예: 0 또는 -1)을 반환하면 배선·전원·WAKE 핀을 점검한다.
- **다른 I2C 장치와 충돌**: 버스에 여러 장치가 연결된 경우 주소가 겹치지 않는지 `i2cdetect`로 확인한다.

## 8. 실습 과제
1. 1분 간격으로 CO2를 기록하고 그래프로 출력하라.
   - 힌트: 값 리스트를 유지하고 `matplotlib`의 `plt.plot()`으로 표시한다.
2. CO2가 1000ppm을 초과하면 "환기 필요!"를 출력하도록 분기하라.
   - 힌트: `if eco2 > 1000:`로 분기한다.
3. 숨을 10초간 센서 근처에서 내쉬고 CO2 변화를 관찰·기록하라.
   - 힌트: 워밍업 후 실험하고, 변화가 나타나는 데 시간이 걸릴 수 있음을 관찰한다.
4. eco2와 tvoc 값을 CSV 파일로 저장하는 코드를 작성하라.
   - 힌트: `open("air.csv", "a")`로 append 모드에서 쉼표 구분 한 줄씩 기록한다.
5. CO2 값에 따라 LED 색(빨강/초록)을 바꾸는 실습을 1.LED와 결합해 작성하라.
   - 힌트: `eco2 > 1000`이면 채널 A(빨강)를 켜고, 아니면 채널 B(초록)를 켠다.
6. eco2와 tvoc의 비율(tvoc/eco2)을 계산해 대기 상태를 추정해 보라.
   - 힌트: 비율이 높으면 휘발성 오염원(페인트·세제)이 주범일 가능성이 크다.
7. CO2가 1500ppm을 연속 3회 초과하면 "경고!"를 출력하는 코드를 작성하라.
   - 힌트: 카운트 변수를 두고 조건 충족 시 1씩 증가, 아니면 0으로 리셋한다.
8. 측정값을 5분 동안 1분 간격으로 기록하고 평균 CO2를 출력하라.
   - 힌트: `for i in range(5):` 안에서 값을 누적하고 `time.sleep(60)`으로 간격을 둔다.
9. eco2 값을 50ppm 단위로 반올림해 출력하라.
   - 힌트: `round(eco2/50) * 50`으로 계산한다.
