# 11. 미세먼지 센서 (PCF8591 A0 + GPIO LED 제어)

## 1. 학습 목표
- 아날로그 출력형 미세먼지(분진) 센서를 PCF8591 ADC의 **A0 채널**로 읽는 방법을 익힌다.
- 미세먼지 센서 구동에 필요한 LED 발광 제어(GPIO)와 타이밍(펄스 제어)의 원리를 이해한다.
- `Jetson.GPIO`로 보드 GPIO 핀(`CAM_AF_EN`)을 출력 모드로 제어하는 방법을 배운다.
- 미세먼지 농도 판정을 위해 전압값을 읽는 시퀀스(0.28ms LOW → 측정 → 0.04ms 대기 → 9.68ms HIGH)를 이해한다.

### 1.1 배경 지식: 아날로그 미세먼지 센서의 측정 원리
- 아날로그 미세먼지(분진) 센서는 내부에 **적외선 LED와 포토다이오드**를 갖고 있다. LED가 먼지에 반사된 적외선을 포토다이오드가 받아 전압으로 변환한다.
- 먼지가 많을수록 반사광이 강해 **출력 전압이 높아진다**. 전압이 높을수록 미세먼지 농도가 높다.
- LED를 켜고 끄는 시점을 데이터시트에 맞춰야 안정적인 측정이 가능하다. (펄스 폭 ~0.32ms, 주기 10ms)
- 이 코드는 ADC 읽기를 위해 센서 내부 LED를 **LOW로 꺼서 노이즈를 줄이고**, 측정 후 다시 **HIGH로 켜는** 시퀀스를 반복한다.
- 전압(V)을 농도(µg/m³)로 환산하려면 센서 데이터시트의 특성 곡선(예: `농도 ≈ a × V + b`)을 적용해야 한다. 원본은 원시 전압만 출력한다.

## 2. 준비 사항
### 2.1 필요 하드웨어
- NVIDIA Jetson Xavier NX 보드 (JetPack 4.x)
- PCF8591 ADC 모듈 (I2C 주소 0x48)
- 아날로그 미세먼지(분진) 센서 (예: GP2Y1010AU0F 계열) → PCF8591의 **A0** 채널, 센서 내부 LED 구동선은 GPIO **'CAM_AF_EN'** 핀에 연결

### 2.2 필요 라이브러리 (설치 명령 포함)
```bash
sudo pip3 install adafruit-circuitpython-pcf8591 Jetson.GPIO
```

### 2.3 사전 설정
- PCF8591의 SCL/SDA를 Jetson의 **SCL_1 / SDA_1** 핀에 연결한다.
- 센서의 AOUT을 PCF8591 AIN0(A0)에, 센서 LED 제어선을 'CAM_AF_EN' GPIO 핀에 연결.
- `sudo i2cdetect -y -r 1`로 0x48 확인. GPIO 권한 확인(`sudo chmod 777 /sys/class/gpio/export`).

### 2.4 배선 요약
| 센서/모듈 핀 | Jetson/PCF8591 연결 | 비고 |
| --- | --- | --- |
| VCC (센서) | 5V | LED 구동 전원 |
| GND | GND | 접지 |
| V-LED (센서) | GPIO 'CAM_AF_EN' | 내부 LED 제어 |
| AOUT (센서) | PCF8591 AIN0(A0) | 측정 전압 |
| PCF8591 SCL/SDA | Jetson SCL_1/SDA_1 | I2C |

## 3. 실행 방법 (셀 실행 순서 안내)
1. 모듈 import (imp, time, busio, board, PCF8591, AnalogIn, Jetson.GPIO)
2. GPIO 핀 'CAM_AF_EN'을 출력 모드로 설정하고 HIGH로 초기화
3. I2C/PCF8591 객체 생성, A0 채널 AnalogIn 객체 생성
4. `while True`에서 센서 LED를 LOW로 끄고 → 측정 → HIGH로 켜는 타이밍에 맞춰 전압을 읽어 출력

**중요**: 원본 코드에 `GPIO.outpit` 오타가 있어 그대로 실행하면 실패한다. 5번의 수정 코드를 먼저 적용한다.

## 4. 코드 해설 (원본 코드 그대로)
```python
import imp
import time
import busio
import board
import adafruit_pcf8591.pcf8591 as PCF
from adafruit_pcf8591.analog_in import AnalogIn
import Jetson.GPIO as GPIO
Light = 'CAM_AF_EN'
GPIO.setup(Light, GPIO.OUT)
GPIO.output(Light, GPIO.HIGH)
i2c = busio.I2C(board.SCL_1, board.SDA_1, frequency = 100000)
pcf = PCF.PCF8591(i2c)
pcf_in_0 = AnalogIn(pcf, PCF.A0)
while True:
    GPIO.outpit(Light, GPIO.LOW)
    time.sleep(0.00028)
    raw_value = pcf_in_0.value
    scaled_value = (raw_value/65535) * pcf_in_0.reference_voltage
    time.sleep(0.00004)
    GPIO.output(Light, GPIO.HIGH)
    time.sleep(0.00968)
    print("미세먼지량 : %.2f"%scaled_value)
```

**줄 단위 해설 (오타 수정 전의 의미 기준)**
- `import imp`: Python의 내장 모듈 import 유틸리티. 이 코드에서는 실제로 사용되지 않지만 원본에 남아 있다.
- `import time / busio / board`: 지연, I2C 버스, 핀 정의 모듈.
- `import adafruit_pcf8591.pcf8591 as PCF`: PCF8591 드라이버를 `PCF`로 import.
- `from adafruit_pcf8591.analog_in import AnalogIn`: 아날로그 입력 클래스 import.
- `import Jetson.GPIO as GPIO`: Jetson GPIO 라이브러리.
- `Light = 'CAM_AF_EN'`: 미세먼지 센서 내부 적외선 LED를 구동할 GPIO 핀 이름.
- `GPIO.setup(Light, GPIO.OUT)`: 해당 핀을 **출력 모드**로 설정.
- `GPIO.output(Light, GPIO.HIGH)`: LED를 켠 상태(HIGH)로 시작.
- `i2c = busio.I2C(board.SCL_1, board.SDA_1, frequency = 100000)`: I2C 버스 초기화.
- `pcf = PCF.PCF8591(i2c)`: PCF8591(0x48) 객체 생성.
- `pcf_in_0 = AnalogIn(pcf, PCF.A0)`: **A0 채널** 읽기 객체 생성.
- `while True:`: 무한 측정 루프.
- `GPIO.output(Light, GPIO.LOW)`: 센서 LED를 **끄고**(LOW) 측정을 준비. (원본은 `outpit` 오타)
- `time.sleep(0.00028)`: 0.28ms 대기. 이 타이밍은 미세먼지 센서 데이터시트의 LED 펄스 규격(펄스 폭 0.32ms)과 맞추기 위한 것이다.
- `raw_value = pcf_in_0.value`: ADC 원시값(0~65535) 읽기.
- `scaled_value = (raw_value/65535) * pcf_in_0.reference_voltage`: 원시값을 0~1로 정규화 후 기준 전압을 곱해 전압(V)으로 환산.
- `time.sleep(0.00004)`: 0.04ms 추가 대기.
- `GPIO.output(Light, GPIO.HIGH)`: 측정 후 LED를 다시 켠다.
- `time.sleep(0.00968)`: 9.68ms 대기. LED 펄스 주기 규격(10ms)에 맞추기 위한 것이다.
- `print("미세먼지량 : %.2f"%scaled_value)`: 환산 전압을 소수점 2자리로 출력.

**동작 요약**: GPIO로 센서 내부 LED를 10ms 주기로 점멸시키며 그에 동기화해 ADC 전압을 읽고, 전압값으로 미세먼지 농도를 대략 판단한다. 전압이 높을수록 미세먼지가 많다.

**타이밍 시퀀스 (한 사이클 = 약 10ms)**
| 단계 | 동작 | 시간 |
| --- | --- | --- |
| 1 | LED OFF (GPIO LOW) | 시작 |
| 2 | 대기 | 0.28ms |
| 3 | ADC 읽기 (raw_value) | 즉시 |
| 4 | 추가 대기 | 0.04ms |
| 5 | LED ON (GPIO HIGH) | 즉시 |
| 6 | 대기 (주기 10ms 완성) | 9.68ms |

- 각 사이클마다 `미세먼지량 : 0.XX`가 출력된다.

## 5. 원본 코드의 오타/수정 안내
이 노트북에는 **`GPIO.outpit` → `GPIO.output` 오타 1곳**이 있다.

- **수정 (while 루프 내)**
  - 수정 전: `GPIO.outpit(Light, GPIO.LOW)`
  - 수정 후: `GPIO.output(Light, GPIO.LOW)`
  - 수정하지 않으면 `AttributeError: module 'Jetson.GPIO' has no attribute 'outpit'` 오류가 난다.

참고 사항(필수 아님):
- `import imp`는 이 코드에서 사용되지 않으므로 삭제해도 된다. (`imp`는 Python 3.12에서 제거된 내장 모듈이라 일부 환경에서 오류가 날 수 있다)
- 4.Motion 실습과 달리 이 코드에는 `GPIO.setmode()`가 없는데, 'CAM_AF_EN' 같은 테그라 핀 이름 사용 시 일부 버전에서 `GPIO.setmode(GPIO.TEGRA_SOC)`가 필요할 수 있다. 오류가 나면 추가한다.

**전체 수정 코드**:
```python
import time
import busio
import board
import adafruit_pcf8591.pcf8591 as PCF
from adafruit_pcf8591.analog_in import AnalogIn
import Jetson.GPIO as GPIO
GPIO.setmode(GPIO.TEGRA_SOC)
Light = 'CAM_AF_EN'
GPIO.setup(Light, GPIO.OUT)
GPIO.output(Light, GPIO.HIGH)
i2c = busio.I2C(board.SCL_1, board.SDA_1, frequency = 100000)
pcf = PCF.PCF8591(i2c)
pcf_in_0 = AnalogIn(pcf, PCF.A0)
while True:
    GPIO.output(Light, GPIO.LOW)
    time.sleep(0.00028)
    raw_value = pcf_in_0.value
    scaled_value = (raw_value/65535) * pcf_in_0.reference_voltage
    time.sleep(0.00004)
    GPIO.output(Light, GPIO.HIGH)
    time.sleep(0.00968)
    print("미세먼지량 : %.2f"%scaled_value)
```

## 6. 실행 결과 예시
- 청정한 실내: `미세먼지량 : 0.45`
- 담배 연기/먼지를 센서 근처에 흩뿌리면 값이 상승: `미세먼지량 : 1.87`
- (전압은 센서·모듈 특성에 따라 다르므로 상대 변화로 판단한다)

## 7. 주의사항 및 트러블슈팅
- **오타 수정 필수**: `outpit` → `output`을 반드시 적용한다.
- **타이밍 중요**: 미세먼지 센서는 LED 펄스 폭(약 0.32ms)과 주기(10ms)가 데이터시트에 정해져 있다. `sleep` 값을 임의로 바꾸면 측정 정확도가 떨어진다.
- **전압-농도 환산**: 출력 전압(V)을 mg/m³ 농도로 바꾸려면 센서 데이터시트의 특성 곡선(경험식)을 적용해야 한다. 원본은 원시 전압만 출력한다.
- **GPIO 모드**: 'CAM_AF_EN' 핀 이름 사용 시 `GPIO.setmode(GPIO.TEGRA_SOC)`가 필요할 수 있다.
- **I2C 버스**: `board.SCL_1/SDA_1` 사용. 오류 시 01. Device 버전과 구분.
- **센서 열 발생**: 미세먼지 센서 내부 LED가 발열하므로 장시간 구동 시 온도 영향으로 측정치가 드리프트할 수 있다.

## 8. 실습 과제
1. 측정 전압을 데이터시트 특성 곡선을 참고해 농도(µg/m³)로 변환하는 함수를 작성하라.
2. 10회 측정의 평균값을 출력하라.
3. 전압이 0.8V 이상이면 "미세먼지 많음"을 출력하는 분기 코드를 작성하라.
4. GPIO LED(센서용) 대신 PWM을 이용해 펄스 주기를 바꿔보고 측정값 변화를 관찰하라.
5. 미세먼지 농도가 높아지면 부저(3.busio)로 알림이 울리도록 결합하라.
