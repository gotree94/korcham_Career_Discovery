# 5. PIR 센서 (PCF8591 ADC를 이용한 인체 감지)

## 1. 학습 목표
- PCF8591 ADC(Analog-to-Digital Converter)를 사용해 아날로그 센서 값을 읽는 방법을 익힌다.
- `adafruit_pcf8591` 라이브러리의 사용법(A1 채널, reference_voltage)을 이해한다.
- ADC 원시값(0~65535)을 실제 전압으로 환산하는 공식을 이해한다.
- 특정 전압(1.6V) 이상이면 PIR(인체 감지)로 판정하는 임계값 논리를 구현한다.

### 1.1 배경 지식: PCF8591 ADC와 전압 환산
- PCF8591은 8비트 ADC를 내장한 I2C 장치로, 4개의 아날로그 입력 채널(A0~A3)을 갖는다.
- CircuitPython 드라이버는 원시값을 **0~65535(16비트 스케일)** 로 확장해 `value` 속성으로 제공한다.
- 실제 전압 환산식: `전압(V) = (raw_value / 65535) × reference_voltage`
  - 예: raw_value = 32767, reference = 3.3V → 1.65V
- PIR 센서가 아날로그 전압을 출력하며, 인체 감지 시 전압이 올라가는 특성을 가진다. (1.6V 초과 판정)
- A1 채널 상수는 `PCF.A1`이며 `AnalogIn(pcf, PCF.A1)`로 읽는다.

## 2. 준비 사항
### 2.1 필요 하드웨어
- NVIDIA Jetson Xavier NX 보드 (JetPack 4.x)
- PCF8591 ADC 모듈 (I2C 주소 0x48)
- PIR 센서 (아날로그 전압 출력) → PCF8591의 **A1** 채널에 연결

### 2.2 필요 라이브러리 (설치 명령 포함)
```bash
sudo pip3 install adafruit-circuitpython-pcf8591
```

### 2.3 사전 설정
- PCF8591의 SCL/SDA를 Jetson의 **SCL_1 / SDA_1** 핀에 연결한다.
- PIR 센서의 출력(AOUT)을 PCF8591의 AIN1 핀에 연결한다.
- `sudo i2cdetect -y -r 1`로 0x48 주소 확인.

### 2.4 배선 요약
| PCF8591 핀 | 연결 | 비고 |
| --- | --- | --- |
| SCL | Jetson SCL_1 | I2C 클록 |
| SDA | Jetson SDA_1 | I2C 데이터 |
| AIN1(A1) | PIR 센서 출력 | 측정 채널 |
| VREF | 3.3V | 기준 전압 (환산에 사용) |

## 3. 실행 방법 (셀 실행 순서 안내)
1. 모듈 import (버스, 핀, PCF8591, AnalogIn)
2. I2C 및 PCF8591 객체 생성
3. A1 채널의 AnalogIn 객체 생성
4. `while True`에서 값을 읽고 1.6V 초과 시 "PIR 센서 감지됨" 출력

**중요**: 원본 코드에 `mport`/`Analogln` 오타가 있어 그대로 실행하면 실패한다. 반드시 5번의 수정 코드를 먼저 적용할 것.

**단계별 예상 확인 포인트**
- 셀 실행 직후 `NameError`가 나지 않고 루프가 시작되면 오타 수정이 완료된 것이다.
- 사람이 접근하면 "PIR 센서 감지됨"이 출력된다.
- 사람이 없어지면 출력이 멈춘다.
- 아무 반응이 없으면 `print(pcf_in_1.value)`로 원시값을 먼저 확인해 전압과 임계값을 조정한다.

**중단 방법**: 무한 루프이므로 정지(■) 버튼으로 중지한다.

## 4. 코드 해설 (원본 코드 그대로)
```python
import busio
import board
import adafruit_pcf8591.pcf8591 as PCF
from adafruit_pcf8591.analog_in mport Analogln
import time
i2c = busio.I2C(board.SCL_1, board.SDA_1)
pcf = PCF.PCF8591(i2c)
pcf_in_1 = Analogln(pcf, PCF.A1)
while True:
    raw_value = pcf_in_1.value
    scaled_value = (raw_value / 65535) * pcf_in_1.reference_voltage
    if(scaled_value) > 1.6:
        print("PIR 센서 감지됨")
    time.sleep(0.3)
```

**줄 단위 해설 (오타 수정 전의 의미 기준)**
- `import busio / board`: I2C 버스와 보드 핀 정의 모듈.
- `import adafruit_pcf8591.pcf8591 as PCF`: PCF8591 드라이버를 `PCF` 별칭으로 import. 채널 상수(A0~A3)도 여기에 정의되어 있다.
- `from adafruit_pcf8591.analog_in import AnalogIn`: 아날로그 입력 객체(`AnalogIn`)를 import. (원본은 `mport`, `Analogln` 오타)
- `i2c = busio.I2C(board.SCL_1, board.SDA_1)`: I2C 버스 초기화.
- `pcf = PCF.PCF8591(i2c)`: PCF8591(0x48) 객체 생성.
- `pcf_in_1 = AnalogIn(pcf, PCF.A1)`: **A1 채널**을 읽는 아날로그 입력 객체 생성. (원본은 `Analogln` 오타)
- `while True:`: 무한 폴링 루프.
- `raw_value = pcf_in_1.value`: ADC 원시값(0~65535, 16비트)을 읽는다. PCF8591은 8비트 ADC지만 CircuitPython 드라이버가 16비트 스케일로 확장해 준다.
- `scaled_value = (raw_value / 65535) * pcf_in_1.reference_voltage`: 원시값을 0~1로 정규화한 뒤 기준 전압(reference_voltage, 보통 3.3V 또는 5V)을 곱해 실제 전압으로 환산한다.
- `if(scaled_value) > 1.6:`: 환산 전압이 1.6V를 초과하면 PIR 감지로 판정.
- `print("PIR 센서 감지됨")`: 감지 메시지 출력.
- `time.sleep(0.3)`: 0.3초 대기 후 다시 읽기.

**동작 요약**: A1 채널의 전압을 주기적으로 읽어 1.6V보다 높으면 "PIR 센서 감지됨"을 출력한다.

**전압 환산 예시** (reference_voltage = 3.3V)
| raw_value | 환산 전압 | 판정 |
| --- | --- | --- |
| 13107 | 0.66V | 미감지 |
| 32767 | 1.65V | 감지 (1.6V 초과) |
| 65535 | 3.30V | 감지 (최대) |

- 위 표는 이해를 돕기 위한 예시이며, 실제 전압은 센서와 배선에 따라 다르다.
- 판정 경계 근처(1.6V 부근)에서는 출력이 깜빡일 수 있으므로 임계값에 여유를 두는 것이 좋다.

## 5. 원본 코드의 오타/수정 안내
이 노트북에는 **2개의 오타**가 있다. 반드시 아래 수정을 적용해야 실행된다.

- **수정 1: import 오타**
  - 수정 전: `from adafruit_pcf8591.analog_in mport Analogln`
  - 수정 후: `from adafruit_pcf8591.analog_in import AnalogIn`
- **수정 2: 변수/클래스명 오타 (`Analogln` → `AnalogIn`)**
  - 수정 전: `pcf_in_1 = Analogln(pcf, PCF.A1)`
  - 수정 후: `pcf_in_1 = AnalogIn(pcf, PCF.A1)`

**전체 수정 코드**:
```python
import busio
import board
import adafruit_pcf8591.pcf8591 as PCF
from adafruit_pcf8591.analog_in import AnalogIn
import time
i2c = busio.I2C(board.SCL_1, board.SDA_1)
pcf = PCF.PCF8591(i2c)
pcf_in_1 = AnalogIn(pcf, PCF.A1)
while True:
    raw_value = pcf_in_1.value
    scaled_value = (raw_value / 65535) * pcf_in_1.reference_voltage
    if(scaled_value) > 1.6:
        print("PIR 센서 감지됨")
    time.sleep(0.3)
```

**학습 포인트 요약**
- ADC 원시값(0~65535)을 `(raw / 65535) × reference_voltage`로 환산하는 공식이 핵심이다.
- `AnalogIn`은 대소문자까지 정확히 일치해야 한다. (`Analogln` 오타에 주의)
- 감지 임계값(1.6V)은 센서 특성에 맞춰 조정이 필요하다.

## 6. 실행 결과 예시
- 사람이 센서 앞에 없을 때: 출력 없음.
- 사람이 접근/움직임이 있을 때:
  ```
  PIR 센서 감지됨
  PIR 센서 감지됨
  ```
- 전압이 1.6V를 오르내리는 경계 상태라면 메시지가 간헐적으로 출력될 수 있다.

## 7. 주의사항 및 트러블슈팅
- **오타 수정 필수**: `mport`→`import`, `Analogln`→`AnalogIn`을 반드시 적용한다.
- **임계값 조정**: 감지가 잘 안 되면 1.6V 기준을 1.0V 등으로 낮춰 보정한다. 반대로 노이즈 감지가 잦으면 2.0V로 올린다.
- **A1 채널 배선**: 센서 출력이 PCF8591의 AIN1(A1)에 연결되어 있어야 한다. A0에 연결했다면 `PCF.A0`로 바꾼다.
- **기준 전압**: `reference_voltage`는 PCF8591의 VREF 배선에 따라 달라진다. 환산 전압이 이상하면 VREF 배선을 확인한다.
- **I2C 버스**: 이 버전은 `board.SCL_1/SDA_1`. 오류 시 01. Device의 `board.SCL/SDA`와 혼동하지 않게 한다.
- **값이 0으로만 출력**: 센서 전원이 인가되지 않았거나 AIN1에 연결이 끊어졌을 수 있다. 배선을 점검한다.
- **계속 감지 상태**: 임계값이 너무 낮으면 항상 감지로 판정될 수 있다. 실제 전압을 먼저 출력해 경계값을 확인한다.

## 8. 실습 과제
1. 감지 전압(1.6V)을 바꿔가며 감도 차이를 실험하라.
2. 감지 시점에 "PIR 감지!" 메시지를 한 번만 출력하고 3초간 잠금(재감지 무시)하는 코드를 작성하라.
3. 전압이 1.6V 이하일 때 "감지 안됨"을 출력하도록 else를 추가하라.
4. 감지 횟수를 누적 카운트하여 출력하라.
5. A1 대신 A2 채널에 같은 센서를 연결하고 코드를 수정해 동작을 확인하라.
