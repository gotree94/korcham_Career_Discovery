# 6. Flame 센서 (화염 감지)

## 1. 학습 목표
- PCF8591 ADC의 **A2 채널**을 이용해 화염 센서 값을 읽는 방법을 익힌다.
- ADC 원시값을 전압으로 환산하는 공식을 복습하고 응용한다.
- 화염 센서의 특성(불꽃 근처에서 전압 하락)을 이해하고 1.6V 미만 판정 로직을 구현한다.
- 이전 실습(5.PIR)과 비교해 임계값 부등호의 방향이 센서 특성에 따라 달라짐을 이해한다.

### 1.1 배경 지식: 화염 센서의 특성
- 화염 센서는 불꽃에서 나오는 적외선을 감지한다. 불꽃이 가까울수록 수신되는 적외선이 많아진다.
- 모듈에 따라 **불꽃 감지 시 출력 전압이 내려가는 특성**을 가지며, 이 실습은 `1.6V 미만`을 감지 조건으로 사용한다.
- 따라서 5.PIR 실습의 `>1.6`과 반대로 `<1.6`이다. 같은 ADC 코드라도 **센서 특성에 따라 부등호 방향이 달라짐**을 보여준다.
- I2C 초기화 시 `frequency=100000`(100kHz)를 지정해 더 안정적인 통신을 한다.

## 2. 준비 사항
### 2.1 필요 하드웨어
- NVIDIA Jetson Xavier NX 보드 (JetPack 4.x)
- PCF8591 ADC 모듈 (I2C 주소 0x48)
- 화염(Flame) 센서 → PCF8591의 **A2** 채널에 연결

### 2.2 필요 라이브러리 (설치 명령 포함)
```bash
sudo pip3 install adafruit-circuitpython-pcf8591
```

### 2.3 사전 설정
- PCF8591의 SCL/SDA를 Jetson의 **SCL_1 / SDA_1** 핀에 연결한다.
- 화염 센서의 AOUT을 PCF8591의 AIN2(A2)에 연결.
- `sudo i2cdetect -y -r 1`로 0x48 확인.

### 2.4 배선 요약
| PCF8591 핀 | 연결 | 비고 |
| --- | --- | --- |
| SCL | Jetson SCL_1 | I2C 클록 |
| SDA | Jetson SDA_1 | I2C 데이터 |
| AIN2(A2) | 화염 센서 출력 | 측정 채널 |
| VREF | 3.3V | 기준 전압 |

## 3. 실행 방법 (셀 실행 순서 안내)
1. 모듈 import 및 I2C/PCF8591 객체 생성 (주파수 100kHz 지정)
2. A2 채널 AnalogIn 객체 생성
3. `while True`에서 값을 읽어 1.6V 미만이면 "Flame 센서 감지됨" 출력

**중요**: 원본 코드에 `Analogln` 오타가 있어 그대로 실행하면 실패한다. 5번의 수정 코드를 먼저 적용한다.

**단계별 예상 확인 포인트**
- 셀 실행 직후 오류가 없어야 한다. (`AnalogIn` 수정 완료 확인)
- 불꽃(라이터/초)을 가까이 하면 "Flame 센서 감지됨"이 출력된다.
- 불꽃을 치우면 출력이 멈춘다.
- 반응이 없으면 전압을 먼저 출력해 임계값(1.6V)과 배선을 확인한다.

**중단 방법**: 무한 루프이므로 정지(■) 버튼으로 중지한다. 실험 후 불꽃을 반드시 소화한다.

## 4. 코드 해설 (원본 코드 그대로)
```python
import busio
import board
import adafruit_pcf8591.pcf8591 as PCF
from adafruit_pcf8591.analog_in import Analogln
import time
i2c = busio.I2C(board.SCL_1, board.SDA_1, frequency = 100000)
pcf = PCF.PCF8591(i2c)
pcf_in_2 = Analogln(pcf, PCF.A2)
while True:
    raw_value = pcf_in_2.value
    scaled_value = (raw_value / 65535) * pcf_in_2.reference_voltage
    if(scaled_value < 1.6):
        print("Flame 센서 감지됨")
        
    time.sleep(0.3)
```

**줄 단위 해설 (오타 수정 전의 의미 기준)**
- `import busio / board`: I2C 버스 및 핀 정의 모듈.
- `import adafruit_pcf8591.pcf8591 as PCF`: PCF8591 드라이버를 `PCF`로 import.
- `from adafruit_pcf8591.analog_in import AnalogIn`: 아날로그 입력 클래스 import. (원본은 `Analogln` 오타)
- `import time`: 지연 시간 모듈.
- `i2c = busio.I2C(board.SCL_1, board.SDA_1, frequency = 100000)`: I2C 버스를 100kHz 주파수로 초기화. (센서 노이즈가 있을 때 낮은 주파수가 안정적)
- `pcf = PCF.PCF8591(i2c)`: PCF8591(0x48) 객체 생성.
- `pcf_in_2 = AnalogIn(pcf, PCF.A2)`: **A2 채널** 읽기 객체 생성. (원본 `Analogln` 오타)
- `while True:`: 무한 폴링 루프.
- `raw_value = pcf_in_2.value`: ADC 원시값(0~65535) 읽기.
- `scaled_value = (raw_value / 65535) * pcf_in_2.reference_voltage`: 원시값을 0~1로 정규화 후 기준 전압을 곱해 실제 전압 환산.
- `if(scaled_value < 1.6):`: 환산 전압이 1.6V **미만**이면 화염 감지로 판정. 화염 센서는 불꽃을 감지하면 출력 전압이 낮아지는 특성이 있다. (PIR 실습의 `>1.6`과 부등호 방향이 반대)
- `print("Flame 센서 감지됨")`: 감지 메시지 출력.
- `time.sleep(0.3)`: 0.3초 대기.

**동작 요약**: A2 채널 전압이 1.6V 아래로 내려가면 "Flame 센서 감지됨"을 출력한다.

**판정 요약** (reference_voltage = 3.3V)
| 상황 | 환산 전압 | 판정 |
| --- | --- | --- |
| 화염 없음 | 2.5V | 미감지 (1.6V 이상) |
| 화염 근접 | 0.8V | 감지 (1.6V 미만) |
| 화염 매우 근접 | 0.2V | 감지 (강한 신호) |

- 실제 전압은 센서 모듈마다 다르다. 실습 시작 시 전압을 먼저 출력해 확인한다.

## 5. 원본 코드의 오타/수정 안내
이 노트북에는 **`Analogln` → `AnalogIn` 오타 2곳**이 있다.

- **수정 1 (import 줄)**:
  - 수정 전: `from adafruit_pcf8591.analog_in import Analogln`
  - 수정 후: `from adafruit_pcf8591.analog_in import AnalogIn`
- **수정 2 (객체 생성 줄)**:
  - 수정 전: `pcf_in_2 = Analogln(pcf, PCF.A2)`
  - 수정 후: `pcf_in_2 = AnalogIn(pcf, PCF.A2)`

**전체 수정 코드**:
```python
import busio
import board
import adafruit_pcf8591.pcf8591 as PCF
from adafruit_pcf8591.analog_in import AnalogIn
import time
i2c = busio.I2C(board.SCL_1, board.SDA_1, frequency = 100000)
pcf = PCF.PCF8591(i2c)
pcf_in_2 = AnalogIn(pcf, PCF.A2)
while True:
    raw_value = pcf_in_2.value
    scaled_value = (raw_value / 65535) * pcf_in_2.reference_voltage
    if(scaled_value < 1.6):
        print("Flame 센서 감지됨")
    time.sleep(0.3)
```

**학습 포인트 요약**
- 5.PIR 실습과 같은 ADC 코드지만 **부등호 방향만 `<`로 반대**라는 점이 핵심이다. (센서 특성 차이)
- 화염 센서는 불꽃 근접 시 출력 전압이 내려간다.
- `AnalogIn` 대소문자 오타(`Analogln`)는 5.PIR과 동일하게 수정한다.

## 6. 실행 결과 예시
- 화염이 없을 때: 출력 없음.
- 라이터/촛불 불꽃을 센서 앞에 가져가면:
  ```
  Flame 센서 감지됨
  Flame 센서 감지됨
  ```
- 불꽃이 멀어지면 다시 출력이 멈춘다.

## 7. 주의사항 및 트러블슈팅
- **오타 수정 필수**: `Analogln` → `AnalogIn`을 반드시 적용한다.
- **안전 주의**: 불꽃 실험 시 화재 위험에 유의하고 가연물을 치운다. 센서를 불꽃에 직접 닿게 하지 않는다.
- **임계값 방향**: 화염 감지 시 전압이 내려가는 센서 기준으로 `< 1.6`이다. 센서마다 반전 특성이 있을 수 있으니 전압을 먼저 출력해 확인한다.
- **주변광 영향**: 밝은 조명/적외선(태양광)이 감지되면 오작동할 수 있다.
- **I2C 버스**: `board.SCL_1/SDA_1` 사용. 주파수 100kHz 지정이 붙어 있다.
- **감지가 되지 않을 때**: 임계값을 높여보고(예: 2.0V), AIN2 배선과 센서 전원을 확인한다.
- **항상 감지 상태**: 적외선을 내는 전자제품이 앞에 있거나 임계값이 너무 높으면 항상 감지로 판정될 수 있다.

## 8. 실습 과제
1. 감지 임계값을 1.6V에서 1.0V/2.0V로 바꿔 감도 변화를 실험하라.
2. 불꽃과 센서 사이 거리에 따른 전압 변화를 표로 기록하라.
3. 감지 시 소리(부저)를 함께 울리도록 3.busio 실습과 결합하라.
4. 화염이 감지되면 "위험!" 메시지를 3회 출력하고 5초간 잠금되는 코드를 작성하라.
5. 전압이 1.6V 이상일 때 "안전"을 출력하도록 else를 추가하라.
