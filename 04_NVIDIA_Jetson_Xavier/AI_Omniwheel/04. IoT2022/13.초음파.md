# 13. 초음파 센서 (Arduino 직렬통신으로 6개 초음파 거리 측정)

## 1. 학습 목표
- Arduino 직렬통신으로 **초음파 센서 6개**의 거리값을 받는 방법을 익힌다.
- `Omniwheel_Protocol` 패킷에서 MID 0x80(초음파) 데이터를 파싱하는 방법을 이해한다.
- **18자리 문자열을 3자리씩 6개의 거리값으로 분할**하는 파싱 기법을 배운다.
- 함수 내부 코드의 **들여쓰기 오류**(`if` 문이 함수 밖으로 나감)를 찾아 고치는 능력을 기른다.

## 2. 준비 사항
### 2.1 필요 하드웨어
- NVIDIA Jetson Xavier NX 보드 (JetPack 4.x)
- Arduino 보드 + USB 케이블
- 초음파 센서 6개 (옴니휠 로봇 둘레에 배치)

### 2.2 필요 라이브러리 (설치 명령 포함)
```bash
sudo pip3 install pyserial
```
- `Omniwheel_Protocol.py`: 이 아카이브의 `01. Device\libraries\` 아래에 있다. IoT2022 폴더로 복사하거나 해당 폴더가 현재 경로에 있어야 한다.

### 2.3 사전 설정
- 포트 확인: `ls /dev/ttyUSB0`
- **포트 권한 부여**: `sudo chmod 777 /dev/ttyUSB0`
- 이 IoT2022 버전은 **`/dev/ttyUSB0`, 9600** 사용. (01. Device 버전은 `/dev/ttyACM0`, 115200)
- 프로토콜: Arduino_ID=0x20, 요청 CMD 0xA1, 응답 CMD 0xB1, MID 0x80(초음파).

## 3. 실행 방법 (셀 실행 순서 안내)
1. 모듈 import 및 상수 정의
2. 시리얼 열기(/dev/ttyUSB0, 9600), "connect complete" 확인
3. 송신/수신/파싱 함수 정의
4. 모듈 레벨 `while(True)` 루프에서 요청→수신→초음파 데이터 출력

**중요**: 원본 코드는 `Packet_send` 함수의 **들여쓰기가 잘못되어**(`if` 문이 함수 밖) 실행 즉시 `NameError` 또는 `IndentationError`가 난다. 반드시 5번의 수정 코드를 사용한다.

## 4. 코드 해설 (원본 코드 그대로)
```python
import Omniwheel_Protocol
import serial
import time

Arduino_ID = 0x20
REQUEST_Ultra_Sonic_SENSOR = 0xA1
ANSWER_Ultra_Sonic_SENSOR = 0xB1
MID_Ultra_Sonic_SENSOR = 0x80
data_Ultrasonic_Sensors = 0
send_packet = Omniwheel_Protocol.Packet()
recv_packet = Omniwheel_Protocol.Packet()
recv_packet.clearPacket()
send_packet.clearPacket()
recv_list = []
recv_parsing_packet = []
send_flag = False
Serial_Arduino = serial.Serial(port="/dev/ttyUSB0", baudrate=9600, timeout=.1)

time.sleep(1)
print("connect complete")
def Packet_send(_id, _cmd, _mid, _data=None):
    global send_flag
if(send_flag == False):
    send_packet.clearPacket()
    send_packet.setID(_id)
    send_packet.setCMD(_cmd)
    send_packet.clearPayload()
    send_packet.addPayload(_mid, _data)
    send_packet.calcLRC_Lower()
    send_list = send_packet.packetToList()
    Serial_Arduino.write(send_list)
    send_flag = True

def Packet_receive(ser):
    global send_flag

    if(send_flag == True):
        while ser.inWaiting() > 0:
            Arduino_Data = ser.read(1)
            if(len(Arduino_Data) > 0):
                recv_list.append(ord(Arduino_Data))
                if(ord(Arduino_Data) == 0x03):
                    if(recv_packet.parsingList(recv_list)):
                        recv_parsing_packet.append(recv_packet)
                        recv_list.clear()
                        send_flag = False
                        break

def Received_packet():
    result = recv_parsing_packet[0]
    del recv_parsing_packet[0]
    return result

def Ultrasonic_Data(packet):


    global data_Ultrasonic_Sensors
    packet_id = packet.getID()
    packet_cmd = packet.getCMD()

    if(packet_id == Arduino_ID):
        if(packet_cmd == ANSWER_Ultra_Sonic_SENSOR):
            for payload in packet.getPayload():
                if(payload.getID() == MID_Ultra_Sonic_SENSOR):
                    buf = str(payload.getData())
                    data_Ultrasonic_Sensors = [int(float(buf[:3])),
                                            int(float(buf[3:6])),
                                            int(float(buf[6:9])),
                                            int(float(buf[9:12])),
                                            int(float(buf[12:15])),
                                            int(float(buf[15:]))]

while(True):
    Packet_send(Arduino_ID, REQUEST_Ultra_Sonic_SENSOR, MID_Ultra_Sonic_SENSOR)
    Packet_receive(Serial_Arduino)
    if(len(recv_parsing_packet) > 0):
        p = Received_packet()
        Ultrasonic_Data(p)
        print("Ultra_Sonic : " + str(data_Ultrasonic_Sensors))
        time.sleep(0.5)
```

**줄 단위 해설**
- `import Omniwheel_Protocol / serial / time`: 프로토콜 모듈, 시리얼, 지연 모듈.
- `Arduino_ID = 0x20`: Arduino ID.
- `REQUEST_Ultra_Sonic_SENSOR = 0xA1`: 초음파 데이터 요청 명령.
- `ANSWER_Ultra_Sonic_SENSOR = 0xB1`: 응답 명령.
- `MID_Ultra_Sonic_SENSOR = 0x80`: 초음파 센서 데이터의 MID.
- `data_Ultrasonic_Sensors = 0`: 결과 저장 전역 변수 초기화.
- `send_packet / recv_packet = Omniwheel_Protocol.Packet()` 후 `clearPacket()`: 송수신 패킷 객체 및 초기화.
- `recv_list = []`: 수신 바이트 임시 저장소. / `recv_parsing_packet = []`: 완성된 패킷 저장 큐. / `send_flag = False`: 송수신 상태 플래그.
- `Serial_Arduino = serial.Serial(port="/dev/ttyUSB0", baudrate=9600, timeout=.1)`: 시리얼 포트 열기. 이후 `time.sleep(1)` 안정화 후 `print("connect complete")`로 연결 확인.
- `def Packet_send(_id, _cmd, _mid, _data=None):`: 요청 패킷을 만들어 보내는 함수.
  - **오류**: `if(send_flag == False):` 아래 블록이 들여쓰기 없이 함수 밖(모듈 레벨)에 놓여 있다.
    - 원본 그대로 실행하면: (1) 모듈 로드 시 이 if 블록이 즉시 실행되는데, 그때 `_id`, `_cmd`, `_mid`는 정의되지 않아 `NameError`가 발생한다. (2) 함수 본문은 `global send_flag`만 남아 함수가 제대로 동작하지 않는다.
  - 올바른 구조: 아래 블록 전체가 `def Packet_send(...)` 안쪽(들여쓰기 4칸)에 있어야 한다.
- `def Packet_receive(ser):`: 수신 바이트를 누적하고 ETX(0x03)에서 패킷 파싱을 마무리. `recv_parsing_packet`에 저장 후 `send_flag=False`.
- `def Received_packet():`: 큐에서 패킷을 꺼내 반환.
- `def Ultrasonic_Data(packet):`: 응답에서 초음파 데이터 추출.
  - `packet_id == Arduino_ID`, `packet_cmd == ANSWER_Ultra_Sonic_SENSOR`: 올바른 응답인지 확인.
  - `payload.getID() == MID_Ultra_Sonic_SENSOR`: MID 0x80 데이터 선택.
  - `buf = str(payload.getData())`: 데이터를 문자열로 변환 (예: "150235060120200085" 18자리).
  - `[int(float(buf[:3])), ..., int(float(buf[15:]))]`: 18자리를 3자리씩 **6개의 거리값**으로 분할. 예: 150, 235, 060, 120, 200, 085.
- `while(True):` (모듈 레벨): 메인 루프. 요청 → 수신 → 파싱 → 출력 → 0.5초 대기.

**동작 요약**: 초음파 6개의 거리값을 담은 응답을 요청하고, 18자리 문자열을 3자리씩 잘라 6개의 거리(cm)로 출력한다.

## 5. 원본 코드의 오타/수정 안내
원본에는 **들여쓰기 오류 1건**이 치명적이다.

**문제: `Packet_send` 함수의 본문 들여쓰기**
- `if(send_flag == False):` 줄이 함수 밖(열 0)에 위치한다.
- 수정: `if(send_flag == False):`부터 `send_flag = True`까지의 모든 줄을 `def` 안쪽으로 들여쓴다.
- 원본 상태 그대로 실행하면 `NameError`(모듈 로드 시 미정의 변수 사용) 또는 들여쓰기/문법 오류가 발생한다.

- 0.5초 간격으로 6개 초음파 거리값(cm)이 리스트로 출력된다.
- 로봇 주변에 손/장애물을 가까이 대면 해당 위치의 값이 작아진다.

## 7. 주의사항 및 트러블슈팅
- **들여쓰기 수정 필수**: `Packet_send`의 if 블록을 함수 안으로 들여써야 한다.
- **포트와 baudrate**: 이 IoT2022 버전은 `/dev/ttyUSB0`, **9600**. 01. Device 버전(ACM0, 115200)을 쓰면 안 된다.
- **포트 권한**: `sudo chmod 777 /dev/ttyUSB0` 실행.
- **Omniwheel_Protocol.py**: IoT2022 폴더에 없으면 `ModuleNotFoundError`. `01. Device\libraries`에서 복사.
- **센서 배치 순서**: 리스트 인덱스 0~5가 로봇의 어느 위치의 센서인지 Arduino 스케치와 매핑을 확인한다.
- **거리 한계**: 초음파 센서의 측정 범위(예: 2~400cm) 밖은 0 또는 최대값으로 나온다.

## 8. 실습 과제
1. 6개 거리값의 평균을 계산해 출력하라.
2. 어느 하나가 30cm 미만이면 "근접!"을 출력하도록 분기하라.
3. 측정 주기를 0.1초로 줄여 반응 속도를 높여 보라.
4. 가장 가까운 장애물까지의 거리와 센서 번호를 출력하라.
5. 거리값을 cm 대신 m 단위로 변환해 출력하라.
