# 9. temp 온습도/기압 센서 (BME280)

## 1. 학습 목표
- BME280 환경 센서(I2C)를 사용해 온도·습도·기압을 동시에 측정하는 방법을 익힌다.
- `adafruit_bme280` 라이브러리와 `basic` 모듈의 구조를 이해한다.
- I2C 주소를 명시적으로 지정해 센서를 초기화하는 방법을 배운다.
- 출력 포맷에서 `%` 문자를 출력할 때 `%%`로 이스케이프해야 함을 이해한다.

### 1.1 배경 지식: BME280과 환경 측정
- BME280은 **온도(℃), 습도(%RH), 기압(hPa)** 을 동시에 측정하는 환경 센서이다. (온습도+기압 일체형)
- 센서 내부에 보정 계수(calibration)가 저장되어 있어 드라이버가 자동으로 정밀 보정을 적용한다.
- 기압은 해발 고도 측정·날씨 예측에 활용된다. 기압 1hPa 감소 ≈ 고도 약 8.4m 상승.
- I2C 주소는 **0x76**(기본)이며, 일부 모듈은 SDO 핀 상태에 따라 0x77이 된다.
- `basic` 모듈은 해상도·모드 설정 등 고급 옵션 없이 간단히 사용하는 기본 인터페이스다.

## 2. 준비 사항
### 2.1 필요 하드웨어
- NVIDIA Jetson Xavier NX 보드 (JetPack 4.x)
- BME280 온습도/기압 센서 모듈 (I2C 주소 0x76)

### 2.2 필요 라이브러리 (설치 명령 포함)
```bash
sudo pip3 install adafruit-circuitpython-bme280
```

### 2.3 사전 설정
- BME280의 SCL/SDA를 Jetson의 **SCL_1 / SDA_1** 핀에 연결한다. (VCC 3.3V)
- `sudo i2cdetect -y -r 1`로 0x76 주소 확인.
  - 일부 모듈은 SDO 핀 상태에 따라 0x77이 될 수 있다.

### 2.4 배선 요약
| BME280 핀 | Jetson 연결 | 비고 |
| --- | --- | --- |
| VCC | 3.3V | 전원 |
| GND | GND | 접지 |
| SCL | SCL_1 | I2C 클록 |
| SDA | SDA_1 | I2C 데이터 |
| SDO | GND(0x76) / VCC(0x77) | 주소 선택 |

## 3. 실행 방법 (셀 실행 순서 안내)
1. 모듈 import (`basic` 하위 모듈 별칭 지정)
2. I2C(100kHz) 생성 및 BME280 객체 생성 (주소 0x76 명시)
3. `while True`에서 온도/습도/기압을 읽어 출력하고 1초 대기

**단계별 예상 확인 포인트**
- 셀 실행 직후 `Temperature`, `Humidity`, `Pressure` 3줄이 매초 출력된다.
- 숨을 센서에 불면 `Humidity`가 잠시 상승하고 `Temperature`도 약간 오른다.
- 손으로 감싸면 온도가 서서히 올라간다.
- 기압은 보통 1000hPa 전후로 천천히만 변한다.

**중단 방법**: 무한 루프이므로 정지(■) 버튼으로 중지한다.

## 4. 코드 해설 (원본 코드 그대로)
```python
import busio
import board
from adafruit_bme280 import basic as adafruit_bme280
import time
i2c = busio.I2C(board.SCL_1, board.SDA_1, frequency = 100000)
bme280 = adafruit_bme280.Adafruit_BME280_I2C(i2c, 0x76)
while True:
    temp = bme280.temperature
    humi = bme280.humidity
    press = bme280.pressure
    print("\nTemperature: %0.1f C"%temp)
    print("Humidity: %0.1f %%"%humi)
    print("Pressure: %0.1f hPa" %press)
    time.sleep(1)
```

**줄 단위 해설**
- `import busio / board`: I2C 버스 및 핀 정의 모듈.
- `from adafruit_bme280 import basic as adafruit_bme280`: BME280 라이브러리 중 `basic` 모듈(기본 기능)을 `adafruit_bme280` 별칭으로 import.
- `import time`: 지연 시간 모듈.
- `i2c = busio.I2C(board.SCL_1, board.SDA_1, frequency = 100000)`: SCL_1/SDA_1로 I2C 버스를 100kHz로 초기화.
- `bme280 = adafruit_bme280.Adafruit_BME280_I2C(i2c, 0x76)`: I2C 주소 **0x76**을 명시해 BME280 객체를 생성. (주소를 생략하면 기본값 사용, 명시가 더 안전)
- `while True:`: 무한 측정 루프.
- `temp = bme280.temperature`: 온도(℃) 읽기.
- `humi = bme280.humidity`: 습도(%RH) 읽기.
- `press = bme280.pressure`: 기압(hPa) 읽기.
- `print("\nTemperature: %0.1f C"%temp)`: 온도를 소수점 1자리로 출력. `\n`으로 한 줄 띄어 가독성을 높였다.
- `print("Humidity: %0.1f %%"%humi)`: 습도 출력. **`%%`는 `%` 기호 자체를 출력하기 위한 이스케이프**이다.
- `print("Pressure: %0.1f hPa" %press)`: 기압을 hPa 단위로 출력.
- `time.sleep(1)`: 1초 대기 후 재측정.

**동작 요약**: 매초 온도/습도/기압을 한 묶음씩 출력한다.

**단위와 측정 범위 요약**
| 항목 | 속성 | 단위 | 일반적인 실내 값 |
| --- | --- | --- | --- |
| 온도 | `temperature` | ℃ | 20~30 |
| 습도 | `humidity` | %RH | 40~60 |
| 기압 | `pressure` | hPa | 1000~1020 |

- `%%`를 쓰는 이유: `%` 연산 뒤의 문자열에서 `%`는 포맷 지정자를 의미하므로, `%` 기호 자체를 출력하려면 `%%`로 이스케이프해야 한다. (`"Humidity: %0.1f %%"` → "Humidity: 55.2 %")

## 5. 원본 코드의 오타/수정 안내
이 노트북의 코드는 **오타 없이 정상 동작**한다.

참고 사항(필수 아님):
- `%0.1f`의 `0`은 전체 폭이 최소 0이라는 의미로 `%.1f`와 사실상 같다. `%.1f`로 써도 동일하다.
- 주소가 0x77인 모듈을 사용한다면 `bme280 = adafruit_bme280.Adafruit_BME280_I2C(i2c, 0x77)`로 변경한다.

**학습 포인트 요약**
- BME280 하나로 온도/습도/기압 **3개 값을 동시에** 읽는다는 것이 핵심이다.
- I2C 주소를 생성자에 명시(`0x76`)하면 모듈별 주소 차이에 대응하기 쉽다.
- `%%`는 `%` 기호를 출력하는 이스케이프이며, `%%` 없이 `%` 하나만 쓰면 포맷 에러가 난다.
- 5~8번 실습까지의 I2C 센서 읽기 패턴(import → I2C 생성 → 드라이버 생성 → 속성 읽기)이 동일하게 반복된다는 것을 확인한다.

## 6. 실행 결과 예시
```
Temperature: 28.4 C
Humidity: 55.2 %
Pressure: 1008.3 hPa

Temperature: 28.4 C
Humidity: 55.3 %
Pressure: 1008.3 hPa
```
- 숨을 불어 습도를 올리면 `Humidity`가 잠시 상승한다.
- 손으로 센서를 잡아 덥히면 `Temperature`가 상승한다.
- 기압은 보통 수십 초~수 분 단위로만 서서히 변한다. 값이 갑자기 크게 변하면 배선이나 전원을 의심한다.

## 7. 주의사항 및 트러블슈팅
- **주소 확인**: 기본 0x76이지만 모듈에 따라 0x77이다. `i2cdetect`로 확인 후 코드의 주소를 맞춘다.
- **`%%` 주의**: `%` 하나만 쓰면 `print`가 포맷 에러(`ValueError: unsupported format character`)를 낼 수 있다. `%%`를 유지한다.
- **보정**: BME280은 오차 보정 계수를 자체 ROM에 저장해 드라이버가 자동 적용한다.
- **측정 환경**: 손의 열, 숨의 수증기, 직사광선은 값에 즉시 영향을 준다.
- **I2C 버스**: `board.SCL_1/SDA_1` 사용. 오류 시 01. Device 버전과 구분.
- **센서가 검출 안 됨**: 0x76도 0x77도 아니면 배선(특히 SDO 상태)과 전원을 점검한다.
- **습도가 0% 또는 100%로 고정**: 센서 손상 또는 매우 극단적인 환경일 수 있다.

## 8. 실습 과제
1. 온도/습도/기압을 한 줄에 콤마로 구분해 출력하도록 수정하라.
   - 힌트: `print("%.1f, %.1f, %.1f" % (temp, humi, press))` 형태로 한 줄 출력한다.
2. 30초 동안 평균 온도를 계산해 출력하라.
   - 힌트: `temps = []` 리스트에 값을 누적하고 30회 후 `sum(temps)/len(temps)`를 출력한다.
3. 습도가 60% 이상이면 "습함"을 출력하는 분기 코드를 작성하라.
   - 힌트: `if humi >= 60:` 다음에 메시지 출력, 아니면 "쾌적" 출력.
4. 기압 변화(전후 차이)가 2hPa 이상이면 "날씨 변화"를 출력하라.
   - 힌트: 이전 기압을 변수로 저장하고 `abs(press - prev_press)`로 비교한다.
5. 측정 데이터를 CSV 형식으로 파일에 저장하는 코드를 작성하라.
   - 힌트: `with open("data.csv", "a") as f: f.write("...")`로 한 줄씩 추가한다.
6. 기압으로 대략적인 고도(m)를 계산해 출력하라.
   - 힌트: 해수면 기압 1013.25hPa 기준 `44330 × (1 - (press/1013.25)^(1/5.255))` 공식을 사용한다.
7. 온습도 기반 불쾌지수(여름)를 계산해 출력하라.
   - 힌트: `불쾌지수 = 0.81 × 온도 + 0.01 × 습도 × (0.99 × 온도 - 14.3) + 46.3` 공식을 사용한다.
8. 측정 간격을 1초 → 10초로 바꾸고 1시간 동안 로그를 남기는 코드를 작성하라.
   - 힌트: `time.sleep(10)`과 `end = time.time() + 3600`으로 시간 제한 루프를 만든다.
9. 온도·습도로 노점 온도(이슬점)를 계산해 출력하라.
   - 힌트: Magnus 공식 `gamma = ln(습도/100) + 17.62×온도/(243.5+온도)`, `이슬점 = 243.5×gamma/(17.62-gamma)`를 사용한다.
10. 온도가 30℃를 넘으면 "더움", 10℃ 미만이면 "추움", 그 사이면 "보통"을 출력하라.
   - 힌트: `elif`로 구간을 나누고 온도만 판정한다.
