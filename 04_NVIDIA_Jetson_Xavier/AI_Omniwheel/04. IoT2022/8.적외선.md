# 8. 적외선 온도 센서 (MLX90614 주변/물체 온도 측정)

## 1. 학습 목표
- MLX90614 비접촉 적외선 온도 센서(I2C)의 사용법을 익힌다.
- 주변 온도(`ambient_temperature`)와 물체 표면 온도(`object_temperature`)를 함께 읽는 방법을 배운다.
- 비접촉 온도 측정 원리(적외선 방사)와 활용 분야를 이해한다.
- 문자열 포맷팅 오타(`%2.f`)를 찾아 수정하는 능력을 기른다.

### 1.1 배경 지식: MLX90614과 비접촉 온도 측정
- MLX90614은 적외선(IR) 방사량을 측정해 **비접촉으로 물체 표면 온도**를 구하는 센서이다.
- 모든 물체는 절대온도의 4승에 비례하는 적외선을 방출하며, 센서는 이를 흡수해 온도로 환산한다.
- `ambient_temperature`는 센서가 장착된 주변(기판) 온도, `object_temperature`는 센서가 바라보는 물체의 온도(℃)이다.
- 물체와의 거리가 멀어지면 물체 외 주변의 적외선이 섞여 측정 온도가 실제보다 낮아진다.
- 이 센서도 I2C 디지털 센서이므로 ADC 환산이 필요 없다.

## 2. 준비 사항
### 2.1 필요 하드웨어
- NVIDIA Jetson Xavier NX 보드 (JetPack 4.x)
- MLX90614 적외선 온도 센서 모듈 (I2C 주소 0x5A)

### 2.2 필요 라이브러리 (설치 명령 포함)
```bash
sudo pip3 install adafruit-circuitpython-mlx90614
```

### 2.3 사전 설정
- MLX90614의 SCL/SDA를 Jetson의 **SCL_1 / SDA_1** 핀에 연결한다.
- `sudo i2cdetect -y -r 1`로 0x5A 주소 확인.

### 2.4 배선 요약
| MLX90614 핀 | Jetson 연결 | 비고 |
| --- | --- | --- |
| VCC | 3.3V 또는 5V | 센서 전원 |
| GND | GND | 접지 |
| SCL | SCL_1 | I2C 클록 |
| SDA | SDA_1 | I2C 데이터 |

## 3. 실행 방법 (셀 실행 순서 안내)
1. 모듈 import
2. I2C(100kHz) 및 MLX90614 객체 생성
3. `while True`에서 주변 온도와 물체 온도를 읽어 출력하고 1초 대기

**참고**: 원본의 `%2.f` 포맷은 정상 실행되지만 표시가 어색하다. 5번의 안내에 따라 `%.2f`로 고쳐 실행을 권장한다.

**단계별 예상 확인 포인트**
- 셀 실행 직후 주변/물체 온도가 매초 출력된다.
- 초기 몇 초는 값이 안정화되는 동안 조금씩 변한다.
- 손바닥을 센서 앞 3~5cm에 대면 `Object Temp`가 피부 온도(약 36℃)로 상승한다.
- 손을 치우면 값이 다시 주변 온도 수준으로 내려간다.

**중단 방법**: 무한 루프이므로 정지(■) 버튼으로 중지한다.

## 4. 코드 해설 (원본 코드 그대로)
```python
import busio
import board
import adafruit_mlx90614
import time

i2c=busio.I2C(board.SCL_1,board.SDA_1,frequency=100000)
mlx = adafruit_mlx90614.MLX90614(i2c)
while True:
    temp_amb=mlx.ambient_temperature
    temp_obj=mlx.object_temperature
    print("Ambent Temp: %2.f" %temp_amb)
    print("Object Temp: %2.f" %temp_obj)
    time.sleep(1)
```

**줄 단위 해설**
- `import busio / board`: I2C 버스 및 핀 정의 모듈.
- `import adafruit_mlx90614`: MLX90614 드라이버 모듈.
- `import time`: 지연 시간 모듈.
- `i2c=busio.I2C(board.SCL_1,board.SDA_1,frequency=100000)`: SCL_1/SDA_1로 I2C 버스를 100kHz로 초기화.
- `mlx = adafruit_mlx90614.MLX90614(i2c)`: I2C 주소 0x5A의 MLX90614 객체 생성.
- `while True:`: 무한 측정 루프.
- `temp_amb=mlx.ambient_temperature`: 센서 주변(주위) 온도(℃) 읽기.
- `temp_obj=mlx.object_temperature`: 센서가 바라보는 물체의 표면 온도(℃) 읽기.
- `print("Ambent Temp: %2.f" %temp_amb)`: 주변 온도 출력. **`%2.f`는 소수점 이하 자릿수를 지정하지 못하고 폭만 2로 잡는 형식**이라 `%2.0f`처럼 동작한다. "Ambent"는 "Ambient"의 오타지만 출력 문자열일 뿐이라 실행에는 영향이 없다.
- `print("Object Temp: %2.f" %temp_obj)`: 물체 온도 출력. 같은 포맷 이슈가 있다.
- `time.sleep(1)`: 1초 대기 후 재측정.

**동작 요약**: 매초 주변 온도와 물체 온도를 읽어 출력한다. 손바닥을 센서 앞에 가까이 대면 물체 온도가 피부 온도(약 36℃) 근처로 상승하는 것을 볼 수 있다.

**포맷 지정자 비교**
| 지정자 | 의미 | 28.456의 출력 |
| --- | --- | --- |
| `%2.f` | 폭 2 + 소수점 0자리 | 28 (반올림) |
| `%.2f` | 소수점 2자리 | 28.46 |
| `%.1f` | 소수점 1자리 | 28.5 |

- 원본의 `%2.f`는 사실상 `%2.0f`처럼 동작해 소수점이 모두 사라진다. `%.2f`로 고치면 정밀한 값이 출력된다.

## 5. 원본 코드의 오타/수정 안내
이 노트북에는 **포맷 문자열 오타**가 있다. (`Ambent`는 표시 문자열이라 수정해도 무방)

- **수정: `%2.f` → `%.2f` (2곳)**
  - 수정 전: `print("Ambent Temp: %2.f" %temp_amb)`
  - 수정 후: `print("Ambient Temp: %.2f" %temp_amb)`
  - 수정 전: `print("Object Temp: %2.f" %temp_obj)`
  - 수정 후: `print("Object Temp: %.2f" %temp_obj)`
- `%2.f`는 정수부 폭 2 + 소수점 없음으로 해석되어 값이 반올림된 정수로만 보인다. `%.2f`로 바꾸면 소수점 2자리까지 정확히 표시된다.

**전체 수정 코드**:
```python
import busio
import board
import adafruit_mlx90614
import time

i2c=busio.I2C(board.SCL_1,board.SDA_1,frequency=100000)
mlx = adafruit_mlx90614.MLX90614(i2c)
while True:
    temp_amb=mlx.ambient_temperature
    temp_obj=mlx.object_temperature
    print("Ambient Temp: %.2f" %temp_amb)
    print("Object Temp: %.2f" %temp_obj)
    time.sleep(1)
```

## 6. 실행 결과 예시
- 대기 중 상태:
  ```
  Ambient Temp: 28.45
  Object Temp: 29.10
  ```
- 손바닥을 센서 앞에 대면:
  ```
  Ambient Temp: 28.44
  Object Temp: 36.80
  ```
- 뜨거운 물잔을 대면 물체 온도가 더 높게 나타난다.
- 얼음을 비치면 물체 온도가 주변 온도보다 낮게 나타난다.
- 측정값이 갑자기 0℃ 부근으로 떨어지면 센서가 측정 범위를 벗어나거나 배선이 불안정한 경우이다.

## 7. 주의사항 및 트러블슈팅
- **측정 거리**: 물체 온도는 센서가 바라보는 지점의 평균값이다. 거리가 멀수록 주변과 섞여 낮아진다.
- **측정 원리**: 3.3V/5V로 구동하며 적외선 방사량을 온도로 환산한다. 유리·반사면은 정확도가 떨어진다.
- **I2C 주소**: 기본 0x5A. `i2cdetect`로 확인.
- **NMEA/EMC 옵션**: 일부 MLX90614 모듈은 I2C 주소가 다르거나 SMBus로 동작한다. 데이터시트를 확인한다.
- **I2C 버스**: `board.SCL_1/SDA_1` 사용. 오류 시 01. Device 버전과 구분.
- **온도 안정화**: 전원 투입 직후 몇 초간은 값이 안정화되기까지 오차가 있을 수 있다.
- **물체 온도가 이상하게 낮음**: 센서가 빈 공간을 바라보면 방열 평균값이 낮아진다. 측정 대상과 가까이 유지한다.
- **두 온도가 같게 나옴**: 주변 온도와 물체 온도가 실제로 비슷한 환경(전원 투입 직후)이거나 측정 대상이 멀리 있기 때문일 수 있다.

## 8. 실습 과제
1. 차가운 물/뜨거운 물에 각각 온도계를 담가 측정값을 실제 온도와 비교하라.
2. 센서에서 물체까지 거리를 1cm~20cm로 바꾸며 물체 온도 오차를 기록하라.
3. 물체 온도가 35℃ 이상이면 "발열 감지"를 출력하는 분기 코드를 작성하라.
4. 온도 값 30개를 평균 내어 노이즈를 줄이는 코드를 작성하라.
5. 주변 온도와 물체 온도의 차이(ΔT)를 계산해 함께 출력하라.
   - 힌트: `dt = temp_obj - temp_amb`로 계산해 print에 추가한다.
