# 7. Light 조도 센서 (BH1750 I2C Lux 센서)

## 1. 학습 목표
- BH1750 디지털 조도 센서(I2C)를 사용해 조명 밝기(lux)를 읽는 방법을 익힌다.
- `adafruit_bh1750` 라이브러리의 `lux` 속성 사용법을 이해한다.
- I2C 디지털 센서는 ADC 환산이 불필요하다는 점을 이해한다. (센서가 직접 lux 값을 계산)
- 문자열 포맷팅(`%2f` vs `%.2f`)의 올바른 사용법을 익힌다.

### 1.1 배경 지식: BH1750과 lux
- lux(럭스)는 1㎡ 면적에 비추는 광량을 나타내는 조도 단위이다.
  - 예: 밤달빛 ≈ 0.1 lux, 사무실 조명 ≈ 300~500 lux, 맑은 날 실외 ≈ 10000+ lux
- BH1750은 16비트 디지털 조도 센서로, **ADC 환산 없이 센서가 직접 lux 값을 계산**해 I2C로 전달한다. (5/6번 실습의 PCF8591과 차이점)
- `light_sensor.lux` 속성으로 값을 읽는다.
- 대입 연산자 `=`와 하이픈 `-`가 구분이 어려워 복사/붙여넣기 과정에서 오타가 발생한 전형적인 사례이다.

## 2. 준비 사항
### 2.1 필요 하드웨어
- NVIDIA Jetson Xavier NX 보드 (JetPack 4.x)
- BH1750 조도 센서 모듈 (I2C 주소 0x23)

### 2.2 필요 라이브러리 (설치 명령 포함)
```bash
sudo pip3 install adafruit-circuitpython-bh1750
```

### 2.3 사전 설정
- BH1750의 SCL/SDA를 Jetson의 **SCL_1 / SDA_1** 핀에 연결한다. (VCC 3.3V)
- `sudo i2cdetect -y -r 1`로 0x23 주소 확인.

### 2.4 배선 요약
| BH1750 핀 | Jetson 연결 | 비고 |
| --- | --- | --- |
| VCC | 3.3V | 전원 (5V 금지) |
| GND | GND | 접지 |
| SCL | SCL_1 | I2C 클록 |
| SDA | SDA_1 | I2C 데이터 |
| ADDR | GND(기본) | HIGH 시 주소 0x5C |

## 3. 실행 방법 (셀 실행 순서 안내)
1. 모듈 import
2. I2C(100kHz) 및 BH1750 객체 생성
3. `while True`에서 `light_sensor.lux` 값을 읽어 출력하고 1초 대기

**중요**: 원본 코드에 `light_sensor - ...` (하이픈) 오타가 있어 그대로 실행하면 `NameError`가 난다. 5번의 수정 코드를 먼저 적용한다.

**단계별 예상 확인 포인트**
- 셀 실행 직후 `NameError: name 'light_sensor' is not defined`가 나면 `=` 수정이 안 된 것이다.
- 1초 간격으로 lux 값이 출력된다.
- 손으로 가리면 값이 낮아지고, 조명을 비추면 값이 높아진다.
- 값이 0.00으로 고정이면 측정 환경(어두움) 또는 배선을 확인한다.

**중단 방법**: 무한 루프이므로 정지(■) 버튼으로 중지한다.

## 4. 코드 해설 (원본 코드 그대로)
```python
import busio
import board
import adafruit_bh1750
import time
i2c = busio.I2C(board.SCL_1, board.SDA_1, frequency = 100000)
light_sensor - adafruit_bh1750.BH1750(i2c)
while True:
    val = light_sensor.lux
    print("조도 감지 센서 : %2f Lux"%val)
    time.sleep(1)
```

**줄 단위 해설 (오타 수정 전의 의미 기준)**
- `import busio / board`: I2C 버스 및 핀 정의 모듈.
- `import adafruit_bh1750`: BH1750 드라이버 모듈.
- `import time`: 지연 시간 모듈.
- `i2c = busio.I2C(board.SCL_1, board.SDA_1, frequency = 100000)`: SCL_1/SDA_1로 I2C 버스를 100kHz로 초기화.
- `light_sensor - adafruit_bh1750.BH1750(i2c)`: BH1750(0x23) 객체를 생성해 `light_sensor` 변수에 저장하려는 줄. **오타**: `-`(빼기)로 되어 있어 `=`(대입)가 되어야 한다. 원본 그대로 실행하면 `NameError: name 'light_sensor' is not defined`가 발생한다.
- `while True:`: 무한 반복.
- `val = light_sensor.lux`: BH1750이 측정한 조도 값(lux)을 읽는다.
- `print("조도 감지 센서 : %2f Lux"%val)`: lux 값을 출력. **`%2f`는 소수점 없는 2자리 폭 출력**이라 실수로는 어색하다. `%.2f`(소수점 2자리)로 고치는 것이 올바르다.
- `time.sleep(1)`: 1초 대기 후 다시 측정.

**동작 요약**: 매초 BH1750으로 조도를 측정해 lux 값으로 화면에 출력한다.

**포맷 지정자 비교** (`%` 표기법)
| 지정자 | 의미 | 1234.5678의 출력 |
| --- | --- | --- |
| `%d` | 정수 | 1234 |
| `%.0f` | 소수점 0자리 | 1235 (반올림) |
| `%.2f` | 소수점 2자리 | 1234.57 |
| `%2f` | 폭 2 + 소수점 미지정 | 어색한 출력 (의도한 표기 아님) |
| `%2.f` | 폭 2 + 소수점 0자리 | 1235 (반올림) |

- 조도값은 소수점 2자리까지 보여주는 `%.2f`가 권장된다.

## 5. 원본 코드의 오타/수정 안내
이 노트북에는 **2개의 오타**가 있다.

- **수정 1: 대입 연산자 오타 (`-` → `=`)**
  - 수정 전: `light_sensor - adafruit_bh1750.BH1750(i2c)`
  - 수정 후: `light_sensor = adafruit_bh1750.BH1750(i2c)`
  - 이 줄을 고치지 않으면 `NameError`로 즉시 실패한다.
- **수정 2: 포맷 문자열 (`%2f` → `%.2f`)**
  - 수정 전: `print("조도 감지 센서 : %2f Lux"%val)`
  - 수정 후: `print("조도 감지 센서 : %.2f Lux"%val)`
  - `%2f`는 "소수점 이하 자릿수 없이 전체 폭 2"로 해석되어 표시가 이상해진다. `%.2f`가 "소수점 2자리"로 의도된 표기이다.

**학습 포인트 요약**
- BH1750은 lux 값을 **직접 계산해 주는 디지털 I2C 센서**로, PCF8591(5/6번)과 달리 전압 환산이 필요 없다.
- `=`(대입)와 `-`(하이픈) 오타는 복사/붙여넣기에서 가장 흔한 실수이므로, 변수명이 정의되지 않았다는 `NameError`가 나면 대입 연산자를 먼저 확인한다.
- `%` 문자열 포맷팅에서 소수점 자리는 `%.Nf` 형태로 지정한다.

**전체 수정 코드**:
```python
import busio
import board
import adafruit_bh1750
import time
i2c = busio.I2C(board.SCL_1, board.SDA_1, frequency = 100000)
light_sensor = adafruit_bh1750.BH1750(i2c)
while True:
    val = light_sensor.lux
    print("조도 감지 센서 : %.2f Lux"%val)
    time.sleep(1)
```

## 6. 실행 결과 예시
- 어두운 곳: `조도 감지 센서 : 5.23 Lux`
- 밝은 곳(형광등 아래): `조도 감지 센서 : 245.67 Lux`
- 밝기 변화에 따라 lux 값이 매초 갱신된다.
- 손바닥으로 센서를 살짝 가리면 값이 수 초 내로 감소하고, 손을 치우면 다시 상승한다.

## 7. 주의사항 및 트러블슈팅
- **대입 연산자 오타**: `-`를 `=`로 반드시 수정한다. (이 오타는 하이픈과 등호를 구분하기 어려워 복사/붙여넣기 시 자주 발생한다)
- **I2C 주소**: 대부분 0x23이지만 모듈에 따라 ADDR 핀을 HIGH로 하면 0x5C가 된다. 검출 주소에 따라 코드를 바꾼다.
- **VCC 전압**: BH1750은 3.3V로 구동한다. 5V를 주면 손상될 수 있다.
- **창유리/커버**: 센서의 감광부를 가리지 않도록 한다.
- **I2C 버스**: `board.SCL_1/SDA_1` 사용. 오류 시 01. Device 버전(`board.SCL/SDA`)과 구분.
- **값이 0.0으로만 출력**: 측정 모드가 부적합하거나 주변이 매우 어두울 수 있다. 조명을 켜서 확인한다.
- **값이 요동침**: 감광부가 꺼진 화면 등 주기적 광원을 향하면 값이 크게 변한다.
- **값이 65535처럼 터짐**: I2C 통신 오류로 읽기 실패 시 드라이버가 비정상 값을 반환할 수 있다. 케이블과 주파수 설정을 점검한다.
- **시야각**: BH1750은 감광부 위쪽 반구의 광량을 평균하므로 센서를 수평으로 두면 측정값이 낮아진다.

## 8. 실습 과제
1. 손으로 센서를 가리고 밝힐 때 lux 값의 변화 폭을 기록하라.
   - 힌트: 실내 조명 기준 값과 손을 가린 값을 5회씩 기록해 범위를 비교한다.
2. 측정값을 10회 누적한 평균을 출력하라.
   - 힌트: `total = 0`으로 누적하고 10회 후 `total/10`을 출력한다.
3. lux가 100보다 낮으면 "어두움", 아니면 "밝음"을 출력하도록 분기하라.
   - 힌트: `if val < 100:` 이후에 `else:`를 추가한다.
4. 조도에 따라 LED 밝기(duty_cycle)를 자동으로 조절하는 코드를 2.LED2와 결합해 작성하라.
   - 힌트: `duty = int(val * 40)`처럼 조도에 비례하는 duty를 계산해 `pca9685.channels[0].duty_cycle`에 넣는다. (4095 초과는 min으로 제한)
5. `%.2f`를 `%.0f`/`%d`로 바꿔 출력 형식의 차이를 확인하라.
   - 힌트: `%d`를 쓰면 값이 int로 변환되어 소수점이 사라진다.
6. lux 값이 0~50이면 "야간", 50~500이면 "실내", 500 이상이면 "주간"으로 분류해 출력하라.
   - 힌트: 연속된 `if/elif/else`로 범위를 나눈다.
