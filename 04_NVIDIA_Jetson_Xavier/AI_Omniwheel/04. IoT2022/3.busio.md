# 3. busio (PCA9685를 이용한 부저 멜로디 연주)

## 1. 학습 목표
- PCA9685의 주파수 설정(`pca9685.frequency`)과 duty_cycle을 활용해 부저로 음계를 연주하는 방법을 익힌다.
- 주파수(Hz)와 음 높이의 관계를 이해한다.
- 50% 듀티(출력 점멸)로 부저를 구동하는 원리를 이해한다.
- `for` 루프로 멜로디 배열을 순회하며 음을 연주하는 방법을 배운다.

### 1.1 배경 지식: 주파수와 음계, 부저 구동
- 부저(수동형)는 PWM 주파수가 바뀌면 진동 주파수가 바뀌어 **음 높이(피치)**가 달라진다. 예: 261Hz = C4(도), 293Hz = D4(레), 329Hz = E4(미).
- duty_cycle을 50%로 하면 ON과 OFF가 균등하게 반복되어 부저가 최대 출력으로 울린다.
- 음의 지속 시간(`time.sleep(0.3)`)이 길수록 음이 길게 들리고, 사이의 휴지(0.1초)가 리듬을 만든다.
- 채널 15는 이 로봇 기판에서 부저에 배정된 PWM 채널이다. (1·2번 실습의 LED는 채널 0~7)

## 2. 준비 사항
### 2.1 필요 하드웨어
- NVIDIA Jetson Xavier NX 보드 (JetPack 4.x)
- PCA9685 PWM 드라이버 모듈 (I2C 주소 0x40)
- 부저(버저) 1개 (PWM 채널 15에 연결)

### 2.2 필요 라이브러리 (설치 명령 포함)
```bash
sudo pip3 install adafruit-circuitpython-pca9685
```
- `busio`, `board`도 함께 설치된다.
- 확인: `sudo i2cdetect -y -r 1`에서 0x40 검색 확인.

### 2.3 사전 설정
- PCA9685의 SCL/SDA를 Jetson의 **SCL_1 / SDA_1** 핀에 연결한다.
- 부저는 PCA9685의 **채널 15**에 연결한다.
- 1.LED 실습을 먼저 실행해 채널 구동이 되는지 확인한다.

## 3. 실행 방법 (셀 실행 순서 안내)
1. 모듈 import 및 I2C/PCA9685 초기화
2. 채널 15의 duty_cycle을 0으로 초기화 (부저 끔)
3. 멜로디 주파수 리스트 정의
4. `for freq in melody:` 루프로 각 음을 0.3초 연주하고 0.1초 쉬기

셀 실행 시 `[329, 311, 329, 311, 246, 146, 293, 261, 220]` 주파수(Hz)의 멜로디가 연주된다.

**단계별 예상 확인 포인트**
- 초기화(duty 0) 후 첫 음(329Hz)이 0.3초간 울린다.
- 음 사이 0.1초 휴지가 끼어 리듬감이 생긴다.
- 총 9개 음이 순서대로 연주된 후 부저가 조용해진다.
- 소리가 나지 않으면 1.LED 실습으로 채널 구동과 배선을 먼저 점검한다.

**중단 방법**: 연주 중 정지(■) 버튼을 누르면 즉시 멈춘다. (무한 루프가 아님)

## 4. 코드 해설 (원본 코드 그대로)
```python
import busio
import board
import adafruit_pca9685
import time
i2c = busio.I2C(board.SCL_1, board.SDA_1)
pca9685 = adafruit_pca9685.PCA9685(i2c)
pca9685.channels[15].duty_cycle = 0
melody = [329, 311, 329, 311, 246, 146, 293, 261, 220]
for freq in melody:
    pca9685.frequency = freq
    pca9685.channels[15].duty_cycle = int(4096/2)
    time.sleep(0.3)
    pca9685.channels[15].duty_cycle = 0
    time.sleep(0.1)
```

**줄 단위 해설**
- `import busio / board / adafruit_pca9685 / time`: 필수 모듈 import.
- `i2c = busio.I2C(board.SCL_1, board.SDA_1)`: SCL_1/SDA_1 기반 I2C 버스 객체 생성.
- `pca9685 = adafruit_pca9685.PCA9685(i2c)`: PCA9685(0x40) 초기화.
- `pca9685.channels[15].duty_cycle = 0`: 채널 15(부저)를 끈 상태로 시작.
- `melody = [329, ...]`: 연주할 주파수 배열. 각 숫자는 음계의 주파수(Hz). 예: 329=E4, 311=D#4, 246=B3, 146=D3, 293=D4, 261=C4, 220=A3.
- `for freq in melody:`: 배열의 주파수를 하나씩 꺼내 반복.
- `pca9685.frequency = freq`: PWM 주파수를 현재 음의 주파수로 변경. 부저는 이 주파수로 진동하며 해당 음을 낸다.
- `pca9685.channels[15].duty_cycle = int(4096/2)`: 듀티를 2048(≈50%)로 설정해 소리를 낸다. 50% 듀티(절반 ON)는 부저를 효율적으로 구동하는 일반적인 방식이다.
- `time.sleep(0.3)`: 음을 0.3초 동안 유지.
- `pca9685.channels[15].duty_cycle = 0`: 듀티를 0으로 만들어 소리를 멈춘다.
- `time.sleep(0.1)`: 음과 음 사이 0.1초 휴지.

**동작 요약**: 주파수를 음계로 바꾸고 50% 듀티로 구동 → 0.3초 소리 → 0.1초 쉼 → 다음 음, 이 패턴이 반복되어 멜로디가 완성된다.

**연주되는 음의 순서와 의미**
| 순서 | 주파수(Hz) | 음명 | 비고 |
| --- | --- | --- | --- |
| 1 | 329 | E4 | 미 |
| 2 | 311 | D#4 | 레# |
| 3 | 329 | E4 | 미 |
| 4 | 311 | D#4 | 레# |
| 5 | 246 | B3 | 시 |
| 6 | 146 | D3 | 레(낮은) |
| 7 | 293 | D4 | 레 |
| 8 | 261 | C4 | 도 |
| 9 | 220 | A3 | 라 |

- 각 음은 0.3초 연주 + 0.1초 휴지로 총 0.4초씩 진행되어 총 약 3.6초 소요된다.

## 5. 원본 코드의 오타/수정 안내
이 노트북의 코드는 **오타 없이 정상 동작**한다.

참고 사항(필수 아님):
- `int(4096/2)`는 2048로 계산되어 50% 듀티가 된다. 명시적으로 `2048`을 써도 동일하다.
- 부저의 음량이 작다면 채널 15 대신 다른 채널/외부 증폭 회로가 연결되어 있는지 하드웨어 배선을 확인한다.

**학습 포인트 요약**
- **주파수(frequency)**가 음의 높이를, **duty_cycle**이 음량(50%가 최대)을 결정한다.
- 한 음을 연주하는 패턴 = 주파수 설정 → 50% 듀티 → 유지(sleep) → 0 듀티 → 휴지(sleep).
- 부저는 PWM 채널 15에 연결되어 있어 LED(0~7)와 채널 영역이 다르다는 점을 구분한다.
- 이 실습으로 주파수 제어가 가능해지면, 이후 서보·모터 주파수 기반 제어 개념으로 확장할 수 있다.

## 6. 실행 결과 예시
- 터미널 출력은 없다. 부저에서 짧은 멜로디가 1회 연주된다.
- 연주 순서(약): E4 → D#4 → E4 → D#4 → B3 → D3 → D4 → C4 → A3.
- 소리가 나지 않으면 채널 15 배선과 duty_cycle 설정을 확인한다.

**시간별 연주 흐름**
| 순서 | 동작 | 시간 |
| --- | --- | --- |
| 1 | 첫 음(329Hz) 연주 | 0.3초 |
| 2 | 휴지 | 0.1초 |
| 3 | 두 번째 음(311Hz) 연주 | 0.3초 |
| ... | 9개 음 반복 | - |
| 마지막 | 220Hz 연주 후 정지 | 0.3초 |

- 총 소요 시간은 약 9×(0.3+0.1) = 3.6초이다.
- 마지막 음이 끝나면 duty가 0이 되어 부저가 조용해진다.

## 7. 주의사항 및 트러블슈팅
- **배선 확인**: 부저의 양극(+)을 PCA9685 채널 15에, 음극(-)을 GND에 연결. 능동/수동 부저에 따라 외부 회로가 필요할 수 있다.
- **듀티 50%**: PWM의 듀티가 50%일 때 부저가 최대로 울린다. `int(4096/2)` = 2048이 50%에 해당.
- **주파수 범위**: 사람이 들을 수 있는 20Hz~20kHz 범위를 넘지 않도록 한다.
- **I2C 버스**: 이 버전은 `board.SCL_1/SDA_1` 사용. 오류 시 `board.SCL/SDA`로 변경해 배선과 맞춘다.
- **부저가 울리지 않을 때**: `sudo i2cdetect -y -r 1`로 0x40 확인, LED 실습으로 채널 구동이 되는지 먼저 점검.
- **음이 이상하게 들릴 때**: duty_cycle을 0으로 바꾸지 않고 다음 음으로 넘어가면 소리가 끊기지 않고 겹칠 수 있다. 0.1초 휴지가 음 사이 끊김을 만든다.
- **채널 확인**: 부저가 다른 채널에 연결된 로봇이라면 `channels[15]` 대신 해당 채널 번호로 바꾼다.
- **음이 안 나지만 LED는 켜짐**: PWM 채널 구동은 되므로 채널 번호(15)와 부저 배선만 확인하면 된다. 부저 극성(+/-, 능동/수동)도 점검한다.
- **음이 찌그러짐**: 부저가 3.3V로는 부족해 5V 전원을 요구할 수 있다. 모듈 사양을 확인한다.
- **부저가 계속 한 음만 냄**: `pca9685.frequency = freq`가 루프 밖에 있거나 frequency 갱신이 빠져 있을 수 있다. 매 음마다 주파수를 바꾸는 코드가 유지되는지 확인한다.
- **연주 중간에 멈춤**: 다른 셀/코드에서 같은 I2C 버스를 동시에 사용하면 간섭이 생길 수 있다. 이전 셀의 무한 루프를 먼저 정지시킨다.

## 8. 실습 과제
1. 멜로디 배열에 다른 음계(예: [440, 494, 523, 440, 523, 587])를 넣어 다른 곡을 연주하라.
   - 힌트: 440=A4, 494=B4, 523=C5, 587=D5. 서양 음계 표에서 원하는 음의 주파수를 찾아 배열에 넣는다.
2. 각 음의 연주 시간(0.3)과 휴지 시간(0.1)을 바꿔 템포를 조절하라.
   - 힌트: 0.1초로 줄이면 빠른 곡, 0.5초로 늘리면 느린 곡이 된다.
3. 두 개의 부저를 서로 다른 채널에 연결하고 2중 멜로디를 만들어 보라.
   - 힌트: `melody1`, `melody2` 두 배열을 만들고 `for f1, f2 in zip(melody1, melody2):`로 동시에 제어한다.
4. `duty_cycle`을 1024(25%)로 바꿔 음량 변화를 관찰하라.
   - 힌트: 25% 듀티에서는 소리가 작아진다. 0%와 100%에서는 부저가 울리지 않을 수 있다.
5. 멜로디를 3회 반복 연주하도록 `while` 루프로 감싸 보라.
   - 힌트: `for repeat in range(3):` 안에 전체 멜로디 루프를 넣으면 된다.
6. 연주할 주파수를 사용자 입력으로 받아 부저로 연주하는 코드를 작성하라.
   - 힌트: `input()`으로 주파수를 받아 `int()` 변환 후 하나만 연주한다.
