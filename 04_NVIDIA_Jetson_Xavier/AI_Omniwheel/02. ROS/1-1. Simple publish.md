# 1-1. ROS Simple Publish

## 1. 학습 목표

- ROS 1(Topic) 통신의 기본 구조를 이해한다.
- **Publisher(발행자)** 를 만들어 `chatter` 토픽으로 문자열을 주기적으로 발행한다.
- `rospy`의 노드 생성 → Publisher 생성 → 발행 주기 제어 흐름을 익힌다.

## 2. 준비 사항

### 2.1 필요 하드웨어

- NVIDIA Jetson Xavier NX (ROS Melodic 설치 완료)

### 2.2 필요 라이브러리

- ROS 1 Melodic (`rospy`, `std_msgs`) — 기본 설치 시 포함
- Jupyter Notebook

### 2.3 사전 설정

```bash
$ source /opt/ros/melodic/setup.bash
$ roscore          # 별도 터미널에서 실행
$ jupyter notebook
```

> 표준 메시지(`std_msgs/String`)만 사용하므로 `catkin_ws` 빌드는 필요하지 않습니다.

## 3. 실행 방법

1. 터미널에서 `roscore` 실행.
2. Jupyter에서 `02. ROS/1-1. Simple publish.ipynb` 오픈.
3. 셀을 **위에서 아래로 순서대로 실행**.
4. 발행 확인: 터미널에서 `rostopic echo /chatter` 또는 `rostopic list`.

## 4. 코드 해설

### 1) 모듈 추가

```python
import rospy
from std_msgs.msg import String
```

- `rospy`: ROS의 Python 클라이언트 라이브러리 (노드 생성, 통신 기능).
- `std_msgs.msg.String`: ROS 표준 메시지 중 문자열 타입. 발행할 데이터 형식.

### 2) 노드 생성

```python
rospy.init_node('talker', anonymous=True)
```

- `talker` 라는 이름의 ROS 노드를 생성한다.
- `anonymous=True` : 노드 실행 시 이름 뒤에 랜덤 숫자를 붙여, 같은 노드를 여러 개 띄워도 이름 충돌이 없다.

### 3) Publisher 객체 생성

```python
pub = rospy.Publisher('chatter', String, queue_size=10)
```

- `chatter` 토픽으로 `String` 메시지를 보내는 발행자를 생성한다.
- `queue_size=10` : 수신자가 아직 준비 안 된 동안 쌓아둘 메시지 최대 10개. (ROS의 비동기 버퍼)

### 4) 데이터 발행 주기 지정

```python
rate = rospy.Rate(10)
```

- 초당 10회(10Hz) 발행하도록 주기를 설정한다. `rate.sleep()` 을 만날 때마다 이 주기를 맞춘다.

### 5) 문자열 전송 (메인 루프)

```python
while not rospy.is_shutdown():
    hello_str = "hello world %s" % rospy.get_time()

    rospy.loginfo(hello_str)

    pub.publish(hello_str)

    rate.sleep()
```

| 라인 | 설명 |
| ---- | ---- |
| `while not rospy.is_shutdown()` | Ctrl+C로 노드가 종료되기 전까지 반복 |
| `"hello world %s" % rospy.get_time()` | 현재 시각(타임스탬프)이 포함된 문자열 생성 |
| `rospy.loginfo(...)` | 터미널(노트북 출력)에 로그로 표시 |
| `pub.publish(hello_str)` | `chatter` 토픽으로 메시지 발행 |
| `rate.sleep()` | 10Hz 주기를 유지하도록 대기 |

## 5. 실행 결과 예시

```
[INFO] [1659427174.358526]: hello world 1659427174.3580408
[INFO] [1659427174.529116]: hello world 1659427174.5283244
[INFO] [1659427174.628913]: hello world 1659427174.6282961
...
```

`rostopic echo /chatter` 를 다른 터미널에서 실행하면 동일한 문자열이 수신됨을 확인할 수 있습니다.

## 6. 주의사항 및 트러블슈팅

| 증상 | 원인/해결 |
| ---- | --------- |
| `ROS_MASTER_URI` 오류 | `roscore` 미실행 또는 Jupyter 실행 전 `source` 누락 |
| 노드가 실행 즉시 종료됨 | `rospy.is_shutdown()` 이 True → `roscore` 확인 |
| 같은 이름 오류 | `anonymous=True` 미사용 시 충돌 가능 |

> ⚠️ 이 노트북은 **무한 루프(while)** 를 포함하므로, 셀 정지 시
> Jupyter 메뉴 **Kernel → Interrupt** 를 눌러야 합니다.

## 7. 실습 과제

1. 발행 주기를 10Hz → 1Hz로 바꾸고 수신 간격이 어떻게 달라지는지 확인.
2. `hello world` 문자열에 노드 이름(`rospy.get_name()`)을 추가해 보기.
3. 토픽 이름을 `chatter` → `my_topic`으로 바꿔 `rostopic list`에서 확인.
