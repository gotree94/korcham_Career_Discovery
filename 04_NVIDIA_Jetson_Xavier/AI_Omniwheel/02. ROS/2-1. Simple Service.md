# 2-1. ROS Simple Service (Server)

## 1. 학습 목표

- Topic과 달리 **요청/응답(Request/Response)** 구조인 Service 통신을 이해한다.
- **Service Server** 를 만들고, 두 정수를 더해 결과를 반환하는 서비스를 제공한다.
- 커스텀 서비스(`AddTwoInts.srv`) 사용 방법을 익힌다.

## 2. 준비 사항

### 2.1 필요 하드웨어

- NVIDIA Jetson Xavier NX (ROS Melodic 설치 완료)

### 2.2 필요 라이브러리

- ROS 1 Melodic
- `omniwheel_project` 패키지 (커스텀 srv 포함) — **catkin_ws 빌드 필수**

### 2.3 사전 설정 (중요)

```bash
$ source /opt/ros/melodic/setup.bash
$ cd ~/catkin_ws
$ catkin_make                 # AddTwoInts.srv → Python 모듈 생성
$ source devel/setup.bash     # 반드시 source 한 상태에서 jupyter 실행
$ roscore                     # 별도 터미널
$ jupyter notebook
```

> `from omniwheel_project.srv import AddTwoInts` 가 동작하려면
> `catkin_make`로 생성된 메시지/서비스 모듈을 `PYTHONPATH`가 찾아야 합니다.
> `devel/setup.bash`를 source한 터미널에서 Jupyter를 띄워야 합니다.

### 참고: 서비스 정의 (catkin_ws/src/omniwheel_project/srv/AddTwoInts.srv)

```text
int64 a
int64 b
---
int64 sum
```

- `---` 위: 요청(request) 필드, 아래: 응답(response) 필드.

## 3. 실행 방법

1. 사전 설정 완료 후 `2-1. Simple Service.ipynb` 실행.
2. 서버 노드가 생성되고 대기 상태가 되면, 다른 터미널에서 클라이언트로 요청을 보내 응답을 확인.

## 4. 코드 해설

### 1) 모듈 추가

```python
import rospy
from omniwheel_project.srv import AddTwoInts, AddTwoIntsResponse
```

- `AddTwoInts`: 요청/응답 타입 정의 (요청: a, b / 응답: sum)
- `AddTwoIntsResponse`: 응답 메시지 생성용 클래스

### 2) 서비스 요청 처리 함수(핸들러)

```python
def handle_add_two_ints(req):
    print("Returning [%s + %s = %s]"%(req.a, req.b, (req.a + req.b)))

    return AddTwoIntsResponse(req.a + req.b)
```

| 요소 | 설명 |
| ---- | ---- |
| `req` | 클라이언트가 보낸 요청 객체 |
| `req.a`, `req.b` | 요청 메시지의 필드 |
| `AddTwoIntsResponse(req.a + req.b)` | 응답 객체 생성 후 반환 |

> 핸들러는 서비스가 호출될 때마다 자동 실행되며, **반환값이 응답 메시지**가 된다.

### 3) 노드 생성

```python
rospy.init_node('add_two_ints_server', anonymous=True)
```

- `add_two_ints_server` 노드를 생성한다.

### 4) 서비스 서버 생성

```python
server = rospy.Service('add_two_ints', AddTwoInts, handle_add_two_ints)
```

- `add_two_ints` 라는 이름의 서비스를 제공한다.
- 요청이 오면 `handle_add_two_ints` 를 호출해 결과를 응답한다.

> ⚠️ 실제로 서버가 계속 대기하려면 `rospy.spin()` 이 필요합니다.
> (Jupyter에서 셀이 종료되면 서버가 내려가므로, 확인이 끝나기 전에는 셀을 유지하세요.
> 필요 시 마지막 셀에 `rospy.spin()` 을 추가할 수 있습니다.)

## 5. 실행 결과 예시

```
Returning [2 + 3 = 5]
```

- `rosservice call add_two_ints 2 3` → `sum: 5` 반환 확인.

| 증상 | 원인/해결 |
