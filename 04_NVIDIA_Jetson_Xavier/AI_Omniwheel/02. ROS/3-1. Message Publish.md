# 3-1. ROS Custom Message Publish

## 1. 학습 목표

- ROS 표준 메시지가 아닌 **커스텀 메시지(.msg)** 를 사용하는 방법을 이해한다.
- `omniwheel_project/Numb`(정수 1개) 메시지를 발행하는 노드를 만든다.
- 1-1의 기본 Publisher 구조를 커스텀 메시지로 확장한다.

## 2. 준비 사항

### 2.1 필요 하드웨어

- NVIDIA Jetson Xavier NX (ROS Melodic 설치 완료)

### 2.2 필요 라이브러리

- ROS 1 Melodic, `omniwheel_project` 패키지 (커스텀 msg 포함) — **빌드 필수**

### 2.3 사전 설정

```bash
$ source /opt/ros/melodic/setup.bash
$ cd ~/catkin_ws

```

### 참고: 메시지 정의 (catkin_ws/src/omniwheel_project/msg/Numb.msg)

```text

```

- 하나의 `int64` 필드(`number`)만 가진 사용자 정의 메시지.

## 3. 실행 방법

1. 사전 설정 후 `3-1. Message Publish.ipynb` 실행.
2. 발행 확인:
   ```bash
   $ rostopic list                 # msgChatter 확인
   $ rostopic echo /msgChatter     # number 값 증가 확인
   ```
3. 3-2(Message Subscribe) 노트북과 함께 사용하면 커스텀 메시지 통신을 완성.

## 4. 코드 해설

### 1) 모듈 추가

```python
import rospy
from omniwheel_project.msg import Numb
```

- `omniwheel_project.msg.Numb` : 직접 정의한 메시지 타입. 발행할 데이터 구조.

### 2) 노드 생성

```python
rospy.init_node('msg_publisher', anonymous=True)
```

- `msg_publisher` 노드 생성.

### 3) Publisher 객체 생성

```python
pub = rospy.Publisher('msgChatter', Numb, queue_size=10)
```

- `msgChatter` 토픽으로 `Numb` 메시지를 발행하는 발행자.
- 토픽 이름·타입은 3-2의 Subscriber와 **정확히 일치**해야 한다.

### 4) 변수 초기화 및 루프

```python
num = 0
rate = rospy.Rate(10)

while not rospy.is_shutdown():
    num += 1
    pub.publish(num)
    rate.sleep()
```

| 요소 | 설명 |
| ---- | ---- |
| `num += 1` | 1씩 증가하는 카운터 |
| `pub.publish(num)` | **정수를 직접 전달**해도 `Numb` 메시지로 자동 래핑되어 `number` 필드에 담겨 발행 |

> `pub.publish(num)` 은 내부적으로 `Numb(number=num)` 와 동일하게 동작합니다.

## 5. 실행 결과 예시

```

```

## 6. 주의사항 및 트러블슈팅

| 증상 | 원인/해결 |
| ---- | --------- |
| `ImportError: No module named omniwheel_project.msg` | `catkin_make` 후 `devel/setup.bash` source 누락 |
| `number` 필드가 없다는 오류 | `Numb.msg` 재정의 후 `catkin_make` 재실행 필요 |
| 토픽 수신 안 됨 | 3-2와 토픽 이름(`msgChatter`)/타입 일치 확인 |

> ⚠️ 무한 루프 셀 정지는 Jupyter **Kernel → Interrupt** 로 처리합니다.

## 7. 실습 과제

1. `Numb.msg`에 문자열 필드 `name`을 추가하고, 이름+카운터를 함께 발행해 보기.
2. 발행 주기를 1Hz로 낮춰 `rostopic echo` 의 출력 속도 차이 확인.
3. `rostopic hz /msgChatter` 로 실제 발행 주기를 측정해 보기.
