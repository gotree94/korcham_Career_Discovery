# 3-2. ROS Custom Message Subscribe

## 1. 학습 목표

- 커스텀 메시지(`omniwheel_project/Numb`)를 **구독**하고 필드를 읽는 방법을 이해한다.
- 콜백으로 수신한 메시지의 `number` 필드를 출력한다.
- 3-1(Message Publish)과 함께 커스텀 메시지 기반 Topic 통신을 완성한다.

## 2. 준비 사항

### 2.1 필요 하드웨어

- NVIDIA Jetson Xavier NX (ROS Melodic 설치 완료)

### 2.2 필요 라이브러리

- ROS 1 Melodic, `omniwheel_project` 패키지 — **빌드 필수**

### 2.3 사전 설정

```bash
$ source /opt/ros/melodic/setup.bash
$ cd ~/catkin_ws && catkin_make && source devel/setup.bash

```

> 이 노트북은 구독자 역할만 하므로, 발행자(3-1)가 필요합니다.
> **3-1(Messge Publish)을 셀 유지 상태로 실행해 둔 뒤** 실행하세요.

## 3. 실행 방법

1. 3-1(Message Publish) 노트북 실행 → 발행 루프 셀 유지.
2. `3-2. Message Subscribe.ipynb` 실행.
3. 콜백이 수신한 `number` 값이 증가하며 출력되면 성공.

## 4. 코드 해설

### 1) 모듈 추가

```python
import rospy
from omniwheel_project.msg import Numb
```

- 발행자(3-1)와 동일한 `Numb` 타입 import.

### 2) 데이터 수신 처리(콜백) 함수

```python
def callback(data):
    rospy.loginfo("I heard %d", data.number)
```

| 요소 | 설명 |
| ---- | ---- |
| `data` | 수신한 `Numb` 메시지 객체 |
| `data.number` | 커스텀 메시지의 `int64 number` 필드 값 |

### 3) 노드 생성 및 Subscriber 등록

```python
rospy.init_node('msg_subscriber', anonymous=True)

rospy.Subscriber("msgChatter", Numb, callback)
```

- `msgChatter` 토픽에서 `Numb` 메시지를 구독.
- 발행자(3-1)의 토픽 이름·타입과 일치해야 콜백이 호출된다.

> ⚠️ 수신 처리를 위해 마지막 셀에 다음을 추가하면 안정적입니다.

```python
rospy.spin()
```

## 6. 주의사항 및 트러블슈팅

| 증상 | 원인/해결 |
| ---- | --------- |
| 출력이 전혀 없음 | `spin()` 누락 또는 발행자(3-1) 미실행 |
| 토픽 이름 오류 | 발행자와 구독자의 토픽 이름이 서로 다름 → `msgChatter` 통일 |
| `ImportError` | `catkin_make` 후 `devel/setup.bash` source 누락 |
