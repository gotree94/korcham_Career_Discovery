# 2-2. ROS Simple Service (Client)

## 1. 학습 목표

- **Service Client** 가 서버에 요청을 보내고 응답을 받는 과정을 이해한다.
- `ServiceProxy` 로 `add_two_ints` 서비스를 호출한다.
- 2-1(Server)과 함께 Service 통신의 요청/응답 구조를 완성한다.

## 3. 실행 방법

1. 2-1(Service Server) 노트북 실행 → 서버 셀을 실행된 상태로 유지.
2. `2-2. Simple Client.ipynb` 오픈 후 셀을 순서대로 실행.
3. `add_two_ints` 서비스를 호출하고, 반환된 `sum` 값이 출력되면 성공.

## 4. 코드 해설

### 1) 모듈 추가

```python
import rospy
from omniwheel_project.srv import AddTwoInts
```

- 서버와 동일한 `AddTwoInts` 타입을 import 한다. 요청/응답 구조를 공유하므로 타입이 일치해야 한다.

### 2) 서비스 호출 함수

```python
def add_two_ints_client(x, y):
    rospy.wait_for_service('add_two_ints')

    add_two_ints = rospy.ServiceProxy('add_two_ints', AddTwoInts)

    resp = add_two_ints(x, y)

    return resp.sum
```

| 요소 | 설명 |
| ---- | ---- |
| `rospy.wait_for_service('add_two_ints')` | 서버가 준비될 때까지 **대기** 후 진행 |
| `rospy.ServiceProxy('add_two_ints', AddTwoInts)` | 서버를 호출할 프록시(클라이언트 핸들) 생성 |
| `add_two_ints(x, y)` | 서버에 요청을 보내고 응답(Resp)을 받음 |
| `resp.sum` | 응답 메시지의 `sum` 필드 값 |

### 3) 노드 생성 및 호출

```python
rospy.init_node('add_two_ints_client', anonymous=True)

if __name__ == "__main__":
    print(add_two_ints_client(2, 3))
```

- 클라이언트 노드를 생성한 뒤, `x=2, y=3` 으로 요청을 보내 결과를 출력한다.

## 5. 실행 결과 예시

```
5
```

- 서버 노트북(2-1) 출력:
  ```
  Returning [2 + 3 = 5]
  ```

## 6. 주의사항 및 트러블슈팅

| 증상 | 원인/해결 |
| ---- | --------- |
| `wait_for_service`가 끝없이 대기 | 서버(2-1)가 실행 중이 아님 → 서버 셀 유지 확인 |
| 서비스가 이미 등록됨 | 같은 이름의 서버가 중복 실행됨 → 하나만 유지 |
| `ImportError` | `catkin_make` 후 `devel/setup.bash` source 누락 |
