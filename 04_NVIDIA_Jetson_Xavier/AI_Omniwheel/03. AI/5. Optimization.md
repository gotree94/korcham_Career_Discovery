# 5. AI — TensorFlow 모델 최적화 (TensorRT 변환)

## 1. 학습 목표

- TensorFlow 1.15 체크포인트 모델을 **TensorRT 엔진**으로 변환하는 과정을 이해한다.
- `bready` 의 최적화 도구로 `pipeline.config` + `model.ckpt` → FP16 TensorRT 모델을 생성한다.
- 이후 실습(6. Inference, 7. Object Tracking)에서 사용할 `optimization/` 폴더를 만든다.

## 2. 준비 사항

### 2.1 필요 하드웨어

- NVIDIA Jetson Xavier NX (JetPack 4.x, TensorRT 8 설치, GPU 탑재 보드)

### 2.2 필요 라이브러리

- TensorFlow 1.15 (GPU), UFF, TensorRT 8
- **`bready` 패키지** (object_detection_tools 포함) — ⚠️ 아카이브 미포함, 보드 설치 필요

### 2.3 사전 설정

- `03. AI/` 폴더 구조 유지 (아래 참고)
- Jupyter를 이 폴더에서 실행

```
03. AI/
├── recognition/          # 변환할 원본 모델 (체크포인트, config 포함)
│   ├── pipeline.config
│   └── model.ckpt.meta / .index / .data-00000-of-00001
└── 5. Optimization.ipynb
```

> 이 실습은 **카메라/ROS가 필요 없습니다.** 변환은 1회 수행하면 결과물이
> `optimization/` 폴더에 남으므로, 이후 6·7 실습에서 재사용합니다.

## 3. 실행 방법

1. `03. AI/5. Optimization.ipynb` 오픈.
2. 두 셀을 순서대로 실행.
3. 실행 완료 후 `03. AI/optimization/` 폴더에 `frozen_inference_graph.pb` 가 생성되는지 확인.

## 4. 코드 해설

### 1) 최적화 도구 import

```python
from bready.object_detection_tools.lib.optimization_tools import optimizer as det_optimizer
```

- `bready` 패키지 안의 최적화 도구를 가져온다.
- 이 도구가 TF 그래프를 파싱해 UFF로 변환하고 TensorRT 엔진을 생성한다.

> ⚠️ 이 줄에서 `ImportError` 가 나면 `bready` 패키지가 설치되지 않은 것입니다.
> README의 사전 준비를 확인하세요.

### 2) 모델 변환 실행

```python
det_optimizer.convertToOptimizationModel(
  'recognition',
  'optimization',
  config_name='pipeline.config',
  checkpoint_name='model.ckpt',
  precision_mode='FP16',
  mode='tensorrt'
)
```

| 인자 | 값 | 설명 |
| ---- | -- | ---- |
| 1번째 인자 | `'recognition'` | 원본 모델이 있는 폴더 (TF 모델) |
| 2번째 인자 | `'optimization'` | 결과(TensorRT 엔진)를 저장할 폴더 |
| `config_name` | `'pipeline.config'` | Object Detection API 파이프라인 설정 파일 |
| `checkpoint_name` | `'model.ckpt'` | 학습된 체크포인트 이름 (확장자 제외) |
| `precision_mode` | `'FP16'` | 16비트 부동소수점. GPU 메모리·속도 절약 (Xavier 권장) |
| `mode` | `'tensorrt'` | 변환 방식 (TensorRT 엔진 생성) |

## 6. 주의사항 및 트러블슈팅

| 증상 | 원인/해결 |
| ---- | --------- |
| `ImportError` (bready) | `bready` 패키지 미설치 → 보드 원본 이미지의 패키지 확보 후 설치 |
| `FileNotFoundError: pipeline.config` | Jupyter 실행 위치가 `03. AI/` 가 아님 → 작업 디렉터리 확인 |
| `model.ckpt` 파일 부재 | `recognition/` 폴더에 체크포인트 3종(meta/index/data) 확인 |
| CUDA/TensorRT 버전 불일치 | TensorRT 8 + TF 1.15 (JetPack 4.x) 조합 확인 |

## 7. 실습 과제

1. `precision_mode`를 `'FP16'` → `'INT8'`로 바꿔 변환해 보고, 생성 결과물 크기를 비교해 보기.
2. 변환 전(`recognition`)과 변환 후(`optimization`) 폴더 용량을 `du -sh`로 비교해 보기.
3. `optimization/` 결과물을 지운 뒤 다시 실행해, 변환이 재현 가능한지 확인.
