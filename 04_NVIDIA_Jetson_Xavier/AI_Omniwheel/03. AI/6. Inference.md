# 6. AI — 실시간 객체 인식 (Inference)

## 1. 학습 목표

- 카메라 스트리밍 영상을 받아 **실시간으로 사람(person)을 검출**한다.
- 최적화된 TensorRT 모델(`optimization/`)로 추론하는 파이프라인을 이해한다.
- 검출 결과를 Jupyter 위젯(`ipywidgets.Image`)에 실시간 표시한다.

## 2. 준비 사항

### 2.1 필요 하드웨어

- NVIDIA Jetson Xavier NX (TensorRT 8, `bready` 설치)
- CSI/웹캠 카메라

### 2.2 필요 라이브러리

- `bready` (camera_utils, object_detection_tools), OpenCV, `ipywidgets`, `IPython`

### 2.3 사전 설정 (순서대로)

1. **카메라 스트리밍 실행 (필수)**

   ```bash
   $ ./startup.sh     # GStreamer: nvarguscamerasrc → tcpserversink port 5000
   ```

2. **모델 준비**: 5. Optimization 실습에서 생성한 `optimization/` 폴더 확인.
3. Jupyter 실행 후 `03. AI/6. Inference.ipynb` 오픈.

## 3. 실행 방법

1. `startup.sh` 가 실행 중인 상태 확인.
2. 노트북 셀을 순서대로 실행 (마지막 검출 루프 셀 포함).
3. 화면의 `Image` 위젯에 검출 박스가 표시되면 성공.
4. 종료: 셀을 정지(`Kernel → Interrupt`)하면 `KeyboardInterrupt` 로 "종료" 출력 후 종료.

## 4. 코드 해설

### 1) 모듈 추가

```python
import os
import cv2
import time

import bready.camera_utils.PyCamera as PyCamera
from bready.object_detection_tools import ObjectDetector

import ipywidgets.widgets as widgets
import IPython.display
```

- `PyCamera.URLCamera`: TCP 스트리밍(URL) 카메라. 카메라 캡처와 디코딩 담당.
- `ObjectDetector`: 객체 검출기(클래스/박스 좌표/이미지 생성).
- `ipywidgets.widgets.Image`: 노트북에 이미지를 표시하는 위젯.

### 2) 카메라 객체 생성

```python
camera = PyCamera.URLCamera(
    camera_url = "tcp://127.0.0.1:5000",
    live_thread = True
)
```

| 인자 | 값 | 설명 |
| ---- | -- | ---- |
| `camera_url` | `"tcp://127.0.0.1:5000"` | GStreamer가 보내는 영상 주소 (startup.sh) |
| `live_thread` | `True` | 별도 스레드로 프레임을 계속 받아 최신 프레임 유지 |

### 3) 검출 모델(Tester) 생성

```python
obj_model = ObjectDetector.Tester(
    'optimization',
    'detection_classes.txt',
    ["image_tensor"]
)
```

| 인자 | 값 | 설명 |
| ---- | -- | ---- |
| 1번째 | `'optimization'` | 5번에서 만든 TensorRT 모델 폴더 |
| 2번째 | `'detection_classes.txt'` | 클래스(라벨) 이름 목록 |
| 3번째 | `["image_tensor"]` | 모델의 입력 텐서 이름 |

### 4) 검출 루프

```python
image_widget = widgets.Image(format='jpeg')
IPython.display.display(image_widget)

while(True):
    try:
        image = camera.get_frame()

        if(image is None):
            break

        obj_model.execute(image)

        if obj_model.getDetectedCount('person') > 0:
            print("사람이 감지되었습니다")

        result_image = obj_model.getResultImage()
        image_widget.value = cv2.imencode(".jpeg", result_image)[1].tostring()
        time.sleep(0.01)

    except KeyboardInterrupt:
        print("종료")
        break
```

| 단계 | 설명 |
| ---- | ---- |
| `camera.get_frame()` | 최신 프레임(이미지) 가져오기 |
| `if(image is None): break` | 카메라가 닫히면 루프 종료 |
| `obj_model.execute(image)` | 이미지를 검출 모델에 통과(추론) |
| `getDetectedCount('person')` | 검출된 `person` 개수 반환 → 0보다 크면 안내 출력 |
| `getResultImage()` | 검출 박스가 그려진 결과 이미지 반환 |
| `cv2.imencode(".jpeg", ...)` | 이미지를 JPEG 바이트로 인코딩 → 위젯에 표시 |
| `time.sleep(0.01)` | 약 100FPS로 루프 속도 제어 |

## 5. 실행 결과 예시

```
사람이 감지되었습니다
사람이 감지되었습니다
...
종료
```

- 화면의 위젯에 사람 주변 초록색 검출 박스가 실시간 표시됩니다.

## 6. 주의사항 및 트러블슈팅

| 증상 | 원인/해결 |
| ---- | --------- |
| `image`가 계속 `None` | `startup.sh` 미실행 또는 포트 5000 확인 |
| `FileNotFoundError: optimization` | 5번 실습을 먼저 실행해 `optimization/` 생성 |
| `getDetectedCount` 오류 | `detection_classes.txt` 와 모델의 클래스 인덱스 불일치 |
| 화면이 느림 | GPU 메모리 부족 → 카메라 해상도 낮추기 |
| `ImportError` (bready) | `bready` 패키지 미설치 |

## 7. 실습 과제

1. `getDetectedCount('person')` 을 다른 클래스(예: `'car'`, `'dog'`)로 바꿔 검출 여부 확인.
2. `time.sleep(0.01)` 의 값을 0.5로 바꿔 프레임이 어떻게 느려지는지 확인.
3. 검출 개수를 매 프레임 출력하고, 화면에 사람이 보일 때만 `"사람이 감지되었습니다"` 가 출력되는지 관찰.
