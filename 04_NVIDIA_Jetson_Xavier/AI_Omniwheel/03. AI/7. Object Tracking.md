# 7. AI — 객체 추적 주행 (Object Tracking)

## 1. 학습 목표

- 6번의 사람 검출 결과를 이용해 **로봇이 사람을 자동으로 따라가는 주행**을 구현한다.
- 검출된 가장 가까운 사람의 위치로부터 **선속도/각속도**를 계산하고, ROS `/cmd_vel` 토픽으로 발행한다.
- 검출 화면과 추적 시각화 화면을 나란히 표시한다.

## 2. 준비 사항

### 2.1 필요 하드웨어

- NVIDIA Jetson Xavier NX (TensorRT 8, `bready` 설치, ROS Melodic)
- CSI/웹캠 카메라
- 옴니휠 로봇 (미드라이버 + 모터, `/cmd_vel` 구동 노드)

### 2.2 필요 라이브러리

- `bready`, OpenCV, NumPy, ROS 1(`rospy`, `geometry_msgs`)
- `omniwheel_project` 패키지 (구동 노드)

### 2.3 사전 설정 (순서대로)

2. **ROS Master 및 구동 노드**

> ⚠️ `/cmd_vel` 을 구독하는 구동 노드가 없으면 로봇은 움직이지 않고, 노트북은 계산만 합니다.

## 3. 실행 방법

1. 카메라·ROS 준비 완료 확인.
2. 노트북 셀을 순서대로 실행 (마지막 추적 루프 셀 포함).
3. 카메라 앞에 사람이 있으면 **원본 검출 화면 + 추적 마커 화면**이 나란히 표시되고 로봇이 따라움직입니다.
4. 종료: `Kernel → Interrupt` → "종료" 출력 후 종료. **비상 시 로봇 전원을 차단**하세요.

## 4. 코드 해설

### 1) 모듈 추가

```python
import os
import time
import rospy
import cv2

import numpy as np
from geometry_msgs.msg import Twist

import bready.camera_utils.PyCamera as PyCamera
from bready.object_detection_tools import ObjectDetector

import ipywidgets.widgets as widgets
import IPython.display
```

- 6번 구성 + `rospy`/`geometry_msgs.msg.Twist`(로봇 속도 명령), `numpy`(벡터 연산) 추가.

### 2) 카메라 · 모델 생성 (6번과 동일)

```python
camera = PyCamera.URLCamera(camera_url="tcp://127.0.0.1:5000", live_thread=True)

obj_model = ObjectDetector.Tester('optimization', 'detection_classes.txt', ["image_tensor"])
```

### 3) 벡터 길이 계산 함수

```python
def norm(vec):
    return np.sqrt(vec[0]**2 + vec[1]**2)
```

- `(x, y)` 좌표 벡터의 크기(거리)를 계산한다. "가장 가까운 사람" 판단에 사용.

### 4) 가장 가까운 검출 찾기

```python
def closest_detection(detections):
    closest_detection = None

    for det in detections:
        center = (det["detection_center_point_x"], det["detection_boxes"][2])

        if closest_detection is None:
            closest_detection = center
        elif norm(center) < norm(closest_detection):
            closest_detection = center

    return closest_detection
```

| 요소 | 설명 |
| ---- | ---- |
| `det["detection_center_point_x"]` | 검출 박스 중심 x (정규화 0~1) |
| `det["detection_boxes"][2]` | 검출 박스의 아래쪽 y 좌표(정규화) → 바닥 거리 대용 |
| `norm(...)` | 원점(0,0)에서의 거리. 작을수록 화면 중앙·아래쪽 → 가깝다 |

> 6번과 달리 검출 리스트를 받아(`getDetectedList2`) **가장 가까운 사람 하나**를 선택합니다.

### 5) 제어값 계산

```python
def calc_ctrl_data(x, y):
    angular_data = (0.5 - x)
    linear_data = (0.7 - min(y, 0.7)) * (4/0.7)

    return linear_data, angular_data
```

| 반환값 | 의미 | 로직 |
| ------ | ---- | ---- |
| `linear_data` | 선속도(m/s) | 사람이 멀수록(y 작을수록) 크게 → 최대 4 |
| `angular_data` | 각속도(rad/s) | 사람이 화면 중앙(0.5)에서 벗어난 만큼 회전 |

- 사람이 **앞에 있고 가까우면** 선속도가 작아지고, **중앙에서 벗어나면** 회전한다.

### 6) ROS 노드 및 Publisher

```python
rospy.init_node('Person_Detection', anonymous=True)

cmd_pub = rospy.Publisher('/cmd_vel', Twist, queue_size=1)

twist_data = Twist()
cmd_pub.publish(twist_data)
```

- `Person_Detection` 노드를 만들고, `/cmd_vel` 토픽으로 `Twist`(선속도/각속도)를 발행한다.
- 초기 `Twist`를 한 번 발행해 구동 노드와 연결을 확인한다.

### 7) 영상 표시 위젯 (2개 병렬)

```python
image_widget1 = widgets.Image(format='jpeg')
image_widget2 = widgets.Image(format='jpeg')

IPython.display.display(widgets.HBox([image_widget1, image_widget2]))
```

- 왼쪽: 원본 검출 결과 / 오른쪽: 추적 마커(원) 시각화.

### 8) 추적 메인 루프

```python
detect_label = 'person'

while(not rospy.is_shutdown()):
    try:
        image = camera.get_frame()
        if(image is None):
            break

        obj_model.execute(image)
        result_image = obj_model.getResultImage()

        xy_result = closest_detection(obj_model.getDetectedList2(detect_label))

        if(xy_result is not None):
            (x, y) = xy_result
        else:
            (x, y) = 0.5, 0.7

        cmd_vec_data = calc_ctrl_data(x, y)

        twist_data.linear.x = cmd_vec_data[0]
        twist_data.angular.z = cmd_vec_data[1]

        x = int(x * camera.camera_width)
        y = int(y * camera.camera_height)

        radius = int(max(camera.camera_width, camera.camera_height) / 28)
        thickness = int(max(camera.camera_width, camera.camera_height) / 74)

        result_image2 = cv2.circle(image.copy(), (x, y), radius, (0, 255, 0), thickness)

        tmpStream = cv2.imencode(".jpeg", result_image)[1].tostring()
        image_widget1.value = tmpStream

        tmpStream = cv2.imencode(".jpeg", result_image2)[1].tostring()
        image_widget2.value = tmpStream

        time.sleep(0.01)

        cmd_pub.publish(twist_data)

    except KeyboardInterrupt:
        print("종료")
        break
```

| 단계 | 설명 |
| ---- | ---- |
| `getDetectedList2('person')` | 검출된 사람들의 정보 리스트 |
| `closest_detection(...)` | 가장 가까운 사람의 (x, y) 선택 |
| 사람 없음 → `(0.5, 0.7)` | 기본값. 중앙·가까움 → 선속도 0(정지) |
| `calc_ctrl_data` | 추적 속도 계산 |
| `twist_data.linear.x / angular.z` | 선속도·각속도 지정 |
| `camera.camera_width/height` | 정규화 좌표 → 픽셀 좌표 변환 |
| `cv2.circle(...)` | 추적 중심에 초록색 원 표시 |
| `cmd_pub.publish(twist_data)` | **매 루프마다 속도 명령 발행** |

## 6. 주의사항 및 트러블슈팅

| 증상 | 원인/해결 |
| ---- | --------- |
| 로봇이 움직이지 않음 | `/cmd_vel` 구동 노드 미실행 / `roscore` 미실행 |
| `ros::init` 오류 | `roscore` 확인 + Jupyter를 source 후 실행 |
| `getDetectedList2` 결과 없음 | `detect_label`과 `detection_classes.txt`의 클래스명 일치 확인 |
| 갑자기 빙글빙글 | 각속도 발행 과다 → `angular_data`에 게인(예: ×0.5) 적용 |
| 안전 문제 | **비상 정지 버튼/전원 차단 습관** 필수 |

> 🚨 **안전 필수**: 추적 주행 실습은 로봇이 움직이므로 주변에 장애물을 치우고,
> 카메라 인식 실패 시 즉시 정지시킬 수 있도록 준비하세요.
