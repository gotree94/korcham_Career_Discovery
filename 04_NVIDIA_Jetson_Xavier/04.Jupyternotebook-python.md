## 2. Python이란?

### 2.1 Python의 특징

| 특징 | 설명 |
|---|---|
| **배우기 쉬움** | 문법이 간결하고 직관적 |

## 3. Jupyter Notebook에서 Python 실행하기

| 종류 | 용도 | 전환 단축키 |

## 4. 변수와 자료형

### 4.1 변수 (Variable)

변수는 **값을 저장하는 공간**이다. Python에서 변수 선언은 `=`로 한다.

```python
name = "로봇A"
speed = 120
battery = 87.5
is_active = True

print(name)
print(speed)
print(battery)
print(is_active)
```

```text
로봇A
120
87.5
True
```

### 4.2 기본 자료형 (Data Type)

| 자료형 | 예시 | 설명 |
|---|---|---|
| `int` | `42`, `-7` | 정수 |
| `float` | `3.14`, `-0.5` | 실수 |
| `str` | `"Hello"`, `'Hi'` | 문자열 |
| `bool` | `True`, `False` | 논리값 |

```python
# type() 함수로 자료형 확인
print(type(42))          # <class 'int'>
print(type(3.14))        # <class 'float'>
print(type("로봇"))       # <class 'str'>
print(type(True))        # <class 'bool'>
```

### 4.3 변수  naming 규칙

- 영문자, 숫자, 언더스코어(`_`) 사용
- 숫자로 시작할 수 없음
- 대소문자 구분 (`Speed` ≠ `speed`)
- 예약어(`if`, `for`, `class` 등)는 사용 불가

```python
# 올바른 예
robot_name = "A"
speed2 = 100
_private = "내부"

# 잘못된 예
# 2speed = 100      ← 숫자로 시작
# my-speed = 100    ← 하이픈 사용 불가
# if = 100          ← 예약어
```

### 4.4 여러 변수에 값 할당

```python
# 동일 값 할당
a = b = c = 0

# 여러 변수에 각각 할당
x, y, z = 1, 2, 3

# 값 교환
x, y = y, x
print(x, y)  # 2 1
```

## 5. 연산자

### 5.1 산술 연산자

```python
a = 17
b = 5

print("a + b =", a + b)    # 22
print("a - b =", a - b)    # 12
print("a * b =", a * b)    # 85
print("a / b =", a / b)    # 3.4
print("a // b =", a // b)  # 3  (몫)
print("a % b =", a % b)    # 2  (나머지)
print("a ** b =", a ** b)  # 1419857  (a의 b제곱)
```

| 연산자 | 의미 | 예시 | 결과 |
|---|---|---|---|
| `+` | 덧셈 | `7 + 3` | `10` |
| `-` | 뺄셈 | `7 - 3` | `4` |
| `*` | 곱셈 | `7 * 3` | `21` |
| `/` | 나눗셈 | `7 / 3` | `2.333...` |
| `//` | 몫 | `7 // 3` | `2` |
| `%` | 나머지 | `7 % 3` | `1` |
| `**` | 거듭제곱 | `2 ** 10` | `1024` |

### 5.2 비교 연산자

```python
a = 10
b = 20

print(a == b)   # False
print(a != b)   # True
print(a < b)    # True
print(a > b)    # False
print(a <= 10)  # True
print(a >= 15)  # False
```

| 연산자 | 의미 |
|---|---|
| `==` | 같다 |
| `!=` | 같지 않다 |
| `<` | 작다 |
| `>` | 크다 |
| `<=` | 작거나 같다 |
| `>=` | 크거나 같다 |

### 5.3 논리 연산자

```python
x = True
y = False

print(x and y)   # False
print(x or y)    # True
print(not x)     # False
```

| 연산자 | 의미 | 예시 | 결과 |
|---|---|---|---|
| `and` | 그리고 | `True and False` | `False` |
| `or` | 또는 | `True or False` | `True` |
| `not` | 부정 | `not True` | `False` |

### 5.4 복합 대입 연산자

```python
x = 10
x += 5    # x = x + 5  → 15
x -= 3    # x = x - 3  → 12
x *= 2    # x = x * 2  → 24
x /= 4    # x = x / 4  → 6.0

print(x)  # 6.0
```

## 6. 조건문 (if)

### 6.1 기본 구조

```python
조건이 참(True)이면:
    이 코드를 실행
```

Python은 **들여쓰기로 코드 블록**을 구분한다.

```python
temp = 35

if temp >= 30:
    print("더움")
elif temp >= 20:
    print("쾌적")
elif temp >= 10:
    print("선선")
else:
    print("추움")
```

```text
더움
```

### 6.2 들여쓰기 규칙

Python은 **4칸 공백(또는 Tab)** 으로 블록을 구분한다. 반드시 일관되게 사용해야 한다.

```python
# 올바른 예
if True:
    print("안쪽")
    print("안쪽")
print("바깥")

# 잘못된 예 (들여쓰기 오류)
# if True:
# print("오류!")
```

### 6.3 실습: 로봇 배터리 상태

```python
battery = 45

if battery >= 70:
    state = "충분"
elif battery >= 30:
    state = "보통"
elif battery >= 10:
    state = "부족"
else:
    state = "위험"

print(f"배터리 {battery}% → 상태: {state}")
```

```text
배터리 45% → 상태: 보통
```

### 6.4 실습: 홀짝 판별

```python
num = 7

if num % 2 == 0:
    print(f"{num}은 짝수")
else:
    print(f"{num}은 홀수")
```

```text

```

### 6.5 중첩 조건문

```python

battery = 60

if battery >= 20:

        print("저속 주행 중")
```

## 8. 리스트 (List)

### 8.1 리스트 생성과 접근

리스트는 **여러 값을 순서대로 저장**하는 자료구조이다.

```python
robots = ["A", "B", "C", "D"]
print(robots[0])    # A  (첫 번째)
print(robots[-1])   # D  (마지막)
print(robots[1:3])  # ['B', 'C']  (슬라이싱)
```

### 8.2 리스트 메서드

```python
nums = [3, 1, 4, 1, 5]

nums.append(9)      # 끝에 추가
print(nums)         # [3, 1, 4, 1, 5, 9]

nums.sort()         # 정렬
print(nums)         # [1, 1, 3, 4, 5, 9]

nums.pop()          # 마지막 제거
print(nums)         # [1, 1, 3, 4, 5]

print(len(nums))    # 5  (길이)
print(sum(nums))    # 14 (합계)
print(max(nums))    # 5  (최대)
print(min(nums))    # 1  (최소)
```

| 메서드 | 동작 |
|---|---|
| `append(x)` | 끝에 x 추가 |
| `insert(i, x)` | i 위치에 x 삽입 |
| `pop()` | 마지막 요소 제거 |
| `sort()` | 정렬 |
| `reverse()` | 순서 뒤집기 |
| `count(x)` | x의 개수 |
| `index(x)` | x의 위치 |

### 8.3 리스트 컴프리헨션

반복문을 한 줄로 압축하여 리스트를 만드는 문법.

```python
# 기존 방식
squares = []
for i in range(10):
    squares.append(i ** 2)

# 리스트 컴프리헨션
squares = [i ** 2 for i in range(10)]
print(squares)
```

```text
[0, 1, 4, 9, 16, 25, 36, 49, 64, 81]
```

```python
# 조건 추가: 짝수만
evens = [i for i in range(10) if i % 2 == 0]
print(evens)  # [0, 2, 4, 6, 8]
```

### 8.4 실습: 점수 처리

```python

avg = sum(scores) / len(scores)
print(f"평균: {avg:.1f}")
```

## 9. 딕셔너리 (Dictionary)

### 9.1 딕셔너리 생성과 접근

딕셔너리는 **키(Key)-값(Value) 쌍**으로 데이터를 저장한다.

```python
robot = {
    "name": "로봇A",
    "speed": 120,
    "battery": 87.5,
    "active": True
}

print(robot["name"])     # 로봇A
print(robot["speed"])    # 120
```

### 9.2 딕셔너리 수정과 추가

```python
robot["battery"] = 75    # 값 변경
robot["color"] = "red"   # 새 키-값 추가
del robot["active"]      # 키-값 삭제

print(robot)
```

```text
{'name': '로봇A', 'speed': 120, 'battery': 75, 'color': 'red'}
```

### 9.3 딕셔너리 메서드

```python
robot = {"name": "로봇A", "speed": 120, "battery": 87}

print(robot.keys())     # dict_keys(['name', 'speed', 'battery'])
print(robot.values())   # dict_values(['로봇A', 120, 87])
print(robot.items())    # dict_items([('name', '로봇A'), ...])
```

### 9.4 딕셔너리 순회

```python
robot = {"name": "로봇A", "speed": 120, "battery": 87}

for key in robot:
    print(f"{key}: {robot[key]}")
```

```text
name: 로봇A
speed: 120
battery: 87
```

```python
for key, value in robot.items():
    print(f"{key} = {value}")
```

### 9.5 실습: 여러 로봇 정보 관리

```python
robots = [
    {"name": "로봇A", "speed": 120, "battery": 87},
    {"name": "로봇B", "speed": 85,  "battery": 65},
    {"name": "로봇C", "speed": 150, "battery": 92},
]

# 배터리 80% 이상인 로봇만 출력
for r in robots:
    if r["battery"] >= 80:
        print(f"{r['name']}: 배터리 {r['battery']}%")
```

```text
로봇A: 배터리 87%
로봇C: 배터리 92%
```

## 10. 문자열 (String)

```python
s1 = "Hello"
s2 = 'World'
```

### 10.2 문자열 포매팅

```python
name = "로봇A"
speed = 120

# f-string (가장 권장)
```

### 10.3 문자열 메서드



### 10.4 실습: 문자열 분석


## 16. 종합 실습

### 16.1 로봇 관리 시스템

```python
class RobotManager:
    def __init__(self):
        self.robots = []

    def add(self, name, speed, battery):
        self.robots.append({
            "name": name, "speed": speed, "battery": battery
        })

    def show_all(self):
        for r in self.robots:
            print(f"  {r['name']:8s} 속도:{r['speed']:4d}  배터리:{r['battery']:3d}%")

    def fastest(self):
        if not self.robots:
            return None
        return max(self.robots, key=lambda r: r["speed"])

    def low_battery(self, threshold=30):
        return [r for r in self.robots if r["battery"] < threshold]


mgr = RobotManager()
mgr.add("Alpha", 120, 87)
mgr.add("Beta",  85,  25)
mgr.add("Gamma", 150, 92)
mgr.add("Delta", 95,  18)

print("=== 전체 로봇 ===")
mgr.show_all()

print("\n=== 최고 속도 ===")
fast = mgr.fastest()
print(f"  {fast['name']} ({fast['speed']})")

print("\n=== 배터리 부족 ===")
for r in mgr.low_battery():
    print(f"  {r['name']}: {r['battery']}%")
```

```text
=== 전체 로봇 ===
  Alpha     속도: 120  배터리: 87%
  Beta      속도:  85  배터리: 25%
  Gamma     속도: 150  배터리: 92%
  Delta     속도:  95  배터리: 18%

=== 최고 속도 ===
  Gamma (150)

=== 배터리 부족 ===
  Beta: 25%
  Delta: 18%
```
