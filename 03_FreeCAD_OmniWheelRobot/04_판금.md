# 04. 판금 (Sheet Metal)

이 장에서는 **판금(Sheet Metal)** 설계를 배웁니다.
옴니휠 로봇의 **전면/후면 패널, 센서 보호 패널** 등은
알루미늄/철판을 절곡한 **판금 부품**으로 제작되는 경우가 많습니다.
프로젝트의 `Front_SheetMetal.FCStd` 가 대표적인 예입니다.

---

## 4.1 판금 설계란?

- 두께가 얇은 금속판(알루미늄, 스테인리스, 아연도금강판 등)을
  **절곡(Bending)** 하여 3D 형상을 만드는 설계 방식.
- 제조는 **프레스 브레이크(절곡기)** 나 **CNC 판금** 공정.
- 설계 시 중요한 것은:
  1. **판 두께**
  2. **절곡 반경 (내측 R)**
  3. **절곡 허용치 (K-계수 / 벤딩여유)**
  4. **전개도(Flat Pattern)** — 절곡 전 평판 치수

```
[절곡 전 (평판)]          [절곡 후 (3D)]
┌─────────────────┐       ┌──────┐
│                 │  ──►  │      │
│                 │       │      └──────┐
└─────────────────┘       └─────────────┘
```

> 💡 판금 부품은 항상 **전개도(Flat)에서 절곡(Bent)** 으로 만들어지는 특성이 있습니다.
> FreeCAD의 Sheet Metal 워크벤치는 **Bent → Flat** 전개가 자동으로 가능합니다.

---

## 4.2 Sheet Metal 워크벤치 설치

1. **Tools → Addon Manager(부가 기능 관리자)** 실행
2. 검색: `Sheet Metal`
3. **Install** 클릭
4. 재시작 → 워크벤치 목록에 **Sheet Metal** 표시

> ⚠️ 설치가 안 되어 있으면 판금 기능이 없습니다. 01장에서 설치 확인.

### 주요 도구

| 도구 | 기능 |
| ---- | ---- |
| **Make Wall** | 두께가 있는 벽(베이스) 생성 |
| **Bend** | 벽을 절곡 (각도/R 지정) |
| **Sketch On Sheet** | 판금 위에 스케치 (홀/슬롯) |
| **Unfold(Flat Pattern)** | 전개도 생성 |
| **Corner relief** | 모서리 절곡 여유(노치) 자동 생성 |

---

## 4.3 실습: 전면 패널 만들기

**목표**: 200(W) × 120(H) mm, 두께 1.5mm 알루미늄 패널을
아래/위쪽 15mm씩 절곡한 C-채널 형태로 만든다.

```
정면도 (Bent)
┌────────────┬────────────┬────────────┐
│   상부 플랜지 15mm      │             │
├────────────┴────────────┤             │ 120mm
│        본체             │             │
├─────────────────────────┤             │
│   하부 플랜지 15mm      │             │
└────────────┬────────────┴────────────┘
```

### Step 1. 베이스 벽(Wall) 생성
1. 워크벤치: **Sheet Metal** 선택
2. 새 문서 + `Part Design` 바디 생성
3. `XY_Plane`에 스케치: **직사각형 200 × 120**
4. 스케치 닫기
5. **Make Wall** 클릭
   - Thickness(두께): `1.5 mm`
   - 선택: 직사각형 스케치
   - OK → 판 1개 생성 (200×120×1.5)

### Step 2. 절곡 (Bend)
1. 아래쪽 짧은 모서리 선택
2. **Bend** 클릭
   - **Angle(각도)**: `90°`
   - **Radius(내측 반경)**: `1.5 mm` (기본값, 판 두께와 동일하거나 2배)
   - **방향**: 위쪽으로 절곡
   - OK → 하부 플랜지 생성
3. 위쪽 모서리에도 동일하게 절곡

### Step 3. 홀/슬롯 추가 (센서, 버튼용)
1. 본체 면에 스케치 생성
2. 직사각형 슬롯 (예: 20×5mm), 원형 홀 (Ø6) 배치
3. 스케치 닫기 → **Pocket** (관통) 실행
   - 또는 **Sketch On Sheet** 사용

> 💡 절곡선 위에 구멍을 배치하면 **가공이 불가능**할 수 있습니다.
> 구멍 중심은 절곡선에서 **최소 3~5mm 이상** 떨어져야 안전합니다.

### Step 4. 전개도(Flat Pattern) 확인
- **Unfold / Make Flat Pattern** 도구 실행
- 전개도 크기 확인:
  - 전개 폭 = 벽 길이 합 − (절곡 여유 × 절곡 수)
  - 예: (200 + 15 + 15) − 2×(벤딩 허용치) ≈ 222~224mm

> 💡 전개도는 DXF로 내보내 **레이저 절단**에 바로 사용합니다.

## 4.4 절곡 허용치와 K-계수

판금 절곡 시 안쪽면은 압축, 바깥면은 인장됩니다.
**중립축(Neutral Axis)** 위치에 따라 전개 치수가 달라집니다.

| 항목 | 의미 |
| ---- | ---- |
| 내측 반경 (R) | 절곡 안쪽 곡률 반경 |
| K-계수 (t위치) | 중립축의 두께 비율 (보통 0.3~0.5) |
| 벤딩 여유 (Bend Allowance) | 절곡부를 편 상태의 길이 증가량 |

### 일반 규칙 (AL 재질)

- **K-factor ≈ 0.44 ~ 0.5**
- 내측 반경 = 판 두께 이상 권장
- 최소 절곡 반경(AL): 판 두께의 1배 (1.5t) 권장

### 예시 계산

- 판 두께 `t=1.5`, 절곡 반경 `R=1.5`
- 90° 절곡 1회 시 벤딩 여유 ≈ `0.5 × (R + K·t) × (90° → 라디안)`
- 대략 `2.5 ~ 3.0 mm` 정도 길이 감소.

> 💡 실제 업체마다 K-계수/벤딩 여유값이 다르므로
> **설계 후 업체에 전개도를 확인**받는 것이 안전합니다.

## 4.5 판금 설계 주의사항

| 항목 | 주의사항 |
| ---- | -------- |
| 최소 절곡 길이 | 절곡선에서 짧은 플랜지가 너무 짧으면 절곡 불가 (≈ 2~3t) |
| 홀 위치 | 절곡선으로부터 홀 가장자리 ≥ 3t 권장 |
| 모서리 겹침 | C/U 채널의 모서리는 노치(relief) 필요 |
| 재질 두께 | 두께에 따라 절곡 반경/공정이 바뀜 |
| 단위 | 전개도는 반드시 mm 단위로 확인 |
| DXF 출력 | 레이저 절단 시 곡선을 호/원으로, 폴리선 단순화 |

### 관통 패스너(하네스) 주의
- PCB나 센서 고정용 **탭(플랜지)을 뽑아** 볼트 체결할 때:
  - 탭 높이 ≥ 판 두께의 2~3배
  - 탭 구멍 (자리) 직경 규격 확인

---

## 4.6 전개도 DXF 내보내기

1. **Unfold**로 전개도 생성 (2D 스케치 형상)
2. 전개도 선택 → **File → Export → DXF**
3. 레이저 절단 업체에 전달
   - 절단 후 절곡 지시선(벤드라인)도 함께 표기
   - 재질, 두께, 절곡 R 명시

> 💡 전개도에는 **절곡선(Bend line)** 을 함께 표시해야
> 절곡기 작업자가 방향/각도를 알 수 있습니다.
> (FreeCAD Sheet Metal의 Unfold 결과에 절곡선이 포함됩니다.)

## 4.7 실습: 센서 브래킷 (판금 응용)

**목표**: LiDAR나 초음파 센서를 고정하는 L형 판금 브래킷.

```
정면         측면(절곡)
┌──────┐     ┌──────┐
│ 40mm │     │ 40mm │  ← 수직 벽
│      │     └──────┐
└──────┘            │  ← 절곡부
        바닥 40mm   │
```

### 순서
1. 벽 생성: 40(W) × 40(H) × 1.0t
2. 아래 모서리 절곡 90° (플랜지 20mm)
3. 수직 벽에 Ø3.2 홀 2개 (센서 고정)
4. 바닥에 Ø3.2 홀 2개 (로봇 플레이트 고정)
5. Unfold → DXF → 가공

---

## 4.8 판금 부품 STEP 내보내기

- 절곡 완성 상태를 **STEP**으로 내보내 **어셈블리에 조립**할 수 있습니다.
- 전개도(Flat)는 별도로 DXF로 관리합니다.

```
판금 부품 (Bent, 3D)
   ├─ STEP  → 어셈블리/간섭 검사
   └─ DXF   → 레이저 절단
```

## 4.10 요약

- 판금 = 평판 + 절곡으로 만드는 얇은 금속 부품.
- **Sheet Metal 워크벤치**에서 Wall → Bend → Hole → Unfold 순서.
- 전개도(Flat Pattern)는 **레이저 절단용 DXF**로 내보냄.
- 절곡 허용치(K-계수)를 고려해 치수를 계산.
- 홀은 절곡선에서 떨어뜨려 가공성을 확보.
- 3D는 STEP, 전개는 DXF로 이원화해 관리.
