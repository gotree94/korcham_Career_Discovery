# 01. FreeCAD 설치 및 환경 설정

이 장에서는 FreeCAD를 설치하고, 한글화와 사용자 환경을 설정하며,
앞으로 학습할 작업대(Workbench)에 대해 이해합니다.

---

## 1.1 FreeCAD란?

FreeCAD는 오픈소스 **파라메트릭 3D CAD 모델러**입니다.

- **파라메트릭(Parametric)**: 치수·피처 값을 나중에 수정해도 모델이 자동으로 갱신됩니다.
  (예: 판 두께 5mm → 8mm로 바꾸면 모델 전체가 갱신됨)
- **무료(Free)**: 상용 CAD 대비 비용 부담 없음.
- **스크립팅**: Python으로 작업 자동화 가능.

| 항목 | FreeCAD | 비교 (상용 CAD) |
| ---- | ------- | --------------- |
| 가격 | 무료 (LGPL) | SolidWorks 등 유료 |
| 파라메트릭 | ✔ | ✔ |
| STEP/IGES 불러오기 | ✔ | ✔ |
| 판금/어셈블리 | 워크벤치 플러그인 | 기본 탑재 |
| 단점 | 구동 방식이 조금 생소함 | 익숙함 |

> 🚨 주의: FreeCAD는 "전통적인 CAD 습관"이 아니라 "기능 → 피처 → 모델" 개념을
> 먼저 익히는 것이 중요합니다. 이 과정에서 크게 도움이 되는 것이 **Part Design** 워크벤치입니다.

## 1.2 설치 방법 (Windows)

### A. 인스톨러 버전 (권장: 신규 사용자)

1. 공식 사이트 접속: <https://www.freecad.org/downloads.php>
2. Windows 64비트 설치 파일 다운로드 (예: `FreeCAD_1.1.1-Windows-x86_64.exe`)
3. 설치 실행 → Next → 설치 위치 선택 → 설치 완료
4. 바탕화면 `FreeCAD 1.1` 아이콘으로 실행

### B. 포터블 버전 (현재 프로젝트에서 사용 중)

- 다운로드: `FreeCAD_1.1.1-Windows-x86_64-py311.7z` (압축 파일)
- 압축 해제: 예) `C:\Users\Administrator\Downloads\FreeCAD_1.1.1-Windows-x86_64-py311`
- 실행 파일: `bin\FreeCAD.exe`
- 레지스트리 변경 없이 폴더만 삭제하면 제거됩니다.

```
C:\Users\Administrator\Downloads\FreeCAD_1.1.1-Windows-x86_64-py311\
├─ bin\FreeCAD.exe        ← 실행 파일
├─ data\                  ← 환경 데이터
├─ lib\                   ← 파이썬/라이브러리
├─ Mod\                   ← 워크벤치 모듈
└─ share\                 ← 추가 리소스
```

> 💡 포터블이더라도 **사용자 설정**은 `%APPDATA%\FreeCAD` 폴더에 저장됩니다.
> (예: `C:\Users\Administrator\AppData\Local\FreeCAD`)

## 1.3 첫 실행 및 초기 화면 이해

`bin\FreeCAD.exe`를 실행하면 3가지 주요 영역이 보입니다.

```
┌─────────────────────────┬────────────────────────────────────────┐
│   3D 뷰 (중앙)           │   모델 트리 (왼쪽)                      │
│   - 물체를 회전/이동      │   - 문서의 구조 (파트/피처/스케치)       │
│   - 가시성 제어           │   - 현재 선택된 항목                    │
├─────────────────────────┼────────────────────────────────────────┤
│   콤보 뷰 (Combo View)   │   탭: 모델(Model) / 작업(Tasks) / 파이썬 │
└─────────────────────────┴────────────────────────────────────────┘
```

### 마우스 조작 (기본)

| 동작 | 조작 | 효과 |
| ---- | ---- | ---- |
| 회전 | 휠(가운데) 드래그 | 3D 회전 |
| 이동 | Shift + 휠 드래그 | 화면 평행 이동 |
| 확대/축소 | 휠 스크롤 | 줌 인/아웃 |
| 선택 | 왼쪽 클릭 | 객체 선택 |
| 상자 선택 | 왼쪽 드래그 | 여러 객체 선택 |
| 회전 축 설정 | Ctrl+Shift+클릭 | 회전 중심 지정 |

> 💡 터치패드 사용 시: 두 손가락 이동 = 회전, 두 손가락 스크롤 = 줌.

## 1.4 한글화 (한국어 UI 설정)

1. 메뉴: **Edit(편집) → Preferences(환경설정)**
2. **General(일반) → General → Language(언어)** 탭
   - Language: **한국어(Korean)** 선택
3. 아래 `Restart` 클릭 → FreeCAD 재시작

> ⚠️ 번역이 완벽하지 않은 부분이 많습니다. 본 교재에서는 **영문 메뉴명**을 함께 표기합니다.
> (예: Part Design → 파트디자인)

## 1.5 필수 환경 설정

### 1.5.1 내비게이션 스타일

- **Edit → Preferences → Display → Navigation**
- Navigation style: **CAD** (솔리드웍스/캣리아 계열과 유사, 휠 드래그로 회전)

### 1.5.2 단위 설정

- **Edit → Preferences → General → Units**
- Unit system: **MMGS (mm, g, sec)** 또는 **Standard (mm, kg, sec)**
  → 기계 설계이므로 **밀리미터(mm)** 기준으로 설정합니다.

### 1.5.3 저장 백업

- **Edit → Preferences → General → Document**
- 자동 백업: 기본값 유지
- 최근 파일 목록 개수 설정 (기본 10개)

### 1.5.4 뷰 배경색 (선택)

- **Edit → Preferences → Display → Colors**
- 배경색을 밝게/어둡게 조절 가능. (스크린 캡처용은 밝은 배경이 유리)

### 1.5.5 추가 기능 (Addon Manager)

- 메뉴: **Tools(도구) → Addon Manager(부가 기능 관리자)**
- 아래 플러그인은 필요에 따라 설치합니다.

| 부가 기능 | 용도 | 권장 |
| --------- | ---- | ---- |
| **Sheet Metal** | 판금 설계 (벤딩/플랫패턴) | ✔ 필수 (04장) |
| **A2plus** | 경량 어셈블리 | 선택 (03장) |
| **Assembly4** | 어셈블리 (설계 참조) | 선택 (03장) |
| **Fasteners** | 볼트/너트 표준 부품 | ✔ 추천 |
| **KicadStepUp** | KiCad PCB ↔ FreeCAD 연동 | PCB 연동 시 |

> 💡 FreeCAD 1.1에서는 **기본 Assembly 워크벤치**가 포함되어 있어
> 별도 플러그인 없이도 어셈블리를 학습할 수 있습니다.

## 1.6 작업대(Workbench) 이해

FreeCAD는 목적에 따라 도구 모음이 바뀌는 **워크벤치** 구조입니다.
왼쪽 상단의 드롭다운 메뉴로 전환합니다.

```
[워크벤치 선택 ▾]
┌────────────────────┐
│ Part Design        │ ← 3D 솔리드 설계
│ Sketcher           │ ← 2D 스케치 (구속조건)
│ Part               │ ← 기본 3D 프리미티브
│ Assembly           │ ← 부품 조립 (1.1 기본)
│ Sheet Metal        │ ← 판금 (설치 후 표시)
│ TechDraw           │ ← 2D 도면 추출
│ Draft              │ ← 2D/건축
│ ...                │
└────────────────────┘
```

| 워크벤치 | 주요 용도 | 학습 시점 |
| -------- | --------- | --------- |
| Start | 시작 화면 (새 문서, 최근 파일) | 이 장 |
| Sketcher | 2D 스케치와 구속조건 | 02장 |
| Part Design | 스케치 기반 3D 피처 설계 | 02장 |
| Part | 기본 입체(박스, 원통 등) 모델링 | 02장 |
| Assembly | 부품 조립과 구속조건 | 03장 |
| Sheet Metal | 판금 벤딩과 전개 | 04장 |
| TechDraw | 3D → 2D 도면 | 02/04장 |

## 1.7 문서 형식 이해

| 확장자 | 설명 |
| ------ | ---- |
| `.FCStd` | FreeCAD 네이티브 (압축 zip 형태) |
| `.STEP` / `.stp` | 표준 교환 포맷 (파라메트릭 없음, 기하만) |
| `.IGES` / `.igs` | 표준 교환 포맷 (곡면 중심) |
| `.STL` | 3D 프린팅/메시 포맷 |
| `.DXF` | 2D CAD 교환 포맷 |
| `.SVG` | 2D 벡터 (가공/레이저 절단에 활용) |

> 프로젝트 폴더에 `.FCStd`, `.igs`, `.dxf` 파일이 섞여 있는 것이 보입니다.
> STEP은 3D, DXF는 2D 레이저 절단에 주로 사용됩니다.

## 1.8 실습: 시작 문서 만들기

1. FreeCAD 실행
2. **File → New** 로 새 문서 생성 (또는 시작 화면에서 "새 문서")
3. 왼쪽 상단 워크벤치에서 **Part Design** 선택
4. 콤보 뷰의 **Model(모델)** 탭에서 문서 구조 확인
5. **File → Save** 를 눌러 `C:\Users\Administrator\Desktop\ME\practice.FCStd` 저장

> 💡 이 실습 파일은 02장에서 계속 사용합니다.

## 1.9 트러블슈팅 (자주 묻는 문제)

| 문제 | 원인/해결 |
| ---- | --------- |
| 화면이 갑자기 검게 변함 | Display → Navigation 설정 점검 |
| 마우스로 회전이 안 됨 | 내비게이션 스타일을 CAD로 변경 |
| 한글이 안 보임 | 언어 변경 후 FreeCAD 재시작 필요 |
| 포터블 실행 시 DLL 오류 | 압축 해제가 비정상인 경우 재해제 |
| 저장 경로에 한글이 있으면 오류 | 한글 경로보다 영문 경로 권장 |

> 💡 포터블의 경우 **한글 경로**에서 실행 시 일부 기능이 오류날 수 있습니다.
> `C:\Users\Administrator\Desktop\ME` 는 한글 없이 영문 경로라 문제없습니다.

## 1.10 요약

- FreeCAD는 파라메트릭 무료 CAD이며, 현재 프로젝트는 **1.1.1 포터블** 사용 중.
- 실행 파일: `...\FreeCAD_1.1.1-Windows-x86_64-py311\bin\FreeCAD.exe`
- 한글화: **Edit → Preferences → General → Language → 한국어**
- 단위: **mm (MMGS)**
- 필요한 부가 기능: **Sheet Metal**, (선택) Fasteners, A2plus/Assembly4
- 워크벤치 = 목적별 도구 모음 (Sketcher / Part Design / Assembly / Sheet Metal / TechDraw)
