# 02. 기초 설계 (Sketcher & Part Design)

이 장에서는 FreeCAD에서 가장 중요한 두 워크벤치,
**Sketcher(2D 스케치)** 와 **Part Design(3D 솔리드 설계)** 를 익힙니다.
옴니휠 로봇의 플레이트, 브래킷, 센서 거치대 등을 만들 때 쓰는 기본기입니다.

---

## 2.1 설계 기본 개념

### 파라메트릭 설계 순서

```
스케치(Sketch) → 3D 피처(Feature) → 파트(Part) → 어셈블리(Assembly)
  (2D 도형)       (돌출/컷 등)       (완성 부품)    (부품 조립)
```

- **스케치**는 2D이며, **구속조건(Constraint)** 으로 형태를 고정합니다.
- 치수를 나중에 바꾸면 형상이 **자동으로 갱신**됩니다.

### 중심 개념: 구속조건(Constraint)

구속조건은 도형이 "어떻게 고정될지" 결정합니다.

| 종류 | 예시 | 의미 |
| ---- | ---- | ---- |
| 수평/수직 | 선이 수평/수직 | 방향 고정 |
| 수직(Perpendicular) | 선끼리 직교 | 각도 90° |
| 평행 | 선끼리 나란히 | 기울기 같음 |
| 동심 | 원끼리 중심 일치 | 중심 정렬 |
| 접선 | 원과 선이 접함 | 접촉 |
| 일치(Coincident) | 점/끝점 일치 | 위치 결합 |
| 치수(Dimension) | 길이·각도·반지름 | 크기 지정 |
| 대칭(Symmetric) | 선 중심 대칭 | 대칭 구속 |

> 💡 **자유도(DOF, Degree of Freedom)** 개념:
> 스케치의 모든 요소가 구속되면 **완전 구속(fully constrained)** 상태가 됩니다.
> 색상으로 구분됩니다 — 검은색(구속됨), **녹색/파란색(미구속)**, 빨간색(과구속).

## 2.2 실습 1: 기본 스케치 — 정사각형 플레이트

**목표**: 100mm × 100mm, 2mm 두께의 플레이트를 만든다.
(옴니휠 로봇 하부 플레이트의 축소판)

### Step 1. 파트디자인 워크벤치 선택
- 워크벤치 드롭다운에서 **Part Design** 선택

### Step 2. 바디(Body) 생성
- 도구 모음: **Create body(바디 만들기)** 클릭 → `Body` 생성

### Step 3. 스케치 생성
- **Create sketch(스케치 만들기)** 클릭
- 평면 선택: `XY_Plane` 선택 → OK

### Step 4. 사각형 그리기
- 도구 모음: **Rectangle(직사각형)** 클릭
- 원점 주변에 직사각형을 대략 드래그로 그림

### Step 5. 구속조건 적용
- **수평/수직 치수**: 선 두 개를 선택 → **Set horizontal distance / vertical distance**
- 100 입력 → Enter
- 실제 작업 예:
  - `100` (가로), `100` (세로)

### Step 6. 스케치 닫기
- 도구 모음의 **Close(닫기)** 클릭
- 스케치가 `Sketch`로 트리에 표시됨

### Step 7. 돌출(Pad)
- 스케치 선택 → **Pad(패드/돌출)** 클릭
- **Length(길이)**: `2 mm` 입력 → OK

### 완성 트리 구조
```
Body
 └─ Pad          ← 돌출 피처 (100×100×2mm)
    └─ Sketch    ← 스케치 (평면도)
```

## 2.3 실습 2: 원형 파트 — 모터 장착 원반

**목표**: 지름 60mm, 두께 5mm 원반에 중심 구멍(Ø6mm)을 뚫는다.
(RB35GM 모터 마운트의 단순화)

### Step 1. 새 바디 생성
- `Create body` → 바디 클릭 → **Create sketch** → `XY_Plane`

### Step 2. 원 그리기
- **Circle(원)** 클릭 → 원점 중심으로 대략 그림
- 원 선택 → **Set radius(반지름 치수)** → `30` 입력

### Step 3. 패드(Pad)
- Close → **Pad** → Length `5 mm` → OK

### Step 4. 구멍(Pocket)
- 윗면(원형 면) 선택 → **Create sketch** → 원점 중심으로 원 하나 더 그림
- 반지름 `3 mm` 설정 → Close
- 그 스케치 선택 → **Pocket(포켓/홀)** 클릭
  - **Type**: Through All(관통) → OK

### 완성 트리
```
Body
 ├─ Pad          ← Ø60 × 5mm
 │  └─ Sketch    ← 지름 60
 └─ Pocket       ← Ø6 관통
    └─ Sketch001 ← 지름 6
```

> 💡 **Pad vs Pocket**
> - **Pad** = 스케치를 밀어 올려 솔리드 추가
> - **Pocket** = 스케치를 밀어 내려 솔리드 제거(구멍)
> - 볼트 구멍, 배선 통로, 절곡 슬롯 등 모두 Pocket으로 만듭니다.

## 2.4 실습 3: 복합 파트 — 모터 브래킷

**목표**: L자 형태의 모터 브래킷 (옴니휠 모터를 플레이트에 고정하는 부품)

### Step 1. 스케치 (L자 단면)
- `XY_Plane`에 스케치: 직사각형 2개를 겹쳐서 그리거나
  **Polyline(폴리라인)** 으로 L자 외곽선을 그림

```
            ┌───────────────┐
            │   수직 벽     │  ← 30mm 높이
            │               │
┌───────────┴──────┐        │
│  바닥판(40mm)     │        │
└───────────────────────┘   │
                            └──── 50mm
```

- L자 형상: 외곽 6개 점을 순서대로 클릭
- 치수: 가로 40, 세로 30, 두께 5 등 입력

### Step 2. Pad
- **Pad** → Length `40 mm` (브래킷 깊이) → OK

### Step 3. 볼트 구멍 추가
- 바닥판 윗면에 스케치 → 지름 4mm 원 2개 배치
- **Symmetric(대칭)** 구속 또는 치수로 위치 고정
- **Pocket** → Through All → OK

### Step 4. 라운드(Round) 추가 (선택)
- 모서리 선택 → **Chamfer(챔퍼)/Fillet(필렛)** 도구로 안전 반경 부여

## 2.5 구속조건 완전 정리

### 구속이 부족하면?

- 스케치의 선이 **파란색/녹색**으로 남습니다 → 아직 움직일 수 있음.
- **완전 구속(검은색)** 상태를 목표로 합니다.

### 좋은 스케치 관례

1. **원점 기준 정렬**: 도면의 기준이 되는 점/선은 원점에 맞춥니다.
2. **중복 구속 피하기**: 이미 고정된 길이를 또 지정하면 과구속(red) 오류.
3. **치수는 가능한 한 중심 기준**: 부품을 중심으로 대칭 구속을 활용.
4. **좌표계 의식**: XY(바닥면), XZ(정면), YZ(측면) 각각 용도가 다름.

### 유용한 단축키

| 단축키 | 기능 |
| ------ | ---- |
| `C` | 원 만들기 |
| `R` | 직사각형 |
| `L` | 선(Line) |
| `D` | 치수 지정 (Dimension) |
| `Escape` | 현재 도구 종료 |
| `V` | 스케치를 수직 화면으로 |
| `F2` | 선택 요소 이름 변경 |

> 💡 단축키는 워크벤치에 따라 다릅니다. (Part Design / Sketcher에서 주로 사용)

## 2.6 피처(Feature) 종류 요약

| 피처 | 용도 | 예시 |
| ---- | ---- | ---- |
| **Pad** | 돌출 (솔리드 추가) | 플레이트, 브래킷 본체 |
| **Pocket** | 파기 (솔리드 제거) | 구멍, 홈, 슬롯 |
| **Revolution** | 회전 돌출 | 원형 축, 손잡이 |
| **Hole** | 나사 구멍 (규격 기반) | M3/M4 탭 구멍 |
| **Fillet** | 모서리 라운딩 | 응력 저감, 안전 |
| **Chamfer** | 모서리 모따기 | 조립 안내, 스크래치 방지 |
| **Mirrored** | 대칭 복사 | 좌우 동일 부품 |
| **LinearPattern** | 선형 배열 | 반복 구멍 |
| **PolarPattern** | 원형 배열 | 볼트 홀 배열 |

### Hole 사용 예 (나사 구멍)

```
1. 면 선택 → 스케치 → 점(Point) 배치  (구멍 중심)
2. Close → Hole 도구 클릭
3. 나사 규격 선택: M3 → 깊이/타입 설정
4. OK → 규격에 맞는 구멍 자동 생성
```

## 2.7 치수 기반 설계 실습 — 베이스 플레이트

**목표**: 120×120mm, 3mm 두께 베이스 플레이트에
**모터 장착 구멍(4×Ø4)** 과 **중앙 배선 홀(Ø20)** 을 뚫는다.

```
        ┌─────────────────────────────┐
        │   ○       ● ●       ○       │   ← 모서리 4곳 Ø4 (모터/스탠드오프)
        │                             │
        │        ●        ●          │   ← 중앙 4곳 Ø3 (센서)
        │           ┌─────┐           │
        │           │ Ø20 │           │   ← 배선 홀
        │           └─────┘           │
        │      ○       ○             │   ← 중심 2곳 Ø6 (스프로킷)
        │                             │
        │   ○       ● ●       ○       │
        └─────────────────────────────┘
```

### Step 1. 스케치
- 120×120 사각형 + 원점을 중심으로 중앙 정렬

### Step 2. 홀 배치
- 중심이 원점인 Ø20 원
- 구석 Ø4 홀 4개: X/Y 각각 ±50mm 배치

### Step 3. 완료
- Pad 3mm → 구멍들 Pocket (Through All)

### 설계 치수 표 만들기 (실제 작업 시 참고)

| 구멍 | 위치 | 크기 | 용도 |
| ---- | ---- | ---- | ---- |
| Ø4 × 4 | 모서리 (±50, ±50) | 4mm | 스탠드오프 |
| Ø20 | 중앙 (0,0) | 20mm | 배선 통로 |
| Ø3 × 4 | 중앙 사각형 배치 | 3mm | 센서 마운트 |
| Ø6 × 2 | 중심 근처 | 6mm | 바퀴 축용 |

## 2.8 도면 만들기 (TechDraw)

3D 모델을 2D 도면(제작 도면)으로 추출합니다.

### Step 1. TechDraw 워크벤치
- 워크벤치 드롭다운에서 **TechDraw** 선택

### Step 2. 페이지 생성
- **Insert Default Page(기본 페이지 삽입)** → A4 페이지 생성

### Step 3. 뷰 추가
- 3D 뷰에서 바디 선택 → **Insert View(뷰 삽입)** 클릭
- 방향: **Front / Top / Right** 원하는 대로 추가
- 스케일: 1:1 또는 1:2 선택

### Step 4. 치수 주석
- **Insert Dimension(치수 삽입)** → 모델 모서리 선택 → 치수 배치

### Step 5. 내보내기
- **File → Export → DXF** 선택
- → 레이저 절단 업체/판금 가공에 DXF 공유

> 💡 판금 전개도는 04장에서 다시 다룹니다.
> TechDraw는 단순 "제작 도면" 용도로만 사용합니다.

## 2.9 STEP 파일 가져오기/내보내기

- **Import**: **File → Import** → `.STEP` / `.IGES` / `.STL`
  - STEP은 다른 CAD(솔리드웍스 등)와 호환.
- **Export**: **File → Export** → STEP 선택
  - 시중 판금/CNC 업체에 제출할 때 표준 포맷.

### 프로젝트 파일 활용 예
- `58mm_Plastic_Omni_Wheel.FCStd` — 옴니휠
- `RB35GM-Motor.FCStd` — 모터
- `7inch HDMI LCD (H).FCStd` — 디스플레이

이 파일들을 열어 보고, 트리 구조를 탐색하며 어떤 피처로 만들어졌는지 확인해보세요.
**이것이 가장 빠른 FreeCAD 학습법입니다.**

## 2.11 요약

- **스케치(2D) + 구속조건 → 피처(Pad/Pocket 등) → 파트(3D)** 순서.
- 구속조건으로 완전 구속 상태를 만드는 것이 핵심.
- 홀/슬롯/배선 통로는 `Pocket`으로, 추가 형상은 `Pad`로.
- **Hole** 도구로 나사 구멍 규격을 자동 생성.
- **TechDraw**로 2D 도면, **DXF/STEP**으로 제작용 데이터 공유.
- 남의 모델(프로젝트의 기존 FCStd)을 열어 트리를 분석하는 습관이 중요.
