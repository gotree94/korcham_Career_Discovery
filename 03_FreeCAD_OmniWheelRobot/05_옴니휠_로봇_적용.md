## 5.1 옴니휠 로봇의 구조

전형적인 옴니휠 로봇의 구조:

```
[옴니휠 로봇 단면/상면 구조]

┌────────────────────────────────────────────┐
│   7인치 HDMI LCD (상단 표시부)             │
├────────────────────────────────────────────┤
│   TOP PCB        (Jetson Xavier NX + 센서) │
│   Lidar / 센서 (전방)                     │
├────────────────────────────────────────────┤
│   Middle Acrylic  (중간 구조판)            │
│   배터리 / 전원 / 메인 PCB                │
├────────────────────────────────────────────┤
│   Bottom Plate   (하부 베이스 플레이트)     │
│   모터 × 3~4 + 옴니휠 × 3~4              │
└────────────────────────────────────────────┘
```

> 💡 옴니휠 로봇은 **3개 휠(120° 배치)** 또는 **4개 휠(90° 배치)** 구조가
> 일반적입니다. 전방향(Omni-directional) 이동을 위해 바퀴가
> 차체 중심에서 벡터합을 계산해 움직입니다.

## 5.3 실무 실습 1: 바퀴 간섭(오프셋) 검토

옴니휠은 차체 바깥으로 돌출되어야 주행이 가능합니다.

```
정면도
        ┌─────── 차체 ───────┐
        │                    │
   ═══╪═                    ═╪═══   ← 옴니휠
   옴니휠                   옴니휠    (바퀴 외경이 차체보다 돌출)
```

### 확인 사항
1. 휠 반경(R) 과 차체 하부 이격 거리 확인
2. 휠 접지선(바닥)과 하부 플레이트의 최소 간격
3. 모터 축 + 휠 장착 시 간섭 여부
   - 모터 커플러/볼트가 플레이트 홀과 충돌하지 않도록

### 간섭 검사
- **Assembly 워크벤치 → 간섭 검사(Interference)** 실행
- 휠 회전 시 가상 궤적을 확인: 회전 반경 = 휠 반경
- 차체 모서리와 간격 < 3mm이면 구조 보강 필요

## 5.4 실무 실습 2: 모터와 휠 결합 (동력 전달)

### 결합 방식
| 방식 | 설명 | 사용 부품 |
| ---- | ---- | --------- |
| 직접 축 결합 | 모터 축 = 휠 축 | 커플러, 키 |
| 기어/체인 | 감속 후 구동 | 스프로킷, 기어 |
| 밸트 | 부드러운 전달 | 타이밍 밸트 |

### 설계 체크리스트
- [ ] 모터 축 직경 ↔ 휠 허브 보어 직경 일치
- [ ] 커플러 체결부 길이
- [ ] 모터 정격 토크와 휠 하중 (재질/두께 결정)
- [ ] 58mm 옴니휠 ↔ RB35GM 모터 조립 확인

### Step
1. `58mm_Plastic_Omni_Wheel` + `RB35GM-Motor` 를 새 문서에 조립
2. 축 동심 결합 (Coincident)
3. 간섭 없이 회전하는지 `Revolute`로 확인
4. 실제 차체(Bottom_Plate)에 장착

## 5.5 실무 실습 3: PCB/센서 장착 슬롯 설계

**목표**: `TOP_PCB` (상부 PCB)와 센서가 들어갈 슬롯/스탠드오프 배치.

### 스탠드오프(Standoff) 사용
- 스탠드오프: PCB를 플레이트에서 **이격**시켜 고정하는 원통형 부품.
- 나사: M2.5/M3 규격.
- 일반 높이: 5, 8, 10, 15, 20mm.

```
단면도
┌────── TOP_PCB ──────┐
│  ◉   ◉   ◉   ◉     │  ← PCB 구멍 Ø3.2 (M3용)
├──── 스탠드오프 8mm ─┤
│  ◉   ◉   ◉   ◉     │  ← 플레이트 나사자리
└──── 플레이트 ───────┘
```

### 설계 순서
1. `TOP_PCB.FCStd`의 PCB 외형 치수 읽기
2. PCB 모서리 4곳에 장착 구멍(Ø3.2) 위치 확인
3. 베이스 플레이트에 **같은 좌표**로 나사자리(Ø2.7 관통 or 탭) 배치
4. PCB 높이(이격) = 스탠드오프 길이 → 플레이트에 간섭 없는지 확인
5. 센서(LiDAR, 초음파)가 케이블/PCB와 간섭하는지 점검

> 💡 PCB 3D 데이터를 FreeCAD에 가져오는 방법은 06장에서 다룹니다.

## 5.6 실무 실습 4: 케이블 & 열 관리

### 케이블 경로
- 전원/통신 케이블 통로(슬롯)를 플레이트에 마련
- 모터 케이블 → 베이스 → 중간판 → 제어 PCB 경로 설계
- 최소 굽힘 반경 확인 (일반 5~10mm)

### 발열 부품
- Jetson Xavier NX, 모터 드라이버는 열 발생
- 히트싱크/팬 장착 여유 공간 설계
- 공기 유입구/배출구 (판금 패널에 슬롯)

### 설계 반영 예
```
중간판 케이블 슬롯
┌────────────────────┐
│   ┌───┐    ┌───┐   │
│   │ │ │    │ │ │   │  ← 슬롯 (Pocket)
│   └───┘    └───┘   │
└────────────────────┘
```

## 5.7 실무 실습 5: 전체 어셈블리 구성

### 최종 조립 순서
1. `Bottom_Plate1` 기준(고정)으로 설정
2. 모터 3~4개 장착 (120°/90° 배치)
3. 옴니휠 3~4개 결합
4. `Middle_Acrylic` 상부에 배치
5. `Front_SheetMetal` 전면 부착
6. `TOP_PCB` + 센서 + LiDAR + LCD 순서로 적층

### 검증 (검사 리스트)
- [ ] 간섭 검사 통과
- [ ] 휠 회전 자유
- [ ] 모터/케이블 여유
- [ ] PCB 이격 확보
- [ ] 무게중심 (배터리 위치) 합리적
- [ ] STEP 전체 내보내기 성공

## 5.10 요약

- 옴니휠 로봇 = 하부(모터+휠) + 중간(배터리/PCB) + 상부(센서/LCD) 구조.
- 기존 FCStd 파일 분석이 실무 진입의 지름길.
- 휠 돌출량, 간섭, 케이블 여유, 열 관리가 핵심 검토 포인트.
- PCB 장착은 스탠드오프 좌표를 플레이트와 일치시키는 것이 중요.
- 최종 검증 후 STEP/BOM/도면으로 문서화.
