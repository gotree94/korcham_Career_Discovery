# 03. 어셈블리 (Assembly)

이 장에서는 FreeCAD의 **Assembly 워크벤치**를 사용하여
개별 부품(파트)들을 조립하는 방법을 배웁니다.
옴니휠 로봇은 베이스 플레이트 + 모터 + 휠 + 센서 + PCB 등 여러 파트가
한 공간에서 서로 간섭 없이 동작하도록 조립됩니다.

---

## 3.1 어셈블리란?

- 여러 부품을 **하나의 조립체**로 모은 것.
- 각 부품 사이에 **구속조건(Joint/Constraint)** 을 부여해 위치를 고정.
- 부품 하나를 수정하면 어셈블리에서 **자동 갱신**됩니다.

```
[어셈블리 구조]
Assembly
 ├─ Part1 (베이스 플레이트)   ← Fixed(고정)
 ├─ Part2 (모터)              ← Part1과 동심/면 접합
 ├─ Part3 (옴니휠)            ← 모터 축과 동심
 ├─ Part4 (센서)              ← 베이스에 정렬
 └─ Part5 (PCB)               ← 스탠드오프로 이격
```

### 어셈블리 vs 파트

| 구분 | 파트(Part) | 어셈블리(Assembly) |
| ---- | ----------- | ------------------ |
| 대상 | 단일 부품 | 여러 부품 조립체 |
| 파일 | `.FCStd` (1개 문서) | `.FCStd` (참조 포함) |
| 예시 | `RB35GM-Motor.FCStd` | `OMNI_WHEEL_ROBOT.FCStd` |
| 수정 | 파트 자체 수정 | 부품 배치/결합 수정 |

---

## 3.2 FreeCAD 1.1의 Assembly 워크벤치

FreeCAD 1.0 이상부터 **내장 Assembly 워크벤치**가 제공됩니다.

> ℹ️ FreeCAD 1.1의 기본 Assembly 워크벤치는
> **게시된 요소(공개 참조 평면/축/점)** 를 사용해 조립합니다.
> 개별 파트에 **공개 표시(그린/파란 표시)** 를 해두어야 참조할 수 있습니다.

### 1.1 Assembly 핵심 개념

| 개념 | 설명 |
| ---- | ---- |
| `Assembly` | 조립 루트 문서 |
| `App::Link` | 원본 파트를 **링크(참조)** 로 연결 (원본 복사 아님) |
| Joint | 부품 간 결합 (Fixed / Revolute / Prismatic / Cylindrical 등) |
| Contact | 접촉 결합 (면과 면) |
| Visibility | 부품 숨김/표시 토글 |

> 📌 원본 파트를 링크로 가져오므로 **원본 파일을 수정하면 어셈블리에 즉시 반영**됩니다.
> 이것이 외부 참조(External reference) 방식입니다.

## 3.3 실습: 옴니휠 로봇 하부 조립

**목표**: 베이스 플레이트 + 모터 + 옴니휠을 조립한다.

### Step 0. 준비물
- `Bottom_Plate1.FCStd`
- `RB35GM-Motor.FCStd`
- `58mm_Plastic_Omni_Wheel.FCStd`

> 💡 기존 프로젝트 파일이 없으면 02장에서 만든 플레이트 + 모터 원반을 사용해도 됩니다.

### Step 1. 새 어셈블리 생성
1. 워크벤치에서 **Assembly** 선택
2. **File → New** 로 새 문서 생성
3. 도구 모음: **Insert Assembly(어셈블리 삽입)** 클릭 → `Assembly` 생성

### Step 2. 부품 링크 추가
- **Insert Part(파트 삽입)** 클릭 → 파일 선택 → `Bottom_Plate1` 추가
- 같은 방법으로 `RB35GM-Motor`, `58mm_Plastic_Omni_Wheel` 추가

```
Assembly
 ├─ Bottom_Plate1  (링크)
 ├─ RB35GM-Motor    (링크)
 └─ 58mm_Plastic_Omni_Wheel (링크)
```

> 💡 트리의 파트를 더블클릭하면 원본 문서로 이동해 편집할 수 있습니다.

### Step 3. 부품 이동/회전
- 조립 전에 부품을 대략적으로 배치:
  - 파트 선택 → **Move(이동)** / **Rotate(회전)** 도구
  - 또는 3D 뷰에서 드래그

> ⚠️ 자유 이동 후에는 **Joint(결합)** 를 반드시 추가해야 위치가 고정됩니다.

### Step 4. 고정(Joint) 추가 — 모터를 플레이트에 결합

1. 도구 모음: **Insert Joint(결합 삽입)** 클릭
2. 결합 대상:
   - **모터 바닥면** 선택
   - **플레이트의 모터 장착면** 선택
3. 결합 종류: **Fixed(고정)** 또는 **Parallel(평행) + Coincident(일치)**
4. OK → 모터가 플레이트 위에 고정

### Step 5. 옴니휠을 모터 축에 결합

- 결합 종류: **Revolute(회전 결합)** 또는 **Coincident(축 정렬)**
- 대상: **옴니휠의 축 구멍**과 **모터의 축**
- 축을 선택하면 두 축이 일치하도록 정렬

### Step 6. 구동 확인
- **Move/Rotate**로 모터/휠이 조립된 상태에서만 이동하도록 설정:
  - **Revolute** 결합이면 휠은 축 중심으로만 회전 가능 (옴니휠이므로 회전 유효)

### 완성 어셈블리
```
Assembly
 ├─ Bottom_Plate1
 ├─ RB35GM-Motor
 │   └─ Joint (Plate와 Fixed)
 ├─ 58mm_Plastic_Omni_Wheel
 │   └─ Joint (Motor 축과 Revolute)
 └─ Assembly (하위 어셈블리 선택적)
```

## 3.4 결합(Joint) 종류

| 결합 | 기능 | 예시 |
| ---- | ---- | ---- |
| **Fixed** | 완전 고정 | 플레이트 ↔ 모터 |
| **Coincident** | 두 축/점 일치 | 축 정렬 |
| **Parallel** | 면/축 평행 | 면 정렬 |
| **Perpendicular** | 직교 | 벽면 수직 |
| **Revolute** | 축 회전만 허용 | 모터 축 ↔ 휠 |
| **Prismatic** | 한 축 직선 이동 | 리니어 가이드 |
| **Cylindrical** | 축 방향 이동+회전 | 축 슬라이드 |
| **Ball** | 모든 자유 회전 | 볼 조인트 |

> 💡 로봇 설계에서는 **Fixed(고정)** 와 **Revolute(회전)** 가 대부분입니다.

## 3.5 게시된 요소(Published Elements) 사용

링크된 파트에 "공개 참조 요소"를 미리 만들어 두면
어셈블리에서 선택하기 편리합니다.

### 파트 내부에서 공개하기
1. 파트 파일을 연다 (더블클릭)
2. 3D 뷰에서 **원하는 면/축/점** 선택
3. 파트 디자인 워크벤치 → **Part → Set colors / Properties** 에서
   - **공개(Published)**: 선택한 기하요소를 공개 참조로 등록

> ℹ️ 실제 메뉴명: 파트를 선택 → **Object → Properties → Published**
> 공개된 요소는 어셈블리 결합 대화상자에서 바로 선택됩니다.

## 3.6 부품 간 간섭(Interference) 확인

조립 후 가장 중요한 검증은 **간섭 검사**입니다.

1. 어셈블리 완성 후 **도구 → 간섭 검사(Interference check)** 실행
   - Assembly 워크벤치에서: **Inspect → Interference check**
2. 결과로 부품이 겹치는(충돌) 부분이 표시됩니다.
3. 간섭 발견 시:
   - 부품 위치를 미세 조정 (Joint 수정)
   - 또는 파트 설계 수정 (구멍 위치, 두께 변경)

> 💡 전장 부품(PCB, 센서)이 케이스/브래킷에 걸리지 않는지 반드시 확인.

---

## 3.7 자유도(Degree of Freedom) 개념

- 조립된 부품은 이동/회전 자유도가 제한됩니다.
- **잘못된 결합**: 과구속(충돌 오류) 발생 → 빨간색 오류 표시.
- **부족한 결합**: 부품이 미끄러지거나 떠다님.
- Assembly 워크벤치의 **Check constraints** 기능으로 확인.

---

## 3.8 파트 수정 반영 (외부 참조)

1. 어셈블리에서 파트를 더블클릭 → 원본 파트 문서 열림
2. 파트의 치수/피처 수정 (예: 플레이트 두께 3→4mm)
3. 저장 → 어셈블리로 돌아가면 **자동 갱신** 확인

> 💡 링크 구조이므로 파일을 열어놓은 채로 파트를 수정해도
> 저장 후 **File → Reload(새로고침)** 또는 다시 열면 갱신됩니다.

---

## 3.9 어셈블리 내보내기 및 활용

### STEP으로 내보내기
- **File → Export → STEP** 선택
- 업체/다른 CAD에 통합본 전달

### STL로 내보내기
- **File → Export → STL**
- 3D 프린팅, 시뮬레이션에 사용

### PDF 3D로 내보내기 (선택)
- 어셈블리를 3D PDF로 내보내 협업자와 공유.

## 3.11 요약

- 어셈블리는 부품을 **링크**로 참조해 조립합니다 (외부 참조).
- **Joint(결합)** 로 부품 위치를 고정하고 자유도를 제어.
- 주요 결합: `Fixed`, `Coincident`, `Parallel`, `Revolute`.
- **간섭 검사**로 부품 충돌을 반드시 확인.
- 원본 파트 수정 → 어셈블리 자동 갱신.
- 최종 어셈블리는 **STEP**으로 내보내 협업.
